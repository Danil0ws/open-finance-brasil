## 📝 Descrição

We identified that, when creating data and service consents, the expiration dates differ from each other. According to the specification (https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/1129021472/Transfer+ncias+Inteligentes+-+JO+Jornada+Otimizada+v1.0#Sele%C3%A7%C3%A3o-de-Recursos
), the same account and the same expiration date must be applied to both the data consent and the Intelligent Transfers consent.
