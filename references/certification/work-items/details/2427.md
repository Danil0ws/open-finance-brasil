Dear All,

Two weeks ago, we opened ticket #125798 to report an inconsistency in the "Implicit" field being filled out by the FVP. We identified that the format in which the grants are being sent presents an issue: currently, all grants are being sent as a single string, separated only by spaces.

We would like to emphasize that the correct format requires each grant to be sent as a distinct string, as demonstrated in the examples below: Example 1 (current behavior) and Example 2 (expected successful behavior).

We believe there might be some inconsistency in the directory associated with the SSA registration.

Thank you for your contact.

The FVP executes a DCR everytime a new test plan is created, given that it does not store credentials.

Given this, all the possible erros at DCR can happen. Although having one client stored, making necessary the deletion of the client, the error can happen for a lot of different reasons.

You can find more information in the common issues section at:

https://gitlab.com/raidiam-conformance/open-finance/certification/-/wikis/Automated-Production-Tests#:~:text=of%20this%20session-,Common%20Issues,-List%20of%20common

As described at https://mailchi.mp/d111c28ebee4/open-banking-informa-10140173?e=447d7abb9f, it is the Institution's responsibility to check daily and delete any remaining clients from previous FVP executions.

In that sense, to proceed with the test, you should ensure a successful DCR is executed. Please, feel free to reopen the ticket if have any additional evidence the error is coming from the FVP.

We are happy to help with any additional needs!
