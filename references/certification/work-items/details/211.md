Hi Jose,

When we first got a hold of the specs on PIX Scheduling we have been provided the following document - https://github.com/thbezerra/ob-docs/blob/main/pix-agendamento-proposta-final.md

This document states that the codes were to be in English, this being the reason that we have implemented them in English.

Given that the document on the portal is more formal than the draft proposal I assume it's a more up-to-date code. Nonetheless, to avoid updating it and then having to revert it, we will wait for the final version of the PIX Scheduling API to settle on which error codes should we use. 

With this in mind, I really wouldn't recommend you to update any of the error codes until we reach the final version of the PIX API 1.1.0, in which the CS will also have to adapt
