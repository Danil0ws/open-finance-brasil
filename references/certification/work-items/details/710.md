## 📝 Descrição

## 1. What Happened and what were you expecting?
`payments_api_json-accept-header-jwt-returned_test-module_v2` and `payments_api_jti-reuse_test-module_v2` tests are failing because of below reason:

_Validate Self link: Phase4bPaginationValidator: Unable to find element $.totalRecords on the Phase4bPaginationValidator API response_

However, according to the technical specification, the element `meta` should contain only the field `requestDateTime`.
