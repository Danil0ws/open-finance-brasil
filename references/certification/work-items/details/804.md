## 1\. What Happened and what were you expecting?

All the Phase4b tests should be inserting the Consent Url retrieved from the directory, as shown bellow:

![image.png](/uploads/b0d62d0abdcdf3f4df58b9767d11f13d/image.png)

But as seen at https://web.conformance.directory.openbankingbrasil.org.br/plan-detail.html?plan=SBLYzdIX6p8PU, the following test modules are not:

* core_test-module 
* transactiondate_test-module 
* wrong-permissions_test-module 
* pagination-transaction_test-module 
* pagination-transactions-current_test-module 
* pagination-list-cond_test-module

Therefore, we need to change the tests to guarantee that all test modules are being retrieved from the directory.
