## 📝 Descrição

We are currently conducting JSR retests with some institutions and have noticed issues affecting test executions since approximately **June 10th**. The following problems have been identified:

1. **New fields in test plan configuration:**\
   In the JSR v2.1 test plan configuration, we noticed **six new fields** that were not present before. These changes were not previously communicated and are directly impacting test execution. Please refer to the attached screenshot for details.
2. **Incorrect proxy in FVP POST /payments request:**\
   While executing tests in FVP, we observed that the `data.proxy` field in the `POST /payments` request is now populated with an invalid Pix key:\
   **`cliente-a00001@pix.bcb.gov.br`**\
   This Pix key is not configured or linked to the user running the test, which causes institutions to reject the request due to the invalid key. Logs of the failed request are also attached for reference.

These issues are blocking current retests. We kindly ask the team to investigate and advise on how to proceed.
