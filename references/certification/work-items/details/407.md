List below in an API-suitable format to aid on the feature development

| API                                            | Endpoint                                         | Operating Limit |
|------------------------------------------------|--------------------------------------------------|-------------------|
| Account                                        | Balances                                         | 420x              |
| Account                                        | Limits                                           | 420x              |
| Account                                        | Transaction                                      | 4x                |
| Account                                        | Transaction-current                              | 240x              |
| Account                                        | AccountId                                        | 4x                |
| Account                                        | Root                                             | 4x                |
| C.C.                                           | bills                                            | 30x               |
| C.C.                                           | bills-transactions                               | 30x               |
| C.C.                                           | Limits                                           | 240x              |
| C.C.                                           | Transaction                                      | 4x                |
| C.C.                                           | Transaction-current                              | 240x              |
| C.C.                                           | ccid                                             | 4x                |
| C.C.                                           | Root                                             | 4x                |
| Consent                                        |                                                  | N/A               |
| Resources                                      |                                                  | N/A               |
| Loans/Financings/Unarranged/Invoice Financings | contracts;  scheduled-instalments;payments       | 30x               |
| Loans/Financings/Unarranged/Invoice Financings | contracts-contradid; warranties                  | 4x                |
| Customer-Business/Customer-Personal            | identification;qualification;financial-relations | 4x                |


For the transactions-current check, the sum of API calls + Pagination should be superior to the operational limit to make sure that pagination is not counting towards the operating limit - The number of pagination should be equal to 20 always.

No change is required for the Consents and Resources test as no operating limits apply for those APIs and an arbitrary but large enough number was chosen.

For all the other APIs we must make sure we are calling exactly the number set on the operational limits for each client_id - resourceid pair (applicable only for the accounts and c.c. that asks for 2 resources)
