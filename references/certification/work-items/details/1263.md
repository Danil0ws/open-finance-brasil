Thanks for opening the ticket!

As for the new beta.3 specification released, when a invalid x-fapi-interaction-id is sent in the request, a new and valid x-fapi-interaction-id must be generated and sent by the server in the response as described on the image bellow:

![Screen_Shot_2024-01-23_at_16.43.42_PM](/uploads/2574db084c2844260b55846f5011c3b0/Screen_Shot_2024-01-23_at_16.43.42_PM.png)

Therefore the conformance suit is operating as expected, to be able to run the test successfully please make sure that:

1. When a invalid x-fapi-interaction-id is sent in the request, a new and valid one is sent on the response header
