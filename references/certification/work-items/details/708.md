## 📝 Descrição

When we try to make a Bradesco Iniciador, Mock Bank Detentor payment using Dynamic QRCode, we are receiving the error below:
`"errors": [ {"code":"VALOR_INVALIDO","detail":"required QrCode value - proxy is not present","title":"Valor inválido."} ] `

Example of Dynamic QRCode:
`00020101021226880014BR.GOV.BCB.PIX2566qrpix-h.bradesco.com.br/qr/v2/e9c60bac-e206-4b49-9ead-f550d841252e52040000530398654041.015802BR5914TETEGE JRHRHRG6009SAO PAULO62070503***63046CBE`

Dynamic QRCode has a location, where the institution searches for QR data, in this example:
`qrpix-h.bradesco.com.br/qr/v2/e9c60bac-e206-4b49-9ead-f550d841252e`

When opening the JWT we have the QR data as determined in the Central Bank specification for QRCodes used in the PIX:
