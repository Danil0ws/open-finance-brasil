### Comentário 10
**Autor**: Erick Domingues (@erick.domingues1)
**Criado em**: 14/06/2022, 23:45:57

Hi Roberto, that is an expected behavior. The transactions that are registered on the Mock Bank are not for the current day, which means the payload will be returned empty.

Here we have that the accounts/v1/accounts/{accountId}/transactions endpoint definition has a pair of http request parameters - fromBookingDate and toBookingDate. 

The description of these is -
`Start/End date of filtering. [Restriction] Must be sent if the from/toBookingDate field is informed. If not informed, the current day must be assumed. `

This means that you would need to request data from a longer period (2 years) to get transactions out of the platform. 

Best,
