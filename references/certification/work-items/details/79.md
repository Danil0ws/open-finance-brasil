First, the description of the test is wrong... it says it's waiting for 422 but the right error code for JTI reuse is 403 as described at [OpenBanking Informa #81](https://us5.campaign-archive.com/?u=49f5ff8910ce85bdb1d9a7864&id=db99e2d5c2).

Second, the test is wrong because when returning 403, it validates that the return type is application/json but it tries to parse the response as application/jwt.

The swagger specification is clear about the return type for POST consent when returning 403 error code:
![reuse_jti](/uploads/484a7bb931aefa84e9b470d3b62e1508/reuse_jti.png)
