### Comentário 9
**Autor**: Fabrício Lobo (@Fabricio_lobo)
**Criado em**: 06/06/2024, 12:49:35

Hi Aurelio,

Thanks for the ticket.

The webhook test on FVP expect the server to do a webhook call to the tool and not the other way around. In the dcr request, fvp will send the webhook uri so the server can build it from there as specified in https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/200736835/Registro+do+Webhook+-+Webhook+-+v1.2.0. The client only send the base uri https://web.fvp.directory.openbankingbrasil.org.br/test-mtls/fvp/w, and is the responsibility of the server to build the whole webhook from the host one.

With that, the server is expected to call the webhook endpoint in a format as https:///test-mtls/fvp/w/open-banking/webhook/v1/payments/v3/consents/{consentId}, since here it is a payments flow.

I don't know if I got right what you complained about. Please let me know if this answers your question. 

If not, please expand a bit more on the issue you are facing
