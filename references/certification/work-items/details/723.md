Hi,

Thanks for the ticket! 

The table in informa 218 is outdated. We recommend you verify the correct security method to be used in each endpoint in the swagger (https://openbanking-brasil.github.io/openapi/swagger-apis/payments/2.0.0.yml).

Regarding:

- GET payments endpoint: even though the swagger mentions both security methods, it should use only client_credentials. This is the only endpoint that is not currently updated in the swagger - which is tracked as a known specs problem in [BCLOG-FO3-V2-009](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/31162369/v2.0.0+Problemas+conhecidos)
- PATCH endpoint: the correct flow to be used is client_credentials, as shown in the swagger:
 
![image](/uploads/a2896b606818038d1452729de28a63e0/image.png)


Therefore, there is no corrections on the CS side. To a successful execution, the implementation needs to be adapted so that it is conformant to the behavior described above.

Feel free to open another ticket if you get any other issue! Happy to help!
