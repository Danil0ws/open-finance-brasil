## 1. What Happened and what were you expecting?

On class https://gitlab.com/obb1/certification/-/blob/master/src/main/java/net/openid/conformance/openbanking_brasil/testmodules/support/CompareResourceIdWithAPIResourceId.java

We compare if the number of resources returned on all pages of the resource api - `extracted_resource_id`
Is equal to the number of resources returned on the first page of the tested API (E.G. Loans) - `extracted_api_ids`


In the situation above the most we should be able to do is to confirm that extracted_api_ids is contained within extracted_resource_id, however, I cannot confirm that they must be equal.

## 2. Suggested Approach

1. Update test so extracted_api_ids obtains all the IDs from all the possible pages

Or

2. Update test so extracted_api_ids must only be contained within extracted_resource_id
