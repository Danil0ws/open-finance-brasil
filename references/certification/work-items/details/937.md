## 1\. What happened and what were you expecting?

We noticed that during testing, the engine displays the error "resourceendpoint returned a different http status than expected". When we check the URL being called, we identify that the URL path is not correct: https://hom-secure.opf.api.itau/itau-itau/open-banking/accounts/v2/accounts 

The product and resource APIs do not use the same path "logic" as the consent URL, which is also formed by the "brand-organization" (itau-itau) information. 

We need the URL to be adjusted to: https://hom-secure.opf.api.itau/open-banking/accounts/v2/accounts So that the call is made correctly or the URLs are called through the sandbox directory.
