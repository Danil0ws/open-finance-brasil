Hi,

As responded in issue https://gitlab.com/raidiam-conformance/open-finance/certification/-/issues/1438:

Test module failed when conformance suit executed the following call:

GET pix/recurring-payments/{recurringPaymentId}

And the authorization server included the field proxy in the response.

Although, as described in the most recent [automatic payments spec](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/312049950/Informa+es+T+cnicas+-+SV+Pagamentos+Autom+ticos+-+v1.0.0-rc.3), the proxy field is present in the POST /pix/recurring-payments endpoint,

it is not present on the GET pix/recurring-payments/{recurringPaymentId} response payload, which is what the conformance suit is validating when the test failed.

To ensure the test module can be run successfully please make sure that the GET pix/recurring-payments/{recurringPaymentId} is as described in the spec.
