## 📝 Descrição

1. What Happened and what were you expecting?

resources-dcr-happy-path test is requesting the scopes openid resources and consents. Some banks are correctly rejecting this as a set of permissions and scopes that do not result in usable data being shared. e.g the resources endpoint would be empty and should return a 404 even if a customer did consent to sharing just their resources endpoint. 

It is recommended to change this test to incorporate all permissions and scopes for phase 2 during consent whilst retaining the call to the resources endpoint.

The impact upstream to the OIDF test suite will need to be confirmed.
