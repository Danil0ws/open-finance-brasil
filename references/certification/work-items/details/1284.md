## 1\. What happened and what were you expecting?

After the consent is revoked, the test module is trying to validate whether the "rejection" object is present on the payload response.

![image](/uploads/96768c247a0ce2c633e55c331d2ff75a/image.png){width="363" height="115"}

As this is a REVOKED consent, it should try to find the "revocation" element as defined in the PATCH response at [\[SV\] Pagamentos Automáticos - v1.0.0-rc.1](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/264176303/Informa+es+T+cnicas+-+SV+Pagamentos+Autom+ticos+-+v1.0.0-rc.1)
