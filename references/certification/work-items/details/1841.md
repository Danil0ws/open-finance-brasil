Hi,

Thanks for opening the ticket!

Indeed test module execution resulted in failure due to field:

"extensions": { "credProps": "true" }

Which is sent in response for Request to endpoint /fido-registration-options

Here credProps is supposed to be a Boolean, which means it can either be set to: true or false, but given that in the response credProps is sent as "true", that makes this field a string and not a boolean. So in order to make it a boolean, removal of the "" is required.

Therefore the is no need to remove the whole field, just make sure that it is being sent as the expected boolean type.

Feel free to reopen this issue and add comments if further assistance is required.

Happy to help!
