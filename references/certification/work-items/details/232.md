## 📝 Descrição

## 1. Issue Description

When creating the DCR Automated Tests one of our planned tests plans will have the following behavior:

Test Behavior:
- Perform a DCR and obtain a client_id
- Generate an access Token with this client_id
- Use token to call either POST Consents or payments-consents API
- Data should be syntactically correct but invalid
- Expect the server to return a XXX for payments-consents or `XXX` for consents, ensuring that the client could be used to access a functional API 

Our question comes from what should be the expected codes on this case


## 2. Questions

1. Can a server accept a POST Consents request even if the loggeduser does not bank with him? 
2. **If yes**, what would be the expected failure on the redirect?
3. **If no**, what are the error code that he should return and the error message?
