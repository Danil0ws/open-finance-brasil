## 📝 Descrição

#### Current Behavior:
---
Although the MB enrollment process was recently updated to support the EC2 key type (improvement reference: #2123), an issue was identified with the Authorise Consent FIDO endpoint. MB is still validating the signature as RSA as the only option, which is no longer correct. Below are the error details:

`code": "RISCO",`

`"detail": "invalid signature",`

`"title": "RISCO"`

#### Expected Behavior:
---
MB should validate the signature as either RSA or EC2, depending on the key type used.

#### Evidence:
---
- x-fapi-interaction-id: `c9526cc3-ac72-445e-ad9b-df39733087d8`
