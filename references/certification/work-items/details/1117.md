Hi,

After thoroughly evaluating the test module related to the regex validation issue you reported, we have identified that the problem lies in the specification itself. The regex pattern provided in the specification is **`^(?:[01]\d|2[0123]):(?:[012345]\d):(?:[012345]\d)|Z$`**. However, this pattern fails to match the input correctly.

As it is characterizes as an error on the spec we will be notifying the structure so it is fixed for when a newer version comes out. We will promptly fix it once we have agreed on the correct format for the regex.

Feel free to open another ticket if you get any other issue!
