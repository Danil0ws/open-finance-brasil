## 📝 Descrição

**Observed behavior**

* postFixedIndexerPercentage is being required when indexer = PRE_FIXADO.
* remunerationTransactionRate is being required when type = ENTRADA, regardless of the product remuneration type.
* indexerPercentage is being required when type = ENTRADA, regardless of the product remuneration type.

**Expected behavior**

* postFixedIndexerPercentage must be required only when indexer != PRE_FIXADO or for hybrid remuneration products.
* remunerationTransactionRate must be required only when type = ENTRADA and the product is pre-fixed or hybrid.
* indexerPercentage must be required only when type = ENTRADA and the product is post-fixed or hybrid.

* TestId: ORHP78nnnrNJirJ
