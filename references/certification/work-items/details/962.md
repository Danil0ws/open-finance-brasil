## 📝 Descrição

## 1. What happened and what were you expecting?

CS is incorrectly using an authorization code token to perform a GET consents request at the step _"Calling GET Consent with x-fapi-interaction id, expecting success"_ in the test `payments_api_x-fapi_test-module_v3`.

Below it follows the error:

- `authorization_code` generated:
![image](/uploads/2c56954277bc40c491678c993044cb98/image.png)

- token used later at GET Consent:
![image](/uploads/77e1496a401557d3321327b322efa7c6/image.png)

According to OAS, we should only accept client_credentials token in this request.

![image](/uploads/b23be640eb7a23b3d28bf4a26c58db15/image.png)
