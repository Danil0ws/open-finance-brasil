## 📝 Descrição

**Context**

Surfaced while reviewing an unusually large Open Data response, around 1.4 MB and about 37 thousand fields in 7 records. The response respects the pagination rules of its own specification, page-size 25 with meta.totalPages 1, but pagination in these APIs is per record and a single record has no size bound, so a conformant response can be arbitrarily large. Two behaviours were observed.

---

**Module: opendata-insurance-personal_api_structural_test-module_v2n1**

Observed behavior

The endpoint returns HTTP 200 with a valid, paginated response. The module stops the structural validation partway through and ends as FAILED with the message "This condition attempted to log over 150000 log entries and has been aborted". No schema deviation is reported. The outcome depends only on the number of records in the response, not on their content, so a response that complies with the specification is reported as a failure.

Evidence: https://web.conformance.directory.openbankingbrasil.org.br/log-detail.html?public=true&log=NMQzsdtRXsnkFIk

Expected behavior

The module completes the structural validation of the whole response regardless of payload size and reports only genuine deviations against the specification.

---

**Modules: personal-financings_api_structural_test-module_v1n1 and business-financings_api_structural_test-module_v1n1**

Observed behavior

The endpoints return HTTP 200 with the required array `data` set to null. The module records the deviation and then ends as INTERRUPTED with the internal execution error "Test condition needs to throw error() if it logs failures/warnings". The result does not state which field deviates or what the specification requires, so the deviation is not actionable from the log.

Evidence:

* https://web.conformance.directory.openbankingbrasil.org.br/log-detail.html?public=true&log=5AAvd7S12iHpC1e
* https://web.conformance.directory.openbankingbrasil.org.br/log-detail.html?public=true&log=xHzvuIzk9VopIPu

Expected behavior

When the structural validation finds a deviation, the module ends as FAILED and the log names the deviating field and the constraint it breaches.

---

**Scope**

The first behaviour is reachable by any Open Data family whose response packs an entire institution catalogue into a single record, including insurance, pension, capitalization bonds, investments and acquiring services.
