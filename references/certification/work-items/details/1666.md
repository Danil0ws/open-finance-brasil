## 📝 Descrição

#### Current Behavior:

---

The access token expiration time is 15 minutes according to Open Finance specification. In the timezone test I created the test at 23:38, but it expired 15 minutes later. The test suite correctly generated a new token, but it did not use this new token it received. Instead, it used the old one instead that was already expired.

#### Expected Behavior:

---

The test suite must use this new token it received when making the GET request, otherwise the test will only work if it's started around 23:46.

---
