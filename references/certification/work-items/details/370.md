## 1. What Happened and what were you expecting?

When fetching Account Current transactions with invalid date parameters, the account-api-transactions-current-test-v2 validator is requiring x-fapi-interaction-id header to be found in the resource endpoint response headers. However, according to the Cabeçalhos HTTP section, it is not mandatory for it to be present.
