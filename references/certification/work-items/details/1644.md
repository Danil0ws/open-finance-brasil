Hi,

Thanks for opening the ticket,

Test module execution failed while conformance suit executed following step:

**Validating post consent extension response**

In which POST /consents/{ConsentId}/extends was called sending the following payload in request_body:

**{"data":{"expirationDateTime":"2025-05-23T19:36:44Z","loggedUser":{"document":{"identification":"30762349867","rel":"CPF"}}}}**

Note that, even though the timestamp looks the same, it is actually, extending the consent for +365 days, making it's expiration date time due in 2025.

Therefore conformance suit is operating according to expected in this regard.

Although we do have a misleading instruction on test description, but it does not, by any means, prevent the test from being successfully executed, which is the described step:

* Call the POST Extends Endpoint with expirationDateTime as D+60, and all required headers

Which should be:

* Call the POST Extends Endpoint with expirationDateTime as D+365, and all required headers

The description will be fixed so that no confusion is caused by it,

Happy to help!
