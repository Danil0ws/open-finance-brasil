## 📝 Descrição

We notice a possible inconsystency in https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/691962030/Informa+es+T+cnicas+-+DC+Adiantamento+a+Depositantes+-+v2.3.0 specification, being different then the standard used for such cases in other api specifications.

![image](/uploads/612a91c7da913351ea4ac42ea9e5edd4/image.png)

![image](/uploads/0eb3fd91db669ef420906cc92cc36e3c/image.png)

Currently the field instalmentPeriodicityAdditionalInfo is considered required and has the following patterns: ^(?!\\s)\[\\w\\W\\s\]\*\[^\\s\]$ Although in it's description says that it only has to be provided if field instalmentPeriodicity is filled with value “OUTROS”, and otherwise it should be an empty string.

What should be written in the specification is: **instalmentPeriodicityAdditionalInfo** (opicional) \[Restrição\] Campo obrigatório para complementar a informação relativa à periodicidade de pagamento regular quando tiver a opção OUTROS.

The current behavior of this field suggest that a better configuration for this field would be: The correct behavior would be for it to be an optional field, mandatory only when instalmentPeriodicity = OUTROS, and it should not be filled when the value is different from OUTROS.

What we need evaluation from Wg is:

* Shouldn't this field follow the standard adopted to other fields where they are conditional based on the value of another field?
