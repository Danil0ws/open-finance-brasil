## 1\. What happened and what were you expecting?

CS is incorrectly validating that there should be no `totalRecords` or `totalPages` fields in a 403 response, but those fields are mandatory when meta is returned.

Hi @carla-raidiam! 

There is a new fix to be made. As stated in the implementation guide, when the resource is pending authorisation the correct syntax when a call is made to the resource url is 403, code: "STATUS_RESOURCE\_**PENDING_AUTHORISATION**" .

The test is expecting "STATUS_RESOURCE\_**AWAITING_AUTHORIZATION**".
