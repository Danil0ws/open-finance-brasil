#### Current Behavior:

---

When running the recurring payment retry test, the **JWT** in the `POST` request body for the `.../pix/recurring-payments/{originalRecurringPaymentId}/retry` endpoint has an incomplete `aud` (audience) field with the value: `"pix/recurring-payments"`.

This format is considered invalid by our API, which validates the `aud` based on the full endpoint URL, resulting in a validation error.

#### Expected Behavior:

---

The `aud` field in the JWT **must be identical to the complete URL of the endpoint** being accessed.

Therefore, for the endpoint `.../pix/recurring-payments/{originalRecurringPaymentId}/retry`, the expected value for the `aud` field in the JWT is: `"pix/recurring-payments/{originalRecurringPaymentId}/retry"`.
