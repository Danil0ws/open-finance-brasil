In this case, you are failing because you are returning a 400 - PARAMETRO_NAO_INFORMADO status code when a request without a mandatory parameter in the payload is made. For this scenario, according to the specification, you should return a 422 - PARAMETRO_NAO_INFORMADO status code, with the consequent change in the consent status to Consumed.

Therefore, if you correct the returned status code to 422, you should be able to succeed in the test.
