## 📝 Descrição

## 1. What Happened and what were you expecting?
While testing the resource api, according to RN003, our endpoint is returning a empty body and HTTP Status Code 202. But seems resources-api-test are not prepared to evaluate this behavior.

RN003: caso a Transmissora ainda esteja preparando a listagem dos
recursos autorizados da API de Recursos (Resources), deve ser retornado o
código HTTP Status Code 202 - accepted com o body vazio e a Receptora
deverá seguir as recomendações de polling.
