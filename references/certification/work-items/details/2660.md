### Comentário 2
**Autor**: Matheus Mantovani (@matheus-mantovani)
**Criado em**: 17/04/2026, 21:43:55

Olá, @Celinakt.

O problema ocorre ao tentar ler o campo `valor` do `payloadJWS` decodificado. O payload que você utilizou na configuração do teste é:

`{
  "txid": "fc9a4366ff3d4964b5dbc6c91a8722d3",
  "valor": "500.00"
}
`

O teste CHANGE QRDN espera que `valor` seja um **objeto** no formato troco:

`{
  "valor": {
    "original": "50.00",
    "retirada": {
      "troco": { "valor": "10.00" }
    }
  }
}
`

O `payloadJWS` configurado tem `valor` como string primitiva, que é o formato de um QR code Pix simples, não compatível com o cenário de troco.

Para ter sucesso, reconfigure o campo `brazilQrdnPaymentConsent.data.payment.details.payloadJWS` com um QR code no formato saque/troco, onde `valor` é um objeto contendo `original` e `retirada.troco.valor`.
