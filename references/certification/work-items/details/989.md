Hi Marcos! Thanks for the ticket!

According to the [RFC 6749](https://www.rfc-editor.org/rfc/rfc6749#section-4.1.2:\~:text=value%20it%20issues.-,4.1.2.1,-.%20%20Error%20Response%0A%0A%20%20%20If): 

If the resource owner denies the access request **or if the request fails for reasons other than a missing or invalid redirection URI,** the authorization server informs the client by adding the following parameters to the query component of the redirection URI using the "application/x-www-form-urlencoded" format, per [Appendix B](https://www.rfc-editor.org/rfc/rfc6749#appendix-B)

And it does not refer to an authorization code. In that sense, if the request is denied, the authorization code cannot be sent back.
