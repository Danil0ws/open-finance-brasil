Hi Tatiane! Thanks for the ticket!

The error is happening because the Directory Client ID you are sending is actually the Software Statement ID, making the token request for the directory to fail. For Software Statements created before 2022, these IDs were different, for recent ones, they are the same.

To identify the client ID, we you have to go on the directory and select the Software Statement you are using, click on Software Statement Details. There, you will have both the software statement ID and the Client ID:

![image.png](/uploads/c54d13c87e79023a873d69f9fa8958b9/image.png)

In that sense, if you fill the field "Directory Client ID" with the clientID instead of the software statement ID, the test will pass without further problems.

We are happy to help with any additional needs!
