## 1. What happened and what were you expecting?
In this scenario, it was expected that the extension would not be authorized due to the expirationDateTime having more than 12 months to expire. However, in 2024, it will be a leap year.

Another point, In the current POST request, the `x-fapi-customer-ip-address` header is still being sent. However, based on the statement, it should not be included in this request.

The test actually has two different requests, as showed at the summary:

Call the POST Extends Endpoint with expirationDateTime as D+365, and do not send the x-fapi-customer-ip-address header\
• Expects 401 - Validate Error Message

**• Call the POST Extends Endpoint a Client Credentials Token**\
• Expects 401 - Validate Error Message

The error you are receiving is at this second request where a client credential token is being accepted, where it should be only a authorization_code one, as specified at the swagger.

In that sense, your implementation has to change to guranrantee that client credentials token should no be accepted at this endpoint.
