# What did you do?
Tried to run test CreditCard-Api-wrong-permissions-test-v2

# What did you expect would happen?
Test would pass

# What did happen?
Test creates a Consent with customer personal permissions ("CUSTOMERS_PERSONAL_IDENTIFICATIONS_READ", "CUSTOMERS_BUSINESS_IDENTIFICATIONS_READ", "RESOURCES_READ") and sends the businessEntity on the data payload. Test expects a success 201 - Expects a success on Redirect as well. However, according to a Customer Test (customer-api-businessentity-personal-permissions-v2), the server should reject the consent creation request if businessEntity is sent on the consent creation together with personal customer data permission.

### Comentário 2
**Autor**: Erick Domingues (@erick.domingues1)
**Criado em**: 08/09/2022, 21:10:55

On your test plan configuration, you are sending

```
    "resource": {
        "brazilCpf": "76109277673",
        "brazilCnpj": "59458541000100"

    "consent": {
        "productType": "personal"
```

Which is only expected if you are sending the customer business product type on tests. Removing the field brazilCnpj or changing the product type to "business" should make the test work.
