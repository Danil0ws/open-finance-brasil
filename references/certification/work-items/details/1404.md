## 1. What happened and what were you expecting?

During the test POST automatic-payments/v1/pix/recurring-payments call the provided payload does not have the object riskSignals.

According to the specification, when a SWEPPING recurring consent is created such field is mandatory:

![image](/uploads/837485260e87b80324c9fbc2606b2157/image.png)

**Expected behavior:** Since the test creates a SWEEPING recurring consent the payment payload should have a valid riskSignals object set.
