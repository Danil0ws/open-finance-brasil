Right ok! Yes so the logic now is: 
- if you don't send an accept header, you get a jwt
- If you send an accept header that is application/jwt, you get a jwt
- If you send application/json (or an invalid accept header) you get a json

Since postman does default to the */* accept header I will make a change to ignore this too but for now follow the above rules. Thanks
