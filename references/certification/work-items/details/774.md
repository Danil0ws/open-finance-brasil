Thanks for the ticket!

According to [Informa #310](https://mailchi.mp/780543062934/open-banking-informa-9291225?e=%5BUNIQID%5D), the `x-fapi-interation-id` in any payments endpoint header is mandatory since 17/05/2023. 

Therefore, the CS is conformant to the latest updates. The information displayed at the documentation about this point seems to be indeed outdated and for a change on the API specification we ask you to raise a Service Desk ticket with the contents of this ticket. Feel free to mention this issue with them.
