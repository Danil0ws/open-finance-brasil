## 📝 Descrição

## 1\. What happened and what were you expecting?

#### **1. Observed Behavior:**

The test bank-fixed-incomes_api_pagination-list-cond_test-module, with the condition EnsureNumberOfTotalRecordsIsAtLeast51, is trying to fetch 51 tins inside the data from the array.

#### **2. Expected Behavior:**

We should be using the EnsureNumberOfTotalRecordsIsAtLeast51FromMeta condition instead, which looks at the number of records from meta.

This is a problem, because, according to https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/17377470/Pagina+o#Regras-Adicionais , the ASPSP can define a max page size lower than the one requested. In that sense, even if we request a page-size=1000, it can still return 25 itens inside the data array.

#### **3. Evidence (test ID):**

https://web.conformance.directory.openbankingbrasil.org.br/log-detail.html?log=gyCFRdhpevoIbgW
