## 1\. What happened and what were you expecting?

The test module is using the incorrect URL to request the PATCH Payments consents.

**It is using:** PATCH payments/v4/consents/{consentId} ![image](/uploads/d38799da1d1fb29c329ef9be4e8e7dda/image.png){width=581 height=63}

**It should be using:** PATCH /payments/v4/**pix/payments**/consents/{consentId} ![image](/uploads/c03e6bef8e06ec0f5f248e65da34a092/image.png){width=681 height=38}
