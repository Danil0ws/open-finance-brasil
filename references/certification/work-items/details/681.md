Hi Vitor! Thanks for the ticket!

After the changes described at [Informa 371](https://mailchi.mp/264517e1a5de/open-banking-informa-9341188?e=%5BUNIQID%5D), the security specs have been changed as described at https://gitlab.com/obb1/certification/-/issues/674#note_1390913455.

In that sense, for now, as the authorization server should not grant access to the resources for an access token that is linked to a CONSUMED consent, the error should be a 401, as stated at the [security specs](https://openbanking-brasil.github.io/specs-seguranca/open-banking-brasil-financial-api-1_ID3-ptbr.html#name-servidor-de-autoriza231227o-2).

This is issue is already mapped by the WG and new updates will be informed soon and updated at #674, where this is being tracked.

Happy to help with any additional needs!
