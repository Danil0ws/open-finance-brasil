## 📝 Descrição

A api de validação para fluxo de enrollment para processo de piloto JSR v2.2.0 deveria retornar um atributo chamado ApiMetadata, como no exemplo: 

```json
"ApiMetadata": {
  "fase": "Em homologação"
},
```

Porém na api pública do diretório não é apresentada essa informação, fazendo alguns testes do piloto, vi que as apis estão disponíveis.![image.png](/uploads/23774b9175604ac299d72015a4aa7e29/image.png){width=629 height=600}

Poderiam confirmar esta informação ?
