## 📝 Descrição

**Observed behavior**

* FVP automatic ticket creation is sending tickets with the mandatory field **“Instituição Requerente”** empty.
* Due to the rule introduced in [**[Open Finance] Informa #816**](https://us5.campaign-archive.com/?u=49f5ff8910ce85bdb1d9a7864&id=6a82d910d9), the Service Desk now validates the data sent via API and requires all mandatory fields to be filled.
* As a result, tickets created without this field populated remain in the status **“Aguardando Requisitante”** (“Waiting for Requester”) until the information is manually added.

---

**Expected behavior**

* When a ticket is created automatically by FVP via API, the **“Instituição Requerente”** field should be populated by default with: **“Open Banking Brasil - Raidiam”**.
* Tickets should be opened already compliant with the new validation rule, with all mandatory fields filled in and without remaining in the **“Aguardando Requisitante”** status due to missing data.

---

**Evidence:**

* Example tickets: **128654**, **128892**
