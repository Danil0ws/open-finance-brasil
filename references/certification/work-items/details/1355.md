## 📝 Descrição

## 1\. What happened and what were you expecting?

When running exchange_api_operational-limits_test-module, test module is trowing the following failure:

> Validating Operations Events Endpoint response: GetOperationsEventsValidatorV1: Class cast exception, expect JsonArray, but found JsonObject. Field: foreignPartie on the Exchanges API - Get Operations Events V1 API response

It seems that while validating the response for GET Operations Events, test module expectes foreignPartie Field to be a JsonArray, but according to the specification, ForeignPartie is defined as an object, the mentioned specification is available at:

https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/262144738/Informa+es+T+cnicas+-+DC+C+mbio+-+v1.0.0-rc.4

The same behavior can be observed in the following two modules according to the attached Test Ids
