#### Current Behavior:
   While Executing internal tests against the newly developed fvp-consents_api_negative_test-module_v3 a unexpected behavior was found when following steps are executed in test:

•Creates consent api V3 request for DateTime greater than 1 year from now

• Expects failure with a 422 Error

The following error is thrown:

* Value from element code does not match any given enumeration on the Post Consent V3 API response

This occurs due to the following error message being returned:

<table>
<tr>
<td>"code":"Expiration time must be within a year"</td>
</tr>
</table>

According to [Consents v3 specs](https://openbanking-brasil.github.io/openapi/swagger-apis/consents/?urls.primaryName=3.0.0#/Consents/consentsPostConsents), the allowed error codes for 422 are:

* SEM_PERMISSOES_FUNCIONAIS_RESTANTES
* INFORMACOES_PJ_NAO_INFORMADAS
* PERMISSOES_PJ_INCORRETAS
* PERMISSAO_PF_PJ_EM_CONJUNTO
