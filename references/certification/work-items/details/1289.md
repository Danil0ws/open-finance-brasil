## 📝 Descrição

## 1\. What happened and what were you expecting?

In the test summary, the conformance suite should try to create a payment using a consent in the `PARTIALLY_ACCEPTED` state and expects a `422 CONSENTIMENTO_INVALIDO`.

![image.png](/uploads/2d0b581b3613af9090aa145d6c6d2a32/image.png){width="438" height="69"}

However, in this step, the test module is really expecting a successful response (`201`) instead of the `422 CONSENTIMENTO_INVALIDO` specified in the test summary.

![image.png](/uploads/b123ccb6fea623a7f498d7f48f3653cb/image.png){width="325" height="38"}
