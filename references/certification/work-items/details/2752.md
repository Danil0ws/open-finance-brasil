## 📝 Descrição

Estamos recebendo tickets relacionados a cenários que retornam a mensagem de erro:

Unable to locate resource endpoint to continue 

Esse comportamento ocorre porque, para algumas marcas, determinados endpoints podem não existir no diretório, e isso é intencional. Por exemplo, a marca Íon não possui o endpoint de loans.

No cenário fvp_credit-portability_api_invalid_token_test-module_v3-3, quando a busca pela API de loans é feita no diretório e o endpoint não é encontrado, o teste retorna erro, gerando tickets desnecessários.

Exemplo de resultado:

[Link para o log do teste](https://results.conftpp.directory.openbankingbrasil.org.br/SGjhBnHggSPXC/test-log-fvp_credit-portability_api_invalid_token_test-module_v3-3-K48vi5rnCFrRn78.html)

Sugestão:

Revisar a lógica do teste para que, quando um endpoint não existir no diretório por ser uma característica intencional da marca, o teste realize um skip ao invés de falhar. Implementar essa verificação especificamente para os casos conhecidos, como a marca Íon e seu endpoint de loans.
