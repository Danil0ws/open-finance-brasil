## 📝 Descrição

Atualmente, não está sendo possível publicar planos de teste para certificação quando estes não estão 100% concluídos ou quando nem todos os cenários foram executados com sucesso.\
\
No entanto, para alguns marcos de certificação que não exigem a conclusão total do plano, essa restrição está impedindo a publicação da certificação correspondente.

O erro retornado é o seguinte:

`{
  "error": "Unable to create certification package",
  "error_description": "All tests have not been completed or tests have failed. ",
  "plan_name": "payments-withdraw_test-plan_v5",
  "test_plan_id": "LZ7jVu917xQur",
  "variant": "",
  "failed_tests": {
    "payments_api_pix-withdraw-invalid-amount_test-module_v5": {
      "testId": "psnA42uStc3RfSB",
      "status": "INTERRUPTED",
      "result": "FAILED"
    }
  }
}`

Entendemos que talvez é necessário ajustar o processo para permitir a publicação de certificações em marcos que aceitam planos de teste parciais, garantindo maior flexibilidade e aderência aos requisitos específicos de cada marco.
