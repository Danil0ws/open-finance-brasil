As mentioned on: https://github.com/OpenBanking-Brasil/specs-seguranca/issues/212

The DCR specification contains a table of regulatory roles to scopes mapping that says PAGTO should have access to the RESOURCES and CONSENTS scope. 

This table was created before the phase 3 specification was published. In the payment_swagger there is no requirement to support resources, indeed the description explicitly states that the permissions and resources model will not be adopted for phase 3 payments.

The Functional Test Suite for Phase 2 has a test in it that requires banks to ONLY support the scopes that are indicated on the phase 3 swagger specification. i.e openid and payments. 

Some Banks are granting the resources scope, as well as part of DCR for Phase 2 and w,e believe that this is the culprit.

I would urgently recommend that this is clarified with GT Specifications, GT Sandbox and this table is updated to remove the RESOURCES and CONSENTS scope from the PAGTO regulatory role.
