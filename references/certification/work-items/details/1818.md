## 📝 Descrição

**Description:**

We have identified two issues in the official [PCM Integration documentation](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/37912663/Documenta+o+da+API)concerning the Enrollments API. These issues may lead to integration problems and inconsistencies when following the specification:

1. **Version Mismatch:**\
   The available version of the documentation only considers Enrollments API  v**1.1.0**, which does not consider the updates provided in versions **1.3.1** and **2.0.0**. This discrepancy causes confusion when referencing the correct API behaviors and features. 
2. **Incomplete Client and Server Requirements:**\
   The "Client Obrigatoriedade" and "Server Obrigatoriedade" tabs in the [documentation](https://openfinancebrasil.atlassian.net/wiki/download/attachments/37879861/Tabela%20additionalInfo%20–%20campos%20contexto%20e%20obrigatoriedade_v17-.xlsx?api=v2) does not describe the endpoints for Enrollments. Without proper endpoint descriptions, it's unclear how to correctly implement and integrate the Enrollments API as per the PCM requirements.

**Suggested Resolution:**

- Update the documentation to include versions **1.3.1** and **2.0.0**, ensuring that all changes and improvements in these versions are reflected.
- Complete the "Client Obrigatoriedade e Server" tab by adding clear descriptions of the Enrollments API endpoints, detailing the required interactions and behaviors for both client and server sides.
