Hi,

Looking at the test that you have provided you have sent the webhook API call as a JSON:

![image](/uploads/378874af4248064101e9cb253c7053cf/image.png)

We note that on the specification, as we are dealing with Payments, it expects a JWT:

https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/118915156/Informa+es+T+cnicas+-+Webhook+-+v1.0.0-beta.2

As it's a JWT you must not only encode it but also add all the expected claims as defined on https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/82083996/EN+Open+Finance+Brasil+Financial-grade+API+Security+Profile+1.0+Implementers+Draft+3#6.1.-Message-Content-Signing-Considerations-(JWS)
