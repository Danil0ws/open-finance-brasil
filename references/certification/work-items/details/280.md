I think this point is in line with https://gitlab.com/obb1/certification/-/issues/219 where we mention that normally the IETF/OIDF do not limit the size of parameters. I would have to check with our FAPI experts but my first hypothesis is that this field is also not limited by the specs.

Regarding the directory  

[Directory swagger](https://github.com/OpenBanking-Brasil/specs-directory/blob/main/openapi.yaml) sets a limit of 255 for this field

```
        ClientName:
          description: Software Statement client name
          maxLength: 255
          type: string
```

Note that we had a recent discussion about blocking the customerfriendlyname to 40 characters however nothing was mentioned about this ClientName field, so i don't believe we will be changing this soon.
