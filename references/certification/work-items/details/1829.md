Hi,

Thanks for opening the ticket!

It seems the mentioned test modules failed due to inclusion of this parameter on the Test Module Config:

```
  "brazilPixPayment": {
            "data": [
                {
                    "localInstrument": "DICT",
                    "proxy": "cliente-a00001@pix.bcb.gov.br",
                    "payment": {
                        "amount": "1.00",
                        "currency": "BRL"
                    },
                    "creditorAccount": {
                        "ispb": "99999004",
                        "issuer": "0001",
                        "number": "12345678",
                        "accountType": "CACC"
                    },
                    "remittanceInformation": "Pagamento da nota XPTO035-002.",
                    "cnpjInitiator": "61820817000109"
                }
            ]
        },
```

Conformance Suit does not recognize this parameter and it is not needed since all the needed information related to the payment can be filled in test module config Form.

Please remove this field from Json Config and try again.

Feel free to open a new issue if you require further assitance,

Happy to help!
