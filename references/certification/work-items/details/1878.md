## 📝 Descrição

#### Current Behavior:
---
The test fails because it expects the `PARAMETRO_INVALIDO` code when an invalid `x-fapi-interaction-id` is sent, but we are returning `400` as the error code in the response payload. The `PARAMETRO_INVALIDO` code does not exist in the Consents 3.1.0 specification (https://openbanking-brasil.github.io/openapi/swagger-apis/consents/3.1.0.yml).

#### Expected Behavior:
---
The Consents specification does not list an enum of expected values; it is a string field that accepts any value with a maximum length of 255 characters:

![image](/uploads/fb5b2caf3816d7783575923908fb51e5/image.png){width=723 height=551}

Therefore, we expected the test to run successfully.
