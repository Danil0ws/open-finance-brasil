Technically it's not a bug on the tests as the security specification defines -

https://github.com/OpenBanking-Brasil/specs-seguranca/blob/main/open-banking-brasil-financial-api-1_ID3-ptbr.md#servidor-de-autoriza%C3%A7%C3%A3o--lifecycleauth

`4.deve garantir que os access tokens são emitidos com os scopes necessários para permitir acesso aos dados especificados em elemento Permission do Consentimento (Consent Resource Object) relacionado;`

so as long as the consent got the underlying permission you should be granting the scope regardless.

We will change the test because it's not intended behaviour, but technically the conformance suite is correct here.
