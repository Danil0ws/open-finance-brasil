## 📝 Descrição

## 1\. What happened and what were you expecting?

The test module requires that 125 events to be returned on the event endpoint and after calling the GET Operations Events endpoint 29 times to ensure that at least 125 events are returned, it calls the endpoint again sending a query Parameters page-size=25, page=1, repeating it **four times** to reach the last page.

![image](/uploads/2eb643d9cc55d13b0fbfad72c5388ed3/image.png){width="602" height="80"}

The problem is that after reaching the last page (page 5), the test module is expecting a next link to be present on the payload. As it is the last page,[ there is no next so it shouldn't require it.](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/17377470/Pagina+o#Meta)
