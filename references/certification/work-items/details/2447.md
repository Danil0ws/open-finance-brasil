## 📝 Descrição

We request the creation of one CPF associated with two distinct CNPJs. This configuration is necessary to validate real-world scenarios within the CNPJ client flow.

The requirement arises due to the logic of our security key, which depends on a unique combination of account, CNPJ, and CPF. This structure can impact other keys linked to the same CPF, making it essential to create this data set for consistent testing.

To meet this need, providing one CPF linked to two CNPJs will be sufficient.
