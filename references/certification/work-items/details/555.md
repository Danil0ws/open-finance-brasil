But today, after executing the tests, this option wasn't available

Hi, 

The removal of the aforementioned button was deliberate to avoid confusion when users were generating the certification package. You can still set your tests results to public by the publish certification button, but really we see no reason for one to do it as The Regulators and Initial Structure already have full access to logs, regardless of whether them being public or not.

Regarding the need to execute X% of the tests before the cut-off date, there's no requirement for those tests to be published

Links have been updated so they should now work. Please note that we plan to no longer use the documents on that link, so please don't get anything signed until we send out next week the final version of how to request certification.
