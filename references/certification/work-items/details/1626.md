## 📝 Descrição

By executing the FVP 1.0 test plan available in the FVP test plataform (https://web.fvp.directory.openbankingbrasil.org.br), we noticed that the test plan we were executing had 22 tests in total, and the test plan that is automatically executed every thursday has 29 tests. Is it supposed to be like that? Can the remaining 7 test be added to the test plan available for us to run manually? My objective is to run the FVP 1.0 tests without having to open a ticket for it, so we could garantee the test is not going to fail in the regular execution and the requested executions.
The missing tests are:

dcr_api_fvp-revoked-certificate_test-module

dcr_api_fvp-unhappy-tls-client-auth_test_module

dcr_api_fvp-dcm-subjectdn_test-module

dcr_api_fvp-brcac2022-support_test-module

directory_api_certification-status_test-module

payments_api_consents_negative_no_redirect_test-module_v3

dcr_api_fvp-fapi1-advanced-final-brazil-dcr-no-authorization-flow_happy-flow_test-module
