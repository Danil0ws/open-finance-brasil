Hi, @felipeferreira3 

Thanks for the ticket! 

After evalutation it was found that the test flow has failed because a recurring consent was created, but during the `/authorize` step, the scope sent was:
- `consent:urn:raidiambank:c5199e5b-22b4-454b-a650-1b6becf6b89c`

instead of:
-  `recurring-consent:urn:raidiambank:c5199e5b-22b4-454b-a650-1b6becf6b89c`

Therefore, there is no corrections on the MB side. To a successful execution, the implementation needs to be adapted so that it is conformant with the specification ([API Automatic Payments v2.0.0-rc.1](https://raw.githubusercontent.com/OpenBanking-Brasil/openapi/main/swagger-apis/automatic-payments/2.0.0-rc.1.yml)):
