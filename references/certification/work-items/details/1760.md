Test module execution failed due to:

The test module being created and executed at:

> Thu Aug 08 2024 20:44:24 GMT-3 (Brasilia Standard Time)

As described in test summary:

> Ensure payment reaches an accepted state when executed between 9pm UTC-3 and 11:59pm UTC-3.
>
> To ensure that the server can process the date, which is set as UTC-3, **this test must be executed between 9pm UTC-3 and 11:59pm UTC-3**

By the time that Conformance Suit reached the CurrentTime evaluation it was:

![image.png](/uploads/34fedc869cd39688454528c8699affb8/image.png)Therefore, Conformance Suit is not subtracting hours from execution time.

If you are executing this test module outside from Brasil, in UTC Timezone, you should run this test module at between:

> 00:00 and 03:00 AM

The timer on the left of the Logs (8:45:10 PM) is solely for guidance and reporting reasons, Conformance Suit does not perform any operations using this time.

Remember, using another timezone, be it from being outside of Brasil or using VPN, will not change the timezone used in this test module, which, again, is UTC-3
