Hi, in both cases the responses have the "errors" object inside a "data" object. This is the incorrect structure for the 422 response. This is why it is throwing a null pointer. Below is the example from the specifications (note it states the meta object is optional):

{
  "errors": [
    {
      "code": "FORMA_PGTO_INVALIDA",
      "title": "Forma de pagamento inválida.",
      "detail": "Meio de pagamento inválido."
    }
  ],
  "meta": {
    "totalRecords": 1,
    "totalPages": 1,
    "requestDateTime": "2021-05-21T08:30:00Z"
  }
}

Below is the response you sent:

{
  "data": {
    "errors": [
      {
        "code": "DETALHE_PGTO_INVALIDO",
        "title": "O documento informado é invalido.",
        "detail": "O CNPJ informado é invalido"
      }
    ]
  }
}

I hope this clarifies the issue. Should it still persist please re-open this issue. Thanks!
