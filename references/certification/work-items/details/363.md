## 1. What Happened and what were you expecting?

Test consent-api-test-permission-groups-v2 expects a 201 call for every single resource, however some servers might not support every single permission group. When this happens the test might return a valid 422 which should be accepted on test.

Test must be updated to change from 
- Creates a series of consent requests with valid permissions group and expect for each of them a 201 to be returned by the server

to

- Creates a series of consent requests with valid permissions group and expect for each of them a 201 to be returned by the server with matching permissions or, instead, a 422 error response because server does not support the sent group.
