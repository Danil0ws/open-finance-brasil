Hello! I've identified an issue with the **fido-registration-options** endpoint. 

The problem is that it's not returning the correct EC2 **alg** (algorithm) on the **pubKeyCredParams**.  To resolve this, I guess, we should add the following structure to the **pubKeyCredParams** array:  {   "type": "public-key",   "alg": -7 }
