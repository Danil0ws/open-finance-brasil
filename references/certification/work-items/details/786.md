## 📝 Descrição

## 1. What Happened and what were you expecting?
In the step _"Call GET Transactions endpoint with page-size equal to 1000 - Expects 200 status code and totalRecords >= 51"_, the request URI is not set correctly. 

Instead requesting using the `/investments/{investmentId}/transactions` endpoint, CS is requesting using the Product Identification endpoint: `/investments/{investmentId}`. As shown below:
