## 📝 Descrição

I'm encountering a discrepancy in the test case consents_api_multiple-consents-extension-cond_test-module_v3. The test description specifies that for extensions involving joint accounts, the expected error code should be 422 DEPENDE_MULTIPLA_ALCADA. However, the test is currently only accepting the following error codes:

- COMBINACAO_PERMISSOES_INCORRETA
- PERMISSOES_PJ_INCORRETAS
- PERMISSAO_PF_PJ_EM_CONJUNTO
- SEM_PERMISSOES_FUNCIONAIS_RESTANTES
- INFORMACOES_PJ_NAO_INFORMADAS

None of these error codes match the official 422 error code array for the API.
