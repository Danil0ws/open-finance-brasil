## 📝 Descrição

# Incorrect `account-data` endpoint path in API Discovery — MockBank

## Current Behavior

The MockBank authorization server publishes the Credit Portability API (`ApiFamilyType: "credit-portability"`, `ApiVersion: "1.0.0"`) via the Open Finance Brasil Directory with the following discovery endpoint for account data:

```
GET /open-banking/credit-portability/v1/account-data
```

Source — Directory entry for Organisation `74e929d9-33b6-4d85-8ba7-c146c867a817`, `ApiResourceId: 5eeb1686-f41f-4a36-b7b8-2c492be5039d`:

```json
{
  "ApiDiscoveryId": "8234726d-d579-482f-8211-1966c45cf53d",
  "ApiEndpoint": "https://matls-api.mockbank.poc.raidiam.io/open-banking/credit-portability/v1/account-data"
}
```

## Expected Behavior

According to the [Open Finance Brasil Credit Portability API specification v1.0.0](https://openbanking-brasil.github.io/openapi/swagger-apis/credit-portability/1.0.0.yml), the account data endpoint path is:

```
GET /open-banking/credit-portability/v1/portabilities/{portabilityId}/account-data
```


The `/portabilities/{portabilityId}` segment is missing.

## Evidence

| Item | Value |
|------|-------|
| Organisation ID | `74e929d9-33b6-4d85-8ba7-c146c867a817` |
| Authorisation Server ID | `c8f0bf49-4744-4933-8960-7add6e590841` |
| Api Resource ID | `5eeb1686-f41f-4a36-b7b8-2c492be5039d` |
| `ApiFamilyType` | `credit-portability` |
| `ApiVersion` | `1.0.0` |
| Endpoint published in Directory | `/open-banking/credit-portability/v1/account-data` |
| Correct endpoint per OFB spec | `/open-banking/credit-portability/v1/portabilities/{portabilityId}/account-data` |
