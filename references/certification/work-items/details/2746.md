#### Current Behavior:

---

The tests listed below are currently failing in the consent creation requests with a 422 error. This error indicates that the requests sent to our API contain an invalid field, specifically **`data.payment.purpose`**, which should not be included according to the v4 contract.

#### Expected Behavior:

---

The expected behavior is that the FVP tool should correctly create consent requests and receive a 201 status code. Since the **`data.payment.purpose`** field is not part of the v4 contract, the tool should refrain from including it in the requests. Proper configuration of the FVP tool should ensure that it adheres to the defined API contract, allowing for successful consent creation.
