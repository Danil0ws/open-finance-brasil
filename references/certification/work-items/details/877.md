## 📝 Descrição

## 1. What Happened and what were you expecting?

The `transactionUnitPrice` object on transactions endpoint, API Variable Incomes is mandatory when `transactionType` = "COMPRA" ou "VENDA". However the test is requesting this value as mandatory when `transactionType` is neither those 2 values, as shown below:

![image](/uploads/a70ef3c23153f086f20c542798485310/image.png)

![image](/uploads/188ce6dc36af8bc82140020b0035ed15/image.png)
 
Swagger reference: https://openbanking-brasil.github.io/draft-openapi/swagger-apis/variable-incomes/1.0.0.yml
