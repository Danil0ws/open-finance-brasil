Hi,

Thanks for creating this issue!

The execution of this test module resulted in failure due to TimeOut.

While Conformance Suit expected the payment status to change to SCHD it executed 5 rounds of Get requests,

Before the fifth pooling sequence could end, the pooling sequence reached it's timeout.

After internal tests we were able to verify that test module is working as expected, you can access a successful execution trough the link:

https://web.conformance.directory.openbankingbrasil.org.br/log-detail.html?log=2DFT6IT1FTAyQou&public=true

Make sure that First payment transitions to SCHD state is reached before pooling sequence timeout is reachedm
