## 📝 Descrição

## 1. What Happened and what were you expecting?

In payments_api_x-fapi_test-module_v3, step `Ensure error when calling POST Payments without x-fapi-interaction id`, a request to POST /payments/v3/pix/payments is made using a client_credentials token, instead of authorisation code.

So, in our side we return a 401 instead of a 400 because an authorization_code token should be used when calling this endpoint.
