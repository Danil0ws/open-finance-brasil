Hi Andreina! Thanks for the ticket!

The second 401 message is expected since the security schema for this endpoint should only accept authorization_code, as specified at the [swagger](https://openbanking-brasil.github.io/openapi/swagger-apis/consents/2.2.0-rc.1.yml):

security: 

* OAuth2AuthorizationCode: 
  * openid
  * 'consent:consentId'

Therefore, when a request to this endpoint is made using a client credentials token, a 401 should be expected.

We are happy o help with any additional needs!
