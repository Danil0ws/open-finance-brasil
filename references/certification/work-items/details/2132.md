## 📝 Descrição

#### Current Behavior:
---

Good afternoon.

When accessing the endpoint for consuming Raidiam data through the endpoint (customers/v2/personal/identifications), the data related to the field `otherNationalitiesInfo` is returning a boolean value instead of a string indicating the nationality.

There is also an issue regarding the date filter. When a date is provided, for example, 2025-03-17, no data appears for the CPF used, which is 76109277673.

It follows the consentId for better issue analysis:
`urn:raidiambank:56d3c0a9-b070-48d6-8935-19b0e44e2e48.`

#### Expected Behavior:
---

According to the specs ([API Customers v2.2.0](https://raw.githubusercontent.com/OpenBanking-Brasil/openapi/main/swagger-apis/customers/2.2.0.yml)), it is expected that the field returns a string indicating all other nationalities the client may have, using the country code according to the ISO-3166 alpha3 code, e.g. ‘CAN’.

Hi,

This is indeed an issue in the Mock Bank response, and we will correct it to provide a valid nationality code in the MB response.

Regarding the reported date filter error, the spec does not define any date filter parameter for this endpoint, so the reported issue seems not to be a problem.

Here it is important to note that the following points require clarification for the WG to decide:

1. The spec states that the field `otherNationalitiesInfo` must be filled if the client has no Brazilian nationality, listing all additional nationalities using ISO alpha3 codes. However, the spec does not clarify how multiple values should be represented (comma, space, etc.), which may cause interoperability issues.
2. The spec defines conditionality differently from the usual pattern, as it does not include the `[Restrição]` tag, which is typically present in such cases.

To address these points, we suggest the following spec improvements:

1. Define the field as an enum or specify how multiple values should be represented to avoid ambiguity.
2. Add `[Restrição]` to align with standard conditionality rules and adjust the engine accordingly.

We kindly ask for WG clarification on the points mentioned.
