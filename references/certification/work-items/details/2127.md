The test failed because the field `data.riskSignals.automatic.lastLoginDateTime` is incorrectly formatted as: 

![image](/uploads/02ff87969e87d997265507c36c066de4/image.png)

According to the specification ([API Automatic Payment v2.0.0-rc.1](https://raw.githubusercontent.com/OpenBanking-Brasil/openapi/main/swagger-apis/automatic-payments/2.0.0-rc.1.yml)) the expected pattern should be:

![image](/uploads/4333cbd4fd28cd5467a9b855128b57cd/image.png)

Therefore, there is no corrections on the MB side. To a successful execution, the implementation needs to be adapted so that all the fields sent in the request are conformant to the API swagger.
