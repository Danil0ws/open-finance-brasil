According to what is determined in [API Payment Initiation specification](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/347079010/Informa+es+T+cnicas+-+SV+Pagamentos+-+v4.0.0):

> **2. Validações na criação do pagamento - Síncrono (_POST /payments_)**
>
> 2.2 **Casos de erro sintáticos e semânticos, previstos com retorno HTTP Code 422 - Unprocessable Entity (detalhamento adicional na documentação técnica da API):**
>
> 2.2.1 **Sintáticos**
>
> 2.3.1.1 Envio de campos obrigatórios: Valida se todos os campos obrigatórios são informados (PARAMETRO_NAO_INFORMADO);
>
> 2.3.1.2 Formatação de parâmetros: Valida se parâmetros informados obedecem a formatação especificada (PARAMETRO_INVALIDO).

Given that consentId has the following restriction:

**consentId:** \[Restrição\] Este campo é de preenchimento obrigatório quando o valor do campo authorisationFlow for igual a FIDO_FLOW.

Therefore, correct expected error code is in fact PARAMETRO_NAO_INFORMADO.

Conformance suit is validating erro code correctly. Test summary will be changed in order to reflect Conformance Suit behavior
