## 📝 Descrição



Observed Behavior:
The transactions and transactions-current endpoint of the funds API returned an error due to the incorrect use of the parameters fromTransactionDate and toTransactionDate, instead of fromTransactionConversionDate and toTransactionConversionDate.

Error on GET funds/v1/investments
errors":[{"code":"400","title":"Bad Request","detail":"A requisição foi malformada, omitindo atributos obrigatórios, seja no payload ou através de atributos na URL.

Expected Behavior:
The endpoint should accept the parameters fromTransactionConversionDate and toTransactionConversionDate, as specified in the technical documentation, allowing for the correct query of transactions.
