## 📝 Descrição

CURRENT BEHAVIOR

Sweeping startDateTime is set with ZonedDateTime.now(UTC) when the recurring configuration object is built (AbstractCreateRecurringConfigurationObject.getStartDateTime), during resource endpoint setup, before the long enrollment journey.

Several minutes may pass before the real POST recurring-consents and the value is not refreshed immediately before the POST.

![image.png](/uploads/eec97e3d8fd7ae851e8c916c43ad3852/image.png){width=900 height=295}

![image.png](/uploads/e4d0bd248b14c4d2c13220c7a378c5ff/image.png){width=343 height=600}

An ASPSP that compares startDateTime to server time at receipt returns 422. The test fails on the step expecting 201 and never reaches the intended sign-options step.
