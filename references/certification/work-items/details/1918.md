## 📝 Descrição

**Description**:

It was identified that the riskSignals field is marked as mandatory, but there is a restriction stating that it would only be mandatory for the Automatic Pix scenario. 

https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/718406041/Informa+es+T+cnicas+-+SV+Pagamentos+Autom+ticos+-+v2.0.0-beta.2

![image](/uploads/dea3c0766753e850b563d6a1f943790b/image.png)

However, this seems contradictory, considering the following points discussed:

- Consent editing is exclusive to Automatic Payments (Automatic Pix), so the field would always be necessary.
- The current restriction does not make sense because, in practice, the field should not be mandatory outside this scenario, but it is currently treated as such.

**Suggested actions**:

Review the mandatory rule for the riskSignals field to align it with the correct scenario.
Correct the documentation or field validation to eliminate inconsistencies.
