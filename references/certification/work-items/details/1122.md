## 📝 Descrição

## 1. What happened and what were you expecting?
The test is failing when it validates if the API Endpoints on Auth Server json matches one of the defined endpoints in regex expressions.

There is the following endpoints registered on Auth Server:
 - https://mtls.of.c6bank.com.br/open-banking/payments/v3/consents
 - https://mtls.of.c6bank.com.br/open-banking/payments/v3/consents/{consentId}
 - https://mtls.of.c6bank.com.br/open-banking/payments/v3/pix/payments
 - https://mtls.of.c6bank.com.br/open-banking/payments/v3/pix/payments/{paymentId}

I think the regex expressions can be a problem if applied on the string json, because there are requirements to start and to end in them.
