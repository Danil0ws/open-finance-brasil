## 1. What happened and what were you expecting?
When created consent was send transaction limit out of object periodic_limits
"recurringConfiguration": {
      "sweeping": {
        "periodicLimits": {
          "day": {
            "quantityLimit": 2,
            "transactionLimit": "500.00"
          },
          "year": {
            "transactionLimit": "600.00"
          }
        },
        "totalAllowedAmount": "600.00",
        "transactionLimit": "400.00"
      }
    },
When calling the payments API, the transaction limit is global and is not contained in the periodic limit, therefore the error should not be about exceeding the periodic limit

These errors are only related to periodic limits
 4.2.2.11 Limite valor excedido por período: Foi atingido o valor limite permitido pelo usuário por um determinado período de tempo no consentimento do pagamento (LIMITE_PERIODO_VALOR_EXCEDIDO);
