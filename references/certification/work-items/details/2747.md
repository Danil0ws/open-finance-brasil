#### Current Behavior:

---

The test below is currently failing in the consent creation requests with a 422 error. This error indicates that the requests sent to our API contain an invalid field, specifically **`data.payment.schedule.custom.additionalInformation`**, which should not be included according to the v5 contract.

#### Expected Behavior:

---

The expected behavior is that the FVP tool should correctly create consent requests and receive a 201 status code. Since the **`data.payment.schedule.custom.additionalInformation`** field is not part of the v5 contract, the tool should refrain from including it in the requests. Proper configuration of the FVP tool should ensure that it adheres to the defined API contract, allowing for successful consent creation.
