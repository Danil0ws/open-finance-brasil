## 1. Question

The conformance suite is currently evaluating a happy scenario for PIX Scheduled test where we will
- Request user Consent over a Scheduled PIX Payment for a future date
- POST Payments over an authorized Consent Request 
- Pool GET Payments endpoint for x minutes until it arrives at a given state. 

In the Cycle 1 and 3 tests, this state was ACCC and it should have been accepted within 5 minutes. We understand this here won't be the case as we will still on a date before the settlement date 

With this in mind, For this new Cycle we are not sure if we can also expect the payment to arrive at either SASP 
or SASC within 5 minutes or it can still continue at PNDG?
