Hi,

Thanks for opening the ticket.

Test module execution failed during step:

**Calling resource endpoint without x-fapi-interaction-id**

When **GET business/identifications** was called without **x-fapi-interaction-id** and authorization server returned a **200 OK.** 

As can be seen in image below, this is the request made by the Conformance suit:

![image.png](/uploads/a592a00bcc70d91ce217269320bff9ec/image.png)This is the response by Authorization Server:

![image.png](/uploads/ad371fa90a08c3b4586bab45559877bb/image.png)While conformance suit is validating response from Authorization server, it executes another **GET /business/identifications** call to validate correct implementation of Self Link Field. During this second **GET /business/identifications** request it sends **x-fapi-interaction-id** as expected. 

Later it executed the following validation:

EnsureResourceResponseCodeWas400

Which is where it fails execution, given response to first **GET business/identifications** was not as expected.

Conformance suit is operating as expected in this regard. Make sure that Authorization server returns the correct error code when **x-fapi-interaction-id** is not sent on request.
