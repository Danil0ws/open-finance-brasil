## 1. What Happened and what were you expecting?
The test expected a success status `201`, but in the request body sended to create a consent, the `proxy` has the value `"cliente-a00001@pix.bcb.gov.br"` and the QRES sended is related with this proxy `"key": "+5561990010001"`

Because of this divergence, the request is failing, and we are returning a `422` with the code `DETALHE_PAGAMENTO_INVALIDO`

Do you guys have other understanding about this validation?
