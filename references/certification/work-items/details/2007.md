Hi,

After thorough investigation it was found that the generation of certificate fails due to missing prefix:

```
-----BEGIN CERTIFICATE-----
```

and  suffix:

```
----END CERTIFICATE-----
```

Please make sure to add those to Configuration on the Certificate field to be able to run test sucessfully.

Happy to help!
