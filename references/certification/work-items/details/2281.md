Hi @fabricio.cardoso1 

According to [RFC 4122, Section 3](https://datatracker.ietf.org/doc/html/rfc4122#section-3):

> _“The hexadecimal values ‘a’ through ‘f’ are output as lower case characters and are case insensitive on input.”_

This means that when parsing UUIDs, input must be accepted regardless of letter case (upper, lower, or mixed). The value we are sending is a valid UUID under RFC 4122.

The `400 Bad Request` indicates that the server is rejecting the value due to mixed case. This is stricter than the RFC’s requirements.
