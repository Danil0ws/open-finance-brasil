## 📝 Descrição

## 1. What happened and what were you expecting?

Currently, there is uncertainty regarding the specific field that should be used for pagination in two key endpoints within the Phase v2-1 APIs, leading to participants confusion. It is crucial to provide clear instructions about which object should be validated for pagination purposes at the following Phase v2-1 API endpoints:

* GET `/contracts/{contractId}/scheduled-instalments`
* GET `/contracts/{contractId}/payments`

In particular, the `scheduled-instalments` endpoint currently accepts an optional object (`balloonPayments`) for validation, further adding to the ambiguity. Additionally, there is a need for clarification on the expected behavior when pagination objects are not included
