Hi,

Thanks for opening the ticket!

Test module execution failed due to the following reason:

→ Conformance suit executed step: **Call the GET Identifications Endpoint without the x-fapi-interaction-id**

→ Authorization server response: response_status_code **200 OK**

As no x-fapi-interaction-id was sent, correct response would be a response_status_code 400.

Given that Authorization Server returned wrong status code, conformance suit proceeded to verify and validate the payload of the response. While doing this, conformance suit typically verifies the Self link field in meta by making a GET request to it. Thus expecting a 200 response for the GET request of the endpoint contained within self link field.

To ensure test module is executed as expected, please make sure that correct status code is received when endpoint is called without **x-fapi-interaction-id.**
