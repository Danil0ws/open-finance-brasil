## 📝 Descrição

## 1. What Happened and what were you expecting?
During the steps below, only one `fromTransactionDate` and `toTransactionDate` parameter are expected. However, CS sends these parameters in the request more than once.

Steps:
- _GET Investments Transactions endpoint with fromTransactionDate=D-180 and toTransactionDate=D+0_
- _GET Investments Transactions endpoint with fromTransactionDate=D-360 and toTransactionDate=D-180_
- _GET Investments Transactions endpoint with both query parameters set to save value_
