## 📝 Descrição

#### Current Behavior:

---

No cenário **fvp-optimised-journey_enrollments-balances_test-module-v1**, foram identificados dois comportamentos inesperados na chamada GET para o endpoint _resources_:

1. **Content-Type inválido:** a requisição está sendo enviada com `Content-Type: text/plain`, o que não é compatível com os padrões esperados por esta API.
2. **Payload inesperado no corpo da requisição:** está sendo incluído um payload JWT no _request body_, o que também não é um comportamento previsto para este endpoint.

#### Expected Behavior:

---

O comportamento esperado é o envio de uma requisição GET padrão, **sem** `Content-Type` e **sem** _request body_, seguindo o mesmo padrão das demais chamadas do plano.
