Olá, @M-Petra-FN ,

Obrigado por abrir o chamado e informar o log como evidência.

Sobre o campo resourceUrl: no formulário de configuração deste plano não existe esse campo. O único dado que o teste pede é o Authorisation Server ID (conforme imagem), e é a partir daí que localizamos  os endpoints no Diretório.

Provavelmente os dados de resourceUrl vieram de um JSON previamente montado com diversas outras informações.

Como o teste sempre resolve os endereços pelo Diretório, esse campo não tem efeito neste cenário, e por isso ele não é disponibilizado. 

Analisando o log, a primeira API funcionou normalmente. A falha ocorreu na segunda API, bank-fixed-incomes, com a mensagem "Unable to locate resource endpoint to continue". Isso indica que a instituição ainda não publicou no Diretório o endpoint de opendata-investments/bank-fixed-incomes na versão 1.x (ou está registrado em uma versão fora do padrão esperado).

Como o teste exige as duas APIs, ele foi interrompido ao não encontrar a segunda. Para que o teste passe, basta publicar/registrar no Diretório a API bank-fixed-incomes (v1.x), da mesma forma que já foi feito com a API de funds. 

Após esse cadastro, o teste conseguirá localizar o endpoint automaticamente e prosseguir. 

Qualquer dúvida, estamos à disposição para ajudar.
