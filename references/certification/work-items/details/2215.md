## 📝 Descrição

Hi, the credit-portability_api_core_test-module_v1 test is using a incorrect creditor CNPJ (institution.creditor.companyCnpj property) in POST /portabilities execution. The test is using the number 21128159000166, but it should use the number retrieved of GET /loans/v2/contracts. Our application deny the request because the number of creditor CNPJ doesn't match institution CNPJ.

#### Expected Behavior:

Our understanding is the test use companyCnpj retrieved of /loans/v2/contracts and pass to institution.creditor.companyCnpj property of POST /portabilities execution.

Hi WG,

**Identified Issue:**

The participant reported that the execution of `POST /portabilities` in the test is using an incorrect value for the `institution.creditor.companyCnpj` property.

* **Value used by the Conformance Suite (CS) in `POST /portabilities`:** `21128159000166`
* **Value returned by the participant's API (`GET /loans/v2/contracts`) for the creditor institution's `companyCnpj`:** `07237373000120`

**Context and Question:**

The participant understands that the `companyCnpj` in `POST /portabilities` should be populated with the value retrieved from the `GET /loans/v2/contracts` endpoint, ensuring data consistency.

The [specification](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/950861986/Informa+es+T+cnicas+-+PC+Portabilidade+de+Cr+dito+-+CPC+-+v1.0.0-beta.2) for the `companyCnpj` field indicates: "Full CNPJ number of the institution responsible for the Registration - the CNPJ corresponds to the registration number in the Legal Entity Register. Only the CNPJ numbers should be provided, without mask."

**We request the GT to evaluate and clarify the expected behavior for the `institution.creditor.companyCnpj` field in the `POST /portabilities` payload within this test (`credit-portability_api_core_test-module_v1`):**

1. Should the test, in fact, extract and use the `companyCnpj` returned by the participant's `GET /loans/v2/contracts` endpoint to ensure consistency with the creditor institution's data?
2. What should be the Cnpj provided for Proposing?
