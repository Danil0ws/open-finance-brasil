## 📝 Descrição

#### Current Behavior:
---
We identified a problem with the swagger documentation for the [Consents API v3.0.1](https://openbanking-brasil.github.io/openapi/swagger-apis/consents/3.0.1.yml). Specifically, in the POST `/consents/{consentId}/extends` endpoint, the swagger lists the field `permissions` as required under the object `CreateConsentExtensions`. However, this item is not actually included in this object's `properties`, as seen below:

![image](/uploads/cbf03628293885751ba47f6711a60532/image.png)

What should be the expected behaviour here? Should `permissions` be removed as required for the body of POST `/consents/{consentId}/extends` or should it be added in the `properties` expected for this endpoint?
