1. What Happened and what were you expecting?


When the Resources (/resources) API is called it is returning:

{
            "resourceId": "5250435f-e456-419e-af92-a960a0fbca51",
            "type": "CREDIT_CARD_ACCOUNT",
            "status": "AVAILABLE"
        },

When calling the CreditCardAccount API in /accounts it is returning:

"data": [
        {
            "creditCardAccountId": "PIITR3459087",
            "brandName": "Sib Bank",
            "companyCnpj": "40156018000100",
            "name": "Dinners Grafite",

When trying to access specific card data, it is only possible via ID ""creditCardAccountId": "PIITR3459087"".

The ID returned in /resources should be the same as the one returned in the cards api.
