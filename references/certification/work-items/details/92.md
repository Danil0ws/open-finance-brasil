@ErickDomingues - for interoperability there must be consistency. Either the banks must accept cnpj initiators that isn’t the client ID owner or they must not, you can’t have inconsistency in behaviour.

The majority of banks accept cnpj “on behalf of functionalitty” indeed, the initial requirement was for banks to support any cnpj initiator provided they were on the directory. This was changed to “to do bot validate” and so banks should not validate.

If we change this test to align the cnpj initiator we must add a new test with the existing behaviour so that this inconsistency is identified and fixed at an ecosystem level,

You can’t have TPPs being able to make payments “on behalf of” with only half of the banks in brazil accepting them.
