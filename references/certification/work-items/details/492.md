## 📝 Descrição

Test **payments-api-qrdn-good-proxy-test** will always fail because the endToEnd Id is being generate with a '00000000' ispb: 

The hard coded variable is at: 
```
class:  DictHomologKeys
public static final String PROXY_E2EID_ISPB = "00000000";
```

As our payments system checks if entToEnd is correct we throw an error. We expect the ISPB to be the same as the payment initiator in the pix-tester environment. In our vision, we should not have to ignore a wrong endToEndId for this test to pass.
