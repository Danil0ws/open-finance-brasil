On our side we are getting your URI and changing the order on which the parameters are sent

Self you returned on your GET is: 

https://trust-openbanking-h.api.santander.com.br/open-banking/accounts/v2/accounts/5d4352f9fe55e64790c6c3eeb5e0ee417acc0901cb0fc246d99ee6073d22e0ff/transactions?pagination-key=7912a654-bce9-494f-9318-3ac2679456ae?toBookingDate=2022-09-22&fromBookingDate=2021-09-27&pagination-key=7912a654-bce9-494f-9318-3ac2679456ae&page=1&page-size=25

Which contains:

- ?pagination-key=7912a654-bce9-494f-9318-3ac2679456ae
- ?toBookingDate=2022-09-22
- &fromBookingDate=2021-09-27
- &pagination-key=7912a654-bce9-494f-9318-3ac2679456ae
- &page=1&page-size=25

Our request send the exact same parameters in a different order:

Our request URI:

https://trust-openbanking-h.api.santander.com.br/open-banking/accounts/v2/accounts/5d4352f9fe55e64790c6c3eeb5e0ee417acc0901cb0fc246d99ee6073d22e0ff/transactions?pagination-key=7912a654-bce9-494f-9318-3ac2679456ae?toBookingDate%3D2022-09-22&pagination-key=7912a654-bce9-494f-9318-3ac2679456ae&fromBookingDate=2021-09-27&page=1&page-size=25

Which contains:

- ?pagination-key=7912a654-bce9-494f-9318-3ac2679456ae
- ?toBookingDate%3D2022-09-22
- &pagination-key=7912a654-bce9-494f-9318-3ac2679456ae
- &fromBookingDate=2021-09-27
- &page=1&page-size=25


So the same parameters on different order.

We can work on changing the order but i don't think it will solve the issue. Can you give a double check on the self link you return?
