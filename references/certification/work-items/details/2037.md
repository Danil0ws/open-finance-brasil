The test failed because the token has an expiration time of 300 seconds, and the test is taking longer to execute due to the time the server is taking to update the status. This is causing an extended polling phase, leading to token expiration before the test completes.

To address this, we will improve the test so that a new client credentials token is issued before polling begins, ensuring a smoother execution.

Let us know if you have any questions, and we appreciate your patience while we implement this improvement.
