## 📝 Descrição

## 1. What happened and what were you expecting?

The `payments_api_qrdn-with-qres-code_test-module_v3` is failing because it incorrectly expects an authorization code within the parameters sent back to the CS after the redirect. As shown below:

![image](/uploads/95b913c93faa8f6ebcca2ddd9f50fcb2/image.png)

Test summary is clear to mention the expected behaviour:

> * Redirects the user to authorize the created consent
> * Ensure an error is returned **and that the authorization code was not sent back**
