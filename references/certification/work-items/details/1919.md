## 📝 Descrição

Description:

 During the consent editing process for recurring payments, we identified two specific issues related to the creditors object:

1. Updating the name field without updating cpf/Cnpj:
    * When changing the name (e.g., from "NET" to "CLARO") within the creditors array during a PATCH request for consent editing, the associated cpfCnpj (CNPJ/CPF) remains unchanged.
    * This raises the question: Shouldn't the cpfCnpj field also be updated when the name field is changed? 
2. Impact on firstPayment configuration:
    * The firstPayment object contains payment-related details, including account information.
    * If a creditors update occurs (e.g., changing the recipient name and potentially the CNPJ), should the firstPayment configuration also be updated to reflect the changes? 

Specification Reference:

https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/718406041/Informa+es+T+cnicas+-+SV+Pagamentos+Autom+ticos+-+v2.0.0-beta.2

* POST /recurring-consents:
    * creditors object includes mandatory fields: personType, cpfCnpj, and name.
    * Restriction: For automatic Pix products, only one creditor (PJ) is allowed.
* Fields:
    * name (string, maxLength: 120)
    * cpfCnpj (string, pattern: ^\d{11}$|^\d{14}$) 
    
Questions for Clarification:
1. When editing the name field in the creditors object, should the associated cpfCnpj also be updated to maintain data consistency?
2. If creditors are updated, should the firstPayment configuration (e.g., account information) also be updated accordingly? 

Expected Behavior:
* Clarify whether changes to the creditors object require corresponding updates to cpfCnpj and the firstPayment configuration.

Prezado,
Agradecemos o apontamento.
1) Ao editar o campo nome no objeto de credores, o cpfCnpj associado também deve ser atualizado para manter a consistência dos dados?
R: É permitida apenas a edição do nome do recebedor para o caso de mudanças de marca, fusões, etc. Porém, caso o CNPJ seja alterado, será necessário a criação de um novo consentimento.

2) Se os credores forem atualizados, a configuração do firstPayment (por exemplo, informações da conta) também deve ser atualizada de acordo?
R: Não. A atualização do nome do credor não implica em alterações no objeto firstPayment, uma vez que a atualização é apenas de nome, e não de CNPJ.
