Authorization headers are the headers used to authenticate the client, there the only header within the scope is the authorization one, since it has the token used to access the api.

Regarding all the other headers, they should follow what was defined in:

The appropriate working group has been working on improving the documentation to make this matters clear.

After analyzing the test module provided, Given the definition of a 401 response_status_code in the spec is as follows: 

[en] 401 - Missing/invalid authentication header or invalid token

[pt] 401 - Cabeçalho de autenticação ausente/inválido ou token inválido

It can be stated that the conformance suit is operating as expected and no changes are required on it. 

To ensure a successful execution of the test module, please be sure to: 

- Respond with 401 response_status_code when a request is made missing a required header.
