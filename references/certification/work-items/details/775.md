Thanks for the ticket!

The `dcr_api_dcm-pagto-remove-webhook_test-module` does so because this test module is meant to ensure that the tested institution accepts a DCM request to remove the webhook notification endpoint. Therefore, we validate that the webhook notification endpoint has been removed - that meaning it should not be called.
