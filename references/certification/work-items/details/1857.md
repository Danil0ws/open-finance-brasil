Hi Larissa,

Thanks for the ticket.

Have you done the validation using your local terminal, or have you used any other stack to do the ocsp validation.

For testing purposes, I would like to ask you to run this command in your terminal using the certificate generated on sandbox:

openssl ocsp -issuer chain.pem -cert certificate.pem -url http://ocsp.pki-g2.sandbox.directory.openbankingbrasil.org.br -header Host=ocsp.pki-g2.sandbox.directory.openbankingbrasil.org.br -no_nonce

If it doesn't work, could you please provide the certificate you are using and the commands executed for validation?

Also, this subject was discussed in another a while ago. I would recommend you to go through the discussion to see if it could help you around that https://gitlab.com/raidiam-conformance/open-finance/certification/-/issues/1207
