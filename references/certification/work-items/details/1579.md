## 📝 Descrição

## 1. What happened and what were you expecting?
In the resources_api_unavailable_test-module_v3 test there are multiple validations that probably are incorrect.

The test description says the following:
• Depending on the unavailable resource, call one of the following APIs depending: (1) /contracts/{contractId}/warranties for credit operations, (2) /accounts/{creditCardAccountId}/bills for credit cards, or (3) /accounts/{accountId}/balances for accounts
• Expect a 403 - Validate that the field response.errors.code is STATUS_RESOURCE_TEMPORARILY_UNAVAILABLE / STATUS_RESOURCE_UNAVAILABLE

But what is happening is:

There are **two status code** validations

EnsureResponseCodeWas200 - Received the expected 200 response status.

EnsureResponseCodeWas403 - Expected a 403 response.

Also, there is mention of an **DEPRECATED** step:

DEPRECATED_DO_NOT_USEErrorValidator
Referencing $.errors in the response from the DEPRECATED_DO_NOT_USEErrorValidator API.

Hi,

Thanks for opening the ticket!

The test module execution failed while ensuring unavailable resource cannot accessed. When GET accounts/{accountId}/balances was called, a 403 response_status_code was expected but a 200 was provided. As the Server returned a 200 with a Payload, conformance suit proceeded to validate payload's fields such as self link, while doing so, validating the self link involves calling the self link url and ensuring it is the same as the one used in the GET request, thus expecting a 200 and thereafter expecting the GET accounts/{accountId}/balances to be a 403, which it does correctly.  Therefore the test module would have failed regardless of the deprecated validators as a incorrect response status code was provided.

To run the test successfully make sure that a 403 response_status_code is sent when a GET call is made to access a unavailable resource.

Although the test can be executed successfully provided a 403 code is sent on the response for GET accounts/{accountId}/balances, we will make sure the deprecated validators are switched to new ones.
