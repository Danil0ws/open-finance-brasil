Hi Gutemberg,

Thanks for the ticket.

The handshake_failure error happens when the directory can't verify the certificate being used. In this case there was an instability from the Certificate CA, leading to the referred failure.

Despite the failure in this test due to the handshake, no ticket is supposed to be opened for failures resulted from this type of issue. If a ticket was opened for you organization it is probably because the server failed in another test module as well.

If you think a ticket was opened by mistake let us know so we can investigate.
