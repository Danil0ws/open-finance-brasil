## 📝 Descrição


The fvp-customer_data_unique_happy_path_test-module is currently making a request to the transaction-current endpoint with the fromTransactionDate parameter set to D-360. This value is outside the business rules specified in the Open Finance Brasil documentation.

As described in the Open Finance Brasil documentation:

Data inicial de filtragem. O período máximo utilizado no filtro é de 7 dias inclusive (D-6).
[Restrição] Deve obrigatoriamente ser enviado caso o campo toTransactionDate seja informado. Caso não seja informado, deve ser assumido o dia atual.
The test module should align with these business rules by:

Ensuring the fromTransactionDate value does not exceed D-6.
Sending the fromTransactionDate parameter only if toTransactionDate is provided.
Steps to Reproduce:

Run the fvp-customer_data_unique_happy_path_test-module.
Observe the request sent to the transaction-current endpoint.
Note that the fromTransactionDate parameter is set to D-360.
Expected Behavior:
The fromTransactionDate parameter should adhere to the documented business rules.
