Hello @joao.oliveira24. Thanks for the details.

The root cause is the test configuration being used in your run. In this config, the scope `payments` appears to have been manually added in the **JSON tab**. For the [Optimised Journey](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/1129250817/Orienta+es+Gerais+-+JO+Jornada+Otimizada+v1.0), this scope is not required, and it’s also not expected that scopes are edited directly in the JSON to run Conformance Suite Tests.

![image.png](/uploads/7b5d7726749ba8dae432e4e670bf306c/image.png){width="623" height="158"}

This also explains why there is no field in the test configuration UI to fill scopes. The intended approach is to keep the config within the supported fields and not add extra keys manually, because these changes can affect the behavior.

To fix the issue, please remove the custom scope from the config JSON and rerun the module using the standard config only.

![image.png](/uploads/6d7bc0d77829940266872a79b80f70ef/image.png){width="213" height="80"}

For reference and to illustrate the expected behavior, we also share a successful execution against the Mock Bank for the same module:

[test-log-optimised-journey_automatic-pix_test-module-v1-9t5SzfvSxof7egM.html](/uploads/8317ed34e0d89e9292a4a270a8aa23ad/test-log-optimised-journey_automatic-pix_test-module-v1-9t5SzfvSxof7egM.html)
