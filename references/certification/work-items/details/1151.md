Hi Cássio,

Thanks for the ticket. The issue in the directory is being fixed and you should be able to register the endpoints next week.

Meanwhile, there are two ways you could still execute the tests:

1. **Register only the first endpoint of the API in the directory.**
   The exchanges/v1/operations is available to publish if you only select this option, as in the image below
   ![image](/uploads/4da69c34c52ee17faef3c83b22643966/image.png)

2. **Include the consentUrl in the configuration of the test plan.**
   If you add the consentUrl: 'https://www.example.com/open-banking/exchanges/v1/operations in the configuration, the test module will retrieve the endpoint from there.

I believe both ways could unblock you from the issues you are facing from now. Let us know if it doesn't.
