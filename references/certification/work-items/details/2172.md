## 📝 Descrição

Test: accounts_api_operational-limits_test-module_v2-4

Error:

`Array from element data is more than the required maxItems on the EnsureOnlyOneRecordWasReturned API response`


According to the specification:

"Para as APIs de Dados Cadastrais e Transacionais, o comportamento esperado da transmissora/detentora é que o page size mínimo é 25 e o máximo é 1000, exceções se aplicam a primeira página, quando for única, e a última página." 

https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/17377470/Pagina+o
