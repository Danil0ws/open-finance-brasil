## 📝 Descrição

As discussed during our 2 last meetings we would like to check if we can already start the development of Phase 3 functional conformance Tests, using the 1.0.0 rc 5.0.1 specs on https://openbanking-brasil.github.io/areadesenvolvedor/#fase-3-apis-do-open-banking-brasil

The specs are not yet frozen, however, we consider we already have a very stable version on our portal that we understand that can be already developed against. In fact, the only thing that we are currently evaluating is adding a third way to initiate payments.
 
Looking at this, we currently have three ways of payment initiation for PIX which might be inside the scope of the API:
	• Manual Insertion (Inserção Manual)
	• PIX Keys (Chaves PIX)
	• Receiver Insertion (Iniciação Recebedor)

We have already developed the API for both Manual Insertion and PIX Keys. The receiver insertion method is currently being evaluated by the Specs team and they have not yet come to the conclusion that they are going to be deployed. This decision will be taken this Friday during the board meeting.

Supposing we freeze the specs this Friday (or at the beggining of next week) we also would like to propose the following timelines:

Specs Freeze: 16/07 (To be Defined)
Beta Release: 02/08
Final Release: 15/08 
Certification Start: 16/08
Limit date to send the functional conformance certification request: 23/08
Go-Live: 30/08

Please let me know what you think about the above timelines.
