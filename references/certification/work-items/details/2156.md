Hi @rogeriorocha083 

Based on our analysis of the issue, the API response is behaving as expected. However, there appears to be an inconsistency in the pagination logic implemented in your request.

Specifically, the Resources API is returning a "next" link even when the response contains the last page of data. According to the Open Finance specification, the "next" link should be omitted when there are no subsequent pages available.

In the example you provided:

`{"data":[{"resourceId":"92792126019929279212650822221989319252576","type":"ACCOUNT","status":"AVAILABLE"},{"resourceId":"XXZTR3459087","type":"CREDIT_CARD_ACCOUNT","status":"AVAILABLE"}],"links":{"self":"https://auth.staging.ofpdev.app-terosopenbanking.com/open-banking/resources/v3/resources","first":"https://auth.staging.ofpdev.app-terosopenbanking.com/open-banking/resources/v3/resources","prev":"https://auth.staging.ofpdev.app-terosopenbanking.com/open-banking/resources/v3/resources","next":"https://auth.staging.ofpdev.app-terosopenbanking.com/open-banking/resources/v3/resources","last":"https://auth.staging.ofpdev.app-terosopenbanking.com/open-banking/resources/v3/resources"},"meta":{"totalRecords":1,"totalPages":1,"requestDateTime":"2021-05-21T08:30:00Z"}}`

The response indicates that totalRecords is 1 and totalPages is 1, meaning this is the only and last page. However, the "next" link is present, which is causing the error.

To resolve this issue, you should review the [pagination](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/17377470/Pagina+o) logic in your application and ensure that the "next" link is omitted when totalPages is equal to 1 or when you are on the last page of the response.
