## 📝 Descrição

Hi, 
In the `payments-contenttype-jwt-refreshtoken-v2` test, there is an assertion for the nonce claim in the id token issued from a refresh request. https://web.conformance.directory.openbankingbrasil.org.br/log-detail.html?log=LJqQuiUKVlntd2g&public=true

Is this expected behavior? There was an errata released by the OpenID Foundation clarifying that the claim can be omitted https://bitbucket.org/openid/connect/pull-requests/341/errata-clarified-nonce-during-id-token

`Fixed #1025 - Clarified that "nonce" should not be present in ID Tokens issued in response to refresh requests.`
