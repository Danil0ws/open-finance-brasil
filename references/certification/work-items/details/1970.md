Hi,

Thanks for opening the issue:

At the beginning test module executes:

> • Call the POST recurring-consents endpoint with sweeping accounts fields

Sending in it's request payload:

```
  },
    "recurringConfiguration": {
      "sweeping": {
        "startDateTime": "2025-01-09T19:47:29Z",
        "totalAllowedAmount": "1.00",
        "useOverdraftLimit": false
      }
```

Then later test executes:

> • Call the POST recurring-payments endpoint with the amount as 0.60 to the selected creditor\
> • Expect 201 - Validate Response

Not sending **riskSignals**.

As this regards a Sweeping Accounts consent, we should indeed send **riskSignals** in Post recurring-payments.

We will work towards a fix for this matter,

Happy to help!
