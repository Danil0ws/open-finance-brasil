## 📝 Descrição

## 1. What Happened and what were you expecting?

One institution has implemented multiple records on their sandbox environment making the resource not return the resource id of the testes api on the first page.

To allow for this institution to execute the test the proposed quick fix is to call a page-size equal to 1000 so we guarantee that all records are shown



## 2. Test Id


https://web.conformance.directory.openbankingbrasil.org.br/plan-detail.html?plan=x7IN272xyYSWL&public=true 

## 3. Requirements

For the 6 xxx-resources-api-test (accounts-resources, financings-resources...), when calling the resources API call it with the query parameter page-size 1000
