## 📝 Descrição

#### Current Behavior:

Hello everyone!

Currently, the `loans_api_x-fapi_test-module_v2-5` is failing incorrectly. The `GetLoansListV2n3OASValidator` is expecting these fields:
- totalPages
- totalRecords

However, following the ChangeLog of the version 2.5.0 of Loans, for the error cases we shouldn't provide the totalPages and totalRecords anymore, only the requestedDateTime field.

#### Expected Behavior:
---

Should pass this test plan without validating `totalPages` and `totalRecords`.
