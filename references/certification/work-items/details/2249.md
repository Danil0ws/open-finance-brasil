Boa tarde prezado,

**O cenário é o mesmo da Issue** #2249  **na API Bank Fixed Incomes:**

* Sua API está retornando um link `links.next` que não aponta corretamente para a próxima página de resultados. Em vez de incrementar o parâmetro `page` (ou equivalente), ele provavelmente está retornando a URL da página atual, ou uma URL que não permite o avanço na paginação.
* Isso faz com que o motor de conformidade continue chamando a mesma página repetidamente.
* Após um certo número de tentativas ou um período de tempo (timeout), o teste falha porque não conseguiu coletar todos os IDs necessários para a comparação ou porque excedeu o limite de requisições.

Para resolver este problema, sua equipe precisa revisar a implementação da paginação em sua API Accounts para garantir que os campos `links.next`, `links.first`, `links.prev` e `links.last` estejam corretamente formatados e que o `links.next` direcione adequadamente para a próxima página de resultados.

É fundamental que sua API siga as especificações de Paginação do Open Finance Brasil (como as encontradas em https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/17377470/Pagina+o) para que o motor de conformidade possa navegar pelas páginas e coletar todos os dados necessários para validar o teste.
