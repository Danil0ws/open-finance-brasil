#### Current Behavior:

---

Currently it is defined on v2.0.0-beta.2 recurring-consents endpoint that field:

**recurringConfiguration.automatic.interval**

is set as optional

We understand that defining the interval during consent creation should be required, as it sets the recurrence for the payment and will be used during other validations that also take  **paymentReference** in to consideration (required field for automatic Pix provided on recurring-payments).

Also analyzing the current swagger, it seems that although field period (v2.0.0-beta.1) was changed to interval (v2.0.0-beta.2), this update did not reflect on **recurringConfiguration required fields on swagger,** as period is still shown:

![image.png](/uploads/090eb3392e8ae0bd4c83512093c6c10d/image.png)

https://raw.githubusercontent.com/OpenBanking-Brasil/openapi/main/swagger-apis/automatic-payments/2.0.0-beta.2.yml

What we need evaluation from WG is:

* Should interval field be required in recurring-consents?
