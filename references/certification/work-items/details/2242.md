Given the FVP is a production environment used for testing real and live implementations from bank this is a sensitive environment and restricted for tests only configured inside the application, with clients and certificates pre configured and stored in a safe place.

For this reason, it is not possible to use the Swagger APIs to create or run test plans from FVP.
