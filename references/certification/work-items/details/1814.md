## 📝 Descrição

We request the creation of new CNPJs with linked CPFs, similar to the existing one CNPJ: 43053510000130. 

The need to make new CNPJs available in our system is fundamental due to the specific configuration of our security key, which is directly linked to a unique combination of account, CNPJ and CPF. When configuring a security key, it may interfere with the configuration of another security key associated with the original CPF.
