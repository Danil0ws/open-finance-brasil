## 📝 Descrição


#### Current Behavior:
When attempting to run the server using Docker, the build fails due to Linux file system case sensitivity. Some references in Java files do not match the expected file paths exactly.

#### Expected Behavior:
The system should build correctly regardless of the underlying operating system, avoiding case sensitivity issues when running on Docker.

#### Evidence:
Changes were made to two Java files to adjust imports with case sensitivity issues. After these changes, the build successfully completed in the Docker environment. The details of the changes are as follows:

1. Adjusted path in the file `AbstractCreditCardApiPageSizeTooLargeTestModule.java`.
2. Adjusted path in the file `CreditCardApiPageSizeTooLargeTestModuleV2n.java`.
