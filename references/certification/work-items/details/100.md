Under https://openbanking-brasil.github.io/areadesenvolvedor/#paginacao

We have that if on the request the page size is superior to 1000 (max value according to the API) the Bank must return a 422 

> Se for requisitado uma quantidade de registros maior que o suportado pela API, o retorno será o código HTTP status code 422 Unprocessable Entity, indicando que o servidor entendeu a requisição, mas não é possível processá-la conforme foi solicitado.

However when we look at the possible error codes on the accounts API, for example, the 422 is not a supported error code: https://openbanking-brasil.github.io/areadesenvolvedor/swagger/swagger_accounts_apis.yaml
