Hi,

Thanks for opening the ticket! The test module execution resulted in failure due to the following reasons:

1. API of family type customers-personal could not be found while conformance suit parsed the AuthServer configuration from participants endpoint, meaning that the customers api has not been registered as a ApiEndpoint for the AuthServer used while executing the test module;
2. Given topic 1, conformance suit had to build Customer Identification endpoint url from the available Consent V3 endpoint url which was provided in the consentUrl on the test config.

In order to execute the test module successfully, please make sure to register the customers API to the AuthServer on the directory so that it can be properly fetched and called during test execution.

Happy to help!
