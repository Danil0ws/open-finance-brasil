There was a recent update on the tests plans and we are now enforcing randomly generated amounts to make sure the QRCodes are not unique anymore.

This has also been reflected on the Mock Bank that is expecting a QRCode with a matching value to be sent.

For a value of 1333.00 on the amount field the following QR code can be used. 

00020126510014BR.GOV.BCB.PIX0129cliente-a00001@pix.bcb.gov.br52040000530398654071333.005802BR5922Marco Antonio de Brito6014BELO HORIZONTE62070503***6304B62D

To change the amount you can parse the QRCode you can use the following tool https://openpix.com.br/qrcode/scanner/

Bear in mind that the 4 last digits are calculated based on the rest of the the QRCODE as noted on https://www.bcb.gov.br/content/estabilidadefinanceira/pix/Regulamento_Pix/II_ManualdePadroesparaIniciacaodoPix.pdf

"Polinômio 0x1021, C.I. 0xFFFF. A ordem dos objetos modifica o CRC."

Please re-open the issue if the problem persists.
