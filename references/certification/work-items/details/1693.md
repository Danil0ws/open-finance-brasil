## 📝 Descrição

We request the availability of new registrations with a variety of CPFs. Today we can only use the CPFs: 76109277673 and 96644087000, however due to a limitation of our business' internal rules we are experiencing difficulties with the amount available. We would like you to make new registrations available, similar to the CPFs mentioned above.

The need to make multiple CPFs available in our system is fundamental due to the specific configuration of our security key, which is directly linked to a unique combination of account and CPF. When configuring a security key, even if it is for a different account using the same CPF, this may interfere with the configuration of another security key associated with the original CPF.
