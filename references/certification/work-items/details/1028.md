## 1\. What happened and what were you expecting?

financings_api_operational-limits_test-module_v2-1 test is incorrectly validating whether the scheduled-payments data array is empty or not and requesting it to have totalRecords and totalPages = 0 if it is empty. 

However, this endpoint is an object and does not have an array, so we understand it should have totalRecords:1 and totalPages:1
