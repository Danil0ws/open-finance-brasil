Hi,

Thanks for opening the ticket!

After analyzing the provided test module, it can be stated that the test module failed due to a invalid self link provided in the response for the GET /operations/{operationId} request. Therefore the conformance Suit is operating as expected.

As defined in the specification, the self link must be “Complete URI that originated the current response”, but the value found by the conformance suit was: 

**"links":{"self":"[https://mtls-api-uat.bvopen.com.br/open-banking/exchanges/v1/operations/{operationId}](https://mtls-api-uat.bvopen.com.br/open-banking/exchanges/v1/operations/%7BoperationId%7D)"}**

The specification can be found in the following link:

https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/262144738/Informa+es+T+cnicas+-+DC+C+mbio+-+v1.0.0-rc.4

To ensure a successfull execution of the test module, please make sure of the following:

- The self link provided in the response is the same as the request_uri
