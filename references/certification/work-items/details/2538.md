Hello @renan.satake1. Thanks for raising this.

As described in the summary, this test expects a 422 ORIGEM_FIDO_INVALIDA response after calling POST /authorise with an invalid origin:

```
{
  "type": "webauthn.get",
  "challenge": "m0g7D8ovPRETQgZnzhc8oidPozqWMqRDfbxv6F8m97k",
  "origin": "INVALID_ORIGIN",
  "crossOrigin": false
}
```

However, your implementation returned **204 No Content**, which is why the test is failing.

Once you add/update the validation to reject invalid origins and return 422 ORIGEM_FIDO_INVALIDA, the test should pass.

Feel free to reopen this issue if you need anything else.
