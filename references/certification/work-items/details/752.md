Hi,

Thanks for the ticket! According to the [Security Specs update](https://github.com/OpenBanking-Brasil/specs-seguranca/blob/main/open-banking-brasil-financial-api-1_ID3.md#authorization-server-1):

```
2. shall only share access to resources when presented with an access_token linked to an active and valid consent;
i. In the Invalid Token Receive scenario, status code 401 should be returned.
```

In that sense, the expected response should only be 401 for the Invalid Token Receive scenario.

That being said, accepting a 403 is indeed an unexpected behavior and we will fix it.
