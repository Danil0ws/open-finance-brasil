Hi,

Thank you for creating the issue!

The observer failure occurred due to the use of an expired token after the polling phase.

When token endpoint is called, a token with a expiration of 300 seconds is generated, during pooling FVP performs multiple Get Request sequences to check if the created payment transitions to the expected ‘ACSC’ status. In your case, three polling sequences were executed before the expected state was reached, If no change is detected, it waits for 30 seconds before attempting another request, after the this pooling sequence,  which resulted in the token expiring afterward.

Could you please ask for re-execution of this test module? Let us know if the issue persists by reopening this issue and adding a comment with the log!

Happy to help!
