## 📝 Descrição

According to the rules (RN002), if the consent is about customer data, in other words, a consentId without a resource, when consulting the resource (GET) is expected a 200 and empty array.
![image](/uploads/55fb54a11f4f58be768157af4e961787/image.png)

The resources-api-test-404-customer-data-v2 test requires a 404 response, as it was in Major 1. Now, it should expect a 200 with empty array.

In the log below we adjusted the resources API to answer a 404 in this case, but already changed back to a 200 empty string.
https://web.conformance.directory.openbankingbrasil.org.br/log-detail.html?log=gw4V0zyGQUOgWol
