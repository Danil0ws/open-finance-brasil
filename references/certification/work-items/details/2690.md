While testing the scenario payments_api_qrdn-good-proxy_test-module_v5, I noticed that the body of the POST request for consent creation is missing the purpose field.

According to the API v5 specification, unscheduled PIX transactions must include this field with the value "IMMEDIATE". Without it, our validation rejects the request.

The test scenario must include the purpose field in the consent creation payload.
