Hi,

Thanks for opening the ticket!

The provided logs were analyzed, the explanation of the failure is as follows:

Test module execution failed during steps:

• Call the PATCH enrollments endpoint\
• Expect a 204 response\
• **Expect an incoming message for enrollments, which must be mtls protected - Wait 60 seconds for both messages to be returned**\
• Return a 202 - Validate the contents of the incoming message, including the presence of the x-webhook-interaction-id header and that the timestamp value is within now and the start of the test

Conformance Suit expected to receive a webhook call from the server, which did not happen.

As described in the body of this issue, there is indeed a typo in the writing of the summary in this test module:

![image.png](/uploads/cbf33bf9733b088dbbefc8ee0b6c2975/image.png)

Although that does not impact test module execution whatsoever. Conformance suit is correctly set to receive the webook call from the following incoming path:

/test-mtls/a/{alias}/open-banking/webhook/v1/enrollments/v1/enrollments/{enrollmentId}

The failure in this test module is due to the server not sending the webhook call to this path, therefore conformance suit never received it, resulting in failure as expected. This can be better seen trough the following evidence of Conformance Suit running against Mockbank:

![image.png](/uploads/fdd38dba74a3071f8ffa2e8b660fc8e8/image.png)

Here, MockBank is making the HTTP request to the correct path, which is received by the conformance suit and test module is executed successfully. You can access this test log trough the following link: https://web.conformance.directory.openbankingbrasil.org.br/log-detail.html?log=uCj6cwTQIIgcc8w&public=true

There is also evidence of public test plans from other participants as well: https://web.conformance.directory.openbankingbrasil.org.br/log-detail.html?log=FOuTZfLGc12xv7u&public=true

Although  test module is being executed correctly, the description of the test module will be adjusted so there are no misunderstanding regarding it.

Feel free to add comments and reopen issue if you require further assistance,
