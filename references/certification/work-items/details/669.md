## 📝 Descrição

## 1. What Happened and what were you expecting?

In order to perform the second call to GET Payments, Conformance Suite is trying to issue a new access token using the authorization flow's refresh token and expecting HTTP 200. But, since this request occurs after POST Payments, consent is in CONSUMED status and a new access token can't be issued.
