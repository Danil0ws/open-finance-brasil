## 📝 Descrição

**Issue Description:**

There is a need for clarification regarding the behavior of user journeys initiated in mobile browsers within the context of open banking redirection rules. The current guidelines contain conflicting information:

1. [**Redirection App-to-App**](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/240650317/v1.0+-+Redirecionamento+App-to-App)**:** According to the specification available, user journeys initiated on mobile devices should be redirected directly to the application of the Transmitter Institution, bypassing browsers entirely.
2. [**User Experience Guide**](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/17378535/Guia+de+Experi+ncia+do+Usu+rio)**:** Conflicting points are noted on page 43:
   * One point states that journeys on mobile devices need to be redirected to the app:
     * ![image.png](/uploads/2791e824dd28fe701c555c0051570550/image.png){width="677" height="113"}
   * Another point states that journeys initiated in a browser should continue in the browser, except in cases of app-only: "
     * ![image.png](/uploads/63383aa7cfa49c8580624e2211e253c2/image.png){width="692" height="104"}

**What we need clarification from the WG:**

1. Should user journeys initiated in a **mobile browser be redirected to the app, or should they remain within the browser?**

For testing criteria and from our perspective, every time we have the app available, the journey should go through it. In that sense, _we believe that a user journey initiated in the mobile browser should open the app, whenever applicable_. We haven't observed this as a production issue with institutions; we are simply seeking to understand the expected behavior so it can be enforced across the ecosystem.
