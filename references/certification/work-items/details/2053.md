#### Current Behavior:
---
Os testes de DCR para Clients estão repetindo SSA o que causa erro de validação conforme descrito abaixo, pois o SSA deve ser único: 

{
  "error": "invalid_software_statement",
  "error_description": "Software statement ja utilizado"
} 

Estamos detectando uma alta frequencia deste erro nos relatórios de testes.

#### Expected Behavior:
---

Cada teste de requisição DCR para criação de um novo Client deve enviar um SSA diferente e único.

Thanks for opening the ticket!

The Automatic FVP uses the same Software Statement on different tests, performing the client deletion by test end:

![image.png](/uploads/b41100877866395f2ff3772fc06e4ae5/image.png)

The failure being faced happened because FVP could not properly delete the client by the end of one of the tests, this can happen when the unregistering process with the server fails, and therefore the same client is used to perform a DCR for the second time, Resulting in the observed failure:

"error_description":"Software statement ja utilizado"}

Please make sure to manually delete the registered client so that Automatic FVP can be properly executed.

Automatic FVP also created a ticket informing that the client needs to be deleted and which.

Feel free to reopen this issue and add comments in case further assistance is required.
