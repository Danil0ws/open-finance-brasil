Hi, thanks for the ticket.

This test uses mtls2 and mtls3 certificates linked to directory2.client_id, present in the conifguration of the test. From the configuration of the plan tou have created, the directory2.client_id is missing, and that is why the test fails. Since this test shouldn't be using both directory1.client_id and directory2.client_id, you can add the same on for testing.

Note that both certificates mtls2 and mtls3 must be different so the test runs correctly. If you are trying to replicate the configuration on FVP, please have a look at https://gitlab.com/raidiam-conformance/open-finance/certification/-/wikis/Automated-Production-Tests/
