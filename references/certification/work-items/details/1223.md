Hi,

thanks for opening the ticket!

The test failed due to the productType not being present on the test config json.

To execute this test successfully, please make sure that you include in the test config the following:

```
"consent": {
"productType": "personal"
},
```

This test module is going to be updated so that this fields is no longer required on the test config json and instead user the provided brazilCPF or brazilCNPJ to automatically detect the appropriate productType

This issue is already being treated at https://gitlab.com/raidiam-conformance/open-finance/certification/-/issues/1239, and will post updated there once we have it solved.
