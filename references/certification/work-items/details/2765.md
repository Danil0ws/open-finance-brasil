## 📝 Descrição

Estamos recebendo alguns tickets relacionados às marcas **itauemps** e **portobankpj** com situações que, pela nossa análise, estão ligadas à forma de execução e não a um problema da API.

Ambas as marcas são **PJ**, porém temos identificado cenários sendo executados sem CNPJ. Nesses casos, ao chamar a API de criação de consentimento, é retornado o erro:

`json"errors": [
  {
    "code": "Bad Request",
    "title": "Brand itauemps não permitida para este tipo de consentimento.",
    "detail": "Not allowed"
  }
]`

A mensagem de erro reflete justamente essa condição de uso incorreto. Para otimizar o trabalho de todos, gostaríamos de pedir o apoio de vocês para:

* Verificar com as equipes que realizam as execuções se a configuração com CNPJ está sendo utilizada nesses cenários;
* Validar, sempre que possível, se o comportamento está aderente à configuração antes de abrir um novo ticket.

Isso nos ajuda a focar a análise em potenciais problemas reais da API e reduz o retrabalho de ambas as partes.

Agradecemos desde já o apoio e a parceria.

Exemplo de execução:

https://results.conftpp.directory.openbankingbrasil.org.br/9MGtFULdA1jP5/index.html
