Hello!
I know that the expirationDateTime field is mandatory, but that's not the point.
If you had opened the test that I indicated in the ticket, you would see that what is happening is a totally different scenario. 

Here's what's happening:

According to the specification you sent above, the field is mandatory, but it can be an empty string. This means that the consent won't have a final date. 

In the tests I reported in the ticket, I'm saying that when we send an empty string, the response is also an empty string. The conformance test is validating the pattern**(^(\d{4})-(1[0-2]|0?[1-9])-(3[01]|[12][0-9]|0?[1-9])T(?:[01]\d|2[0123]):(?:[012345]\d):(?:[012345]\d)Z$)** that is specified on swagger.  In other words, when the response is an empty string, it shouldn't validate this pattern because there is no date to validate.
