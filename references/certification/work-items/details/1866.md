#### Current Behavior:
---
We identified a problem with the swagger documentation for the [Treasure Titles API v1.0.1](https://openbanking-brasil.github.io/openapi/swagger-apis/treasure-titles/1.0.1.yml). Specifically, the regex expression for verifying the TreasureTitlesQuantity attribute is presenting a space after the $ symbol which invalidates the regex verification, causing our integrated tests to fail when comparing to it.

#### Expected Behavior:
---
Regex Expression for attributes (in this case, TreasureTitlesQuantity) being rightfully formatted.

As described in informa: [**Informe #646**](https://mailchi.mp/d2b3e0d0df27/open-banking-informa-10139208?e=e3cfd5d4a5)

> O Squad Qualidade de Dados comunica que identificou erro nas especificações das APIs Títulos do Tesouro Direto e Adiantamento a Depositantes, comprometendo o processo de validação do Motor de Qualidade de Dados (MQD). Dessa forma, os tickets abertos referentes às devidas APIs devem ser encerrados se estiverem apontando erro para os seguintes campos:
>
> * API Título do Tesouro Direto
>   * data.quantity
>     * pattern “^\\d{1,15}\\.\\d{2,8}$ ”
>     * Erro na especificação: Existência de espaço em branco após o caractere “$”, afetando na validação do JSON-SCHEMA
> * API Adiantamento a Depositantes
>   * data.amortizationScheduledAdditionalInfo
>     * Erro na especificação: O JSON-SCHEMA não consegue validar a obrigatoriedade com base na descrição do campo, conforme a seguir: “_Description: Campo obrigatório para complementar a informação relativa à amortização quando selecionada a opção OUTROS. Preencher o campo quando não aplicável com string vazia ("")”_

This error identified in the swagger is due to be fixed on future api version updated.

This issue will be closed as there are no follow ups on this matter at the moment.
