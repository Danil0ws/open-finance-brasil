## 📝 Descrição

We are getting the error: "Call to token endpoint https://matls-auth.sandbox.directory.openbankingbrasil.org.br/token failed - Received fatal alert: handshake_failure" in several tests.

We verified that calls to this endpoint are being sent with the "client_id" parameter with a different value than what we are filling in our configuration due to the "OverrideClientWithOldBrcacClient" step. And with this client_id you are sending an invalid certificate.

Client_id value in our configuration: vDOx6XogovQZ2iaLwjAiE

client_id value in request body: QjRzruzFWi_U_tMahlz01

Log detail: https://web.conformance.directory.openbankingbrasil.org.br/log-detail.html?log=SjlPX4b3Fua98z6
