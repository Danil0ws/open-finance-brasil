Hi Wesley, following what Renan said. The test in question makes a call with the same payload using the same idempotency key therefore it will be the same response and not expecting a 422. However, in the circumstance you alter the payload and use the same idempotency key, you should be expecting a 422. Further clarification can be found in the specifications. Thank you.
