Hi,

Thanks for the ticket! 

The test failed because, according to the swagger, both `creationDateTime` and `expirationDateTime` should follow the `UTC` format and in the test ID sent the 2 parameters are incorrectly using `UTC-3`. That said, CS is indeed correct to spot this implementation error.

It follows below the swagger reference about this topic:

![image](/uploads/96dd486693531ca84ace452c92c23fb8/image.png)
[API Payment Initiation 3.0.0-rc.1.0](https://raw.githubusercontent.com/OpenBanking-Brasil/openapi/main/swagger-apis/payments/3.0.0-rc.1.yml)

Therefore, there is no corrections on the CS side. To a successful execution, the implementation needs to be adapted so that it is conformant to the swagger.

Feel free to open another ticket if you get any other issue! Happy to help!
