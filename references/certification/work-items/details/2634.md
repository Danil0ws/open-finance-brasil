#### Current Behavior:
---
An inconsistent behavior was identified in the  
`credit-cards_api_instalment_test-module_v2-4` module when the test dataset contains **more than one installment transaction associated with a credit card**.

Observed behavior:
- ✅ When the dataset contains **only one installment transaction**, tests run and complete successfully.
- ❌ When the dataset contains **more than one installment transaction**, the test engine reports a failure/inconsistency, even though the data is compliant with the Swagger definition and functional documentation.

#### Expected Behavior:
---
The test engine should correctly support scenarios with **multiple installment purchases**, as long as the data is compliant with the functional and contractual API specifications.

Clarification is requested regarding:
- whether there is any known limitation in the `credit-cards_api_instalment_test-module_v2-4` module concerning multiple transactions;
- whether there is a planned adjustment to the test engine to properly support this scenario.

#### Evidence:
---
- Failed test result involving more than one installment purchase (with the same ordering as the successful test):
