Hi @gpassossilva 

Thanks for reaching out, the failure is happening because of the following reason, when conformance suit executes step:

**GET credit-fixed-incomes/v1/investments?page-size=1000&page=2**

That aims to validate this [field](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/163512596/Informa+es+T+cnicas+-+Renda+Fixa+Cr+dito-+v1.0.1):

![image](/uploads/f7527e95692897005c931f496deca089/image.png)

It receives as response for the GET: https://openbanking.sandbox.api.pagseguro.com/open-banking/credit-fixed-incomes/v1/investments

But it is missing the end: "https://openbanking.sandbox.api.pagseguro.com/open-banking/credit-fixed-incomes/v1/investments?**page-size=1000&page=2**",

For that reason, conformance suit proceeds to validate this self link provided and identifies error while validating it.

You can check a successful test here:

https://web.conformance.directory.openbankingbrasil.org.br/log-detail.html?log=eCSQSz9bJ1yGDqc&public=true
