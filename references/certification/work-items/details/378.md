@gustavo.loli ,

Error message is pretty clear on your side

![image](/uploads/c1d8ea860a8dbbfb91613779ce716571/image.png)

The server is not accepting a new DCR because there is already a client_id that has been generated for this Software Statement which is a new requirement from the initial structure.

In this case, this client has also been created on a previous DCR test module, and, due to a test being stopped before it ending the client was not correctly Deleted.

Here you should Manually delete the created client by searching for the SoftwareStatementID 368bceef-6096-4e1a-a702-64c07d12c98a,
