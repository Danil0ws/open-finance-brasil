Hi,
Thanks for creating a new test plan!

After throughly analyzing the provided new test plan, it was possible to conclude that the test module failed due to a wrong self link being provided in the response_body for the POST /v3/consents request.

The CS received the self link as follows: 

```
"links":{"self":"https://openbanking-gw-h.bndes.gov.br/open-banking/consents/v2/consents/urn:bndes:b608d923-323f-445a-b34d-af3ec494c5e7"}}
```

Therefore directing the CS to call the wrong version for the GET consents endpoint, resulting in the referred failure. Hence, the conformance suit is operating as expected. To ensure the test module can be run successfully please make sure of the following:

1. The provided Self link in the response body for the POST consents request referes to the intended v3 version

Feel free to open a new ticket if you have any more questions,
