## 📝 Descrição

We need clarification from the WG on the following questions:

**PJR52 - Clarification Needed on the Following Points:**

* Upon enrolling a device, it is necessary to select a debtor account to which the enrollment will be linked. If the selected debtor account has multiple consents (Múltiplas Alçadas), what should the flow be?
* In the scenario above, will the enrollment status transition from AWAITING_ACCOUNT_HOLDER_VALIDATION to AWAITING_ENROLLMENT, or will it require approval from both account approvers?
* Is the flow described in the `enrollments_api_multiple-consents-core_test-module_v1` document correct for multiple consents payment with an enrolled device?
