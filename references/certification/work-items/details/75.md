## 📝 Descrição

Hi,
In java class EnsurePaymentDateIsToday the ZoneId was changed to BET and after this change the engine started to launch exception!
Also the correct zoneId should be UTC, according to the documentation: https://openbanking-brasil.github.io/areadesenvolvedor/#tipos-de-dados-comuns
