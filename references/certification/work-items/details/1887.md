## 📝 Descrição

#### Current Behavior:

An ITP is sending the `client_assertion` to the `/token` endpoint with the `aud` field as a list. Upon reviewing the tests in the engine, we noticed it is not being sent as a list. We would like to confirm: is it allowed to send the `aud` field as a list?

Example:

{\
  "aud": \[\
    "[https://example.com.br/token"](https://example.com.br/token%22 "https://example.com.br/token%22")\
  \],\
  "exp": 1731511140,\
  "iat": 1731510240,\
  "iss": "19GqEwhBGhtt-asd-ow",\
  "jti": "e1d3241b-2c53-4355-be51-890a196cd523",\
  "sub": "19GqEwhBGhtt-asd-ow"\
}
