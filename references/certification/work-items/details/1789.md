#### Current Behavior:

---

What's happening at the moment is: after approximately 10 minutes from the start of the process, the token expires and the test stops before receiving a response from the API with the cancelled payment.

#### Expected Behavior:

---

The test apparently creates a payment in SCHD status (scheduled), and polls it for 10 minutes until it eventually switches to CANC (cancelled, following the enum established in the documentation). It turns out that the previously generated token is not configured to remain available for that long, so a token refresh call is expected so that the GET request can continue to be made.
