## 📝 Descrição

## 1\. What Happened and what were you expecting?

Because, the test currently is based on swagger [Fundos de Investimento - v1.0.0-rc2.0](https://openbanking-brasil.github.io/openapi/swagger-apis/funds/1.0.0-rc2.0.yml), we are getting error in the compliance engine, when trying to run the tests for the modules:

![MicrosoftTeams-image (37).png](/uploads/0419b5085b6669e586c4f9dc2be1d5f0/MicrosoftTeams-image__37_.png)

* funds_api_transactions-current-timezone_test-module
* funds_api_transactions-timezone_test-module
* funds_api_transactiondate_test-module

According to the latest swagger ([Fundos de Investimento - v1.0.0](https://openbanking-brasil.github.io/openapi/swagger-apis/funds/1.0.0.yml)), the following parameters should be updated:
* `fromTransactionDate` should be changed to `fromTransactionConversionDate`
* `toTransactionDate` should be changed to `toTransactionConversionDate`

Thanks for the ticket! 

The parameter mentioned as wrong is contained in the self link, which is sent by the implementation.

The test failure occurred because the test is receiving parameters (`fromTransactionConversionDate` and `toTransactionConversionDate`) that are not described in the respective swagger in which the test plan is based:
![image](/uploads/8be52932a4d16096248515b940efc0a4/image.png)

Therefore, to a successful execution, the implementation needs to be adjusted so that it is conformant to the respective swagger documentation. You can access the swagger documentation here: https://openbanking-brasil.github.io/openapi/swagger-apis/funds/1.0.0-rc2.0.yml
