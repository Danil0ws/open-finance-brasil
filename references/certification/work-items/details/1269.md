## 📝 Descrição

## 1\. What happened and what were you expecting?

When the test module executes the following step:

> “Call pix/payments endpoint with the second creditor's CNPJ ”

It attempts to create a new payment using a token which has **grant_type=client_credentials**. It should be using a token with **grant_type=authorization_code.**
