In order for the API to be registered on The Directory, it  executes a conformance test against the endpoint and evaluates if it is being able or not to pass on the test.

This function will wait at most 10 seconds (increasing to 20 seconds in February) before it will be interrupted. This time is seem as reasonable given that according to the performance page low frequency endpoint should have average response times of 4000ms, so 10 seconds is much more than the average time.

The reason you are not being able to register is because your endpoint is taking 11 seconds to pass, so above the timeout time. We ask you to please correct this in order for you to be able to register/certify the endpoint on the directory.
