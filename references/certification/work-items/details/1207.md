Hi Marcelino,

There is indeed no keys in the first link because it is a certificate generated for the production environment. Even revoked, the private key should not be provided. However, you can use that certificate to validade that it is revoked, since you don't need the key for that.

The CRL links for production are the following:

- PKI Configuration Root Pem Url - http://crl.pki-g2.directory.openbankingbrasil.org.br/root-ca.pem 
- PKI Configuration Issuing Pem Url - http://crl.pki-g2.directory.openbankingbrasil.org.br/issuer-ca.pem

However, you should not be using these crl to validate the certificates from DCR, since you should be using the crl from the respective CA of the certificate being used. In the case of the test, you should be using the crl or the ocsp url of Soluti.

Both the ocsp and crl uri should be found in the certificate.
