## 1. What Happened and what were you expecting?

"The payments-api-test test is not sending the transactionIdentification in the payment request when the localInstrument is INIC, even when the transactionIdentification field is in the brazilPixPayment of the config."


For this specific test the localinstrument is provided on the consents block and is left not touched, however the transactionIdentification is to be provided by the Conformance Suite. For any localinstrument that isn't INIC this field should not be sent, however if the INIC is provided the conformance suite must make sure that the transactionIdentification will be added. 

The happy scenario for all tests must guarantee that INIC will add a transactionIdentification.
