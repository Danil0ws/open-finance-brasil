## 1. What happened and what were you expecting?
The test module is using the wrong validator when running the step "2. Ensure error when PATCH payments endpoint is called in a state different from SCHD/PDNG/PATC".

It expects an `422 - PAGAMENTO_NAO_PERMITE_CANCELAMENTO`, but incorrectly uses the `CreatePaymentErrorValidatorV4`, which does not contain this enum, instead of using a PATCH validator.
