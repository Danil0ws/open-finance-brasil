Actually, this is not a Bug.

Test Called Credit Cards Accounts List Endpoint, Authorization Server returned an empty data field in response.

As conformance suit needed to call subsequent Credit Cards endpoints which require the account Id in their path to be called, not having access to this information caused Conformance Suit to Failure.

We will improve the behavior of Conformance so that, when accounts listing APIs return data as empty field, it will throw INFO and will move on to testing the next APIs.
