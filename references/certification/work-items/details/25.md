## 📝 Descrição

On the Test "resources-api-test-credit-card" you are requesting the following set of permissions on the consent creation:
{"data":{"permissions":["CREDIT_CARDS_ACCOUNTS_READ","RESOURCES_READ"],"loggedUser":{"document":{"identification":"00002707330","rel":"CPF"}},"expirationDateTime":"2021-07-27T20:57:18Z"}}

This is an invalid group and the correct requests should be permissions":["CREDIT_CARDS_ACCOUNTS_READ","CREDIT_CARDS_ACCOUNTS_BILLS_READ","CREDIT_CARDS_ACCOUNTS_BILLS_TRANSACTIONS_READ","RESOURCES_READ"]

Aligned with the description on: https://openbanking-brasil.github.io/areadesenvolvedor/swagger/swagger_consents_apis.yaml

I still haven't had the opportunity to evaluate if other tests present the same error so I also ask you to please check if any other tests haven't been updated to match the permissions group.
