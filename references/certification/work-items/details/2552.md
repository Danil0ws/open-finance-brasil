## 📝 Descrição

Dear all,

We would like to request an evaluation of potential improvements to the Automated FVP:

* Greater clarity in notifications regarding the cutoff time considered for the valid automatic execution of the day.
* Inclusion, in the notification description, of all tests that reflect the failure related to the execution day.
* Removal of tests that have some type of technical debt which, for any reason, do not generate notifications for the institution but still appear as failed in the evidence link, making analysis difficult.
  * Ensuring that removed tests are not forgotten and are included in a remediation pipeline for correction.
* Ensuring that test executions follow an ordered sequence, as displayed in the evidence links.
* Providing more precise and up-to-date details about the Automated FVP in the Automated Production Tests documentation, as well as creating a Portuguese version of the page.
  * In the documentation, explicitly clarifying the distinction between functional endpoint regularization and the formal recognition of compliance by the Automated FVP.
