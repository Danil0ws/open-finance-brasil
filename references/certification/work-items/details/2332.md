## 📝 Descrição

### 🔍 Current Behavior

The Participant Directory in the Sandbox environment is currently generating the URL for the endpoint `GET /portabilities/{portabilityId}/account-data` based on outdated patterns from earlier beta versions of the Credit Portability API (e.g., v1.0.0-beta.1). As a result, the endpoint is either incorrectly exposed or not available at all for integration and testing.

This endpoint is critical for retrieving banking information required to settle credit portability operations via STR (TED), and its absence or misconfiguration blocks the certification flow and STR integration testing.

---

### ✅ Expected Behavior

The Participant Directory should generate the endpoint URL `GET /portabilities/{portabilityId}/account-data` according to the latest stable version of the Credit Portability API specification. This includes:

- Proper exposure of the endpoint in the directory metadata.
- Alignment with the technical documentation regarding request/response structure and payload signing.
- Compatibility with the STR settlement flow as defined by Open Finance Brasil.

---

---

### 🧪 Evidence

- Internal validations show that the endpoint is still being generated using legacy paths.
- Sandbox directory metadata does not reflect the current specification for this endpoint.

---

### 🛠️ Suggested Fix

1. **Update the Participant Directory logic** to reflect the stable version of the Credit Portability API.
2. **Ensure endpoint metadata generation** includes the correct path and parameters for `GET /portabilities/{portabilityId}/account-data`.
3. **Validate against the latest OpenAPI schema** and product requirements.
4. **Coordinate with the Sandbox and GT Portabilidade teams** to align the directory exposure with the certification milestones and STR integration timeline.
5. **Ensure functional tests are executed** using the Conformance Engine, and validation links are included in QTEST as per acceptance criteria.
6. **Follow REST exposure rules** as defined in the Open Finance integration guide.
