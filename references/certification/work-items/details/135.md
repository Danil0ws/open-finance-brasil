## 📝 Descrição

The QRDN initiation Type always sends a Dynamic QRCode which always contains a txid.

There was a claim from one of the participants that this field should thus be mandatory for this type of localInstrument as it's required on the PIX API.

The specs don't mention it being mandatory which implies that it's entirely optional. To change this behavior on the CS so it becomes mandatory we need a clarification from the Specifications Work Group.
