The Conformance Suite treats the optional with the following rule
- If present it will be entirely validated
- If missing test will be a success

Here, when you send a "links": null we consider the field to be present and thus expect the whole structure to be sent. For an optional field, we require you to remove the field from the JSON altogether instead of sending it with the null value.
