## 📝 Descrição

When running the test **FVP PF Limits Negative** (module `fvp-enrollments_api_automatic-payment_enrollment-limits_negative_test-module_v2-2`), the test fails after the step "Validating 422 response" with:

```
Error: setStatus() called but status is the same: WAITING -> WAITING
Class: net.openid.conformance.testmodule.TestFailureException
Origin: TestRunner.java background task
```

The API returns 422 as expected and the validation of the 422 response completes successfully. The failure is caused by the test engine calling `fireTestFinished()` twice, which leads to `setStatus(Status.WAITING)` being invoked when the status is already WAITING.
