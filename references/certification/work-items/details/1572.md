* The image provided regards:
  * **OrganisationName**: ITAU UNIBANCO S.A.

  * **OrganisationName**: ITAU UNIBANCO S.A.
  * Authorization Server: itau_fapi

Therefore when conformance suit searches for the ApiResources related to Authorization Server itau_fapi, it does not find the invoice-financings ApiEndpoint and thus has to build it, resulting on the failure.

Hi,

after evaluating the provided test module, we were able to conclude that when conformance suit executed the following step:

**Validating Authorisation Server has supported Endpoint**

It retrieved the AuthServer From Participants Endpoint and while parsing the result, it could not find the following Fields for the /invoice-financings/v2/contracts endpoint:

* "ApiDiscoveryId"
* "ApiEndpoint"

Thus, conformance suit had to build it using the consents URL and resulted in the mentioned error.

As conformance suit is working as expected in this regard, please make sure that the invoice-financings URL correctly registered in the provided Authorization server configuration so that the correct url can be used by the conformance suit when executing the test module.
