## 1. What Happened and what were you expecting?
Apparently, the resources-api-test-unavailable test, when polling, is not calling the GET RESOURCES API to check if a resource has been updated to TEMPORARY_UNAVAILABLE or UNAVAILABLE. According to the test description, it should:

_• POLL the GET RESOURCES API with the authorized consent for 10 minutes - Refresh Token to be called each 3 minutes;_

_• Continue pooling until AT LEAST one Resource returned and is on the state TEMPORARILY_UNAVAILABLE/UNAVAILABLE_
