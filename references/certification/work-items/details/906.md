## 📝 Descrição

## 1. What happened and what were you expecting?

CS is requiring the `productType` for the financings tests to be `DIREITOS_CREDITORIOS_DESCONTADOS`, which is the Invoice-financings enum list. However, as this is a Financings test, CS should use the following enum list: `[ FINANCIAMENTOS, FINANCIAMENTOS_RURAIS, FINANCIAMENTOS_IMOBILIARIOS ]`

Swagger reference: https://openbanking-brasil.github.io/openapi/swagger-apis/financings/2.1.0-rc.1.yml
