Hi,

Thanks for the ticket! 

The test failed because the test received an webhook notification with a pattern it was not expecting:

- `/test-mtls/a/picpay1/automatic-payments/v1/pix/recurring-payments/65f1e68eeed46a729b898eae`

According to the latest specification ([API Webhook 1.2.0](https://openbanking-brasil.github.io/openapi/swagger-apis/webhook/1.2.0.yml)), the pattern should should be:

- `/test-mtls/a/<alias>/open-banking/webhook/v1/automatic-payments/v1/pix/recurring-payments/{recurringPaymentId}`

Therefore, there is no corrections on the CS side. To a successful execution, the implementation needs to be adapted so that it is conformant to the spec.
