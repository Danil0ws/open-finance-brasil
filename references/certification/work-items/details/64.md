## 📝 Descrição

Hi all,

In `payments-api-dict-pix-response-test`, the payload used to create a consent is mutated. More specifically, `$.creditor` and `$.payment.details` are changed to the following values:

```
...
"creditor": {
    "name": "Joao Silva",
    "cpfCnpj": "11122233300",
    "personType": "PESSOA_NATURAL"
},
"payment": {
    ...
    "details": {
        "proxy": "cliente-000000@pix.bcb.gov.br",
        "localInstrument": "DICT",
        "creditorAccount": {
            "number": "22917383379",
            "accountType": "CACC",
            "ispb": "99999060",
            "issuer": "0024"
        }
    },
    ...
},
...
```

However, the payload used to create a payment right after the consent is created is not changed at all (that is, the definition of `$.proxy` and `$.creditorAccount` are still the same as defined in the test plan's configuration, not matching what has been specified in consent creation API call).

Log sample: http://web.conformance.directory.openbankingbrasil.org.br/log-detail.html?log=MMBHk2ffi218Dib

Is this a known issue, or could there be a misconfiguration on our side?

Thanks.
