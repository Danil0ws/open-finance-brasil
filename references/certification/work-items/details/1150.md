## 1. What happened and what were you expecting?

According to the test module description:
```
•Call the Registration Endpoint without sending the “webhook_uris” field.
•Expect a 201 - Ensure that the “webhook_uris” is not returned on the response body
```

It should create a client without webhook_uris, but on the registration payload it sets the webhook_uris field which, unsurprisingly, causes the test to fail because it then asserts that the created client does not have a registered webhook_uri.
