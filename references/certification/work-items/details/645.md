Hi,

Thanks for the ticket!

There is indeed an issue with the validation of `additionalInfo` field at `Channels Electronic Channels Api test` and we will fix it.

Regarding the failure at `ProductsNServices Personal Credit Cards API test`: the Conformance Suite is conformant to the swagger, as it should be. In the swagger, the field `additionalInfo` is marked as required (as seen by the red *) and it must be filled with "NA" when non applicable. To a successful execution, the implementation needs to be adapted so that the cited field is compliant to the cited pattern. Finally, we believe the information displayed at the documentation about this point is indeed deceiving and for a Change on the API specification we ask you to raise a Service Desk ticket with the contents of this ticket. Feel free to mention this issue with them.

Happy to help!
