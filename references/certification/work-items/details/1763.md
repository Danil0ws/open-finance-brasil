#### Current Behavior:

---

During our review of the [Pagination specification](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/17377470/Pagina+o), a question came up regarding the use of query parameters in self links when the requested page-size exceeds the Authorization Server's limit.

**Example Request:**

Client Requests: `GET https://www.example.com/resources/v3/resources?page-size=1000`

**Scenario:**

The Authorization Server enforces a page-size limit of 50. We are uncertain which of the following should be used for the self link, and other links, in the response payload:

1. `self: https://www.example.com/resources/v3/resources?page-size=50` - with the server's page-size limit.
2. `self: https://www.example.com/resources/v3/resources?page-size=1000` - with the requested page-size, but only 50 records returned.
3. `self: https://www.example.com/resources/v3/resources` - without a page-size parameter, returning only 50 records.

According to what is described on the specification: 

* A instituição transmissora/detentora pode definir um tamanho máximo da página (`page-size`) inferior ao tamanho máximo permitido pela API, caso entenda necessário diminuir o limite para atender o SLA de resposta:
  * Para as APIs de Dados Cadastrais e Transacionais, o comportamento esperado da transmissora/detentora é que o page size mínimo é 25 e o máximo é 1000, exceções se aplicam a primeira página, quando for única, e a última página.
    * Exemplo: A receptora solicita 5 registros por página, entretanto, a transmissora possui 47 registros. Pelo comportamento descrito, a transmissora retornará 25 registros na primeira página de 22 registros na segunda.

Taking the self link description:

* Quando chamado o método GET deverá retornar o link para o próprio recurso consultado
* Quando chamado o método POST deverá retornar o link para o recurso criado
* Quando chamado método PATCH deverá retornar o link para o recurso alterado

Therefore it is our understanding the link self should contain by the end the query parameter with page-size detemrined by it's defined limit.

The specification isn’t clear on this point. Could you please clarify the expected behavior?
