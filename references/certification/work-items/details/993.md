## 📝 Descrição

## 1. What happened and what were you expecting?
The test calls the POST Payments Endpoint with a different city on the qrcode and it expects status code 422 with error code PAGAMENTO_DIVERGENTE_CONSENTIMENTO. This error is in accordance to swagger, in case of sync payment process (Reference Swagger - Error 2.2.2.6), but in case of async process, the test should expect status code 201 on POST Payments and validate the rejection reason with PAGAMENTO_DIVERGENTE_CONSENTIMENTO on GET Payment endpoint (Reference Swagger - 4.1.5).
