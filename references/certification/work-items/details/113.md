## 📝 Descrição

We have that:

On products and services
> @PublishTestModule(
   testName = "ProductsNServicesApi-test",
   displayName = "Validate structure of all ProductsNServices data Api resources",
   summary = "Validate structure of all ProductsNServices data Api resources",
   profile = OBBProfile.OBB_PROFILE,
   configurationFields = {
      "server.discoveryUrl",
      "resource.brazilCpf",
      "resource.resourceUrl",
      "resource.consentUrl"
   }
)

And for admin

>@PublishTestModule(
   testName = "admin-api-test",
   displayName = "Validate structure of admin API resources",
   summary = "Validates the structure of admin API resources",
   profile = OBBProfile.OBB_PROFILE,
   configurationFields = {
      "server.discoveryUrl",
      "client.client_id",
      "client.jwks",
      "mtls.key",
      "mtls.cert",
      "mtls.ca",
      "resource.consentUrl",
      "resource.brazilCpf",
      "resource.resourceUrl"
   }
)

The configuration fields are explicitly asking for a lot of not needed fields like

      "server.discoveryUrl",
      "resource.brazilCpf",
      "resource.consentUrl"
      "server.discoveryUrl",
      "client.client_id",
      "client.jwks",
      "mtls.key",
      "mtls.cert",
      "mtls.ca",

We should only have the "resource.resourceUrl" as there is no consent or validation to access the endpoint.

The same thing happened for channels
