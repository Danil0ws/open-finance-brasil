#### Current Behavior:
---
We are receiving a request body with a `debtorAccount` without the `accountType` attribute. The test expects an error with the `code` being `CONTA_INVALIDA`, but this enum, according to the [swagger](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/405995741/Informa+es+T+cnicas+-+SV+V+nculo+de+dispositivo+-+v1.3.1) is for errors `422` in the creation of the enrollment. 

#### Expected Behavior:
---
In this case we believe that this is an error `400` since an mandatory attribute is missing (`debtorAccount.accountType`) and because of this the enum `CONTA_INVALIDA` should not be used in this validation. Is this interpretation correct?
