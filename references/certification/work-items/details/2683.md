## 📝 Descrição

The test plan `payroll-credit-portability_test-plan_v1` is failing during conformance test execution. The root cause is a validation that requires the `cnpjConsignee` field to be populated for loans with `productSubType` set to `CREDITO_PESSOAL_COM_CONSIGNACAO`.

#### Problem:
---
The `cnpjConsignee` field was removed in the current version of the Loans API (v6). Since the test plan still validates the presence of this field, all tests involving this `productSubType` fail, preventing the full execution of the plan.
