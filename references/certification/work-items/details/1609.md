## 1. What happened and what were you expecting?

1. What happened?
The CS did not flag an empty 'requestTime' field in this participant's admin endpoint as non-compliant. This field was processed without errors even though it was empty, which contradicts the Open Finance specification that mandates a string in the $date-time format with a length limit of up to 20 characters. The endpoint is question is : https://api.original.linaob.com.br/open-banking/admin/v2/metrics

2. What were you expecting?
I was expecting the CS to validate the 'requestTime' field strictly according to the Open Finance specifications. Any deviations, such as an empty string or a string that exceeds 20 characters, should be identified as errors, and the request should be flagged as non-compliant.
