## 📝 Descrição

## 1. What Happened and what were you expecting?

The parameters below were recently updated on Transactions/Transactions-Current endpoints to be in conformance with the latest swagger version for Funds API ([Fundos de Investimento - v1.0.0](https://openbanking-brasil.github.io/openapi/swagger-apis/funds/1.0.0.yml)):

* `fromTransactionDate` was changed to `fromTransactionConversionDate`
* `toTransactionDate` was changed to `toTransactionConversionDate`

However, the tests mentioned below still uses the old parameters `fromTransactionDate` and `toTransactionDate` but they should not:
* **funds_api_core_test-module** (in the steps below the correct parameters `fromTransactionConversionDate` and `toTransactionConversionDate` should be sent but the request is being called without parameters as the step "Set query parameters for next API call" still got the outdated name `fromTransactionDate` and `toTransactionDate`)
* * _Call the GET Investments Transactions endpoint with the extracted investmentID - Send query Params fromTransactionDate equal D+0 and toTransactionDate equal to D+360_
* * _Call the GET Investments Transactions-Current endpoint with the extracted investmentID. Send query Params fromTransactionDate equal D+0 and toTransactionDate equal to D+6_
* **funds_api_operational-limits_test-module**
