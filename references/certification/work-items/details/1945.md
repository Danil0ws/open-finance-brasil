---

The specification requires an eight digit field, but the test send only five ("ispb": "11111").

---
[ISPB with eight digits](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/718406041/Informa+es+T+cnicas+-+SV+Pagamentos+Autom+ticos+-+v2.0.0-beta.2)

```
ispb*	string
minLength: 8
maxLength: 8
pattern: ^[0-9]{8}$
example: 12345678
```
