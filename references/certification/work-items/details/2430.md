### Comentário 3
**Autor**: Matheus Mantovani (@matheus-mantovani)
**Criado em**: 26/11/2025, 10:55:01

Hello @adelino.avelino, thanks for raising this point.

You are correct. The **Optimized Journey** [documentation](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/1129250817/Orienta%2Bes%2BGerais%2B-%2BJO%2BJornada%2BOtimizada%2Bv1.0) describes the mandatory scopes for sweeping payments with shared acount balances as:

`openid consent:consentId **consents** resources accounts recurring-consent:recurringConsentId recurring-payments  `

In the current implementation of this optimised journey test, the pushed authorization request is only using the `dynamic consent` scopes together with `resources`, `accounts`, and `recurring-payments`, so the static `consents` scope is indeed missing on our side.

As you pointed out, from an OAuth/FAPI perspective there is an important nuance here:

* The PAR is a backchannel call that prepares the authorization request and defines the scope that will later be attached to the authorization_code access token.
* In practice, the authorization_code token for this journey is used to call endpoints such as balances and the recurring-payments APIs, which rely on the dynamic consent scopes and the resource scopes.
* The `consents` scope, on the other hand, is typically used with a client_credentials token to call the Consents API, and **not with the browser-based part of the flow that uses the authorization_code grant.**

This explains why the test was originally modelled using only the dynamic consent scopes and the resource scopes, even though the JO table lists consents as part of the mandatory scope set.

Given this apparent mismatch between the way the scope set is described in the journey and the way the scopes are effectively used (auth code vs client credentials), we will raise this point with **DTO/Working Group** so they can confirm how this journey is expected to behave and how the scope set should be modelled going forward in both documentation and tests.

We'll keep you updated.

Best regards
