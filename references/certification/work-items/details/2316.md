Boa tarde prezados,

O teste tem a seguinte sequência de validações:

1. Um webhook é esperado quando o consentimento atinge o status `AUTHORISED`.
2. Posteriormente, o teste chama o `GET` no consentimento e espera que o status mude para `CONSUMED`.
3. Neste ponto, o teste **espera receber um segundo webhook** com a notificação do status `CONSUMED`.

Seu log mostra que o webhook foi enviado para o status de consentimento (`AUTHORISED`), mas o motor de conformidade não recebeu a notificação quando o status mudou para `CONSUMED`.

A falha `Expected 2 webhooks, but received 1` indica que o webhook para o status `CONSUMED` não chegou ao motor de conformidade. Embora a sua API tenha enviado o webhook de `AUTHORISED`, a ausência da notificação de `CONSUMED` impede que o teste seja finalizado com sucesso.

Por favor, verifiquem se a sua implementação está configurada para disparar o webhook quando o consentimento atinge o status `CONSUMED`, conforme a máquina de estados:
