Hi, both consent and resource APIs must be in sandbox directory.

Organisation > YOUR ORG > Authorisation Servers > YOUR AUTH SERVER > API Resources > New Api Resource

![Screenshot_from_2024-01-16_09-28-54](/uploads/c187bb7ca45e94b40c2711a23cba4a64/Screenshot_from_2024-01-16_09-28-54.png)

Before clicking API Resource button, make sure to register the APIs in all Auth Servers that are in the Authorisation Servers list.

![Screenshot_from_2024-01-16_09-37-00](/uploads/1aa32a8a1c16acb839c4e1f9446b1140/Screenshot_from_2024-01-16_09-37-00.png)

Later, don't forget to do the same in directory production environment.

PS: I was getting errors filling the field API URL. Usually you just need to include the protocol + host, but it wasn't working for consents and resources V3. To do so, I used the link bellow:

https://github.com/OpenBanking-Brasil/conformance/blob/main/submissions/functional/payments/3.0.0/58616418_3.0.0_payments_v3_11-10-2023.json

If it doesn´t work, try this one:

https://github.com/OpenBanking-Brasil/conformance/blob/main/submissions/functional/consents/1.0.3/API_Consents.zip
