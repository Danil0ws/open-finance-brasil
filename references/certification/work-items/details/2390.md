## 📝 Descrição

Request for creation of test data with alphanumeric CNPJ and linked CPF for Open Finance journey

 

Dear Team,\
We are requesting the creation of a test dataset that meets the following requirements:

 CNPJ in alphanumeric format (not only numeric), to validate scenarios where the system must correctly accept and process this type of data.\
Linked CPF that can execute the complete journey of calling the Mock Bank as a data provider in the Open Finance flow.

 **Justification:**\
Including an alphanumeric CNPJ is essential to ensure solution robustness because:

 It validates business rules and integrations that should not assume CNPJ is always numeric.\
It prevents failures in real-world scenarios where data may contain letters or special characters.\
It guarantees compliance with edge case testing and quality standards required by Open Finance.

 Additionally, we emphasize that the current test data provided by your team does not meet our testing needs, as it does not include this type of CNPJ nor the proper linkage with CPF for executing the full journey.

 **Importance for Testing:**

 Without this dataset, we cannot validate critical flows of consent and data sharing.\
This directly impacts certification and production readiness.\
Success and error scenarios depend on this configuration to ensure full coverage.

 **If possible, please also include**:\
Initial status as Pending Authorization, to validate screen behavior and filters.

Hello @scheilabraga.

Sharing the new guidance we received from DTO:

* The alphanumeric CNPJ itself is a government initiative, with a start currently indicated for June 2026 ([reference](https://www.gov.br/receitafederal/pt-br/acesso-a-informacao/acoes-e-programas/programas-e-atividades/cnpj-alfanumerico)). From that month onward, alphanumeric CNPJs will begin to be issued.
* The related conformance tests are scheduled (per the Central Bank timeline) to run from 01/07 to 31/07.

Please feel free to reopen this issue if needed. You may also raise any new questions regarding this matter via the Service Desk for the OPF Working Groups.
