## 📝 Descrição

## 1. What Happened and what were you expecting?
The test accounts_api_operational-limits_test-module_v2 is requiring the self-link to present page parameter, but it is not present on the request URI.

![image](/uploads/f8ecace67155ec6fb9cf47683f585e40/image.png)
![image](/uploads/a35cd10ace5c8d484e13f74eb9193684/image.png)

The problem seems to be related to the method `ValidateNumberOfRecords.prepareRecordData`. It shouldn't always expect that `selfLink` has page parameter. Self-link should be equals to request URI and the request URI could have not the page parameter.
