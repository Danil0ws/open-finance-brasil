Hi,

According to the specification, the observed behavior is expected.

For **Payment Initiator Institutions (PAGTO)** participating in Open Finance Brasil, the scopes must be used as follows:

* Tokens used to access **consent-related endpoints** must include the `payments` scope.
* Tokens used to access **payment endpoints** must include **both** `openid` **and** `payments` scopes.
