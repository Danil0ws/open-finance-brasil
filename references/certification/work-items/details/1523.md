Thanks for opening the ticket!

The conformance suit failed while performing the Validate Self link step.

The request_uri used in this call comes from the Self link field provided in the response to the POST pix/recurring-payments request,

so it's not a link generated automatically by the conformance suit engine, it actually comes from the server's response.

You can see below the link included in the response body sent by the implementation:

![image.png](/uploads/3698610dc9f515e50fbb8cd0e1ca9e5d/image.png)

Therefore the conformance suit is operating as expected, to ensure that the test runs successfully, make sure that the self link field in the response to POST pix/recurring-payments is being sent correctly.
