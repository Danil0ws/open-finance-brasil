#### Current Behavior:

---

During FVP tests, after participants consent authorization, many tests are returning the error "Got an HTTP request to 'implicit/XXXXXXXX' that wasn't expected".

One possible motive considered during previous problem analysis was an unwanted double click in the consent authorization button, but the same error is observed with single clicks.

We were informed that this error occurs almost every time after the following steps:

1. Execute FVP without being logged in mobile browser.
2. Then proceed with profile authentication.
3. Re-run the test.
4. After that, every attempt to execute FVP culminates in this error.

#### Expected Behavior:

---

After consent authorization, FVP should execute successfully without generating unexpected HTTP requests.
