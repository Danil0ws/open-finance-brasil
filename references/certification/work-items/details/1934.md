## 📝 Descrição

#### Current Behavior:
---
Currently, MB incorrectly requires the field `data.riskSignals.automatic.pixKeyRegistrationDateTime` as mandatory in the request body for a POST `/pix/recurring-payments`. When trying to make the request without sending it and with `data.localInstrument` set to `MANU`, MB returns the following error:

```
{
  "code": "body.data.riskSignals.automatic.pixKeyRegistrationDateTime",
  "title": "body.data.riskSignals.automatic.pixKeyRegistrationDateTime",
  "detail": "must not be null"
}
```
<img src="/uploads/522d473823efe53d7abb5b4d50cfb179/Erro_Requisi_C3_83_C2_A7_C3_83_C2_A3o.png" width="700"/>

#### Expected Behavior:
---
According to the specification ([API Automatic Payments v2.0.0-beta.2](https://raw.githubusercontent.com/OpenBanking-Brasil/openapi/main/swagger-apis/automatic-payments/2.0.0-beta.2.yml)), the field `pixKeyRegistrationDateTime` should be required only when the field `localInstrument` is `DICT` or `INIC`. It should not be mandatory if `localInstrument` is `MANU`:

<img src="/uploads/080b96d77cf1e26530e3e4844cbdb716/image.png" width="700"/>
