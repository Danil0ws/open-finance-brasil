Hi Marcos! Thanks for the ticket!

The Conformance Suite is throwing this error since you are returning the field as "**errors",** where it should be **"error", as described at** https://datatracker.ietf.org/doc/html/rfc6749#section-5.2.

If you send the field as error, there should be no problems. We are happy to help with any additional needs!
