Boa tarde, prezada

De fato há divergência com relação à especificação técnica sobre este ponto. Neste caso, o motor está com o comportamento esperado correto e a especificação está incorreta, o que é um problema conhecido listado como `BCLOG-F03-V2-005` em https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/31162369/v2.0.0+Problemas+conhecidos. Segue trecho abaixo:

> Nas orientações do header da API sobre validações, os itens 1.2.4.1 e 2.1.4.1 estão orientando erros durante a validação do iss retornem o código HTTP 400, porém nas demais orientações de segurança, por exemplo, como assinar o payload, as orientações são de que o código que deve ser utilizado é o 403

Dessa maneira, não existem erros no plano de teste reportado. Para uma execução bem sucedida do mesmo é preciso adaptar a implementação para que esteja em conformidade com o summary do teste.

Estamos a disposição para qualquer dúvida adicional!
