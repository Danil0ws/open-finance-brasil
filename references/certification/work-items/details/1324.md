## 1. What happened and what were you expecting?

In the section "Mapeamento de mensagens retornadas pela API Consentimento" it specifies the error code:

`CONSENTIMENTO_JA_REJEITADO`.

https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/219480491/Orienta+es+-+DC+Consentimento#Mapeamento-de-mensagens-retornadas-pela-API-Consentimento.

But in the conformance test it expects a different error code:

`CONSENTIMENTO_EM_STATUS_REJEITADO`

Which one is correct?

Prezado,

De acordo com o direcionamento que recebemos do GT Especificações,
Atualmente, existe uma divergência entre duas documentações elaboradas pelo grupo técnico:

No Swagger (e nos testes) foi utilizado o código de erro CONSENTIMENTO_EM_STATUS_REJEITADO
Na página de orientações da API foi utilizado o código de erro CONSENTIMENTO_JA_REJEITADO.

Para corrigir essa situação, o GT elaborou a proposta em anexo. A mesma já foi aprovada (em nível GT) e está em deliberação do CD (4 votos favoráveis até o momento e nenhum contrário).

O GT entende que a proposta não deverá gerar impactos no motor uma vez que este foi desenvolvido com base no Swagger e o mesmo não será alterado.

Assim que possível, a página de orientações será atualizada para refletir o conteúdo da proposta.

Qualquer dúvida, estamos a disposição.
