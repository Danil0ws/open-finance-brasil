Hi,

Thanks for opening the issue!

Test indeed failed due to a timeout:

> PATCH request for "https://rs1.openbanking-hml.bancoamazonia.com.br/open-banking/payments/v4/pix/payments/1401402682": Read timed out

This happened because the response for the PATCH call was not received by the conformance suit in the expected time. 

According to the available specification the definition of the server's response timeout by the client is of 15 seconds:

![image.png](/uploads/34df71147bc9c05bcf1c70153964c618/image.png)

Please make sure that Authorization server is responding to the PATCH call within the delimited range! \\
