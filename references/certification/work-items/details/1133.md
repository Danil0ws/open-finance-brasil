## 1. What happened and what were you expecting?

After receiving a POST payment, the response have a link object, with a self String inside it. The test suite demands that this self String follow a regex ending with the paymentID. Given multiple paymentsIDs, what should be present at the end of the link? Wouldn't it make sense that the resource at the end of this String be the consentID, given all payments in a recurring payment are linked to a single consent? Otherwise, do you expect the first paymentID?
