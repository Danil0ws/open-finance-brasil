## 📝 Descrição

Hello there,

we noticed that the test **payments-api-qres-good-phone-number-proxy-test** is not setting the phone number on the qrCode, due to recent changes on the InjectQRCodeWithRealPhoneNumberIntoConfig class.

**old code**

```java
consentPaymentDetails.addProperty("qrCode", QrCodeKeys.QRES_PHONE_NUMBER);
paymentInitiation.addProperty("qrCode", QrCodeKeys.QRES_PHONE_NUMBER);
```

**new code**

```java
PixQRCode qrCode = new PixQRCode();
qrCode.useStandardConfig();
```

...

```java
 consentPaymentDetails.addProperty("qrCode", qrCode.toString());
 paymentInitiation.addProperty("qrCode", qrCode.toString());
```

This changes affects our execution since we validate the proxy on the payload with the one on the qrCode, we believe this is a mistake on the certication tool.

Could you please help us with this issue?

https://web.conformance.directory.openbankingbrasil.org.br/log-detail.html?log=qkJ6zM0kmSnvXCG
