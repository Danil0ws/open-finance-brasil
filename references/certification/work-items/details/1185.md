Hi, 

thanks for opening the ticket!

After analyzing the provided test ID, it can be stated that the test failed because, of the data_type of the field "data" in the response_body contained within the response for the GET /pix/payments/{paymentId}. More specifically, as described in the specification, which can be found on the following link: https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/239337826/Informa+es+T+cnicas+-+SV+Pagamentos+-+v4.0.0-beta.4

While the "data” field should be an object contains multiple key-value pairs, in the provided response_body the "data” field takes form of an array, thus generating the failure from the validator.

Therefore, the conformance Suit is working as expected. To ensure a Successful run of the test module, please ensure the "data” field is as described in the provided specification.

Feel free to open another ticket if you get any other issue!
