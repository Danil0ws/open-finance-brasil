1. What Happened and what were you expecting?

Some test modules are using the Config provided by the participant for the Creditor account, which is not linked to the Proxy key provided by the conformance suite

For ALL the QRCode tests, the creditor and creditor account fields objects should match the DictHomolog Keys for both the e-mail and the phone examples 

Those keys are defined on: 

https://gitlab.com/obb1/certification/-/blob/master/src/main/java/net/openid/conformance/openbanking_brasil/testmodules/support/payments/DictHomologKeys.java
