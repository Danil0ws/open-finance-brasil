Hi!

Thanks for opening the ticket

The execution of the test module failed while the Conformance Suit executed step:

**Validate Consent Self link**

This means, Conformance Suit proceeded to validate the Self link contained in the response to the POST Consents request.

The self link sent in the response for this request was:

**"links":{"self":"http://oauth2.pop.opf.hom.api.itau/core/itau-itau/open-banking/consents/v3/consents"}**

According to the pagination specification at: [Paginação](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/17377470/Pagina+o)

- When called, the POST method should return the link to the resource created

Thus, as the self link contained in the payload of the POST Consents does not direct to the desired GET endpoint, the Conformance Suit returned an error as expected. In order for the test module to run successfully, make sure that the self link field points to the desired endpoint and follows the standards defined in the specification.
