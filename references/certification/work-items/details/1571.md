Hi,

thanks for opening the ticket!

→ Regarding consents_api_delete_test-module_v3:

The test failed due to the productType not being present on the test config json.

In order to execute this test successfully, please make sure that you include in the test config the following:

`"consent": { "productType": "personal" },`

This test module is going to be updated so that this fields is no longer required on the test config json and instead uses the provided brazilCPF or brazilCNPJ to automatically detect the appropriate productType

→ Regarding consents_api_extension-invalid-status-rejected_test-module_v3

Test module failed because, when it fetched AuthServer From Participants Endpoint, and parsed it's payload, it could not find any ApiDiscoveryEndpoints for the resources v3 api. Meaning that it might not have been configured to the AuthServer. In this regard conformance suit is operating as expected. As access to the resources endpoint is necessary for this test module to run successfully, please make sure that it is properly registered to the AuthServer.

Fell free to open a new ticket or reopen this one if you have any more questions,

Happy to help!
