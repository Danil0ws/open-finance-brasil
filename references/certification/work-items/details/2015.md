## 📝 Descrição

**Current Behavior:** There is a contradiction in the specification regarding the date field for the /pix/recurring-payments endpoint.

In the spec description: The **date field** is described as "A string with the use of **UTC timezone** (UTC time format)". https://openbanking-brasil.github.io/openapi/swagger-apis/automatic-payments/?urls.primaryName=2.0.0-beta.2#/Recurring%20Payments/automaticPaymentsPostPixRecurringPayments

In the "**Convenções de formatação e fuso horário de campos de data e hora**" section: It states, "For fields where the type is string($**date**), the format used is YYYY-MM-DD, with the current **timezone being Brasília Time UTC-3**." https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/728301690/SV+Conven+es+de+formata+o+e+fuso+hor+rio+de+campos+de+data+e+hora

These two descriptions are inconsistent, leading to uncertainty about which format and timezone to use for the date field in /pix/recurring-payments.

**Expected Behavior:**

The description for the date field in the /pix/recurring-payments endpoint and the "Date and Time Formatting and Timezone Conventions" section should be consistent. The specification should clearly define:

Date format: Whether it is expected in UTC or Brasília Time (UTC-3). Timezone: Whether the timezone should always be UTC or match Brasília Time. A clear and unified approach should be provided to avoid misimplementation and discrepancies in compliance testing.

Evidence: Links: https://openbanking-brasil.github.io/openapi/swagger-apis/automatic-payments/?urls.primaryName=2.0.0-beta.2#/Recurring%20Payments/automaticPaymentsPostPixRecurringPayments https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/728301690/SV+Conven+es+de+formata+o+e+fuso+hor+rio+de+campos+de+data+e+hora

Recurring Payments Specifications Relevant Description: date: "Data em que o recurso foi criado. Uma string com a utilização de timezone UTC (UTC time format)."

Date and Time Formatting and Timezone Conventions: Date: "Campos onde o tipo é string($date), o formato utilizado é AAAA-MM-DD. Seu fuso horário atual é o horário de Brasília UTC-3."
