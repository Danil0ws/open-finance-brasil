Hi,

Thanks for opening the ticket!

Test module attempts to refresh token when the token is linked to a consent in status REVOKED.

According to the security spec:

> deve apenas emitir refresh_tokens quando vinculados a um consentimento ativo e válido;

As the consent is not in a valid and active state, such as AUTHORISED, Conformance suit is expecting a 400 when attempting to refresh token, working as expected.
