Hi,

After analysing the execution logs and the response returned by your endpoint, we identified the reason for the failure.

Although your service is returning the header:

Content-Type: application/jwt

the **response body itself is not in JWT format**, but in plain JSON format.

![image.png](/uploads/406ff3c9d070081a9f2601281f860a07/image.png){width=900 height=293}

The FVP engine performs a **body structure validation before validating the Content-Type header**. This validator is universal and applies to all tests. Therefore:

* If the header indicates `application/jwt`,
* The body must be a properly structured JWT (JWS compact serialization),
* Not a JSON payload.

Once the body is correctly returned as a valid JWT, the FVP validation should proceed without this error.

Please adjust the response format accordingly and re-run the test.

We remain available if further clarification is needed.
