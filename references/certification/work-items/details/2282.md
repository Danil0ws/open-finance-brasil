#### Current Behavior:
---
The Conformance Motor test `aRfjYQQqBUthsUm` for `automatic-payments_api_automatic-pix-webhook_test-module_v2n2` is failing. The API is returning a `422 Unprocessable Entity` response instead of `201 Created`.

This is happening because the test request is sending the `paymentReference` property in an outdated format (`W33-2025`), which was used in previous versions (2.0.0/2.1.0).

#### Expected Behavior:
---
The test should use the new `paymentReference` format (`06-07-2025/P1W`) to align with the current specification and allow the test to pass.
