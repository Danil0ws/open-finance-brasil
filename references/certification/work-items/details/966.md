## 📝 Descrição

## 1\. What happened and what were you expecting?

We need to update behavior of payments_api_multiple-consents-no-funds-conditional_test-module_v3 as follows (Changes in **bold**):

This test module should be executed only by institutions that currently support consents with multiple accounts, in case the institution does not support this feature the ‘Payment consent - Logged User CPF - Multiple Consents Test' and 'Payment consent - Business Entity CNPJ - Multiple Consents Test’ should be left empty, which in turn will make the test return a SKIPPED\
This test module validates that the payment will reach a RJCT status when canceled by the payment initiator\
• Validates if the user has provided the field “Payment consent - Logged User CPF - Multiple Consents Test”. If field is not provided the whole test scenario must be SKIPPED\
• Set the payload to be customer business if Payment consent - Business Entity CNPJ - Multiple Consents Test was provided. If left blank, it should be customer personal\
• Creates consent request_body with valid email proxy (cliente-a00001@pix.bcb.gov.br) and its standardized payload, set the Payment consent - Logged User CPF - Multiple Consents Test” on the loggedUser identification field, and the amount to be 9999999999.99, Debtor account should not be sent\
• Call the POST Consents API\
• Expects 201 - Validate that the response_body is in line with the specifications\
• Redirects the user to authorize the created consent - **Expect Failure**

* **Ensure an error is returned and that the authorization code was not sent back**
* Call the GET Consents API
* Expects 200 - Validate response - Check if Status is REJECTED and rejectionReason is SALDO_INSUFICIENTE or VALOR_ACIMA_LIMITE

Also, as seen at https://web.conformance.directory.openbankingbrasil.org.br/log-detail.html?log=sfY2KFa1zvMO5x3&public=true, the test is not executing the last step "Check if Status is REJECTED and rejectionReason is SALDO_INSUFICIENTE or VALOR_ACIMA_LIMITE" accordingly, as it is expecting authorised status and not finding th rejectionReason.
