Prezado,
 

De acordo com o direcionamento que recebemos do GT Especificações,
com as "Informações Gerais" da API Comum, é estipulado que "A instituição deve disponibilizar previamente a previsão de indisponibilidade agendada dos seus serviços [...]", o que implica que a existência de uma programação de indisponibilidade é uma parte da reposta do recurso /Outages para o status 200.


 
Portanto, se não houver nenhuma programação de indisponibilidade para relatar, isso significa que o recurso solicitado não existe naquele momento. Nesse caso, deve-se retornar o status 404, indicando que o recurso solicitado não foi encontrado ou não está disponível.
 

Agradecemos o contato,

Qualquer dúvida, estamos a disposição.
