## 📝 Descrição

**Description:**

An improvement made on March 30th removed an intentionally empty `testCleanup()` override from `AbstractFvpPaymentApiSchedulingAsynchronousTestModule` as part of a cleanup. This caused test 1-2 to inherit the PATCH consent cancellation from the parent class, which runs as part of `validateResponse()`.

The 1-2 → 2-2 test pair requires payments to remain scheduled (SCHD) after test 1-2 so they can settle and be verified as ACSC on D+3 by test 2-2. Cancelling the consent in test 1-2 breaks this flow.
