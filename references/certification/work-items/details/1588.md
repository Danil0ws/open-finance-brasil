Hi,

Thanks for opening the ticket!

The test module execution failed due to:

* After POST Payments endpoint is called, Conformance suit expects an incoming message, one for each defined endpoint, payments and consent, as described on the test description.
* In this step, conformance suit first Validates if Payment Consent Webhook was received, which it did, and so the test followed.
* Afterwards it Validates if Payment Webhook was received. At this step it identified that two Payment webhook calls were received, thus resulting on the observer behavior.

As conformance suit was expecting to receive one of each webhook call, and it actually received one Webhook call from consent and two others from Payment webhook it resulted in error as is to be expected. To ensure test module can be run successfully make sure that only one Payment webhook request is made.
