What could be that I'm doing wrong? Creating a new DCR using private_key_jwt or tls_client_auth I always have to send the crt file and key to make the DCR to work.

### Comentário 6
**Autor**: GeorgeMc (@georgemc)
**Criado em**: 06/06/2022, 14:00:17

May we see your test configuration please? The conformance tests themselves can be configured for either of those two methods of client authentication, and whichever one you choose, your oauth client *must* be able to use that method. Thus, if your client supports tls client auth, the tests *must* be configured to use mtls as the client authentication method. Similarly private key jwt *must* be used with clients configured for private key jwt authentication. 

In either case, the connection to the /token endpoint will be an mtls connection.
