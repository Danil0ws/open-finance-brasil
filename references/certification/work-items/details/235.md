## 📝 Descrição

## 1. What Happened and what were you expecting?
Mock Bank's credit card bills endpoint response does not follow the [pagination specification](https://openbankingbrasil.atlassian.net/wiki/spaces/OB/pages/1737881/Pagina+o#Links).
`prev` and `next` attributes from `links` object are being filled with the same value as the `self` attribute when the response has only 1 page.

According to the specification:
- `prev` -> Mandatory when there is a previous page. Should not be sent when it is the first page.
- `next` -> Mandatory when there is a next page. Must not be submitted when last page.

Since the response has only 1 page, I expected that both `prev` and `next` as `null`, given that the 1 and only page is also the first and last page.

The one credit card available from Mock Bank has a single bill, so I was expecting the `links` object to be (I replaced the credit card resource ID):
```json
"links": {
  "self": "https://matls-api.mockbank.poc.raidiam.io/open-banking/credit-cards-accounts/v1/accounts/1-2-3-4/bills",
  "first": "https://matls-api.mockbank.poc.raidiam.io/open-banking/credit-cards-accounts/v1/accounts/1-2-3-4/bills",
  "prev": null,
  "next": null,
  "last": "https://matls-api.mockbank.poc.raidiam.io/open-banking/credit-cards-accounts/v1/accounts/1-2-3-4/bills"
}
```
Or
```json
"links": {
  "self": "https://matls-api.mockbank.poc.raidiam.io/open-banking/credit-cards-accounts/v1/accounts/1-2-3-4/bills",
  "first": null,
  "prev": null,
  "next": null,
  "last": null
}
```

Instead, the response from the bills endpoint was:
```json
"links": {
  "self": "https://matls-api.mockbank.poc.raidiam.io/open-banking/credit-cards-accounts/v1/accounts/1-2-3-4/bills",
  "first": "https://matls-api.mockbank.poc.raidiam.io/open-banking/credit-cards-accounts/v1/accounts/1-2-3-4/bills",
  "prev": "https://matls-api.mockbank.poc.raidiam.io/open-banking/credit-cards-accounts/v1/accounts/1-2-3-4/bills",
  "next": "https://matls-api.mockbank.poc.raidiam.io/open-banking/credit-cards-accounts/v1/accounts/1-2-3-4/bills",
  "last": "https://matls-api.mockbank.poc.raidiam.io/open-banking/credit-cards-accounts/v1/accounts/1-2-3-4/bills"
},
"meta": {
  "totalRecords": 1,
  "totalPages": 1,
  "requestDateTime": "2021-05-21T08:30:00Z"
}
```
