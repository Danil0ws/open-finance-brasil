## 1. What Happened and what were you expecting?
The conformance suite is the sending the proxy key fixed as "cliente-a00002@pix.bcb.gov.br", which have the following CPF associated to it: "999.922.222-63". At the same time, the test is using the following creditor information:

```
    "creditor": {
      "name": "Joao Silva",
      "cpfCnpj": "99991111140",
      "personType": "PESSOA_NATURAL"
    }
```


As the user from the creditor and the proxy key _are not the same_, we are rejecting this transaction for both payments-api-temporization-conditional-v2 and payments-api-canc-temporization-conditional-v2 and failing the test. For both tests, the creditor information should be the same as the user from the proxy key, including CPF(99992222263), issuer (0002) and account number (11345678).
