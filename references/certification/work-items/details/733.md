Following the changes at [Informe 395](https://mailchi.mp/38e1eca97fc0/open-banking-informa-9342900?e=2eb7798bd9), the idempotency scenarios are now enabled and, following the payments Api swagger:

2.2.2.10 Idempotência: Valida se há divergência entre chave de idempotência e informações enviadas (ERRO_IDEMPOTENCIA).

In that sense, the error 422 with ERRO_IDEMPOTENCIA code should be returned.
