## 📝 Descrição

**Summary** 

The idempotency test module for Payments API v5 calls `PATCH /pix/payments/{paymentId}` to cancel a scheduled payment without first polling to confirm the payment has transitioned to `SCHD` or `PDNG` status. This causes false test failures for institutions that process state transitions asynchronously, which is permitted by the OFB Payments API v5 specification.

**Expected Behavior**

A polling step should be added between _"Expects 422 CONSENTIMENTO_INVALIDO"_ and _"Call PATCH with x-idempotency-key"_:

> Poll `GET /pix/payments/{paymentId}` until `status == SCHD` or `status == PDNG` (with timeout), before proceeding to the PATCH cancellation steps.
