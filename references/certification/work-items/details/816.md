## 📝 Descrição

## 1\. What Happened and what were you expecting?

In the specification, the "Income Tax" structure is described as a conditionally filled structure if the "type" field is filled with the value "SAIDA". During the tests we are getting an error for the fields of this structure, considering that the field "type" is filled as "ENTRADA" and therefore the structure "Income Tax" would be "blank".\
Field validation is expected to be done correctly.

Hi,

Thanks for the ticket! 

Indeed, the field `incomeTax` is required only in the cited conditions. However, the test failed because your transaction `type` is "ENTRADA" and your implementation sends the optional field `incomeTax`, which should not be sent when not required.

Therefore, there is no corrections on the CS side. To ensure a successful execution, the implementation should be adjusted to send optional fields only when necessary.

Feel free to open another ticket if you get any other issue! Happy to help!
