## 📝 Descrição

In consent-api-status-declined-test, after declining the consent, it expects that a call on GET consents return an HTTP 200 with the REJECTED status.
We are failing in this test, as we return in this situation an HTTP 404, the same way that gives us a success in consent-api-test.
We need a standard behaviour in this tests, given that they are basically the same but expecting different results.
