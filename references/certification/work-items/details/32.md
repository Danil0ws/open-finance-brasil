## 📝 Descrição

When customer-business-data-api-test validates customer business qualifications API response, it complains about the pattern of the amount element.
We are returning a valid value in this field according to the specfication, 6426115000.0000, but the test makes some sort of convertion in the validation and the test fails showing the value 6.426115E9
You can check this behaviou on test id BAfNUZRe1nIWIPh, https://web.conformance.directory.openbankingbrasil.org.br/log-detail.html?log=BAfNUZRe1nIWIPh
