## 📝 Descrição

#### Current Behavior:
---
The test CheckIfAuthorizationEndpointError, specifically within the "Verify authorization endpoint response" validation step, is reporting an access error.

However, the preceding validation step, "Make request to authorization endpoint" (which executes the CallPAREndpoint call), resulted in an HTTP 201 (Created) response, indicating a successful request to the PAR endpoint.

#### Expected Behavior:
---
Given that the PAR endpoint request was successful (HTTP 201), the subsequent "Verify authorization endpoint response" validation should not interpret this as an access error, and the CheckIfAuthorizationEndpointError test should not fail under this circumstance.
