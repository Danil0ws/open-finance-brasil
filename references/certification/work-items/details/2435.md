#### Expected Behavior:
---
But i think it's wrong, because that test plan don't involve optimised journey. `isLinked=false`
So, in this case, we have 2 options:
- When `isLinked=false`, don't send `linkId`. Like is consent 3.3 doc 
![image](/uploads/282b03bc07cf956bedeea1e66919e3d7/image.png){width=899 height=352}
- Or when `isLinked=false`, send `linkId=null`

In both cases the documentation will need to be updated.

Hello @VandersonCamatini, following up on this point.

We’ve checked this matter with DTO payments product group and their guidance is that, when the journey is not an optimised journey, the response can be direct and the object in question **should not be sent**. 

In other words, for non-optimised journeys, the presence of that object (and its fields) is not required, as we can see here:

![image.png](/uploads/6609fe749e90d66f3c28cec720aad597/image.png){width=479 height=171}
