## 📝 Descrição

As requested by the participant on SD ticket Number: https://servicedesk.openfinancebrasil.org.br/SREdit.jsp?id=63998&fromId=List&isFromAll=true

Open data API Loans
Field: data.interatestRate.rate
Endpoint: ResponsePersonalLoans

The field currently has pattern ^\d{1}\.\d{6}$
Conformance suit is operating accorgind to avaialble specificaiton

Participant Suggested the update of this pattern  to  follow same pattern defined for interestRates.preFixedRate fields on Customer Data Apis.
Pattern ^\d{1,6}.\d{6}$

Therefore the evaluation required by the participant for the WG is:
* 		Should this pattern be updated to Pattern ^\d{1,6}.\d{6}$ on future version of API?

#### Evidence:
https://web.conformance.directory.openbankingbrasil.org.br/plan-detail.html?plan=qDGgu7NIfmICd&public=true
