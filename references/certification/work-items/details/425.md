This step tests an invalid issuer which expects a 403 as clearly defined [by specifications.](https://openbankingbrasil.atlassian.net/wiki/spaces/DraftOB/pages/74154027/Idempot+ncia+-+v1.2.0+-+Pagamentos)

![image](/uploads/4a2b986ee4743e68a44f469810ba1567/image.png)

As the failure is on the JWT the return of the 403 is a JSON which explains the error that you are receiving.

```
    Forbidden:
      description: O token tem escopo incorreto ou uma política de segurança foi violada
      content:
        application/json; charset=utf-8:
          schema:
            $ref: '#/components/schemas/ResponseError'
```
