## 📝 Descrição

Hello, I caught an error on the payments_api_recurring-payments-patch_test-module_v4.

The regex validates that format:

```
^(https://)(.*?)(/open-banking/payments/v\d+/consents/)urn:indigo:1e4b0e69-84e7-48d8-a6fb-283e20eb201c(.*)
https://mtls.indigo.hml.linaob.com.br/open-banking/payments/v4/consents/urn:indigo:1e4b0e69-84e7-48d8-a6fb-283e20eb201c
```

But if we need to return the same URL as the request, the correct expression is:

```
^(https://)(.*?)(/open-banking/payments/v\d+/pix/payments/consents/)urn:indigo:1e4b0e69-84e7-48d8-a6fb-283e20eb201c(.*)
https://mtls.indigo.hml.linaob.com.br/open-banking/payments/v4/pix/payments/consents/urn:indigo:1e4b0e69-84e7-48d8-a6fb-283e20eb201c
``` 

[Observation] The documentation doesn't specify the correct format:
https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/305594722/Informa+es+T+cnicas+-+SV+Pagamentos+-+v4.0.0-rc.2

Test details can be found here:
https://web.conformance.directory.openbankingbrasil.org.br/plan-detail.html?plan=CwsxLELYe3oDc&public=true
