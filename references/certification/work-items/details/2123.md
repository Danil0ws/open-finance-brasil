## 📝 Descrição

#### Current Behavior:
---
Currently, in the FIDO registration flow, MB supports only RSA keys in the `attestationObject`.

#### Expected Behavior:
---
Since there is no documented restriction on the accepted key types, this task aims to add EC2 as a valid key type in the flow.

#### Evidence:
---
An evidence of EC2 being reject by MB in the mentioned flow can be found under `x-fapi-interaction-id`: _f2d96a37-0ab4-48db-924f-818c7ce3599c_ 

(additional details are available at https://gitlab.com/raidiam-conformance/open-finance/certification/-/issues/2116)
