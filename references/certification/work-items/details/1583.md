Hi,

Thanks for opening the ticket! Actually the test module execution is returning error while executing PostPaymentsPixValidatorV4, meaning that, what is being validated in that stance is the response for POST pix/payments. The response of the POST pix/payments has data field as a Json Object, which is not to be expected according to the specification aforementioned.

What is being provided:

`"data": {}`

What is expected:

`"data": []`

In order to execute the test module successfully make sure that "data” field in POST pix/payments is as array as determined by the specification.

Feel free to open a new issue if you have any more questions, happy to help!
