Hello,

We have discussed this topic and we still haven't confirmed if the Mock Bank must support revocation.

We can confirm that currently, it's a feature that is not supported by the Mock Bank.

This is not against FAPI as we have that on [FAPI Baseline](https://openid.net/specs/openid-financial-api-part-1-1_0.html)

18. should provide a mechanism for the end-user to revoke access tokens and refresh tokens granted to a client as in 16.18 of OIDC;

We will check on our next planning if this endpoint should be added or not.

Currently, we broadcast this endpoint on the MB well-known, so we might need to remove it. 
https://auth.mockbank.poc.raidiam.io/.well-known/openid-configuration
