Hello @jeferson.perito1. When you call POST /api/runner to create the test, the server also auto-starts the execution. So the test is already running right after the first request.

If you then call POST /api/runner/{{id}} to “start” the test, the server starts it again. This **second start** is what creates the second consent.

Please try running the test without the second POST:

* POST /api/runner?plan={{planId}}&test={{testName}}
  * Do not call POST /api/runner/{{id}}.
  * Use POST /api/runner/{{id}} only when you want to restart a previous test.

To check progress and results, use:

* GET /api/runner/{{id}}
  * Use the id returned in the response body from step 1.
  * Call this whenever you need to check the status or the final results.

With this flow, you should get only one consent. Please feel free to reopen this issue if needed.
