## 📝 Descrição

# 1. Issue

Test is failing due to required field not present.
But as per the specification, should be a conditional/dependent situation **"Preenchimento obrigatório se selecionado tipo de transação PAGAMENTO"**

# 2. Test URL

[https://web.conformance.directory.openbankingbrasil.org.br/log-detail.html?log=OHKiGYKLUrA2uQD](https://web.conformance.directory.openbankingbrasil.org.br/log-detail.html?log=OHKiGYKLUrA2uQD)

# 3. Proposed solution

To provide a **default value** for the **paymentType** field

I agree with you paymentType does not have the nullable=true property while also being set as being required, so the field becomes mandatory.

It's also not clear what should be the response in case you don't have this property so you are failing. 

We have checked the file https://openbanking-brasil.github.io/areadesenvolvedor/documents/problemas_conhecidos_fase_02_v11.pdf under https://openbanking-brasil.github.io/areadesenvolvedor/#problemas-conhecidos-da-especificacao and we couldn't find either a proposed return in case you don't have this.
