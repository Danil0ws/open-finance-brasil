After a thorough evaluation of the test log provided, we were able to conclude that the it is not an unexpected behavior from the conformance suit. This behavior happens when conformance suit cannot find the API registered in the directory, thus using the consent url to build the path to the customer api. Please make sure the customer API is correctly configured to the auth server to prevent this failure from happening.\
