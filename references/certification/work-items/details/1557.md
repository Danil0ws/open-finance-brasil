Thanks for opening the ticket!

As it is stated on the test module summary

> Test will make sure that the pagination rules are being respected for the exchange events endpoint, by changing the page-size and the page parameter of the URI and confirming that pagination is being correctly done. Test will also require at least 51 exchange operations events to be returned

As the main objective of this test module it to ensure the correct implementation of the multiple pagination fields, to be able tu run the test successfully it is required that there are at least 51 exchange operations events can be returned. Providing there are at lease 51 exchange operations events, when conformance suit calls \*\*\*\*GET Events endpoint with page-size equal to 25, only the first 25 elements are returned on the response_body and the rest of the elements would be contained within the next link which is called afterwards and is where the test module resulted in failure, due to there not being enough events for a next link to be included on the responde_body meta. Therefore conformance suit is operating as expected in this regard, please make the changes as described above so that test module can be run sucessfully.
