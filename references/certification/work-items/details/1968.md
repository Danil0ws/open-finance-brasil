Hi, @gabvcampaner 

Thanks for the ticket! 

After investigating, I found that the authorization server referred to (`6d5c0bed-5891-4b68-9a95-e9d2ce20c25d`) indeed has the endpoints for automatic payments v2 registered as resources. However, we couldn't determine exactly when these resources were registered to compare with the test execution time.

It’s possible that the endpoints were registered, and the test was executed shortly afterward. This timing could result in the new resources not being recognized, as updates may take up to 15 minutes to propagate before the resources can be utilized.

After a new execution of the same test, the resources are now found successfully, as shown here: https://web.conformance.directory.openbankingbrasil.org.br/log-detail.html?log=cv2HUrl7Ap8o5wO

Regarding the new error displayed: the test indicates that the configuration field `contractDebtorName` within the `resources` object is missing. To execute the tests successfully, it’s necessary to ensure all required fields in the configuration are filled:
![image](/uploads/2bf65d8cbafdeb7a15ee9237d1572fc3/image.png)
