Hi,

After further analysis of the provided logs,

We were able to identify the root cause of the failure:

During test step:

> **Call GET recurring-payments/{recurringPaymentId} endpoint to fetch original payment data**

Conformance Suit calls endpoint: 

**GET** **/automatic-payments/v2/pix/recurring-payments/30d227f4-d365-4999-9ccf-0df12243b71c**

The server returned in the response for this request:

```
"paymentReferece": "W11-2025",
```

Therefore this incorrect information provided by the server is being used by the Conformance Suit to generate the POST Recurring-payments request body, resulting in the observer failure.

Conformance Suit is operating according to expected in this regard, make sure that the server is sending the field correctly on response to the aforementioned endpoint requested.

Feel free to add comments here in case further assistance is needed, happy to help!
