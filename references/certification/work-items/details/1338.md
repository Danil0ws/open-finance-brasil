Hi Everybody! This test has been updated to follow new rules that are being released by Automatic Payments rc.2, which will have an Informa today later and will be released to the ecosystem by the end of this week.

In this new spec, the startDateTime becomes optional and is only mandatory if the startDateTime is in the future. When not sent, the startDateTime should be considered as now.

We recommend you wait until the spec is released to execute the changes, although the tests are already updated.
