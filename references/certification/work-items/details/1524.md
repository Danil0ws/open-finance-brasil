Hi Gutemberg! Thanks for the ticket!

As discussed at https://gitlab.com/raidiam-conformance/open-finance/certification/-/issues/1425, following [**Informações Gerais**](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/312049910/Conven+es+de+formata+o+e+fuso+hor+rio+de+campos+de+data+e+hora+-+v1.0.0-rc.3+-+SV+Pagamentos+Autom+ticos):

* Datas com o padrão "date" ( AAAA-MM-DD), como o campo data.date em POST Payments, devem seguir fuso horário brasília UTC-3.

In that sense, the conformance suite is sending the "date" parameter as localTime. In order to have success, you should adjust the startDateTime sent to be in UTC, and date in Local time, so you don't have this problem.

We are happy to help with any additional needs!
