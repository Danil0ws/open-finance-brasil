## 📝 Descrição

## 1. What happened and what were you expecting?

In test consents_api_extension-invalid-status-rejected_test-module_v2 a token associated with an expired consent (REJECTED) is used to trigger a consent extension request. According to the security specification, any access token/refresh token linked to an expired consent should be revoked.

![image](/uploads/8085bef180fc4b62aa3a7aedafb0d4ae/image.png)

Given this, the HTTP 401 error should be considered valid in this scenario.
