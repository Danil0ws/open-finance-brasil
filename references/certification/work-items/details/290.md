## 1. What Happened and what were you expecting?

Hi, on Informa #191 we received a new definition:

> Definição sobre Consentimentos Ativos
> Informamos aos participantes do Open Finance Brasil que, para fins de esclarecimento e padronização, o consentimento será considerado ativo quando a instituição transmissora enviar o refresh token. Este token de atualização é resultante da troca do authorisation code pelo access token.

Could you please clarify what the intent of this definition is? Is it simply defining what an _active_ consent is? So, a consent is active as long as a refresh token is sent during the auth code exchange for an access token? Therefore if a refresh token isn't sent, the consent is to be considered inactive, is that the intent?

Lastly, is this requirement covered in existing tests that we can use to verify whether we're compliant or not? Or will tests still be developed for it?

Thanks very much in advance!
