## 📝 Descrição

The "payments-api-negative-tests" test checks if the response error code is CONSENTIMENTO_INVALIDO, but in the next step it also checks if the response error code is either VALOR_INCOMPATIVEL or PAGAMENTO_DIVERGENTE_DO_CONSENTIMENTO, which will cause the test to fail no matter which error code was returned.
