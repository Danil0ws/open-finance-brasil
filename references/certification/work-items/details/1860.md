#### Current Behavior:

---

This issue affects the following test plans on OPEN FVP:

* **fvp-payments-e2e_open_test-plan-v4**
* **fvp-no_redirect_payments_open_test-plan-v1**
* **fvp-automatic-payments_open_test-plan-v1**

When creating Test Plans for Payments in OPEN FVP, we initially specified that participants must fill in the following credit fields:

* **creditorAccount - ISPB**
* **creditorAccount - Issuer**
* **creditorAccount - Number**
* **creditorAccount - AccountType**

However, during production testing in OPEN FVP, it was observed that certain default values populate these fields:

* **Creditor CPF**
* **Creditor Name**
* **Creditor Proxy**

By default, these fields are populated in the configuration JSON with the default information:

```
"creditor": {
  "cpfCnpj": "124XXXXXXXX",
  "name": "LuccaXXXXXXXXXXXXXXXXXXXXXXX",
  ...
}

"detais":{
  "proxy": "luccaXXXXXXXXXXXXXX",
  ...}
```

This is a non-blocking bug. While test execution is possible, participants must manually update these fields in the JSON configuration to prevent errors. If participants do not modify these fields in the JSON configuration, any payment creation attempt will most likely fail due to mismatches with the actual creditor account data.

We are actively working to add these fields directly in the configuration form to eliminate the need for manual changes and reduce the chance of errors.
