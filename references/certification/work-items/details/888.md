## 📝 Descrição

## 1. What Happened and what were you expecting?

The data parameters used for delimiting the initial and final dates for Transactions and Transactions-Current endpoints was wrongfully altered on all phase 4b APIs when it should have been modified only for Funds. The correct parameters names for all phase 4b APIs (except for Funds API) should be `fromTransactionDate` and `toTransactionDate`, but it CS is currently using the Funds API parameter name:  `fromTransactionConversionDate` and `toTransactionConversionDate`.
