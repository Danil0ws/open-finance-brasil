## 📝 Descrição

## 1\. What happened and what were you expecting?

In this test module, conformance suit expects: 422 PERMISSAO_PF_PJ_EM_CONJUNTO

In the[ Consents API Swagger](https://openbanking-brasil.github.io/openapi/swagger-apis/consents/?urls.primaryName=3.0.0-rc.1#/Consents/consentsPostConsents) it states that a 422 code field should be:

![image.png](/uploads/97b4af335a3022811b88136c021b5fb0/image.png)

While in [Orientações - \[DC\] Consentimento](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/219480491/Orienta+es+-+DC+Consentimento) it states:

6. Nas situações abaixo, a transmissora deve rejeitar o pedido de criação de consentimento, dando retorno HTTP Status Code 422 com as mensagens especificadas abaixo:

   c. Caso recebam uma solicitação de consentimento com permissões de dados cadastrais PF e PJ em conjunto, retornar HTTP Status Code 422 com a mensagem “PERMISSAO_PF_PJ_EM_CONJUNTO”;

And at the same time:

![image.png](/uploads/2e42dfb118d3db1d23309ebfced6a480/image.png)

What is the correct error message to be considered?
