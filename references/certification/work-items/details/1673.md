#### Current Behavior:

---

Our tests of FVP 1.0 have been failing due to intermittent issues with the OCSP endpoint of the certificate being sent in the dcr_api_fvp-dcm-subjectdn_test-module test. OCSP validation is used to check whether the certificate is valid or has been revoked. The mentioned intermittency is causing the test to fail in some of the executions, but not all, and we would like to know if the certificate really is having problems and if this error is occurring with other entities, or if it is an issue we need to address internally, and if so, how should we handle it?
