Now re-reading your comment it seems you are talking about the transactionFromDateTime that is sent not on the accounts API but on the **consents API.** 

In this case, **YES** we have set the Mock Bank to refuse those fields as they have been removed from version 2 of the API. https://openbanking-brasil.github.io/openapi/swagger-apis/consents/2.0.0-RC1.0.yml. As there we expect to have an explicit test to block this behaviour the Mock Bank will refuse any consent creation with those outdated fields.

If you are implementing a Phase 2 data receiver we recommend going directly without those fields as servers will no longer support it when version 2 of the APIs becomes required.
