The test failed because the webhook is sending a notification before any event triggered it, which is indeed unexpected. The webhook should only respond to specific changes in consents or payments state - you can consult more informations about which events should trigger a webhook notification in https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/135626778/Informa+es+Gerais+-+Webhook+-+v1.0.0-rc.1

Therefore, there is no corrections on the CS side. To a successful execution, the implementation needs to be adapted so that it is conformant to the specs.
