#### Current Behavior:
---
The test is creating the payment according to consent version (which is nice) but is using Payment V3 Payload on Request and validating V4 Payload on response, leading to a test that cannot pass in either cases.

#### Expected Behavior:
---
Use the request payload and the response payload validation on same Payments API version, according to consent or not. But using same version on request payload and on response validation is key to this test success.
