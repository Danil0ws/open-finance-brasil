Thanks for opening the ticket!

Test module execution failed due to the following reason:

Conformance suit called **POST pix/payments**

To which Server responded with response_status_code **200 OK**

As can be seen in [Payments v4 specification](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/347079010/Informa+es+T+cnicas+-+SV+Pagamentos+-+v4.0.0), When **POST pix/payments** is called successfully a 201 response_status_code is expected. 

![image.png](/uploads/9f8e7c0db0e69c41f0e564158b386ccc/image.png){width=661 height=78}

Therefore, conformance suit is working as expected.

Make sure that a 201 is returned for successful **POST pix/payments** calls and the test module will be able to proceed as expected.
