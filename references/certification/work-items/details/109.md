## 📝 Descrição

On [https://openbanking-brasil.github.io/areadesenvolvedor/#metricas](https://openbanking-brasil.github.io/areadesenvolvedor/#metricas)' response body example shows `data.availability.uptime.endpoints` as `array of objects`, but the same property on [Swagger](https://openbanking-brasil.github.io/areadesenvolvedor/swagger/swagger_admin_apis.yaml) is described as a single `object`.

The [GetMetricsAdminApiValidator test](https://gitlab.com/obb1/certification/-/blob/master/src/main/java/net/openid/conformance/openbanking_brasil/admin/GetMetricsAdminApiValidator.java#L118) is following the Swagger logic.

Which version is correct? Areadesenvolvedor or Swagger?
If areadesenvolvedor, I guess the Swagger and tests should be changed.

**Pontos abaixo referem-se a incompatibilidade do motor/especificações frente ao portal**

Teste funcional da API de métricas está com validações diferentes da documentação.

Erro 1 do motor: Validate Admin Metrics response: GetMetricsAdminApiValidator: Class cast exception, expect JsonObject, but found JsonArray. Field: endpoints on the Admin Api GET Metrics API response

A resposta do endpoints deve ser um array, não um objeto como o motor está configurado para buscar.
https://openbanking-brasil.github.io/areadesenvolvedor/#metricas

**Resposta: Motor Conforme com swagger conforme abaixo**

    EndpointUptime:
      type: object
      description: Tempos de uptime por endpoint.
      required:
        - url
        - uptimeRate
      properties:

Erro 2 do motor: Validate Admin Metrics response: GetMetricsAdminApiValidator: Unable to find element generalDowntime on the Admin Api GET Metrics API response

O motor está buscando generalDownTime dentro do objeto downtime,endpoints, mas deve procurar dentro de downtime somente.

**Resposta: Motor Conforme com swagger conforme abaixo**

        downtime:
          type: object
          required:
            - generalDowntime
            - scheduledOutage
            - endpoints
          properties:
            generalDowntime:
              type: integer
              description: Quantidade de segundos de downtime (considerando qualquer api em downtime).



Erro 3 do motor: Validate Admin Metrics response: GetMetricsAdminApiValidator: Class cast exception, expect JsonObject, but found JsonArray. Field: endpoints on the Admin Api GET Metrics API response

Idem Erro 1.

**Resposta: Motor Conforme com swagger conforme abaixo**

    EndpointUptime:
      type: object
      description: Tempos de uptime por endpoint.
      required:
        - url
        - uptimeRate

    EndpointDowntime:
      type: object
      description: Tempos de downtime por endpoint.
      required:
        - url
        - partialDowntime
