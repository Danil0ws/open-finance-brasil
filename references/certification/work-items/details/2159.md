## 📝 Descrição

**Description:**

In the Credit Portability API documentation ([v1.0.0-beta.1](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/905740914/Informa+es+T+cnicas+-+PC+Portabilidade+de+Cr+dito+-+CPC+-+v1.0.0-beta.1)), within the `POST /portabilities` endpoint, the field `referentialRateIndexerAdditionalInfo` includes the following restriction:

> **\[Restrição\] Obrigatório para complementar a informação relativa ao Tipo de taxa referencial ou indexador, quando selecionado o tipo ou subtipo OUTRO.**

### Problem:

The restriction is **ambiguous** and lacks a precise mapping to which specific values of which fields trigger the requirement for `referentialRateIndexerAdditionalInfo`.

### Current field definition:

![image.png](/uploads/f2de476321503a9810cc630c826af083/image.png){width=803 height=126}

### Interpretation:

We are currently assuming that `referentialRateIndexerAdditionalInfo` is **required** when any of the following apply:

* `referentialRateIndexerType` is `OUTROS_INDEXADORES`
* OR `referentialRateIndexerSubType` is one of:
  * `OUTRAS_TAXAS_POS_FIXADAS`
  * `OUTRAS_TAXAS_FLUTUANTES`
  * `OUTROS_INDICES_PRECO`
  * `OUTROS_INDEXADORES`

### Request:

* Please confirm if the above understanding is correct.
* If so, could the specification be updated to list these values in the restriction description for clarity?

O comportamento deve ser idêntico ao já aplicado em produção na API de Operações de Crédito – Empréstimos, em que o campo referentialRateIndexerAdditionalInfo é condicional aos campos referentialRateIndexerType e referentialRateIndexerSubType. O valor "outros" pode representar as seguintes opções: OUTROS_INDEXADORES, OUTRAS_TAXAS_POS_FIXADAS, OUTRAS_TAXAS_FLUTUANTES, OUTROS_INDICES_PRECO ou OUTROS_INDEXADORES.
