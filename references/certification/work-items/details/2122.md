Hi @larissa.mauricio1 

The error presented is a Read Time Out. This means that the server took longer than the allowed time to respond to the request made by the conformance suite. In other words, the suite failed to receive a response within the stipulated time.

The default timeout for this type of request is 15 seconds. This value is configured to ensure that requests are answered within a reasonable amount of time.

According to the Open Finance Brazil specification, the timeout is set to 15 seconds. More information can be found here: https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/17891413/Timeout

Since the conformance suite is being executed locally, you can adjust the timeout directly in the code for testing purposes. These adjustments can be made in the following code section:

requestFactory.setReadTimeout(15000); // time to read the response
requestFactory.setConnectTimeout(15000); // time to connect to the server
requestFactory.setConnectionRequestTimeout(15000); // connection request timeout

These values are set to 15000 ms (15 seconds), but any value other than 15 seconds will not comply with the specification.

Therefore, the conformance suite is working as expected. If you wish to adjust the timeout for local testing, follow the instructions above, but keep in mind that any value other than 15 seconds may cause inconsistencies with the specification.
