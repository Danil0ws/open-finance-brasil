Hi, @Sheila.Moraess 

Thank you for the ticket and for providing the additional details, which were helpful for our investigation.

The request failed because your application is sending `application/json` to an endpoint that returns `application/jwt`. As shown in the detailed logs below, this content type is not supported by the endpoint:

```
2025-12-11T11:38:46.698-03:00
14:38:46.697 [main] ERROR c.r.t.b.f.JwtSigningErrorResponseHandler - error: Specified Accept Types [application/json] not supported. Supported types: [application/jwt]

```

Therefore, no correction seem to be required on the Mock Bank side, as it is behaving according to the specification and correctly returning an error.

To achieve a successful execution, your implementation needs to be adjusted so that the request headers and payload formats are fully compliant with what is defined in the specification. We recommend reviewing the formats being sent and trying again.
