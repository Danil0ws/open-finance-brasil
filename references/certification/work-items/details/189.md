Hi Jose,

The issue here is not about the date, which is completely valid, but about the data.date and data.schedule.single.date being sent at the same time. 

```
    Schedule:
      type: object
      description: |
        Mutuamente exclusivo com o campo date. Este campo é obrigatório no caso de agendamento. Neste caso, o campo date não deve ser informado.
```
You can see that this is what happens on the POST Consents call.

![image](/uploads/a2a07f4567b1cacdf22617b822efdb48/image.png)


This is why we expect a NAO_INFORMADO. Note that the code expected return is up to discussion #187 but it's a clear error.
