#### Current Behavior:

---

A recent update was made to FVP to include in the Configuration the following field **Authorisation Server ID** as can be seen on image below:

![image.png](/uploads/0084e381b66bd6b0c552ba4f30fee362/image.png)

FVP should use the provided Authorisation Server ID to gather the OrgId and the Well known for participants endpoint.

Although to run test successfully FVP is still needing field alias to be filled with OrgId

![image.png](/uploads/3dd03924516f58f1d851251120e5648d/image.png)

FVP can be successfully executed provided that Alias is filled with the desired OrgId

#### Expected Behavior:

---

FVP should not need Alias Field to be able filled with orgId to run, it should use Authorisation Server ID to fetch that information from participants endpoint.
