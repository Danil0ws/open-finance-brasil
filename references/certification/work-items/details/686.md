**Atualizado em**: 18/05/2023, 11:37:16

The auth request we issue contains the following scopes

 * openid
 * payments
 * your payment consent id

This is the norm. The user is then presented with these to authorise, resulting in an authorization code. The conformance suite then exchanges this for an access token, which is what we're looking at in the above JSON object. The scopes openid and payments are added to this token by your own authorisation server, we cannot and do not modify this token.
