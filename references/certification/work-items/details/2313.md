Boa tarde GT,

Verificamos que nessa documentação de PC, está informando que no JOSE Header, o campo typ deve ser preenchido com o valor **oauth-authz-req+jwt** -\> [https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/905740608/Como+assinar+o+payload+-+PC+Portabilidade+de+Cr+dito+-+CPC](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/905740608/Como+assinar+o+payload+-+PC+Portabilidade+de+Cr+dito+-+CPC "https://openfinancebrasil.atlassian.net/wiki/spaces/of/pages/905740608/como+assinar+o+payload+-+pc+portabilidade+de+cr+dito+-+cpc")

 Porém, está seguindo um padrao diferente das demais APIs do OPF: [https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/728301632/SV+Como+Assinar+o+Payload](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/728301632/SV+Como+Assinar+o+Payload "https://openfinancebrasil.atlassian.net/wiki/spaces/of/pages/728301632/sv+como+assinar+o+payload")

O valor correto, por padrão para assinaturas de payloads de API, é `"JWT"`.

Só pra dar um contexto:

* `typ`**: "JWT"**
  * Este é o valor padrão usado para um JWT genérico que carrega um payload de API assinado. A intenção é indicar ao recebedor que o objeto é um JWT comum e que as regras de validação da API devem ser aplicadas. É o que o nosso motor de conformidade usa atualmente.
* `typ`**: "oauth-authz-req+jwt"**\
  Este valor é **específico** para o contexto de fluxos de autorização (como **JAR** - JWT-Secured Authorization Request - ou **PAR** - Pushed Authorization Request). A sua função é explicitamente marcar o objeto como um **OAuth 2.0 Request Object**, informando ao servidor que ele deve aplicar as regras de validação para pedidos de autorização OAuth, não para um payload de API genérico.

  A especificação de Portabilidade, ao exigir o `typ: "oauth-authz-req+jwt"`, está aplicando uma regra de fluxo de autorização a um cenário de assinatura de payload, o que é conceitualmente incorreto e pode, de fato, gerar problemas de segurança e confusão no processamento. Voces podem avaliar, por gentileza?
