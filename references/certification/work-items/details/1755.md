#### Current Behavior:

---

In [API OpenData Credit Cards](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/297500794/Informa+es+T+cnicas+-+DA+Cart+o+de+Cr+dito+-+v1.0.0) Phase 1 we have the following definition of payload to endpoint GET /personal-credit-cards:

![image.png](/uploads/f4526b09cb0298c270bf936fd65eaedb/image.png)

While Field `fees` is required, it only has inside of it the `services` array which is optional.

In this case, what we need a better understanding is: 

* Should `fees` be a required field if the only field that is inside of it is optional?
* Should `services` be a required field in this context? Provided it has property: **_minItems: 1_**

"Agradecemos pelo apontamento. Conforme estabelecido no GT e documentado na Tabela verdade (segue o link: tabela verdade), o campo "fees" deve ser obrigatório para todos os endpoints da antiga API de Produtos e Serviços, enquanto o campo "service" é opcional devido às características individuais de cada produto, mas está padronizado nas novas APIs da Fase 1.
