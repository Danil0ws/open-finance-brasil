## 📝 Descrição

#### Current Behavior:
---

CS incorrectly makes a POST recurring-payments with the field `data.paymentReference` set to `zero`, despite no `firstPayment` being previously informed in the POST recurring-consents. The error is shown below:

![image](/uploads/103cf06320aea5f847ba11f87151aed3/image.png){width=200}

#### Expected Behavior:
---

As the `data.recurringConfiguration.automatic.interval` sent in POST recurring-consents is `SEMANAL`, it is expected that the value for `data.paymentReference` in the POST recurring-payments follow the following pattern:
![image](/uploads/74d8261d953645dafbedde80cee59f50/image.png){width=800}
