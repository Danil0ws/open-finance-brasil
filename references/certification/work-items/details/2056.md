## 📝 Descrição

#### Current Behavior:
---
The conformance suite is validating the value from field "closingProcessInfo". The pattern is the following: "^(?!\s)[\w\W\s]*[^\s]$". The value is "https://novo.brb.com.br/wp-content/uploads/2021/01/CLAUSULAS-GERAIS_Pessoa-F%C3%ADsica_1%C2%BA-Of%C3%ADcio_958293.pdf". This value matchs the previous pattern. However, conformance suite returns "Value from element closingProcessInfo doesn't match the required pattern on the GetPersonalAccountsOASValidatorV1 API response".

#### Expected Behavior:
---
Since value is matched with pattern, conformance suite should accept the address provided.
