Due to the lack of definition on this matter one of the following behaviors must be selected, and included, by the Specs WG:

Option 1:

If the Bank returns a response with a non-default page size he shall return the "links" metadata with the page-size element present. 

  This might happen in the two following scenarios:

-    (1) The TPP requested a non-default page-size 
-    (2) The TPP didn't request a page-size, but the bank works with non-default page size.

**During the 12/11 meeting of the Phase 3 Task Force decided to follow with Option 1. The documentation must be updated on https://openbanking-brasil.github.io/areadesenvolvedor/?javascript#paginacao. The conformance suite will reinforce the behavior mentioned above.**

Option 2:

The Bank may opt to not return the page size element on the "Links" metadata even if a non-default page-size has been provided by the Bank on the request.

Raidiam highly recommends that we go with the first option (1) as it's the best option for interoperability issues.
