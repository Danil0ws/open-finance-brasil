### Comentário 7
**Autor**: Erick Domingues (@erick.domingues1)
**Criado em**: 09/05/2022, 19:27:15

It's about the consent request. The new specifications mandate that you do not send business and person permissions together so we have to know beforehand what to request. 

For the resource, you can set it to point to any valid resource that you own.

The need for this button comes from the fact that not every institution owns the account's resources but all institutions will need to have either business or personal resources, which made us deploy this.

Also please be aware that a significant number of updates are being done on Phase 2 Tests, preparing for the next Mandatory Recertification, and not all of them are completely validated so please don't hesitate to open any tickets if you find any issues!
