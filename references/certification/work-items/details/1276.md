Hi Vitor!

The POST /recurring-payments request was made to the following request_uri:

![image.png](/uploads/adf97ad79e1e618e971d00c5538da4cd/image.png)

As described in the specification, Self link must be the complete URI that generated the response:

![image.png](/uploads/f174820a0c819b0fb8c10435e5add2a6/image.png)Taking into consideration that a request was made to:

<dl>
<dt>

`https://hom-secure.opf.api.itau/itau-itau/open-banking/automatic-payments/v1/pix/recurring-payments`

</dt>
</dl>

The expected self link must have followed the same path from the request uri adding the /paymentId at the end.

Additionally, in the downloadable yml file it is possible to find the expected url common structure for automatic-payments:

![image.png](/uploads/b356dacdd2c329f03e00ab01e7338192/image.png)

Once the self link has been adjusted, so will the regex validate it based on the correct path:

<dl>
<dt>

`automatic-payments/v1/pix/recurring-payments`

</dt>
</dl>

Please if you have any more questions regarding this or other matters do not hesitate to open a new ticket or reopen this one,
