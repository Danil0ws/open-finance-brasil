As of version 3.0.0, the meta object no longer includes the totalPages and totalRecords attributes. However, the 422 error response example still incorrectly shows these fields.

We are currently working on updating the documentation to remove this ambiguity. These fields will be removed from the example — both for this endpoint and others in the API — to ensure consistency with the current specification.
