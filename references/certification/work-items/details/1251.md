## 📝 Descrição


Hello, we verified that the **payments_api_x-fapi_test-module_v4** test
is sending the incorrect token in the GET consents request.

In the section: **"Calling GET Consent with x-fapi-interaction id, expecting success"** : **FAPIBrazilCallPaymentConsentEndpointWithBearerTokenAnyMethodAnyHeaders** The CS is sending a token **grant_type** = _authorisation_code_

But according to the documentation: "Os endpoints de consulta e cancelamento devem suportar somente acesso a partir de access_token emitido por meio de um grant_type do tipo client_credentials"
