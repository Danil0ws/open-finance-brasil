Hi,\
after a more thorough evaluation,\
we were able to conclude that,\
When conformance suit executed the following step:\
**Validating Authorisation Server has supported Endpoint**\
It retrieved the AuthServer From Participants Endpoint and while parsing the result, it could not find the following Fields for the resources v2 URL:

* "ApiDiscoveryId"
* "ApiEndpoint"

Thus, conformance suit had to build it using the consents URL and resulted in the mentioned error.\
As conformance suit is working as expected in this regard, please make sure that the resources URL correctly registered in the provided Authorization server configuration so that the correct url can be used by the conformance suit when executing the test module.\
