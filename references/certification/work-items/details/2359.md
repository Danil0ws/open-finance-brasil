Hello @cleverson.silva1. Thanks for pointing this out.

You’re right that the state section says scheduled (SCHD) payments should be rejected (RJCT) with reason CONSENTIMENTO_REVOGADO when the consent is revoked, except for those scheduled on the same day, which should proceed normally.

However, this particular test (automatic-pix-receiver-revoked-consent-timezone_test-module_v2-2) is designed to cover a specific edge case: **revocation by the receiver between 22:00 and 23:59 (UTC- 3).**

According to the PATCH /recurring-consents/{recurringConsentId} description in v2.2.0-rc.2, when the revocation happens in this time window, scheduled payments beyond 23:59 of the next day must be cancelled (CANC) instead of rejected.

![image.png](/uploads/7315bb388371a3d0dc64fa8fb846d242/image.png){width="842" height="195"}

\
Therefore, the expected behavior in this test (status = CANC and cancellation.reason = CANCELADO_AGENDAMENTO) is consistent with the documentation for this specific time-zone scenario.

Please feel free to reopen the issue if needed.

Best Regards.
