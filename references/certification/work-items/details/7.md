Raidiam: Adding a bit of additional information.

The core solution the model bank is based on is already open source.
https://github.com/panva/node-oidc-provider/ 

We are one of the corporate sponsors of the provider for the open source community. The provider already supports

•	FAPI ID2 Certified, FAPI Final Compliant
•	Brasil FAPI Compliant
•	DCR and Dynamic Client Management

Pretty every single RFC that is required to implement Brasil Open Banking. Whatever additional guides we add for this has to have the appropriate disclaimers license etc put around it because, like any security software, you have to know what you’re doing and set it up for your hosting environment whatever that might be. 

If a Bank is looking for a good way to get started and experiment with OIDC then this library is a great place to start – it is far simpler than any other project to get started. Typically the larger Banks end up buying one of the commercial vendors which we (Raidiam) also partner with (we implement all of them) but feel free to tell them to reach out to us directly if they have any questions.

On the model Bank - yes we will be making a version available however it isn't scheduled until after the conformance suite. We need to remove a lot of build processes that are specific to the Raidiam environment from the core code and write documentation for how to get started on a local machine. A 'Deployed' version has a lot of implementation specifics in it that are only relevant to a given implementation e.g DNS, Certificates, Build Packaging, Testing, KeyStore Management, HSM Integrations, KMS Integrations (if using AWS), remove all of the MFA, Registration, DocuSign Requirements, Notifications so that a developer can see what is going on and what is core to be done. It's going to a take a little bit of time to pare everything back to make it usable and generic.

We will have a deployed service that will be usable by TPPs before mid-july.
- Dynamic Client Registration and Management
- Consent API
- Authorisation Process
- Static Responses to API Requests
