Hi thanks for opening the ticket:

After analyzing the provided test log we were able to conclude that in this case conformance suit is operating as expected.

Rather the reason for the test failure was due to **GET pix/payments/{paymentId}** response_body structure, the server response was as described bellow:

`"data": [ { "cancellation": { "cancelledAt": "2024-02-23T12:23:29Z", "cancelledBy": { "document": { "identification": "02902369085", "rel": "CPF" } }, "cancelledFrom": "DETENTORA", "reason": "CANCELADO_AGENDAMENTO" }, } ],`

Whereas the Specification determines the response_body should follow this structure:

 `"data": { "cancellation": { "reason": "CANCELADO_PENDENCIA", "cancelledFrom": "INICIADORA", "cancelledAt": "2021-05-21T08:30:00Z", "cancelledBy": { "document": { "identification": "11111111111", "rel": "CPF" } } }, }`

Therefore, to ensure test module can be run successfully, please make sure that the the implementation is adapted as described above.

Feel free to open other tickets if you have any other questions,

Happy to help!
