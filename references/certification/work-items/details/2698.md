## 📝 Descrição

# Missing `credit-portability` scope in `scopes_supported` — MockBank

## Current Behavior

The MockBank authorization server (`https://auth.mockbank.poc.raidiam.io`) does **not** include `credit-portability` in its `scopes_supported` list, as advertised via the OpenID Connect Discovery document:

**`GET https://auth.mockbank.poc.raidiam.io/.well-known/openid-configuration`**

```json
"scopes_supported": [
  "openid",
  "accounts",
  "credit-cards-accounts",
  "consents",
  "customers",
  "invoice-financings",
  "financings",
  "resources",
  "unarranged-accounts-overdraft",
  "loans",
  "payments",
  "bank-fixed-incomes",
  "credit-fixed-incomes",
  "variable-incomes",
  "treasure-titles",
  "funds",
  "recurring-payments",
  "exchanges",
  "nrp-consents"
]
```

The scope `credit-portability` is absent from this list.

## Expected Behavior

Since MockBank already publishes the **Credit Portability API v1.0.0** (`ApiFamilyType: "credit-portability"`) via the Open Finance Brasil Directory, the authorization server **must** include `credit-portability` in `scopes_supported` so that relying parties (Proponentes) can request access tokens with the appropriate scope when initiating credit portability flows.

## Evidence

**Directory entry** (Organisation `74e929d9-33b6-4d85-8ba7-c146c867a817`, Authorisation Server `c8f0bf49-4744-4933-8960-7add6e590841`):

| Field | Value |
|-------|-------|
| `ApiFamilyType` | `credit-portability` |
| `ApiVersion` | `1.0.0` |
| `Status` | `Active` |
| `FamilyComplete` | `true` |
| `ApiResourceId` | `5eeb1686-f41f-4a36-b7b8-2c492be5039d` |

**Well-known endpoint:** `https://auth.mockbank.poc.raidiam.io/.well-known/openid-configuration`

**`credit-portability` not present in `scopes_supported`:**
