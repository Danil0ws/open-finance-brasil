## 📝 Descrição

When running the tests for the **credit-cards_test-plan_v2-4** engine, the second one, **credit-cards_api_transactions-current_test-module_v2-4**, has an issue when validating the response of a call to /accounts/{creditCardAccountId}/transactions-current?page=1&page-size=25, for the **Validate Credit Card Account Current Transactions** step.

#### Current Behavior:

---

One of the steps fails with this reason:

**Validate Credit Card Account Current Transactions: CheckExpectedTransactionDateTimeResponse: The returned data array does not contain the expected resource**

It seems that it expects a single object as a response instead of an array, but there's nothing in this request's documentation indicating that a single object should be returned in this case.

#### Expected Behavior:

---

It was expected for the test step to pass because the same response was validated in this test's previous steps without issues.
