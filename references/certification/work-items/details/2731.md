## 📝 Descrição

**Observed behavior**

Test modules in the FVP intermittently fail with `setStatus() called but status is the same: WAITING -> WAITING`. The failure occurs after all functional validations have passed and is non-deterministic - the same module passes on retry without any change to the participant's implementation.

Root cause: duplicate finalization of the test (`fireTestFinished()` / `onPostAuthorizationFlowComplete()`) within the same flow.

---

**Expected behavior**

Test modules in the FVP must finalize exactly once.
