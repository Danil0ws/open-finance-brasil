#### Current Behavior:
---
credit-cards_api_operational-limits_test-module_v2-1 calls the GET Credit Cards Transactions-Current API 20 times according to the plan, but if fails a verification in the last step because it expects a next link in the response, even though it is supposed to be the last page

#### Expected Behavior:
---
There should be no need to validate the presence of a next link in the 20th call, since the test expects 20 transactions only; if we test with more transactions (for an example, 25), the test fails because it only accepts exactly 20 transactions, per https://gitlab.com/raidiam-conformance/open-finance/certification/-/issues/1883
