Hi

Thanks for opening the ticket!

After analyzing the mentioned test module, it can be stated that the reason of the Failure is related to the data type expected for the “data” field that is contained within the JsonObject on the response_body.

As described on the specification, the “data” field must follow the structure of a JsonArray, represented by the use of "data":[ ]

```json
{
  "data": [
    {
```

Therefore the conformance suit is working as expected, to ensure a successful execution of the test module, please make sure to:

- Include the data field as a JasonArray on the response_body

Feel free to open a new ticket if you have any more questions.
