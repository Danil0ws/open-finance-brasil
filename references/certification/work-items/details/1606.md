## 📝 Descrição

## 1. What happened and what were you expecting?

After the compliance tool validates that the enrollment is in **AWAITING_ENROLLMENT** status, instead of sending a request to **REJECT** it is sending a request to **REVOKE**. According to the definition of the state machine, the enrollment can only transition to the **REVOKED** status if it is in the **AUTHORISED** status.
