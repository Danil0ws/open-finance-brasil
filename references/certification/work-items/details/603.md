## 📝 Descrição

## 1. What Happened and what were you expecting?
When conformity tool execute steps "Call the GET Consents endpoint, set header "accept": "*/*"" and "Call the GET Consents endpoint, set header "accept": "application/json"", are saying that will call "get consent", but it is calling "get payment". After this, next step is trying to check field "expirationDateTime", but this field is not from payment, it is from consent. So we understand that this validation is just for consent, not for payment.
