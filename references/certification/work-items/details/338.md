## 1. What Happened and what were you expecting?
cnpjConsignee is a conditional field, which should only be sent when productSubType is set to CREDITO_PESSOAL_COM_CONSIGNACAO. However, the test (loans-api-test-v2) is expecting this field to be present even when productSubType is not CREDITO_PESSOAL_COM_CONSIGNACAO.

Specs: https://openbanking-brasil.github.io/openapi/swagger-apis/loans/2.0.1.yml

[Logs attached.](/uploads/f010d2c8a6cbf6f29e9b05c5ce1801b5/test-log-loans-api-test-v2-private_key_jwt-by_value-openbanking_brazil-plain_response-yONAOOlWy5e1i3T.zip)

##### Failure summary:
![cnpjConsignee1](/uploads/52b1c5d1be525fdf361a97a7fee1b6f6/cnpjConsignee1.JPG)

##### productSubType:
![cnpjConsignee2](/uploads/c6aeb697e59d544d1bff33df10aad95b/cnpjConsignee2.JPG)


```
cnpjConsignee:
          type: string
          maxLength: 14
          pattern: '^\d{14}$'
          example: '60500998000135'
          description: |
            CNPJ do consignante (CNPJ corresponde ao número de inscrição no Cadastro de Pessoa Jurídica). 

            Deve-se ter apenas os números do CNPJ, sem máscara. 

            [Restrição] Informação adicional específica para quando o productSubType for igual a CREDITO_PESSOAL_COM_CONSIGNACAO
```
