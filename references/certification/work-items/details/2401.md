https://results.conftpp.directory.openbankingbrasil.org.br/CoyMS7KRD0E35/test-log-fvp-payments_api_recurring-payments-wrong-custom-quantity_test-module_v4-uvKUp2MCGHSIfaM.html

Error Message:

Too Many Requests

The server is rejecting additional requests because the rate limit has been exceeded. In this specific case, the response does not contain a body ([no body]), meaning the server did not provide additional information about the cause or resolution of the issue.

Error Context:

The error occurs during the execution of a test related to the module: fvp-payments_api_recurring-payments-wrong-custom-quantity_test-module_v4.
The failure happens at the step checkConsentURL, which appears to be verifying a consent URL.
The error is captured by the class org.springframework.web.client.HttpClientErrorException$TooManyRequests, which is used to handle HTTP errors in the Spring framework.
Impact:

This issue is blocking further progress in testing as the server is not responding to requests due to rate limiting.
