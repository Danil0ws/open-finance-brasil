Hi thanks for opening the ticket!

While analyzing the test log, it can be noticed that the test module execution was interrupted before it could reach a failure.

I will then answer based solely on my interpretation of the description on This issue.

As can be found on the request_body for Post Consents:

**"loggedUser":{"document":{"identification":"02133223070","rel":"CPF"}}**

Which is the same as the brazilCpf for Operational Limit and brazilCpf fields filled in the test config.

If the problem regards the businessEntity and CNPJ not showing up on the request_body, this is due to the fact that, although brazilCnpj for Operational Limits was filled in the test config, brazilCnpj field was not, and therefore businessEntity was not included on the request_body for the mentioned test log.
