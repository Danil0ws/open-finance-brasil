Hi Raphael,

Thanks for the ticket.

The test module sends a x-fapi-interactionid with an incorrect value and expects the server to reject the request, while changing the field for a correct one. This behavior is specified on https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/239370570/v3.0.0+Problemas+conhecidos:

"Caso não recebido ou recebido um valor inválido, o detentor deve gerar e retornar na resposta de erro."

While the server is correctly refusing the request, it is not fixing the x-fapi-interaction-id sent, and for this reason the server fails the test module.

Note that there is this same test module for v4 where the referred server is currently passing.
