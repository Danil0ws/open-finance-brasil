## 📝 Descrição

#### Current Behavior:
---

Our institution does not offer the following products/services and, accordingly, does not publish the corresponding endpoints in the Central Directory. Even so, the test plan executes these modules and they fail (the requests return HTTP 404, since the endpoints are not exposed):

* customer-personal_api_alphanumeric_cnpj_test-module_v2-3
* funds_api_alphanumeric_cnpj_test-module_v1-1
* credit-fixed-incomes_api_alphanumeric_cnpj_test-module_v1-1
* variable-incomes_api_alphanumeric_cnpj_test-module_v1-3

But we found this other ticket that seems a related issue: https://gitlab.com/raidiam-conformance/open-finance/certification/-/work_items/2802

The comment on that ticket states that, since the tests are monitored through the endpoints published in the Directory, a failure or a non-execution is not a concern for that specific test module.

#### Expected Behavior:
---

Could you please confirm whether the same understanding applies to the modules listed above? Specifically:

1. Will the test plan be accepted for certification if these four modules fail?
2. If not, is there any action we should take on our side (for example, a specific configuration in the test plan form, or a justification to be submitted along with the certification)?

Thanks in advance.
