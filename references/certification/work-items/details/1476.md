Hi,

After a more thorough evaluation of the test module, we were able to conclude that the cause of the failure was the inclusion of the following in the test configuration:

"client": { "scope": "openid payments", "jwks": 

Therefore conformance suit was sending the payments scope on the POST token endpoint.

To ensure test module can be run successfully make sure not to set the scope on the config of the test.
