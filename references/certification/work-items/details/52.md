## 📝 Descrição

Hi there!

This time I’m focusing on transactionIdentification validation rules.

Current API Payment Initiation OAS says:

* transactionIdentification must be present for INIC localInstrument; and must be absent for MANU and DICT localInstrument (https://openbanking-brasil.github.io/areadesenvolvedor/swagger/swagger_payments_apis.yaml line 474)

But `payments-api-manu-pix-response-test` is trying to call `POST /payments/v1/pix/payments` without removing transactionIdentification for MANU localInstrument; and `payments-api-dict-pix-response-test` is doing the same for DICT localInstrument.

Both tests are failing when we use OAS rules on our implementation http://web.conformance.directory.openbankingbrasil.org.br/plan-detail.html?plan=lnM24JmAszg4S

Probably need to remove localInstrument if present to make it OAS compatible?!

Thanks
