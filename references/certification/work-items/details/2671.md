## 📝 Descrição

**OCS-1064 - Adjust amount decrease validation**

The condition `EnsureAvailableAmountDecreasedByOne` uses Java `double` + `==` to compare monetary amounts, which breaks for values whose decimal subtraction doesn't match IEEE-754 binary (e.g. 1.67−1.00 = 0.6699999999999999 ≠ 0.67), producing false FAILUREs. Fix: Replace `double` + `==` with `BigDecimal.compareTo`

**OCS-1066 - Adjust enrollments cleanup step**

Fix: add `useClientCredentialsAccessToken();` before the PATCH in `AbstractFvpOptimisedJourneyEnrollmentsPaymentTestModule.patchEnrollment()` and `AbstractFvpOptimisedJourneyEnrollmentsRevokedConsentPaymentsTestModule.cleanup()`.
