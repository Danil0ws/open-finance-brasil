Hi,

Regarding the automatic-payments_api_sweeping-accounts-root-cnpj_test-module_v1:

The test description states that:

Ensure a payment using sweeping account can be successfully executed when the creditors are all from the same company. **This test will always use the following CNPJ 98380199000125 as proxy and businessEntityIdentification when creating the payment, and not considering what is informed on this field on the config**, although if this field is not informed the test will be skipped. Therefore the 98380199000125 should be registered in the ASPSP for a successful test run.

As the automatic-payments_api_sweeping-accounts-root-cnpj_test-module_v1 uses the 98380199000125 CNPJ regardless of the CNPJ provided in the test plan config, the “Payment consent - Business Entity CNPJ” field on the config of the test plan does not need to be filled with 98380199000125 CNPJ, rather it can be filled with any other valid CNPJ that would be used to pass the other test modules in the test plan.

To ensure automatic-payments_api_sweeping-accounts-root-cnpj_test-module_v1 can be executed successfully, make sure to inform a valid CNPJ capable of conducting transactions fully in the Payment consent - Business Entity CNP config field.
