Olá, @rafaelsspaiva ! 

O teste está falhando porque a forma como vocês estão enviando os dados do empregador está levemente divergente do modelo da versão 2.3.0.

**Como vocês estão enviando hoje:**

```json
"data": {
  "employerCnpjCpf": "JSHSENGZ000190",
  "employerName": "TESTE EMPREGADOR ALFA D"
}
```

**Como deveria ser na 2.3.0:**

```json
"data": {
  "employers": [
    { "cnpjCpf": "JSHSENGZ000190", "name": "TESTE EMPREGADOR ALFA D" }
  ]
}
```

Duas coisas mudaram da versão antiga para a 2.3.0:

- Antes o empregador vinha "solto" ali no meio dos dados, agora ele precisa vir dentro de uma lista chamada `employers`, porque a nova versão permite mais de um empregador. Mesmo tendo só um, ele tem que estar dentro dessa lista.
- Os campos foram renomeados: o que vocês chamam de `employerCnpjCpf` agora é só `cnpjCpf`, e o `employerName` agora é só `name`.

O valor que vocês mandaram (`JSHSENGZ000190`) está certinho, é só ajustar esse formato. 

Fazendo esse ajuste, deve passar. 

Qualquer dúvida, é só chamar!
