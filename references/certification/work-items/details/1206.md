## 📝 Descrição

## 1. What happened and what were you expecting?

When the test module executes the following steps:

- Creates a Consent with incompatible permissions V3
- Expect 400 - Validate error message

It expects and validates for an error message 400 BAD_REQUEST.

![Screen_Shot_2024-01-11_at_16.41.05_PM](/uploads/66f56004ce248a2660bce30e31151135/Screen_Shot_2024-01-11_at_16.41.05_PM.png)

According to the new specification beta version released, the status expected by the conformance suit should be 422 PERMISSAO_PF_PJ_EM_CONJUNTO, instead of 400 BAD_REQUEST.
