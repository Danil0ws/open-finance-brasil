- Test Name: credit-cards_api_max-page-size_test-module_v2-1 Test ID: 5pO3JQvAvotwUKN

Therefore, regarding the 3 tests mentioned there is no corrections on the CS side. To a successful execution, the implementation needs to be adapted so that the response fields sent are conformant to the swagger.

Regarding the last test ID sent:

- Test Name: accounts_api_bookingdate_test-module_v2-1 Test ID: oqDyoyefthzgRvz

It is failing due to the same unnecessary number of transaction resources being sent, which we reported a test enhancement at #1378 - we have just added this new test ID to the issue. We reinforce that to ensure a successful execution in this scenario, we recommend reducing the transactions to a single page response.
