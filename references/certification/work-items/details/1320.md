## 1. What happened and what were you expecting?

According to the test summary after creating the second recurring payment with the amount of 300.00 an error LIMITE_PERIODO_VALOR_EXCEDIDO is expected. However, test is raising an error stating that the "Value from element code does not match any given enumeration on the CreatePaymentErrorValidatorV4 API response":

![image](/uploads/0c87d6d8e1e6c05007df9c1e6f1f2100/image.png)

Accoding to the specification (https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/264176303/Informa+es+T+cnicas+-+SV+Pagamentos+Autom+ticos+-+v1.0.0-rc.1) LIMITE_PERIODO_VALOR_EXCEDIDO is indeed a valid error code:

![image](/uploads/421d52df879fecbb046b63191c079e9e/image.png)

The test should recognize the error code LIMITE_PERIODO_VALOR_EXCEDIDO as valid.
