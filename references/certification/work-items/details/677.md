## 1. What Happened and what were you expecting?

The test should call the GET payment endpoint using an access token via authorization_code and expects a failure, but instead it's calling the GET payment endpoint using client_credentials. This results in the test pooling the GET payments endpoints until the test fails with a generic error: "Participant took too long to reject request, failing".
