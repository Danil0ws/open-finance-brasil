Thanks for opening the ticket.

After analyzing the provided test id, it can be stated that the test module failed due to the self link included in the response to the PATCH request.

Although the error message is not clear, the conformance suit failed to validade the recurringConsentId element present in the ValidateSelfLinkRegex as the self link provided was:

```
"links": {
    "self": "/urn:arbi:9fe5936e-a914-4ca9-8ed8-c18559ad09a5"
```

In that sense, the conformance suit is operating as expected. To ensure a successful execution of the test module, please, ensure the self link is sent correctly.
