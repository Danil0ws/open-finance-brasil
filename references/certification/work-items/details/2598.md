## 📝 Descrição

## **Current Behavior**

The automated test **`payroll-credit-portability_api_user-cancelled-portability_test-module_v1`** fails during execution because no eligible loan contract is found to proceed with the portability flow.

Although the test expects at least one contract with:

*   `productSubType = CONSIGNADO_SIAPE`
*   `eligibilityStatus = DISPONIVEL`
*   `isEligible = true`

the system returns **no matching contracts**.  
Additionally, the failure message indicates that `productSubType` is being returned as **null**, which prevents the test from selecting a valid contract and blocks the flow before the portability is created.

As a result, the test cannot validate the user-cancelled portability scenario.

***

## **Expected Behavior**

The system should return at least one loan contract that meets the test preconditions:

*   `productSubType = CONSIGNADO_SIAPE`
*   `eligibilityStatus = DISPONIVEL`
*   `isEligible = true`

With a valid eligible contract, the test should:

1.  Create a portability request successfully
2.  Receive the portability with status `RECEIVED`
3.  Allow the user to cancel the portability
4.  Return the final status as:
    *   `CANCELLED`
    *   `statusReason.reasonType = CANCELADO_PELO_CLIENTE`

***
