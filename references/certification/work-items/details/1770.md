#### Current Behavior:
---
Our endpoint consents/v3/consents returns statusCode 422 as expected when called with DateTime greater than 1 year from now; however, the "generic" code we're presenting, "CONSENT_EXPIRATION_EXCEEDS_MAX", is refuted, "Value from element code does not match any given enumeration on the Post Consent V3 API response"

#### Expected Behavior:
---
According the Brazil Open Finance documentation, we currently do not have an assigned code for this situation; we're asked to use a "generic" code

#### Evidence:
---
Documentation: https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/517242956/Informa+es+T+cnicas+-+DC+Consentimento+-+v3.0.1

Relevant excerpt under the 422 code:
"SEM_PERMISSOES_FUNCIONAIS_RESTANTES
INFORMACOES_PJ_NAO_INFORMADAS
PERMISSOES_PJ_INCORRETAS
PERMISSAO_PF_PJ_EM_CONJUNTO
COMBINACAO_PERMISSOES_INCORRETA
**Para o erro referente a envio de data de expiração maior que um ano, diferente de prazo indeterminado (data vazia) ou data referente ao passado, de forma temporária, deve ser informado um code genérico.** Em um momento posterior será adicionado um code definitivo para descrição deste erro."
