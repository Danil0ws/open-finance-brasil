## 📝 Descrição

#### Current Behavior:

---

* The current behavior on validations from POST /portabilities/{portabilityId}/payment is that:
  * It is validating the field "links" on DTO. Although, according to documentation there is no links on response for this request (as described on evidence - _Documentation_) 
  * If this validation, it is raising the following error:
    * "Validate Self link: credit-portability_api_portability-payment_core_test-module_v1: Caught exception from test framework: Cannot invoke "com.google.gson.JsonObject.get(String)" because "links" is null" (as described on evidence - _Plan Execution Logs)_

#### Expected Behavior:

---

* The expected behavior for this test is not validate the links on the response.
