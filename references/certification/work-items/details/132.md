You are correct here. For a **Happy path **any intermediary is acceptable, so PDNG, PART, ACSP, ACSC are all valid states.

For an unhappy path, PDNG and PART are the only two acceptable intermediary states, which is where the confusion might have come from. 

We will fix this on our last release for all three happy path test modules.
