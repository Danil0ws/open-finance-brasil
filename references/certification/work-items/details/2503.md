Hello @rogeriorocha083. Thanks for raising this. 

The Pix key **cliente-a00001@pix.bcb.gov.br** is valid in the DICT homologation (Pix Tester) environment. This is a standard key defined by the Central Bank and has been used in Open Banking/Payments sandbox tests since the early versions of the Payments APIs (used in our test flows since 2022).

In our conformance tests, this value may be sent in the proxy field as a mock/sandbox Pix key to exercise the end-to-end flow. You should be able to query it in the homologation environment.

For reference, the data associated with this key in the homologation environment is:

* Pix key: cliente-a00001@pix.bcb.gov.br
* Financial institution: HOMOLOGAÇÃO BACEN
* Bank code: 998
* ISPB: 99999004
* Branch: 0001
* Account: 1234567-8
* Owner: João Silva (CPF 99991111140)

Could you please confirm whether this information was enough to help you?
