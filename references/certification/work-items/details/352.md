Test will mandate you to send +1 of your total default page size. Assuming you have a 1000 default page size than yes, 1001 will be required, however if you have a default of 25, 26 transactions should be enough.

Test aims to access second page so a second page must be sent here.

Here is a test where the user sent 26 records and passed - https://web.conformance.directory.openbankingbrasil.org.br/log-detail.html?log=VpgP7sL1zE5MiJB&public=true
