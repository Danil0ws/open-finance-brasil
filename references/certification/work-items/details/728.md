## 📝 Descrição

## 1. What Happened and what were you expecting?

In the step "POST consents endpoint using authorization_code token - expects 401" the test is failing because it expects, incorrectly, a content-type "json" in the response, as seen below:

![image](/uploads/4ea26d41f4092c1e43ef28fc1cd878d5/image.png)

According to the documentation, the correct return to be expected is a "jwt":

• https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/18055346/Informa+es+T+cnicas+-+Pagamentos+-+v2.0.0

![image](/uploads/fadd0c23667a60d41fc0a869f9a03938/image.png)

Here it follows a similar problem fixed in other test: https://gitlab.com/raidiam-conformance/open-finance/certification/-/issues/581
