---

**Context**: https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/219512943/Orienta%2Bes%2B-%2BDC%2BRecursos

---

**Observed behavior:**

Step:

> Call the GET Resources API Endpoint
>
> * Expects a 200 or 202 - Validate Response
> * If 202 is returned:
> * Start polling up to 5 minutes until 200 status is returned

The polling logic, repeated 10 times, is considering a 30-second interval **at the end of each sequence**. Therefore, there’s no interval between the normal GET /resources and the first polling GET /resources. And that’s why a participant reported a 4'42" interval between the first and last attempt of GET /resources, not the 5 minutes as described by the test summary.

---

**Expected behavior:**

Adjust the polling logic to consider a 30-second delay before calling the GET /resources. The test should reach the 5 minutes described in its summary.
