## 📝 Descrição

## 1. User Story

As a user, I want to have an area where i can track my current conformance and certification status around mandatory Sandbox tests for my Organization to evaluate if I am not following the expected Regulatory Requirements, and quickly act if I'm missing something.


## 2. Requirements

The High-Level Expectations of this feature are the following:
- Be provided as a separate Raidiam Hosted Web Application 
- Require authentication using the Raidiam Sandbox Environment - User details should be obtained from its id_token
- Integrate with the Conformance Suite APIs to obtain the execution test status of participants by using its organization_id as well as the expected test modules
- Integrate with the Directory Participants API to validate the regulatory requirements of participants and if they have or have not published their APIs
- Integrate with the Conformance Repository to evaluate if the participant has submitted their certification
- Receive a set of Reference Data, provided by Chicago, which will define what is the expected output over the executed tests - This information will contain at least - (1) The Test Plan and (2) The Pass Ratio by Date as well as (3) which organisations are expected to achieve this status
