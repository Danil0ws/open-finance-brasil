Prezados/as, boa tarde. 

O teste ‘credit-portability_api_negative_test-module_v1’ do plano de testes ‘credit-portability_test-plan_v1’ apresenta erro no POST /portabilities: java.lang.NullPointerException: Cannot invoke \"br.com.bb.pcd.model.dto.registrar.blocos.DigitalSignatureProofDto.getDocumentId()\" because the return value of \"br.com.bb.pcd.model.dto.registrar.blocos.ProposedContractDto.getDigitalSignatureProof()\" is null 

Nesse sentido, no POST /portabilities, há tentativa de acessar a propriedade $.data.proposedContract.digitalSignatureProof, sem sucesso. Acontece que a propriedade é obrigatória segundo a especificação (https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/950861986/Informa+es+T+cnicas+-+PC+Portabilidade+de+Cr+dito+-+CPC+-+v1.0.0-beta.2):
