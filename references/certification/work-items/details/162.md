## 📝 Descrição

The Banks are expected to provide JSON input into the payments consent configuration block. If a Bank Provides a JTI property as part of the input a null pointer exception is being thrown. JTI and other attributes related to the JWT creation process are added via the engine and should not be included as part of Banks configuration.

We have evaluated the problem and one of the issues is being caused by Orgs sending a jti on the Payments Consents payload. This field is not expected on the input payload which is throwing the error. Down below is the config sent on the test

      "brazilQrdnPaymentConsent": {
            "jti": "cc4a0922-0563-4aa3-88c7-840bcf19383e",

A JTI is automatically calculated and generated by the test harness and is unexpected as an input.

We understand that we must improve the error message here to clearly state what was wrong and we will work on a fix related to this.

Down below is the execution of the test plan without including the jti on the payload, which managed to execute correctly.
