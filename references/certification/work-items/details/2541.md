## 📝 Descrição

Gostaríamos que fosse desenvolvida uma página com orientações de execução de todos os módulos/planos que fazem parte do **FVP Manual**.

Como referência de estrutura e conteúdo, gostaríamos que fosse seguido o modelo da página no GitLab **“**[Orientações para o Time de Execução da FVP · Wiki ](https://gitlab.com/raidiam-conformance/open-finance/certification/-/wikis/Orientacoes_Execucao_FVP?redirected_from=Scheduled-Tests-[PT])**”**, disponível na _Wiki dos Testes de Longa Duração_.

Os planos de teste que devem ser contemplados nessa página são:

* **API Pagamentos Automáticos v2.2.0 – Pix Automático**\
  _Production Functional Tests for Automatic Pix Payments – API Version 2.2_
* **API Pagamentos Automáticos v2.2.0 – Transferências Inteligentes**\
  _Production Functional Tests for Automatic Sweeping Payments – API Version 2.2_
* **API Dados do Cliente**\
  _Production Functional Tests for Customer Data Happy Path – API Version 3_
* **API Pagamentos v4.0.0**\
  _Production Functional Tests for Payments E2E – API Version 4_
* **API Portabilidade v1**\
  _Production Functional Tests for Credit Portability – API Version 1_
* **API Jornada sem Redirecionamento**\
  _Production Functional Tests for No Redirect Payments – API Version 1_

A página deverá estar disponível em **português e inglês**.
