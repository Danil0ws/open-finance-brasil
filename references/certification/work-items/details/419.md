The Operational Limits tests will always return a WARNING if you don't return the PERMISSIONS that are needed for the test when the Consent is created. 

This validates that if your server does not support this PERMISSION group it means they do not need to test the Operational Limit test for this particular API, being highlighted and futurity evaluated by the WARNING on the test when the certification request is sent.
