## 1. What Happened and what were you expecting?
In the step "Calling GET Consents endpoint - application/json accept header - expects 200 with JWT response or 406" the api returned 200 with content-type "jwt" but the test is expecting "json".

According to the description the test should not fail:

• Call the GET Consents endpoint, set header "accept": "application/json"
• Expects either a 200 or a 406 response - If 200 make sure response is JWT
