## 1. What Happened and what were you expecting?

The Operational limits test is requiring the accountId/creditCardAccountId to be informed beforehand. However, this Identificador can (and in our case, will) change everytime a new consent is issued, making it impossible to run the test. Nowhere in the specification it is requiring the Id to be the same everytime.
