Hi @christianraidiam!

I would like to ask a question, do you have any documentation that indicates this request payload for creating consent should return a 422 status? 

Because I tried to find such documentation, and in version [2.1.0](https://openbanking-brasil.github.io/openapi/swagger-apis/consents/?urls.primaryName=2.1.0#/) there is no `422ResponseErrorCreateConsent` schema. It seems to have been added starting from version 2.2.0-beta-1 and if we take a closer look at [2.2.0-beta-2](https://openbanking-brasil.github.io/openapi/swagger-apis/consents/?urls.primaryName=2.2.0-beta.2#/Consents/consentsPostConsents:~:text=422ResponseErrorCreateConsent) doc, these code errors appear to be related to the `POST /extends` validations and not for the creation of the consents as the schema name indicates
