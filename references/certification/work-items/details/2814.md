## 📝 Descrição

**Context**

The module opendata-investments_api_alphanumeric_cnpj_test-module_v1-1, in the plan open-data_alphanumeric-cnpj_test-plan, calls GET /funds and GET /bank-fixed-incomes to confirm that at least one alphanumeric CNPJ is present. Not every institution offers both products, so some do not register both endpoints in the Directory.

**Current behavior**

When one of these endpoints is not registered in the Directory, the module fails with an "unable to locate resource endpoint" error. The unregistered endpoint is treated as a failure instead of being left out of the run.

**Expected behavior**

OPF now requests that the module run only against the endpoints registered in the Directory. An endpoint that is not registered is skipped, not failed. When neither GET /funds nor GET /bank-fixed-incomes is registered, the module passes with no alphanumeric CNPJ validation.
