## 📝 Descrição

## 1. What happened and what were you expecting?

A few phase 3v3 and 3v2 payments tests validates if the status code of `POST payments/v3/pix/payments` without the x-fapi-interation-id header is 400, but CS sends that header, preventing the error from ever happening. It follows evidence below:

![image](/uploads/acae9da425e902cf286eed5ee8f6e8ab/image.png)

- Test incorrect behaviour:

![image](/uploads/2d6f806faef9cc4c5954b617109b2559/image.png)
