Hi @reginalb 

Based on the attached screenshot, we confirm that we are sending the correct scope — including `credit-portability` — in the authorization request.

![image.png](/uploads/56a93c1bae2716171172fe545eac81dd/image.png){width=900 height=262}

However, during the **DCR process**, the scopes we send must strictly follow the DCR specification:

**Open Finance Brasil – Financial-grade API Dynamic Client Registration 1.0 – Implementers Draft 3**\
(https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/240649661)

According to this specification, **the `credit-portability` scope does not appear anywhere**, meaning it is **not** an allowed or valid scope to be included in the Software Statement.

![image.png](/uploads/cc8105de9e0bb90ea848584c5d010ff3/image.png){width=900 height=353}

For this reason, the Software Statement generated during DCR contains **only `openid`**, which is the correct behavior and fully aligned with the DCR specification.

Happy to help!
