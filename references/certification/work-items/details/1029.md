HI Maurício! Thanks for the ticket!

The header being omitted here I actually the **x-fapi-customer-ip-address**, and not the x-fapi-interaction-id.

This new header is being required as defined at the [latests Consent API Swagger](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/189694174/Informa+es+T+cnicas+-+Consentimento+-+v2.2.0-beta.2):

![image.png](/uploads/8d74acf5ad6daf543809a1f6c4ca4f7c/image.png){width="675" height="103"}

In that case, there is no CS correction for this specific case, and the requirement for this header will need to be implemente in order to be approved in the tests.
