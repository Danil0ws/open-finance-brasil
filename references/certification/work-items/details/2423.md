Hi,

Thanks for reaching out.

The error reported is a **Read Timeout**, which indicates that the server took longer than the allowed time to respond to the request made by the FVP. In other words, the FVP did not receive a response within the configured limit.

For this type of request, the standard timeout value is **15 seconds**, as defined in the Open Finance Brasil specification:

https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/17891413/Timeout

 This configuration ensures that requests complete within a reasonable timeframe.

In this case, the POST request to `https://open.payments.fitbank.com.br/reg` was executed on **2025-11-20 at 08:41:17**, and the timeout occurred at **08:41:45**, resulting in the Read time out error.

Please let us know if you need any further clarification or additional investigation.
