Thank you for reaching out!

The Conformance Suite is an open-source tool, and its source code is located in the GitLab repository. The hosted version of the Conformance Suite is a deployed version of this same source code. We want to remind you that **the hosted Conformance Suite is available and working**, and you can use it to run tests if your current priority is to proceed with certification.

Regarding the specific error you encountered, the dependency `com.raidiam.conformance:kms-jce-provider:jar:1.0.6` is hosted in a private repository that requires specific environment variables to be accessible. It appears that your local setup is not configured to resolve this dependency, which is why the `mvn clean package` command is failing.

To resolve this issue and run the suite locally, you can use the Docker Compose method, as it's the recommended alternative for building the application without Maven.

Here are the steps to follow:

1. First, ensure you have Docker installed on your system.
2. After installing Docker, run the following command to build the application: `$ docker-compose -f builder-compose.yml up`
3. Once the package is built, you can run the suite with the command: `$ docker-compose up`
4. The application will then be available at `https://localhost:443`.

This approach bypasses the Maven dependency issue you're facing by using a pre-configured Docker environment to build and run the application.
