## 📝 Descrição

Hello happy new year.

I think I have a problem with v4 payments tests

When I approve a consent, and have a callback to the engine, I get this error

```
Verify authorization endpoint response: ExtractIdTokenFromAuthorizationResponse: Couldn't parse id_token from authorization_endpoint_response as a JWT
```

I think this happens because id_token has a JWE and no longer a JWS like before the updates to "FAPI Unico".

> No suitable key for decrypting this JWT was provided in the test configuration.

If you add the decryption private key to the client jwks in your test configuration with "use": "enc" that should solve it.
