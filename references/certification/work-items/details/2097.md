Hi, @pedropaulo3 

Thanks for the ticket! 

The test failed because the field `clientDataJSON.origin` should contain a URL but it does not - as seen below:

<img src="/uploads/ab987d3439a736a1d8da8b4dd20bd9ff/image.png" width="900"/>

<img src="/uploads/69e0eda50c6017b572ba7d064786a979/image.png" width="900"/>

As a result, MB correctly returns `ORIGEM_FIDO_INVALIDA` since the provided value cannot be verified. To a successful execution, the implementation needs to be adapted so that the field contains a valid URL.

Additionally, it's important to note that according to the specifications ([API Enrollments for Payment Initiation v2.1.0](https://raw.githubusercontent.com/OpenBanking-Brasil/openapi/refs/heads/main/swagger-apis/enrollments/2.1.0.yml)):

<img src="/uploads/e4c975785923f2e40b73b75ad309a24e/image.png" width="900"/>
