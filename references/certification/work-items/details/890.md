## 📝 Descrição

## 1. What Happened and what were you expecting?
The `variable-incomes_api_resources_test-module` calls GET Investments List Endpoint to extracts all variable incomes resources, then it calls GET Resources API to extract all available resources with investment type = VARIABLE_INCOME in Resources API and finally the test compares both lists.

However, when the Resources API returns the response in multiple pages in the step _"Poll has ended, setting page-size=1000 and calling the resource again"_, the test does not consider all resources - getting only the first page of Resources API results and proceeding to the step _"Compare active resourceId's with API resources"_, which causes the lists not to match.
