## 📝 Descrição

## 1. Question

The PATCH Consents Request includes a loggedUser object that according to the [RN104](https://github.com/thbezerra/ob-docs/blob/main/pix-agendamento-proposta-final.md) must be sent if revoked_by equals to "USER"

![image](/uploads/e7cd59a904a7784f5f2274f8eebd4de0/image.png)

However, it's not clear if this field must be validated somehow by the ASPSP. 

We ask this because we are considering a test scenario where we would send a random logged user on the PATCH however, if the field is not validated, this wouldn't be a valid scenario.

## 2. Specification 

Example 

```
 {
   "data":{
      "status":"REVOKED",
      "revocation":{
         "loggedUser":{
            "document":{
               "identification":"11111111111",
               "rel":"CPF"
            }
         },
         "revoked_by":"USER",
         "reason":{
            "code":"OTHER",
            "additionalInformation":"Não quero mais o serviço"
         }
      }
   }
 }
```
