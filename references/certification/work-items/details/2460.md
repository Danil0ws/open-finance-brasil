## 📝 Descrição

#### Current Behavior:
---

Some Mock Bank endpoints are returning HTTP 429 (Too Many Requests) even when request volume is below the configured rate limits. This issue has been observed on the following flows: consent creation, payment, and enrollment endpoints.

#### Expected Behavior:
---
Mock Bank should return successful responses for requests within the defined rate limits. HTTP 429 should only be returned when rate limits are actually exceeded.
