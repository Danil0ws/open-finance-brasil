We are using all the valid certificates listed in the website: https://www.gov.br/iti/pt-br/assuntos/repositorio/ac-serasa-acp

(A total of 4 certificates for SERASA)

Are there other certificates that should be included in the CA?

I was able to fix the issue by doing a rollback on the CA certificate used on the servers, that raises a concern, in fact there was one certificate missing for the serasa chain, but the CA that was being used when we got this error was updated about two weeks ago containing only the valid certificates listed on the website previously mentioned (https://www.gov.br/iti/pt-br/assuntos/repositorio/ac-serasa-acp). So I checked if the certificate that was missing and causing the issue was listed on the website, but it wasn't. This certificate might be using a chain that has been revoked, in my understanding, this is a problem that could happen to other institutions, specially new ones that don't have a history of past certificates, since revoked/expired certificates cannot be downloaded.
