## 📝 Descrição

## 1. What happened and what were you expecting?

The second part of the test generates a consent with `debtorAccount` information that fails our validation that checks if the account exists. The test is replacing the `accountType` value for CACC, but we only support the TRAN account type for our accounts.

We would like to verify if it is possible to change that behavior, instead of setting the CAAC value for the debtorAccount the test could use the "Payment consent - Debtor Account Type" field of the test plan configuration, where we set it with the TRAN value.
