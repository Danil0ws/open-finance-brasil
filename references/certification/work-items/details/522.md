## 1. What Happened and what were you expecting?
According to the Payments API specification available at https://openbanking-brasil.github.io/openapi/swagger-apis/payments/2.0.0.yml, the transactionIdentification field in the POST pix/payments must match the txId associated with the QR Code when the localInstrument is QRDN or QRES if the QR Code has this information.

For the payments-api-qrdn-good-proxy-test-v2 test to run correctly, a configuration parameter must be provided to include the transactionIdentification/txId of the QR Code, or the conformance suite would need to get info for the QR Code on DICT to be able to insert this information in the request.
