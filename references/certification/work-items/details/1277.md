Hi,

Thanks for opening the ticket

Answering your questions:

1\. This change's purpose is to have the conformance suit compliant with the new HTTP status messages as can be found on the following link:

https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/219480491/Orienta+es+-+DC+Consentimento

As the permissions sent by the conformance suit are:

**"permissions":\["CUSTOMERS_PERSONAL_IDENTIFICATIONS_READ","CUSTOMERS_PERSONAL_ADITTIONALINFO_READ","CUSTOMERS_BUSINESS_IDENTIFICATIONS_READ","CUSTOMERS_BUSINESS_ADITTIONALINFO_READ","RESOURCES_READ"\]**

Following what is described on the specification, it falls into this specific situation:

“If a consent request is received with permissions for PF and PJ registration data together, return HTTP Status Code 422 with the message "PERMISSAO_PF_PJ_EM_CONJUNTO";”

2\. As I see it, this error message is not specifically related to join accounts, rather it relates to a incorrect request of permissions for both PJ and PF at the same time, which should not be allowed.

If you have any more questions related to this or other issues please do not hesitate to open a new ticket or reopen this one,

Happy to help!
