## 1. What happened and what were you expecting?

Some institutions are able to pass on the Conformance Tests for the Admin API while sending invalid metadata, for example:

https://od1.openbanking.credicoamo.com.br/open-banking/admin/v2/metrics?period=CURRENT&page-size=1000

```
"meta": {
"totalRecords": 1,
"totalPages": null
}
```

Tests must validate metadata and links
