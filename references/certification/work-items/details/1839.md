#### Current Behavior:

---

During the steps:

- POLL the GET RESOURCES API for 5 minutes, one call every 30 seconds.
- Continue Polling until the Account Resource returned is on the status AVAILABLE 

The conformance should pool the resources API for 5 minutes, making one call every 30 seconds, at this stage the conformance suit expects to receive code 200 with OK code for the call to the resources api, however it receives from the authorization server 403 STATUS_RESOURCE_PENDING_AUTHORISATION. 

It seems that the conformance Suit is calling GET accounts/{accountId}/balances endpoint again instead of calling the /resources endpoint

#### Expected Behavior:

---

Conformance Suit should poll GET /resources endpoint
