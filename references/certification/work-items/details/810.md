## 📝 Descrição

## 1. What Happened and what were you expecting?

During PCM collection, when calling :

`POST https://api.pcm.sandbox.openfinancebrasil.org.br/open-banking/pcm/report-api/v1/private/report`

And an error occurs, the response headers send a text/html content type:

```
HTTP/1.1 0
Cache-Control: no-cache
Connection: close
Content-Type: text/html; charset=utf-8
Pragma: no-cache
Content-Length: 110

{"codigoErro":null,"mensagens":["Login não realizado: 15984415578657215056"],"severidade":1,"resultado":null}
```

The back-end tries to interpret this body as `application/json` and an exception is thrown:

`UnsupportedMediaTypeException: Content type 'text/html;charset=utf-8' not supported`
