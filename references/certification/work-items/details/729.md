## 1. What Happened and what were you expecting?
During the execution of the tests a request is made to the `GET /consents/:consentId` endpoint and the response code is validated twice, first checking if it was 200 (EnsureResponseCodeWas200) and after if it was 400 (EnsureConsentResponseCodeWas400). Is it an expected behavior?

HI Luis! Thanks for the ticket!

This error is actually happening because the 200 is excepted for the self link, while the 401 is expected for the response itself. In that sense, this is not an error on the conformance suite.

By any means, in other to avoid any confusion, we will delete the self link validation from this request, since it expects a 401 response where links are not sent. But if the 401 response is sent on this request, the test shouldn't have any problems.

We are happy to help any additional needs!
