## 📝 Descrição

#### Current Behavior:

---

[\
](https://gitlab.com/caio.tranjan)While Executing internal tests against the newly developed fvp-consents_api_negative_test-module_v3 a unexpected behavior was found when following steps are executed in test:

•Creates consent api V3 request for DateTime greater than 1 year from now

• Expects failure with a 422 Error

The following error is thrown:

* Value from element code does not match any given enumeration on the Post Consent V3 API response

This occurs due to the following error message being returned:

<table>
<tr>
<td>"code":"Expiration time must be within a year"</td>
</tr>
</table>

According to [Consents v3 specs](https://openbanking-brasil.github.io/openapi/swagger-apis/consents/?urls.primaryName=3.0.0#/Consents/consentsPostConsents), the allowed error codes for 422 are:

* SEM_PERMISSOES_FUNCIONAIS_RESTANTES
* INFORMACOES_PJ_NAO_INFORMADAS
* PERMISSOES_PJ_INCORRETAS
* PERMISSAO_PF_PJ_EM_CONJUNTO
* COMBINACAO_PERMISSOES_INCORRETA

Meanwhile, as described in [Orientações - \[DC\] Consentimento](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/219480491/Orienta+es+-+DC+Consentimento):

> #### Regras para a criação do consentimento
>
> 6. Nas situações abaixo, a transmissora deve rejeitar o pedido de criação de consentimento, dando retorno HTTP Status Code 422 com as mensagens especificadas abaixo:\
>    e. Caso a Instituição Receptora envie data de expiração maior que um ano ou uma data referente ao passado, deve-se retornar HTTP Status Code 422.

Therefore, none of the possible error codes provided in the specification seem to match the situation described in test summary and in [Orientações - \[DC\] Consentimento](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/219480491/Orienta+es+-+DC+Consentimento), which relates to the creation of a consent with invalid expirationDateTime.

What we need clarification from WG is:

* What should be the expected error message in case a attempt to create a consent with invalid expiration date time is made?
