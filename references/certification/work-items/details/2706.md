## 📝 Descrição

hi, master. we hit an issue when calling Mock Bank `fido-registration-options` API — could you help check? thanks!

#### Issue

Mock Bank returns HTTP 200 for:

`POST /open-banking/enrollments/v2/enrollments/{enrollmentId}/fido-registration-options`

but the response is missing `authenticatorSelection`.

For Android FIDO registration, we need this field to confirm authenticator requirements, for example:

```json
"authenticatorSelection": {
  "authenticatorAttachment": "platform",
  "residentKey": "required",
  "requireResidentKey": true,
  "userVerification": "required"
}
```

#### Request details

rp: test.shopee.com.br

platform: ANDROID

#### Ask

Could you please confirm why authenticatorSelection is missing from the response, and whether Mock Bank can include it for Android registration options?

Hi @zhidong.tan, thank you for raising this. We confirmed the following:

Per the Open Finance Brasil Enrollments API specification v2.2.0, `authenticatorSelection` is **optional** in the `fido-registration-options` response, and the conformance suite tolerates its absence. Mock Bank is therefore conformant when it omits the field.

That said, including `authenticatorSelection` would make Mock Bank more useful for real-world Android FIDO initiators. We will track this as an improvement and will keep you posted on updates.
