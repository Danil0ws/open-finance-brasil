## 📝 Descrição

When trying to run the 2 test modules of the FVP Automatic Payments Manual using the fvp-automatic-payments_open_test-plan-v1 plan, a configuration error is displayed, where it is mandatory to inform the ispb field in the debtorAccount object. The DebtorAccount fields do not exist in the form and if I insert them via json it still displays the same error.

Question: Will the debtorAccount object be included as mandatory in the FVP? In v1 of the Automatic Payments API it is not yet mandatory.

Error message: "AddRecurringPaymentConsentRequestBodyToConfig: Unable to find element resource.debtorAccountIspb in config"

Hi, Thanks for opening the ticket! After running test in FVP with other institutions, no debtor account information being included on test plan configuration, I was able to execute both tests with success while not being able to reproduce the mentioned behavior.

Condition: AddRecurringPaymentConsentRequestBodyToConfig does not require debtor account information to be included in the configuration of the test module to succeed.

That Said, this might be related to the config json being used to run the test plan, make sure that only the necessary fields are informed. Or else, attach the logs to the test module execution so that this can be investigated further.
