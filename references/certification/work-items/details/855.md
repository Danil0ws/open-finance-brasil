## 📝 Descrição

## 1. What Happened and what were you expecting?

The `payments_api_no-debtor-account_test-module_v3` is meant to use DICT as the `localInstrument`, as seen in the test summary step below:

_• Calls POST Consents Endpoint with no debtor account information, using DICT as the localInstrument_

However, even though the POST Consents sends the mentioned object correctly, the POST Payments request depends on the config value. If the `brazilPaymentConsent` object in the config is passed with `data.payment.details.localInstrument` as INIC or any other option, the test uses the config one in the POST Payments request, not DICT as it was meant. As seen below:
