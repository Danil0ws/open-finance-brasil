#### Current Behavior:
---
We're receiving a FAILURE at GetCreditCardAccountsTransactionsOASValidatorV2, stated reason being: "Unable to find element feeType on the GetCreditCardAccountsTransactionsOASValidatorV2 API response"

#### Expected Behavior:
---
As seen below, transactionType is "PAGAMENTO"; feeType is only mandatory if transactionType is "TARIFA" (according to the OpenFinance BR documentation)

PS: Both tests have other failure points, but they are not the focus of this issue.
