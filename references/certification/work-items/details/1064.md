We understand that the failure to send a mandatory field indicates a syntax error of the client, that is, a poorly formatted request and that the fact that it does not comply with the minimum requirements should not be processed, http 400.
Indicating the http 401 error, in this case, would not be correct because this code characterizes that the request has been "processed" but that it does not have the necessary credentials to continue the journey.
