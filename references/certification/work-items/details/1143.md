Hello Everyone,

Apologies for any confusion caused. 

To clarify, this test does indeed require a DCR for conducting validations in the test module. Since this test has been incorporated into the test plan along with other modules, the issue where a client is already registered is expected. To address this, our initial proposed solution involves deleting the client ID registered before executing the webhook test module. 

We recognize that this approach is not ideal. Therefore, we will discuss this in the Working Group to incorporate these test modules into a separate plan. This would allow the registration of a new client as required. 

We will provide further updates here as soon as we have more information.
