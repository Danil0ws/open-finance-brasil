During Conformance Suit call to:

**PATCH pix/recurring-payments/01JM2Z8SR814ZBTWXP1729VX4B**

The token used during request has the following **scope=recurring-payments**

As can be seen in the image below:

![image.png](/uploads/e030af98fd34b562f298cd9f65d034e5/image.png)

As described in the [swagger for the Automatic Payments API](https://raw.githubusercontent.com/OpenBanking-Brasil/openapi/main/swagger-apis/automatic-payments/2.0.0-rc.1.yml):

```
patch:
      tags:
        - Recurring Payments
      summary: Cancelamento de solicitação de pagamento automático.
   security:
        - OAuth2ClientCredentials:
            - recurring-payments
```

Meaning that the token used to call this endpoint only requires the scope: recurring-payments, which is being provided as expected.\
Therefore Conformance Suit is operating correctly in this regard!

As a response to the PATCH Request, the server returned:

Server returned: "MTLS authentication failed". After verifying the provided Certificate it appears to be Valid, leading to believe that the error is happening on server side.
