### Comentário 1
**Autor**: Carla Moreno (@carla-raidiam)
**Criado em**: 12/04/2023, 17:17:40

Boa tarde prezado,

Conforme mencionado no ticket equivalente aberto no Service Desk, os testes falharam porque eles foram executados ao mesmo tempo e possuem o mesmo valor "obbsb" de `alias`.

Dessa maneira, não existem erros no plano de teste reportado. Para uma execução bem sucedida do mesmo é preciso adaptar as configurações dos testes para que o campo "`alias`" seja diferente entre eles ou que os testes não sejam executados ao mesmo tempo.

Caso mais de uma pessoa esteja testando simultaneamente, recomendamos a primeira opção citada: usar valores diferentes para o campo "`alias`" nas configurações dos testes.

Estamos a disposição para qualquer dúvida adicional!
