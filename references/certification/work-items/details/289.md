No requirements to be submitted, the initial structure will check the internal logs and results.

All institutions should run it depending on their phase in production. If you are only Phase 3 do run the Payments DCM test.

It's only for institutions that support tls_client_auth for token authentication mechanism.

Please check Informa #190

Esclarecimento sobre obrigatoriedade da execução de teste para troca de certificado TLS

Devido a dúvidas apresentadas pelos participantes, segue esclarecimento sobre Informa #188: “Obrigatoriedade da execução de teste de troca de certificado TLS por transmissoras até 15/07/2022”

O teste se aplica a transmissoras e detentoras de conta que estão certificadas no perfil mtls. Portanto, retifica-se o texto anterior para:

   
   “Informamos que é obrigatória a execução desse teste por todas as instituições transmissoras que estão certificadas no perfil mtls até 15/07/2022. Para esse grupo de participantes, está disponível o plano de testes ‘Resources DCM tests for changing subjectdn’.

   Adicionalmente, também é obrigatória a execução desse teste por todas as instituições detentoras de conta que estão certificadas no perfil mtls até 22/07/2022. Para esse grupo de participantes, está disponível o plano de teste ‘Payments DCM tests for changing subjectdn’.”
