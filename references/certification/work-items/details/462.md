Hi, 

The way our polling routine works is as follow:

- We call the protected resource
- We check the response
- We wait when needed for another call
- We refresh the access token when needed

The same behavior applies for the last execution, when we verify if on timeout the result has changed. 
In your case, it seems we've reached the maximum call number for this test module (10) and the resource we were looking for yet was not found. 

Is it clearer to you?
