## 📝 Descrição

Hi,

We're trying to certificate a deployment that provides only CUSTOMERS_PERSONAL_IDENTIFICATIONS_READ, CUSTOMERS_PERSONAL_ADITTIONALINFO_READ, CUSTOMERS_BUSINESS_IDENTIFICATIONS_READ, CUSTOMERS_BUSINESS_ADITTIONALINFO_READ and RESOURCES_READ permissions for phase 2; note that this deployment has no ACCOUNTS permission.

The problem we're facing is that both `consents-api-status-test` (https://web.conformance.directory.openbankingbrasil.org.br/log-detail.html?log=wArZDKo2S8a6jMf) and `consents-api-delete-test` (https://web.conformance.directory.openbankingbrasil.org.br/log-detail.html?log=XD1VyGhkMwUzogv) tests tries to retrieve accounts resource as seen in `BuildAccountsConfigResourceUrlFromConsentUrl` step, but this deployment doesn't support `GET /accounts/v1/accounts`. 

Could we submit it to certification with these two failures or we should wait for a tester fix that supports a specific resource URL on configuration?

Thanks,

Patrick
