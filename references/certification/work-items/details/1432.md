Upon reviewing the documentation, I would like to clarify the structure of the webhook endpoints as described in the [webhook specification (swagger.yml](https://openbanking-brasil.github.io/openapi/swagger-apis/webhook/1.2.0.yml)). As per the documentation under the **`servers`** section:

```
servers:
  - url: 'https://api.banco.com.br/open-banking/webhook/v1'
    description: Production Server
  - url: 'https://apih.banco.com.br/open-banking/webhook/v1'
    description: Homologation Server
```

This indicates that 'https://api.banco.com.br/open-banking/webhook/v1' (for production) and 'https://apih.banco.com.br/open-banking/webhook/v1' (for homologation) serve as the common base URLs for all related API endpoints.

In the context of the specification where it mentions:

```
paths: '/payments/{versionApi}/consents/{consentId}':
```

The implicit, full path for each endpoint is constructed by appending the specific path to the base URL provided in the servers section. Therefore, the full path for the example you mentioned would be:

```
https://api.banco.com.br/open-banking/webhook/v1/payments/{versionApi}/consents/{consentId}
```

Consequently, the documentation's approach to omit the base URL from each path is a common practice to avoid redundancy and ensure clarity by not repeating the base URL for each endpoint described.

Regarding your test log:

* **Test Endpoint you provided:** **`/test-mtls/a//open-banking/webhook/v1/payments/v4/pix/payments/{paymentId}`**
* **Documented Path:** **`/test-mtls/a/baas-payments-264/payments/v1/pix/payments/{paymentId}`**

Please ensure that when configuring your webhook notifications or testing endpoints, the base URL from the **`servers`** section is appropriately prepended to the paths specified under the **`paths`** section of the documentation. This ensures correct endpoint addressing and integration with our Open Banking Webhook API.
