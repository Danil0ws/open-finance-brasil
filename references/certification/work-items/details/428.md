## 1. What Happened and what were you expecting?
  In conformance testing engine, we have two tests: **customer-api-businessentity-personal-permissions-v2** in **Business Customer Data api** and **customer-personal-api-wrong-permissions-test-v2** in **Personal Customer Data api**.

  The problem is that in the **customer-api-businessentity-personal-permissions-v2**, testing engine expects an error when trying to send the field **businessEntity** and any **CUSTOMER_PERSONAL** permission, but in the other hand, the test **customer-personal-api-wrong-permissions-test-v2** the same data (**businessEntity** and any **CUSTOMER_PERSONAL** permission) expect a success. We have a conflict by the fact that in one API expects an error, but in other expects a success with the same data. The business rule is that we can't send **businessEntity** with any **CUSTOMER_PERSONAL** permissions.
