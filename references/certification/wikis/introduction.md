---

The Open Finance Brasil functional API test suite aims to be a comprehensive, ecosystem-led suite of tests for Open Finance Brasil. It is based on the [OIDC conformance suite](https://gitlab.com/openid/conformance-suite).

The application itself is a Spring Boot Java web application. These pages aim to enable developers, primarily from within the Open Finance ecosystem to contribute to and maintain the test suite on an ongoing basis.
