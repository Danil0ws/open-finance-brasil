# Submission of Results for Open Banking Certification

**_Version 1.1. 7th July 2021_**

This page describes how to submit completed conformance testing results to the Open Banking Brasil to request Certification. Before submission, first all tests must be successfully passed for the desired conformance profiles and testing results gathered, as described in the _instructions_. 

All tests MUST be in the ‘FINISHED’ status. Note that results with warnings are acceptable for certification purposes.

Please note that the full supplied log files will be published as part of a successful certification. These may contain client credentials, private keys, and other potentially sensitive data that are part of the test configuration, so it is recommended to deactivate clients revoke keys before submitting your results.

Some certification profiles require more than one test plan to be run, and a separate submission package should be prepared for each one. 

For all other profiles, simply running the relevant test plan once is all that is required.
For each conformance profile being certified to, the following information must be submitted in its own certification package:

1. A signed copy of the [Certification of Conformance Document](https://github.com/OpenBanking-Brasil/specs-directory/blob/main/conformance/documents/TnC/Certificado%20de%20Conformidade%20Funcional.docx)  naming the profile.
 
2. A copy of the [Certification Terms and Conditions](https://github.com/OpenBanking-Brasil/specs-directory/blob/main/conformance/documents/TnC/Termos%20e%20Condi%C3%A7%C3%B5es.pdf) document accompanying the Certification of Conformance. This must use the filename **OpenBanking-Certification-Terms-and-Conditions.pdf** in the submitted results. (This document is not signed but is included for completeness since it is referenced from the Certification of Conformance).

3. Downloaded test logs.
- The certification package should consist of a single .zip file containing all the files and using the paths above.

- The certification package can be created either manually or by using the ‘Certification Package’ button.

## Submitting the logs into the Service Desk

If you need to submit the logs to the Service Desk, you can do it by accessing [this link](https://servicedesk.openbankingbrasil.org.br/) and signing up if you don't have an account or logging in.

![image](uploads/e03c41450efea6793d373946190aec52/image.png)


After logging in, you'll see a menu where you'll be able to choose the [placeholder] option.

![image](uploads/4d106b23d997703cbb4753f62eb9cc58/image.png)

When you click on the [placeholder], you'll see a form containing the necessary information you need to submit alongside the log attachment:

![image](uploads/595232d7895b98368db4666eec27ede2/image.png)

You should fill out the form in the following way:

Title: Customer Friendly Name of the evaluated brand - Test module with execution issues

Description: Software Statement UUID

For this example, we will use the Mock Bank and the accounts test:

![image](uploads/bf7cfff393cc19e8e58c7fa5f173b9ff/image.png)

After attaching the clean HTML log of your test, you'll press submit, and your request should be then treated by the initial structure of the Open Banking
