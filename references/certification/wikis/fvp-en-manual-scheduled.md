# Restricted FVP

The Restricted FVP gathers the scheduled plans, whose flows span more than one day. Configuring the plan and starting the first module are manual actions, but the flow then continues automatically on the following days and can be followed in Test Manager (Scheduler). These tests are currently conducted only by the Open Finance structure. Select an API/Product/Journey below to view the available plans and more detail on how to configure each one.

- [Automatic Payments](FVP/EN/Manual/Scheduled/Automatic-Payments)
- [Client Management](FVP/EN/Manual/Scheduled/Client-Management)
- [Credit Portability](FVP/EN/Manual/Scheduled/Credit-Portability)
- [Enrollments](FVP/EN/Manual/Scheduled/Enrollments)
- [Payments](FVP/EN/Manual/Scheduled/Payments)
