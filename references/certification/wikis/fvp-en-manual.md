# Manual FVP

The Manual FVP validates the full journey in production and therefore requires user authentication and consent, with real data, both for data sharing and for payment initiation. It is currently split into two profiles, shown below: the Open FVP, corresponding to the immediate plans, which can be run by the Open Finance structure and by participants registered with the PFVPC profile in the Directory; and the Restricted FVP, corresponding to the scheduled plans, whose multi-day flows are conducted only by the Open Finance structure.

[Open the Manual FVP](https://web.fvp.directory.openbankingbrasil.org.br)
