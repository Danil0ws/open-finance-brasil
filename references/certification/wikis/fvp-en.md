# FVP

FVP, the Production Validation Tool, verifies, in the production environment and with real data, whether participants' implementations follow the standards defined by Open Finance Brasil. While the Conformance Suite validates in a testing environment (Sandbox), before go-live, FVP continues that validation afterwards, running the same kind of test plan against participants' real servers. This repository gathers two testing arms, automatic and manual, alongside the release notes and the frequently asked questions, available below.
