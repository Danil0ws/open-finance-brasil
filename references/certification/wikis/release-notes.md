# Overview

Every change recorded on the Conformance Suite pages, in one place, newest
first. Each row links to the page the change was made on, where the same entry
sits alongside the plans and modules it affected.

This page is built from those pages rather than written separately, so it
cannot say something they do not.

Breaking changes are listed on their own above, because a cut-off date is the
one thing here that has a deadline attached. The cut-off is the earliest test
plan creation date accepted for certification, and it is set by the change, not
by the date the change was released. Dates may change.
