# Overview

Phase 3 covers payment initiation and the services built on top of it. In the
Conformance Suite the profile is still named "Phase 3 - Payment Initiation", so a
search for Payments lands here.

Four products, each on its own page because each breaks on its own schedule. The
Payments API has two versions in the suite at the same time, v5.0.0 and v4.0.1.
Automatic Payments covers sweeping and automatic Pix. Enrollments covers the
no-redirect journey, and also has two versions live, v2.2.0 and v2.3.0-rc.1.
