# [Open Finance] Informa #723

[Errata Informa #709] – *Release* 2025A –Implementação de novos campos para a PCM Informamos que a documentação referente a implementação do Pix Automático na PCM sofreu adequação, com o intuito de proporcionar maior detalhamento quanto a obrigatoriedade de envio dos campos *AdditionalInfo* pelas instituições.    A atualização flexibiliza a implementação das instituições para condições específicas, em aderência às restrições de envio para cada *Http Code* e Método.    A documentação atualizada estará disponível à partir de 10/04/2025 e poderá ser acessada através do link abaixo. |

 Release Extraordinária 2025-A1 – Dados relativos à quantidade de consentimentos ativos e únicos por clientes Com o intuito de aprimorar o monitoramento através do autorreporte via PCM, em aderência a estratégia integrada de Monitoramento apresentada durante a 228ª Reunião do Conselho Deliberativo em 14/11/2024, foi aprovada a criação de uma nova API dedicada a obtenção de dados quantitativos de consentimentos ativos e únicos por tipo de cliente para os papeis *Client/Server*.     **EndPoint: /report-api/v1/consents/stock**     Esta solução possibilitará a posterior descontinuidade das informações autorreportadas através de planilhas.     **Cronograma de Implementação**   | Evento | Data | | --- | --- | | Disponibilização da documentação (Swagger versão Beta) | 09/04/2025 | | Disponibilização da documentação detalhada definitiva | 14/04/2025 | | Implementação na PCM em ambiente *sandbox* e produtivo | 28/04/2025 | | Início do período de adaptação para instituições | 29/04/2025 | | Fim do período de adaptação para instituições | 09/06/2025 |    A partir de 09/04/2025 a documentação na versão 1.0.7-Beta poderá ser acessada na área do desenvolvedor através do endereço: *Documentação da API - Área do Desenvolvedor - Open Finance Brasil - Área do Desenvolvedor*. A documentação definitiva e detalhada estará disponível a partir de 14/04/2025 neste mesmo endereço.    As instituições têm o período de 29/04/2025 a 09/06/2025 para integrar a nova API, dentro do prazo estipulado na *release* 2025-A1. Após 09/06/2025, o não envio dos dados poderá resultar em notificações através do Service Desk, onde as instituições deverão tomar as devidas providências para corrigir as não conformidades identificadas. |
