# [Open Finance] Informa #910

Abertura Indevida de Tickets – API Contas |

 Comunicamos que possíveis tickets abertos para as instituições referente a desconformidade no MQD em relação a implementação do endpoint */accounts/{accountId}/reserved-balances* para o campo *reservedIdentification*para API Contas, **deverão ser desconsiderados.**    Em momento oportuno retornaremos em relação aos próximos passos para correção deste tema. |
