# [Open Finance] Informa #682

Cancelamento do *go live* da versão 2.3.0 da API Adiantamento a depositantes (Dados do cliente)  Informamos que, devido a uma alteração indevida no *pattern* dos campos “instalmentPeriodicityAdditionalInfo” e “amortizationScheduledAdditionalInfo”, o *go live* da versão 2.3.0 da API Adiantamento a depositantes está cancelado.   - As instituições não deverão publicar a versão 2.3.0 da API Adiantamento a depositantes no Diretório em 17/01/2024, conforme Informa #664 (“Data para atualização da versão *minor* das APIs Direitos creditórios descontados, Financiamentos e Adiantamento a depositantes (Dados do cliente)”, enviado em 22/11/2024); - Os ajustes contidos na versão 2.3.0 e as correções aos campos citados acima serão publicados em nova versão 2.4.0.   Comunicamos, adicionalmente, que as especificações e a data de entrada em produção da nova versão 2.4.0 serão compartilhadas em um Informa posterior. |
