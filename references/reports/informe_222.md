# [Open Finance] Informa #222

Esclarecimentos sobre a planilha de problemas conhecidos  **A planilha de problemas conhecidos foi criada para tratar divergências nas especificações,** **mitigando problemas de interoperabilidade antes do lançamento de uma nova versão das APIs**. Ela se sobrepõe aos demais documentos (*Swagger*, Dicionário de Dados, Guias, etc.) e deve ser seguida durante a implementação, conforme coluna “orientação até a publicação do ajuste”.  A coluna “Como deveria ser?” é uma orientação para o desenvolvimento de uma versão futura das especificações e **não deve ser implementada pelas Instituições** para a versão à qual a planilha se refere.  Alguns problemas conhecidos informam que “não há a necessidade de orientação adicional até o ajuste”, deste modo, as **especificações do *Swagger* deverão ser utilizadas como base da implementação** conforme Informe #18 - Ratificação da prioridade do *swagger* - enviado em 09 de julho de 2021.    **Exemplos:** |

 - O BCLOG-F02-156 indica que existe um erro no *pattern* que não permite valor “NA” e, portanto, as instituições devem utilizar o valor "0000-01-01T00:00:00Z" até a correção das especificações. - O BCLOG-F02-157 indica que apesar de existir um problema, no momento não existem orientações adicionais. Portanto, deve-se seguir conforme especificado no *Swagger* e para o campo em questão, na versão 1.0.3 da API, utilizar o valor “NAO\_APLICA”. |
