# [Open Finance] Informa #377

Depreciação da v1.2.0 da API de Iniciação de Pagamentos              Conforme cronograma publicado na Instrução Normativa nº 326 de 22/11/2022, o período de convivência entre as versões 1.2.0 e 2.0.0 da API de Iniciação de Pagamentos (fase 3) se encerrará em 16/05/2023, considerado o último dia do período de depreciação da versão 1.2.0. Após essa data as detentoras devem descontinuar a versão 1.X.X. **O desligamento da versão 1.X.X deverá ocorrer no formato *big bang*** (substituição total da v1 pela v2, sem faseamento).    **Orientação às detentoras de conta:**  - **O desligamento da versão 1.X.X deve ocorrer às 23h59 do dia 16/05/2023**   - Remover o cadastro das APIs 1.X.X do diretório central, conforme orientações publicadas no Guia Operacional do Diretório (Capítulo 9 - Cadastrando recursos de uma API, ETAPA 3: Removendo um recurso de uma API)   - Desabilitar em sua infraestrutura interna o acesso às APIs das versões 1.X.X de Iniciação de pagamentos  **Orientação às iniciadoras de pagamento:**  - **Desabilitar o consumo das APIs das versões 1.X.X até as 23:59 do dia 16/05/2023**, caso ainda haja o consumo desta versão. |
