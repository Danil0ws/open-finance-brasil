# [Open Finance] Informa #749

Comportamento esperado no módulo “automatic-payments\_api\_automatic-pix-revoked\_test-module\_v2” presente no piloto do Pix Automático da FVP Informamos que foi identificado pela DTO um erro em um dos testes da certificação da API Pagamentos automáticos. O problema está presente desde a versão 2.0.0 e perdurou até a versão mais recente do produto.  O módulo afetado é o “***automatic-payments\_api\_automatic-pix-revoked\_test-module\_v2***”, que está contemplado na FVP Manual com o título: “*fvp\_automatic-payments\_api\_automatic-pix-revoked\_open\_test-module\_v2*”.  No Informa #732 (“Piloto do Pix Automático – Painel integrado e página centralizada”, divulgado em 30/04/2025), foi compartilhada a página contendo as diretrizes gerais do piloto. Entretanto, em decorrência do erro identificado, informamos que **o sucesso nesse módulo de teste da FVP não será considerado** como critério de sucesso no piloto do Pix Automático.  Adicionalmente, **solicitamos que as instituições se adequem, o mais brevemente possível**, realizando a alteração prevista na especificação, no respectivo *endpoint*:   - PATCH /recurring-consents/{recurringConsentId}:   - *“Quando um consentimento for revogado, todos os pagamentos associados a esse consentimento devem ser CANCELADOS. Ele se aplica para o cenário onde o usuário altera a data de expiração do seu consentimento e exista pagamento associado já agendados para data posterior a nova data definida como expiração.”* |

 LEMBRETE – Marco de 100% da API Pagamentos automáticos v2.1.0 para instituições iniciadoras de transação de pagamentos (ITPs) Informamos que, conforme compartilhado no Informa #726 (“*Transferências Inteligentes – Cronograma de implementação da v2.1.0 (minor) da API Pagamentos automáticos*”, divulgado em 16/04/2025), **o marco de 100% da API Pagamentos automáticos para ITPs ocorrerá em 10/06/2025**.  Destacamos que o marco de 100% exige que, em ambiente produtivo, todas as chamadas realizadas para o produto Transferências inteligentes utilizem a nova versão 2.1.0 da API Pagamentos automáticos.     Reforçamos que instituições que não obtiverem sucesso no marco serão notificadas via tickets do Service Desk. |
