# [Open Finance] Informa #354

Liberação do motor funcional versão beta das APIs de Dados Abertos – Previdência (fase 4A) Informamos a liberação para testes beta do motor de conformidade funcional das APIs de Dados Abertos (fase 4A) – Previdência.  Os testes poderão ser executados no motor de conformidade ou no Diretório de Sandbox, visto que o processo de certificação das APIs de Dados Abertos será realizado de maneira automatizada, conforme Guia Operacional do Diretório (páginas 75 a 80).  **Pedimos às instituições que iniciem esses testes o quanto antes para contribuir com a maturidade do motor funcional**. Durante o período beta, os testes serão atualizados conforme sejam encontradas oportunidades de melhorias e/ou ajustes e suas alterações estarão disponíveis no release notes do Gitlab.  Problemas ou inconsistências identificadas devem ser notificadas através do repositório no GitLab no link abaixo.  Tickets abertos através da plataforma do Service Desk continuarão sendo tratados.  Em breve serão divulgados os marcos de sucesso esperados para a 2ª onda da fase 4A (Capitalização, Previdência e Seguros). |
