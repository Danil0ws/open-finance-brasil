# [Open Finance] Informa #721

Orientação para o período de submissão da certificação da API Pagamentos automáticos v2.0.0  Conforme comunicado no Informa **#661** (“*Novo cronograma de implementação da v2.0.0 da API Pagamentos automáticos (Transferências inteligentes + Pix automático)*”, enviado em 14/11/2024):     **Disponibilização da versão estável do motor de conformidade: 04/04/2025**    O motor de conformidade foi disponibilizado nessa data e contém as seguintes alterações relevantes nos testes do produto Pix automático:   | Nome do módulo | Alteração relevante | | --- | --- | | automatic-payments\_api\_automatic-pix-consent-edition-negative\_test-module\_v2 | Valida novas regras de edição de consentimento e códigos de erro | | automatic-payments\_api\_automatic-pix-consent-edition-restrictive\_test-module\_v2 | Testa cenários de pagamentos agendados para datas posteriores ao “expirationDateTime” do recurring-consent | | automatic-payments\_api\_automatic-pix-minimumVariableAmount\_test-module\_v2 | Valida a edição do campo “MaximumVariableAmount”, que não pode ser definido com valor menor que MinimumVariableAmount | | automatic-payments\_api\_automatic-pix-scheduled-firstPayment\_test-module\_v2 | Valida o envio de “debtorAccount” para consentimentos authorised, quando este não foi informado durante a criação do consentimento |    A lista atualizada dos módulos de testes do motor pode ser acessada na seção “[*Test Plan*](https://bra01.safelinks.protection.outlook.com/?url=https%3A%2F%2Fgitlab.com%2Fraidiam-conformance%2Fopen-finance%2Fcertification%2F-%2Fwikis%2FPhase-3-Automatic-Payments-Tests%23test-plan-list&data=05%7C02%7Cgabriela.lettieri%40chicagoadvisory.com.br%7Cdefdd450b92f49bb299608dd7613479e%7C7531e8b3c928494b9b897ee3d353272d%7C0%7C0%7C638796547451303399%7CUnknown%7CTWFpbGZsb3d8eyJFbXB0eU1hcGkiOnRydWUsIlYiOiIwLjAuMDAwMCIsIlAiOiJXaW4zMiIsIkFOIjoiTWFpbCIsIldUIjoyfQ%3D%3D%7C0%7C%7C%7C&sdata=n9Z7xjtp07e3ECyTYXvQvFbvKyyIoVGVn%2B1Xkru%2FPjE%3D&reserved=0)”.     **Período de submissão da certificação: 07/04/2025 a 18/04/2025**    Durante o período de submissão da certificação, as instituições devem submeter um ticket único no Service Desk, contemplando evidências de sucesso de todos os planos de testes aplicáveis aos produtos Pix automático e Transferências inteligentes.  - Para instituições que não ofertam múltiplas alçadas ou contas PJ, serão aceitas evidências que contenham o resultado “*skipped*” para os respectivos testes; - A certificação será negada apenas em caso de falha (“*failed*”) em algum dos testes obrigatórios; - As instituições que tiverem a dispensa de certificação autorizada para o produto Pix automático deverão submeter o pedido de certificação com o plano de testes de Transferências inteligentes conforme comunicado no Informa **#683** *(“Solicitações de dispensa da certificação do produto Pix Automático para instituições que suportam apenas conta PJ”*, enviado em 10/01/2025).  A certificação será processada apenas para instituições que submeterem planos de teste criados a partir da data de sua última alteração relevante, conforme a tabela a seguir:   | Funcionalidade | Plano de teste | Data de criação do plano | | --- | --- | --- | | Pix automático | Automatic Pix Payments - v2.0.0 | 07/04/2025 | | Automatic Pix Payments Webhook - v2.0.0 | 14/02/2025 | | Automatic Pix Payments Retry - v2.0.0 | | Automatic Pix Payments Timezone - v2.0.0 | | Transferências inteligentes | Automatic Sweeping Payments - v2.0.0 | | Automatic Sweeping Payments Webhook - v2.0.0 | | Automatic Sweeping Payments Timezone - v2.0.0 |    **Período de publicação no Diretório: 07/04/2025 a 21/04/2025**    Em correção ao Informa **#716** *(“[Errata] Esclarecimento sobre as datas de go live das funcionalidades da API Pagamentos automáticos”*, divulgado em 28/03/2025), informamos que a publicação da v2.0.0 da API no Diretório poderá ocorrer em qualquer momento durante a janela de 07/04/2025 e 21/04/2025.    Reforçamos que, mesmo que uma instituição realize a publicação antes do início do piloto, a versão 2.0.0 da API só poderá ser acionada pelas iniciadoras a partir de 22/04/2025.    Por fim, informamos que a versão 1.0.0 da API será mantida no Diretório até o final do período de convivência, previsto para 15/06/2025. |
