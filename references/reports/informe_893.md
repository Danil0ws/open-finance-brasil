# [Open Finance] Informa #893

Disponibilização dos motores da API de Contas v2.5.0-estavel e API de Cartão de Crédito v2.4.0-estavel |

 Conforme compartilhado no Informa #846 ("Atualização do cronograma para as APIs de Contas e Cartão de Crédito"), divulgado em 05/02/2026, os motores de conformidade da API de Contas v2.5.0-estavel e API de Cartão de Crédito v2.4.0-estavel foram disponibilizados em **15/05/2026** e serão utilizados para o marco de 100% em **02/06/2026**.    Para o marco de 100%, as instituições devem obter sucesso nos seguintes planos de testes:    **API Contas v2.5.0-estavel**   - Functional Tests for Accounts API - Based on Swagger version: 2.5.0   **API Cartão de Crédito v2.4.0-estavel**   - Testes Funcionais para a API de Cartão de Crédito - Baseado na versão do Swagger: 2.4.0   As instituições que não atingirem sucesso no marco serão notificadas via tickets do Service Desk.  Mais detalhes sobre os testes podem ser consultados na página de plano de testes. |

 Piloto JO – Novo sucesso nos testes de interoperabilidade da FVP e alterações nos módulos de testes |

 De acordo com o cronograma do Piloto de Jornada Otimizada, disponível na página de diretrizes gerais do Piloto e compartilhado no Informe #879 (Piloto de Jornada Otimizada – Diretrizes gerais), o prazo para obtenção de um novo sucesso nos testes de interoperabilidade da FVP Manual é 22 de maio de 2026.  Para a contabilização de um novo sucesso nos 2 módulos de testes de Interoperabilidade, serão considerados sucessos apenas a partir de 13 de maio de 2026, tendo-se em vista as mudanças de comportamento nos testes, introduzidas pela Issue 2691.  Ambos os módulos de interoperabilidade da FVP foram impactados pela alteração:   - Vínculo de Dispositivo: fvp-optimized-journey\_enrollments-balances\_test-module-v1  - Transferências Inteligentes: fvp-optimized-journey\_sweeping\_payments-balances\_test-module-v1   Instituições cuja responsabilidade de execução dos testes é pelo fornecedor contratado, serão executados sob responsabilidade da estrutura. Demais instituições devem garantir o sucesso nos testes através de execuções por própria responsabilidade.  Mais informações com relação ao Piloto de Jornada Otimizada podem ser encontradas na página das diretrizes gerais do piloto. |

 Informamos que o módulo abaixo será desconsiderado da certificação da API Pagamentos v5.0.0   - Plano: Functional Tests for Payments Withdraw QRES API - Based on Swagger version: v5.0.0   - Módulo: payments\_api\_pix-withdraw-invalid-amount\_test-module\_v5   Instituições que já tiverem criado um plano contendo este módulo poderão submeter para certificação, tendo obtido sucesso ou não. |
