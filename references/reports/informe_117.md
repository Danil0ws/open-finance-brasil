# [Open Banking] Informa #117

Atualização do Guia de Experiência do Usuário   O Grupo Técnico de Experiência do Usuário disponibilizou no dia 24/01/2022, uma nova versão do Guia de Experiencia (Versão 3.05.01).      Nesta versão estão contemplados os seguintes ajustes para Iniciação de Pagamento:   - Inclusão dos Requisitos e Recomendações para o arranjo TED e TEF, com telas ilustrativas - Criação de status exclusivos para os casos de agendamento (Detalhamento dos Status das Jornadas) - Atualização dos requisitos e recomendações para o Ambiente de Gestão de Pagamento - Orientação sobre as funcionalidades de Pix QR Code não previstas atualmente no Open Banking - Pix Cobrança / Pix Saque / Pix Troco - Nova recomendação importante para as ITPs: Desde o início da jornada de Iniciação de Pagamento seja dada visibilidade sobre as etapas que o cliente deve percorrer para finalizar o pagamento, deixando claro que ele será redirecionado para confirmar o pagamento na sua detentora de conta e retornará à iniciadora.   Outras melhorias foram realizadas no Guia de Experiência, mas não alteram as recomendações e requisitos anteriores, buscam apenas garantir clareza para os desenvolvedores na implementação das jornadas do Open Banking. |
