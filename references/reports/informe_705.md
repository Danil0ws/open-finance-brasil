# [Open Finance] Informa #705

Alteração do *rate limit* para o *endpoint* de *participants*      A partir de 10/03/2025 as instituições que ultrapassarem o *rate limit* de 5 TPM (transações por minuto) para o *endpoint* de *participants* serão notificadas. Posteriormente, em 10/04/2025 este *rate limit* será alterado definitivamente para 5 TPM. |
