# [Open Finance] Informa #748

Divulgação do *workshop* de nova política de *onboarding* para transmissoras de dados Informamos que na próxima segunda-feira, dia 09/06/2025, às 14h, a Associação Open Finance realizará um *workshop* para apresentar a nova política de *onboarding* de transmissoras de dados no ecossistema.  **A participação de novos entrantes e das instituições receptoras de dados é fundamental**, pois será abordado como funcionará o processo e quais indicadores das transmissoras serão monitorados pela Associação. |
