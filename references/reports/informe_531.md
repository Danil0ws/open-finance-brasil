 Lançamento da versão *release candidate* (4.0.0-rc.2) da API de Pagamentos   Informamos que a área do desenvolvedor do Portal do Open Finance Brasil foi atualizada, em 21/02/2024, com a versão *release candidate* (4.0.0-rc.2) da API de Pagamentos automáticos.  A entrada em produção (*go live*) dessa API será realizada em 15/04/2024, conforme Informa #526 (“Atualização no cronograma da API de Pagamentos v4.0.0”, enviado em 09/02/2024).  Adicionalmente, comunicamos que a página de *changelog* para essa API foi reformulada. O novo modelo de *changelog* permitirá que os desenvolvedores comparem a atual versão publicada com:   - A última versão publicada. Nesse caso, com a versão *release candidate* (v4.0.0-rc.1); - A última versão *current*. Nesse caso, a v3.0.0 da API de Pagamentos. |

 Lançamento da v1.3.0 da API de Vínculo de dispositivo para pagamentos sem redirecionamento  Informamos que foi publicada a versão 1.3.0 das especificações da API de Vínculo de dispositivo para pagamentos sem redirecionamento.   - Sugerimos consultar o *changelog* para visualizar as alterações entre as versões 1.2.0 e 1.3.0. |
