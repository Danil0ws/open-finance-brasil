# [Open Finance] Informa #395

Atualizações da documentação do perfil de segurança        - A fim de viabilizar o cenário de idempotência na API de iniciação de pagamentos, informamos que houve alteração na documentação de segurança no tópico 7.2.2, item 2, referente à utilização de access\_tokens que possuam o escopo *payments*. - Houve também alteração no tópico 5.2.2, item 21, quanto a impossibilidade de utilização do id\_token\_hint, que agora passa a ser permitida para atender ao protocolo CIBA. |

 Atualização do cronograma de execução completa dos testes da API de iniciação de pagamentos – políticas de autorização              Conforme Informe #383 (“Suspensão do cronograma para execução de plano de testes completo da API Iniciação de Pagamentos para o fluxo client credentials”, enviado em 19/05/2023), **comunicamos que a política de perfil de segurança foi atualizada e novo cronograma já está disponível**:  - de 13/06/2023 a 03/07/2023: **Execução obrigatória** do plano completo da API de Iniciação de Pagamentos - de 04/07/2023 a 17/07/2023: **Execução com sucesso** obrigatório do plano completo - de 18/07/2023 a 24/07/2023: **Implementação das detentoras** em produção - Até 18/07/2023: **Atualização das iniciadoras** e implementação em produção |
