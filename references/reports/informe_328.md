# [Open Finance] Informa #328

Orientações sobre publicações no Diretório de produção Seguem algumas orientações para cadastro das APIs no diretório em produção para a fase 3 v2.0.0 pelas detentoras de conta:   - Relembramos que as instituições detentoras de conta que se certificaram para a v2.0.0 da API de pagamentos devem publicar suas APIs em produção e cadastrá-las no Diretório de participantes; - O cadastro dos *endpoints* da v2.0.0 no Diretório de produção:   - Deve ser realizado junto com publicação em produção da solução;     - Não é permitida a publicação de *endpoints* que não estejam disponíveis para serem chamados.   - Deve conter o JSON recebido no ticket da certificação. - O cadastro dos *endpoints* da v1.2.0 no Diretório de produção deve ser mantido durante o período de convivência.   **Instituições que publicarem a v2.0.0 no diretório e não tiverem versão funcional da API estarão em desacordo com a regulação vigente. Casos como esse podem ser identificados pela Ferramenta de Validação em Produção (FVP).** |
