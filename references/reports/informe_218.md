# [Open Finance] Informa #218

Inclusão de itens à planilha de problemas conhecidos da Fase 3 - escopos (scopes) do token de acesso (access\_token) da API de iniciação de pagamentosFoi identificado um problema de interoperabilidade causado pela divergência de entendimento em relação aos escopos que devem ser utilizados na obtenção do *token* de acesso para cada *endpoint* da API de iniciação de pagamentos (Fase 3).    Sobre este tema, os grupos técnicos de especificações, segurança e arquitetura comunicam que foram adicionados os itens BCLOG-FO3-015, BCLOG-FO3-016 e BCLOG-FO3-017, à planilha de problemas conhecidos da Fase 3. Ressaltamos os seguintes aspectos:  - Requisições ao *endpoint* de criação de consentimento sem o escopo *openid* devem ser aceitas - Caso sejam enviados escopos adicionais não conhecidos, eles devem ser ignorados - A iniciadora está passível de receber um erro caso não envie o escopo *openid* nos *endpoints* de pagamento, exceto quando utilizando o modelo *client-credentials*    **Tabela de escopos utilizados em cada modelo de segurança** |

 As instituições financeiras devem se ajustar até o dia 05/10/2022.    Esta correção fará parte das especificações da API de iniciação de pagamentos em seu próximo versionamento *major*, planejado como v2.0.0. |
