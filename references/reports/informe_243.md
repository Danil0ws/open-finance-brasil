# [Open Finance] Informa #243

**Service Desk – Alteração necessária na API da plataforma**    Com o objetivo de evitar que tickets abertos através de API sejam capturados pelo processo de atendimento automatizado da própria instituição, todas as instituições que utilizam os recursos do Service Desk deverão efetuar uma alteração nas requisições de consulta.     O campo “*assigned\_group*" deverá ser adicionado aos endpoints de suas requisições de consulta, fazendo com que sejam exibidos apenas os tickets que estiverem em seu grupo de atendimento, de acordo com o exemplo a seguir:                  GET: {URL}/api/v1/sr?fields=problem\_type,company,description&**assigned\_group=10**     O campo “*assigned\_group*” deve ser preenchido com o ID do grupo de atendimento da instituição. Para identificar este número durante a requisição de login, deve ser capturado o valor do "id" na *key* "user\_groups" de acordo o exemplo a seguir:  "key": "user\_groups",                  "value": [                      {                        "id": 10,                          "name": "N1 Service Desk",                          "type": 1,                          "supportLevel": 1,                          "visible": true                      }   Essas alterações devem ser executadas **até o dia 05/10/2022**.     Para mais informações referente à esta alteração na API do Service Desk, acesse a FAQ ou abra um chamado na plataforma. |
