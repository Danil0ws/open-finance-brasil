# [Open Finance] Informa #822

Disponibilização do motor de conformidade para o produto Jornada Otimizada + Pagamentos Automáticos |

 Conforme compartilhado no Informa #788 (“*Divulgação do cronograma do produto Jornada Otimizada (JO)*”, divulgado em 23/09/2025), **o motor de conformidade contemplando o cenário infeliz de Jornada Otimizada (JO) + Pagamentos Automáticos foi disponibilizado em 08/12/2025 e será utilizado para o marco de 100% em JO + Pagamentos Automáticos no dia 22/01/2026**.     A implementação da Jornada Otimizada é obrigatória para as instituições detentoras de contas que também atuam no compartilhamento de dados como transmissoras de dados, ou seja, que possuem os papeis regulatórios DADOS e CONTA no Diretório de Participantes.    Para esta versão do motor, foram implementados cenários de teste de exceção, ou seja, situações de **não sucesso** na Jornada Otimizada com Pagamentos Automáticos.  Serão validados:  - A ausência do envio do objeto **Journey**; - A revogação de consentimentos, tanto de **Dados** quanto de **Pagamentos**; - O comportamento do fluxo quando um consentimento de dados é criado com permissões além do escopo original de **saldo** e **cheque especial**; - O tratamento de erro quando o **PAR** é enviado de forma incompleta.  **Sucesso no marco de 100% em JO + Pagamentos Automáticos**  Para o marco de 100% em JO + Pagamentos Automáticos, as instituições devem obter sucesso nos seguintes módulos de teste:  - *optimised-journey\_sweeping\_payments-core\_test-module-v1;* - *optimised-journey\_sweeping\_invalid-request\_test-module-v1;* - *optimised-journey\_sweeping\_invalid-par\_test-module-v1;* - *optimised-journey\_invalid-permissions\_test-module-v1;* - *optimised-journey\_sweeping\_revoked-consent\_test-module-v1;* - *optimised-journey\_sweeping\_revoked-recurring-consent\_test-module-v1;* - *optimised-journey\_automatic-pix\_test-module-v1.*  Reforçamos que instituições que não obtiverem sucesso no marco serão notificadas via *tickets* do Service Desk.    Mais detalhes sobre os testes podem ser consultados na página de plano de testes. |

 Atualização do motor de conformidade das APIs de Recursos, Operações de Crédito (exceto API Empréstimos), Contas e Cartões |

 Informamos que, em ajuste às informações originalmente divulgadas no Informa #789 (“*Divulgação dos cronogramas de versionamento minor para as APIs de Dados do cliente*”, enviado em 25/09/2025), **as datas de disponibilização do motor de conformidade para as APIs de Recursos, Operações de Crédito (exceto API Empréstimos), Contas e Cartões foram alteradas**, conforme abaixo:  - API Adiantamento a depositantes v2.5.0, API Direitos creditórios descontados v2.4.0, API Financiamento v2.4.0 e API Recursos v3.1.0:   - De: 01/12/2025;   - Para: **09/01/2025**. - API Cartão de crédito v2.4.0 e API Contas v2.5.0:   - De: 16/11/2025;   - Para: **23/01/2025**.    As demais informações contidas nos cronogramas divulgados no Informa #789 permanecem inalteradas. |
