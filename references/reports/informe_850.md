# [Open Finance] Informa #850

Cronograma dos Ciclos de Testes de FVP Manual — Aberta e Restrita |

 Conforme comunicado no Informa nº 572 (“Novo modelo de execução da FVP (3.0)”, enviado em 30/04/2024), as instituições para as quais o fornecedor responsável pela execução dos testes restritos da FVP Manual não possui conta aberta devem executar os testes abertos da FVP Manual para todos os seus servidores PF e PJ, quando aplicável.    A relação de marcas para as quais o fornecedor possui conta aberta pode ser consultada no dashboard da FVP. De acordo com o Informa nº 691 (“Novo processo de acesso à plataforma de visualização de dados do Open Finance”, enviado em 27/01/2025), a gestão de acesso à Plataforma de Visualização de Dados do Open Finance Brasil — que inclui os dashboards da Estrutura — deve ser realizada pelo administrador da instituição no Diretório de Participantes.    **Cronograma dos Ciclos**  O cronograma completo dos ciclos de FVP Manual **Aberta** e **Restrita** encontra-se detalhado abaixo.                          As execuções das instituições serão cobradas de acordo com:   - As APIs publicadas no Diretório de Participantes; e - As flags de segmento configuradas em cada servidor de autorização.  **Escopo de Testes — FVP Manual Aberta**  Os seguintes testes estão contemplados no cronograma da FVP Manual Aberta:  **1. API Pagamentos Automáticos v2.2.0 — Pix Automático**  Criação e validação de consentimento, com a realização de dois pagamentos.  - Plano de teste: *Production Functional Tests for Automatic Pix Payments – API Version 2.2* - Módulo de teste: fvp\_automatic-payments\_api\_automatic-pix-semanal-core\_open\_test-module\_v2-2  **2. API Pagamentos Automáticos v2.2.0 — Transferências Inteligentes**  Criação e validação de consentimento, com a realização de dois pagamentos.  - Plano de teste: *Production Functional Tests for Automatic Sweeping Payments – API Version 2.2* - Módulo de teste: fvp\_automatic-payments\_api\_sweeping-accounts-core\_test-module\_v2-2  **3. API Dados do Cliente**  Criação de consentimento com prazo indeterminado e execução de chamadas a todas as APIs de Compartilhamento de Dados, conforme as publicações realizadas pela instituição.  - Plano de teste: *Production Functional Tests for Customer Data Happy Path – API Version 3* - Módulo de teste: fvp-customer\_data\_unique\_happy\_path\_test-module  **4. API Pagamentos v4.0.0**  Criação de dois agendamentos customizados (D+1 e D+2), sem cancelamento.  - Plano de teste: *Production Functional Tests for Payments E2E – API Version 4* - Módulo de teste: fvp-payments\_api\_recurring-payments-custom-not-cancelled\_open\_test-module\_v4  **5. API Vínculo de Dispositivo v2.2.0 (JSR)**  Execução de pagamento sem redirecionamento, no valor de R$ 0,50 (cinquenta centavos), até o estado liquidado (ACSC).  - Plano de teste: *Production Functional Tests for No Redirect Payments – API Version 2.2* - Módulo de teste: enrollments\_api\_payments-core\_test-module\_v2-2   **Escopo de Testes — FVP Manual Restrita**  No âmbito da FVP Manual Restrita, os testes não possuem escopo previamente definido de forma fixa. A definição, priorização e eventual atualização dos testes ocorrem ao longo dos ciclos de execução, considerando necessidades regulatórias, evoluções técnicas, incidentes identificados e diretrizes estratégicas do ecossistema.  Os testes propostos para cada ciclo são apresentados à SQUAD Sandbox, em reunião específica, para fins de avaliação, alinhamento e validação quanto à sua pertinência, escopo e execução no contexto da FVP Manual Restrita.    **Documentação e Painéis de Acompanhamento**  O plano de testes detalhado para a execução da FVP Manual Aberta pode ser consultado na seção Plano de Testes do Guia de Operação da FVP, disponível na Área do Desenvolvedor. |
