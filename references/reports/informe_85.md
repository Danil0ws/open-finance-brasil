# [Open Banking] Informa #85

Orientações sobre as certificações Dando sequência à abertura das certificações que ocorreram na segunda-feria, 08/11/2021, seguem abaixo informações detalhadas sobre as diferentes certificações:  **Orientações**:   1. **Todas as certificações mencionadas abaixo são obrigatórias para entrada em produção de cada público-alvo, em cada fase.**    1. A única exceção é para Participantes da Fase 2, que podem publicar a API de Payments com o certificado de segurança emitido para a Fase 2, dado que ele é válido para todas as fases. No entanto, esse certificado deverá ser atualizado obrigatoriamente até 30/11/2021. 2. Prazos de processamento de certificação:    1. Certificações de segurança: a Open ID Foundation (OIDF) possui capacidade de processamento de cerca de 30 certificados por semana e será feito em ordem de chegada. Incentivamos que façam a submissão o quanto antes.    2. Certificações funcionais: o SLA para pedidos de certificação funcional é de 3 dias  3. Certificação de Segurança Relying Parties (RP) da Fase 3 (escopo *signed*) é válida para a Fase 2 (escopo *unsigned*), mas o contrário não é válido.     **Detalhamento**:     |  |  |  |  |  |  | | --- | --- | --- | --- | --- | --- | | **Fase 2** | | | | | | | **Tipo de certificação** | **Público-alvo** | **Fornecedor** | **Data limite para certificação** | **Nome do teste** | **Versão mínima da certificação** | | Recertificação Funcional | Transmissoras de Dados | Raidiam | 30/nov | - | 4.1.39 build: 403469206 | | Segurança módulos DCR/DCM | Transmissoras de Dados (OP) | OIDF | 30/nov | FAPI1-Advanced-Final: Brazil Dynamic Client Registration Authorization server test | 4.1.37 | | Segurança Relying Parties -Unsigned | Receptoras de Dados (RP) | OIDF | 30/nov | FAPI1-Advanced-Final: Open Banking Brazil Relying Party (Client) Test Plan | 4.1.37 | |  |  |  |  |  |  | | **Fase 3** | | | | | | | **Tipo de certificação** | **Público-alvo** | **Fornecedor** | **Data limite para certificação** | **Nome do teste** | **Versão mínima da certificação** | | Funcional | Detentoras de Conta | Raidiam | Pré-condição para publicação da API Payments | [-](https://github.com/OpenBanking-Brasil/conformance/tree/main/documents/TnC) | 4.1.39 build: 403469206 | | Segurança módulos FAPI (mTLS, Private Key, PAR) | Detentoras de Conta (OP) | OIDF | FAPI1-Advanced-Final: Authorization server test | 4.1.37 - Para novas certificações  (Versões anteriores são válidas para quem já possui o certificado) | | Segurança módulos DCR/DCM | Detentoras de Conta (OP) | OIDF | FAPI1-Advanced-Final: Brazil Dynamic Client Registration Authorization server test | 4.1.37 | | Segurança Relying Parties – Signed | Iniciadoras de Pagamento (RP) | OIDF | Pré-condição para atuação como Iniciadora de Transação de Pagamento | FAPI1-Advanced-Final: Open Banking Brazil Relying Party (Client) Test Plan | 4.1.37 |     **Material complementar**:     1.  Validações de publicações no diretório Para garantir a interoperabilidade entre as instituições e o correto funcionamento do ecossistema, serão feitas validações das publicações das instituições no Diretório. A princípio, serão verificados se:   - Os endpoints estão no formato adequado - Todos os endpoints necessários foram disponibilizados - Os métodos de autenticação informados no well-known estão condizentes com as certificações de segurança   Para os casos em que forem necessárias correções, será enviada uma comunicação para o N2 da instituição pelo Service Desk.
