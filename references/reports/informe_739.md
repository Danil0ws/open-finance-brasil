# [Open Finance] Informa #739

Aviso de indisponibilidade parcial do Diretório de participantes    Informamos que o Diretório de participantes, tanto em ambiente Sandbox quanto em produção, passará por uma manutenção programada para atualização de sua base de dados. A janela de manutenção terá duração de 1 hora, durante a qual haverá indisponibilidade parcial dos serviços oferecidos pelo Diretório.     **Itens indisponíveis durante o período:**   - Interface do usuário (UI) do Diretório; - APIs privadas protegidas por mTLS; - PKI (Sandbox).  **Itens que não serão afetados:**  - APIs públicas (exemplo: GET /*participants*); - *Keystores;* - Serviços de validação via OCSPs.  **Atenção:**  - Durante a manutenção, não será possível realizar atualizações de dados cadastrais no Diretório e nem gerar *Software Statements Agreements* (SSA), seja via interface ou APIs, impossibilitando o DCR/DCM no período; - Participantes que utilizam APIs privadas do Diretório para obtenção de dados cadastrais, como listas de participantes ou *endpoints* de produtos, ficarão impossibilitados de realizar essas operações; - Participantes que utilizam as APIs públicas para o mesmo fim, através do *endpoint* GET /*participants*, **não** serão impactados. Reforçamos que essa é a abordagem recomendada.  **Período de realização da manutenção:**  - **Sandbox:** 21/05 (quarta-feira), das 6h às 7h; - **Produção:** 22/05 (quinta-feira), das 6h às 7h. |
