# [Open Finance] Informa #703

Disponibilização da versão rc.1 do motor de conformidade para API Pagamentos automáticos  Conforme comunicado no Informa #661 (“Novo cronograma de implementação da v2.0.0 da API Pagamentos automáticos (Transferências inteligentes + Pix automático)”, divulgado em 14/11/2024), **a versão rc.1 do motor de conformidade para API Pagamentos automáticos foi disponibilizada em 18/02/2025.**   Houve alteração relevante em 8 módulos de teste, em que 6 serão obrigatórios para todas as instituições e 2 serão obrigatórios para instituições ofertantes de múltipla alçada.
