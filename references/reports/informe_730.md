# [Open Finance] Informa #730

Obrigatoriedade de implementação do produto Portabilidade de crédito para instituições transmissoras de dados  A implementação de portabilidade de crédito será obrigatória para todas as instituições transmissoras de dados que possuam a API Empréstimos publicada e ofertem os produtos Crédito Pessoal *Clean* (CPC) e/ou Consignado Federal.     Os novos entrantes com participação obrigatória na fase de compartilhamento de dados, conforme comunicado no Informa #728 (“*Workshop para novos entrantes na Fase de Compartilhamento de Dados*”, divulgado em 22/04/2025), serão dispensados dos marcos intermediários de implementação, sendo necessária apenas a submissão de certificação e publicação das APIs, conforme o cronograma divulgado no Informa #716 (“*Divulgação do cronograma de certificação e homologação do produto Portabilidade de Crédito Pessoal Clean (CPC)*”, divulgado em 28/03/2025).     Obs.: A disponibilização futura dos produtos CPC e Consignado Federal tornará a implementação obrigatória à instituição que passar a ofertá-los após o lançamento do serviço de Portabilidade. Adicionalmente, com a inclusão de novos produtos no domínio de Portabilidade de crédito, novas instituições poderão ter a implementação obrigatória.     Para garantir o controle, as instituições transmissoras que possuem a API Empréstimos publicada e os novos entrantes que pretendem publicá-la deverão preencher o formulário no link abaixo até 08/05/2025. |
