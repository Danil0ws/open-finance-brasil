# [Open Finance] Informa #460

[Urgente] Levantamento de jornada do usuário para v3.0.0 da API de Iniciação de Pagamentos              A Estrutura do Open Finance está fazendo um **levantamento sobre a jornada que as instituições detentoras de conta estão implementando para o go live da v3.0.0 da API de Iniciação de Pagamentos**, previsto para 13/10/2023, para mapear possíveis sinergias e oportunidades nas jornadas com a alteração das validações para o momento do consentimento.    **Pedimos que todas as detentoras de conta em produção respondam o formulário até 26/09/2023, às 13h45.** |
