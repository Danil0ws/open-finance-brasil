# [Open Finance] Informa #386

Lançamento da versão estável (v1.0.0) das APIs de Capitalização, Previdência e Seguros (Dados Abertos)              Informamos que a Área do Desenvolvedor do Portal do Open Finance Brasil foi atualizada no dia 24/05/2023 com a documentação da **nova versão estável v1.0.0 das APIs de Capitalização, Previdência e Seguros**.  Reforçamos que os testes do **terceiro** (30/05/2023) e do **quarto** (14/06/2023) **marcos de certificação deverão ser realizados para todos os *endpoints* de acordo com esta versão**, conforme comunicado no Informa #378 (“Ajuste no processo de certificação – APIs de Capitalização, Previdência e Seguros - fase 4A”).  Conforme definido pelo Banco Central, a data regulatória para *go-live* destas APIs é 16/06/2023.     Para mais detalhes, sugerimos o acesso aos links de documentação abaixo. |

 Ajuste no “De-Para” das APIs de Capitalização e Previdência              As tabelas que relacionam os campos das APIs de Capitalização e Previdência do Open Finance Brasil e das APIs correspondentes no Open Insurance (“De-Para”) tiveram 3 alterações, já disponíveis na área do desenvolvedor.  Reforçamos que as instituições participantes devem observar as alterações aqui divulgadas quando do desenvolvimento e/ou ajuste de suas APIs. |

 Ajuste da descrição do campo "indemnifiablePeriods" na API de Previdência              A descrição do campo "indemnifiablePeriods" foi ajustada no Swagger da API de Previdência para eliminar a ambiguidade em relação à possibilidade de preenchimento de "NA" neste campo, conforme aprovado recentemente pela convenção do Open Finance Brasil. A nova descrição do campo é:  “*Listagem do pagamento para cada benefício:*  *1. Quantidade determinada de parcelas;*  *2. Até o fim de ciclo determinado;*  *3. NA*  *Observação: Se for pagamento único, este campo não deve ser informado;*”     Para maiores detalhes sobre o preenchimento de campos nulos, consultar o Informa #378 de 15/05/2023. |
