# [Open Finance] Informa #491

Pausa no cronograma da funcionalidade de Pix automático Comunicamos que a funcionalidade de Pix automático, presente na v1 da API de Pagamentos automáticos, poderá apresentar alterações devido à avaliação do Banco Central sobre as sugestões enviadas durante a consulta pública do Pix automático.   - Essas alterações serão futuramente informadas pelo Banco Central ao GT Serviços e, posteriormente, este irá notificar o ecossistema sobre as alterações e se ajustes no cronograma serão necessários.   Dado o cenário acima, **informamos que a certificação da funcionalidade Pix automático será pausada.**     Reforçamos que o **cronograma das funcionalidades *Sweeping accounts* e agendamentos recorrentes permanece** conforme comunicado no Informa #480 (‘’Atualização dos cronogramas de Fase 2 e 4B, Fase 3 e Perfil FAPI único”, enviado em 01/11/2023). |

 Revisão do marco A – API de Pagamentos automáticos Em decorrência das alterações no cronograma da funcionalidade de Pix automático, informamos que os módulos de teste do marco A da API de Pagamentos automáticos v1, inicialmente divulgados no Informa #485 (“Marco A – API de Pagamentos automáticos”, enviado em 01/11/2023), foram revistos para incluir somente cenários da funcionalidade de *Sweeping Accounts*.     Dessa forma, para garantir o desenvolvimento de *Sweeping Accounts* na API de Pagamentos automáticos ainda em 2023 **as instituições detentoras de conta deverão executar com sucesso ao menos 1 dos seguintes módulos abaixo até 15/12/2023:**   - automatic-payments\_api\_negative-consents\_test-module; - automatic-payments\_api\_swepping-accounts-consents-core\_test-module; - automatic-payments\_api\_swepping-accounts-invalid-creditor\_test-module; - automatic-payments\_api\_rejected-consent\_test-module.   Sugerimos a execução do módulo “automatic-payments\_api\_negative-consents-core\_test-module”, que não depende da jornada de experiência do usuário, visto que o Guia de experiência do usuário será disponibilizado posteriormente.     Reforçamos que o marco A da API de Pagamentos v4 ocorrerá nessa mesma data sem alterações, conforme orientado no Informa #480 “Marco A – API de Pagamentos v4”.     Para dúvidas em relação aos testes e certificações, recomendamos a abertura de chamados no Gitlab ou Service Desk. |

 Lançamento da nova versão beta (v1.0.0-beta.1) da API Canais de atendimento e das versões beta (1.0.0-beta.2) das APIs Adiantamento a depositantes, Adiantamento de recebíveis, Cartão de crédito, Contas, Empréstimos e Financiamentos Informamos que a Área do Desenvolvedor do Portal Open Finance Brasil foi atualizada no dia 24/11/2023 com a documentação da nova **versão 1.0.0-beta.1 da API Canais de atendimento**, e da **versão 1.0.0-beta.2 das APIs** **Adiantamento a depositantes, Adiantamento de recebíveis, Cartão de crédito, Contas, Empréstimos e Financiamentos**, de Dados abertos.  É imprescindível que as instituições comecem a desenvolver estas APIs a partir do lançamento desta versão (beta) para não prejudicar o período de certificação e *go live*, conforme cronograma divulgado por meio do Informa #427 (“Cronograma atualizado de Dados Abertos - APIs Produtos e Serviços, Canais de Atendimento, Comuns e Admins ”, publicado em 28/07/2023).  Durante o desenvolvimento dentro das instituições, **poderão ser reportadas à Estrutura melhorias e necessidades de correções destas APIs**. A partir de 27/11/2023 será disponibilizado um período de consulta ao ecossistema, que se encerra em 08/12/2023. Sugestões encaminhadas após o período de consulta não serão consideradas para este versionamento.   - As sugestões devem ser encaminhadas por meio da abertura de ticket no Service Desk, seguindo a opção: Solicitações de Melhorias > APIs; - Na abertura do ticket, o título deve ser registrado como “APIs fase 1 – versão beta” e, no campo descrição, deve ser citado qual é a API (Ex: API Contas), o endpoint (Ex: /personal-accounts), o campo e a sugestão de ajuste na documentação; - Para que o ticket possa ser considerado para a versão 1.0.0 (versão estável) das APIs Contas, Cartão de crédito, Empréstimos, Financiamentos, Adiantamento a depositantes,  Adiantamento de recebíveis e Canais de Atendimento, ele deve ser encaminhado até o prazo máximo estabelecido acima. Do contrário, o ticket será adicionado ao *backlog* de ajustes do GT Especificações Dados abertos para uma próxima versão destas APIs.
