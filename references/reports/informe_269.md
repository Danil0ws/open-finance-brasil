# [Open Finance] Informa #269

Atenção: Execução obrigatória de testes da API de Payments v1.2.0 (para detentoras de conta) Divulgado no Informa #245 [Execução obrigatória de testes da API de Payments v1.2.0 (para detentoras de conta), enviado em 30 de setembro de 2022], o plano de testes da API Payments v1.2.0 foi considerado maduro. Portanto:   - Instituições que já executaram o plano completo com sucesso a partir de 14 de setembro de 2022 não precisarão reexecutá-lo; - Instituições que ainda não obtiveram sucesso no plano de testes completo devem fazê-lo **até dia 10 de novembro de 2022;** - Instituições certificadas apenas no 1º ciclo (Pix manual, chave e recebedor) devem obter a certificação do 3º ciclo (Pix QR code estático e QR code dinâmico) **até o dia 19 de novembro de 2022.**   Não é necessária a recertificação para quem já possui a certificação funcional de pagamentos 3º ciclo (Pix QR code estático e QR code dinâmico), apenas a execução com sucesso do plano completo de testes da API Payments v1.2.0. |
