# [Open Finance] Informa #286

Importante: data regulatória para sucesso nos testes beta do motor de conformidade   Reforçamos que a IN 326 definiu datas regulatórias para que as detentoras de conta obtenham determinadas taxas de sucesso nos testes do motor de conformidade funcional da fase 3 v2.0.0, conforme cronograma abaixo. **Ressaltamos que todas as instituições devem testar com sucesso 30% dos testes beta até 20/12/2022.**     **Cronograma de execução de testes, conforme Instrução Normativa 326:**   - **30/10/2022 - 02/12/2022:** Desenvolvimento do motor de testes (funcionais) para as versões 2.0.0 das APIs - **03/12/2022 - 13/01/2023:** Período de testes do motor e correção de *bugs*   - **20/12/2022**: Data limite para execução com sucesso em 30% dos módulos   - **05/01/2023:** Data limite para execução com sucesso em 50% dos módulos   - **13/01/2023:** Data limite para execução com sucesso em 90% dos módulos, incluindo todos os módulos críticos - **13/01/2023 - 01/02/2023**: Período de envio de pedidos certificação funcional V2.0.0   - Não há garantias de que pedidos de certificação enviados após 01/02/2023 serão processados antes do *go live* - **02/02/2023 - 15/02/2023**: Período de processamento de certificação funcional V2.0.0 - **15/02/2023: *Go live*** – data limite para publicação dos *endpoints* da nova versão da API no Diretório de Participantes        Problemas ou inconsistências identificadas devem ser notificadas através do repositório no GitLab no link abaixo. Tickets abertos através da plataforma do Service Desk continuarão sendo tratados, porém a expectativa é realizar uma transição gradual para o GitLab com intuito de reduzir a abertura de problemas duplicados e aumentar a celeridade da sua resolução. |
