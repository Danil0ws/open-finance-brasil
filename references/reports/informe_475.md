# [Open Finance] Informa #475

Lançamento da v1.0.0-beta.1 da API de Pagamentos automáticos **Especificações**   Comunicamos que, em 20/10/2023, foi publicada a versão 1.0.0-beta.1 das especificações da API de Pagamentos automáticos, as quais estão disponíveis na área do desenvolvedor em:   - Especificações de APIs > Serviços > Iniciação de Pagamentos > API – Pagamentos automáticos > v1.0.0-beta.1 – Pagamentos automáticos    Essa API é de implementação obrigatória para as detentoras de conta e opcional para as iniciadoras de pagamento e sua implementação permitirá o desenvolvimento de novos produtos como Pix automático, *Sweeping accounts*, e, futuramente, VRP.  - A v1 da API de Pagamentos automáticos não substitui a v4 da API de Pagamentos (ou demais versões da API de Pagamentos); - As instituições deverão possuir as duas implementações (API de Pagamentos e API de Pagamentos automáticos).    Informamos também que para essa nova API foram adicionados *scopes* específicos  (“recurringConsent:recurringConsentId” e “recurringPayments”), dessa maneira, é necessária a realização de DCR/DCM entre as instituições. Sendo assim, sugerimos que as instituições iniciem de imediato a adequação de suas estruturas e iniciem o processo de DCR/DCM contendo os novos *scopes* assim que possível.       **Abertura de tickets**   Adicionalmente, informamos que será disponibilizado um período de consulta ao ecossistema, iniciando em 23/10/2023 e encerrando em 10/01/2024. Sugestões encaminhadas após o período de consulta não serão consideradas para a versão 1.0.0 da API de Pagamentos automáticos.  - As sugestões deverão ser encaminhadas por meio da abertura de tickets no Service Desk, seguindo a opção: Solicitações de Melhorias > APIs; - Na abertura do ticket, o título deverá ser registrado como “API Pagamentos automáticos – v1.0.0” e no campo descrição deverá ser citado qual é o *endpoint*, campo e sugestão do ajuste na documentação; - Para que o ticket possa ser avaliado para a versão 1.0.0 (versão estável) da API de Pagamentos automáticos, ele deverá ser encaminhado dentro do prazo estabelecido acima, caso contrário, o ticket será adicionado ao backlog de ajustes do GT Especificações Serviços para uma próxima versão.   **Informações sobre testes e Guia de UX**   Por último, recomendamos que as instituições iniciem o desenvolvimento assim que possível e informamos que o Guia de Experiência do Usuário utilizado para a v1.0.0 de Pagamentos automáticos e o cronograma de certificação serão divulgados em momento posterior. |
