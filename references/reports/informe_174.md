# [Open Finance] Informa #174

Declaração de versão de APIs publicadas no Diretório   Foi realizada uma atualização no Diretório e agora o campo de versão das APIs publicadas no Diretório deverá ser preenchido utilizando versionamento semântico (major.minor.patch) XX.XX.XX, ao invés de só a major, conforme era feito anteriormente. Esse campo está disponível em: Authorisation Server > API resources > Coluna "version".     **As instituições que estão validando esse campo devem se adaptar o mais breve possível.**     Pedimos que as instituições atualizem o campo das APIs já publicadas e novas publicações deverão ser realizadas no formato atualizado. |

 Adequação de certificados emitidos pela cadeia SERASA SSL EV V2   Informamos aos participantes do Open Finance que os certificados emitidos com a cadeia intermediária SERASA SSL EV V2 possuem configuração de propósito incorreta, diferente da configuração anterior (SERASA SSL EV V1), conforme abaixo:  SERASA SSL EV V2  - SSL client : No - SSL client CA : No - SSL server : Yes - SSL server CA : Yes  SERASA SSL EV V1  - SSL client : Yes - SSL client CA : Yes - SSL server : Yes - SSL server CA : Yes  Portanto, solicitamos que as instituições que estiverem enfrentando erros na validação destes certificados emitidos com cadeia V2, que solicitem a reemissão de seus certificados pela antiga cadeia V1, até emissão da cadeia V3.    Até que a cadeia V3 seja emitida, novos certificados Serasa também deverão ser emitidos pela cadeia SERASA SSL EV V1.    Caso participantes do Open Finance verifiquem erros na validação de certificados emitidos por outras Autoridades Certificadoras, solicitamos que comuniquem à Estrutura Central através do Service Desk. |
