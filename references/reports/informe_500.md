# [Open Finance] Informa #500

Alteração relevante no motor funcional da API de Pagamentos – v4.0.0  Informamos que o motor funcional da API de Pagamentos – v4.0.0 terá uma alteração relevante em decorrência de ajustes nos testes “payments\_api\_recurring-payments-consent-limit\_test-module\_v4” e “payments\_api\_recurring-payments-wrong-custom-quantity\_test-module\_v4”.     Esses ajustes devem ocorrer até 13/12/2023, e após essa data será necessário criar um novo plano de testes para reexecução destes módulos. A correção pode ser acompanhada através do item *breaking change* do *release notes*, e o detalhamento dos ajustes será informado através dos *issues* 1086 e 1094.     Conforme Informa #480 (“Marco A – API de Pagamento v4”, enviado em 01/11/2024), para o marco A que ocorrerá em 15/12/2023, será necessária a execução com sucesso de dois módulos de teste desta API. |
