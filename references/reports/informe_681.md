# [Open Finance] Informa #681

Lançamento da versão *patch* da API Renda variável (Dados do cliente)  Informamos que a área do desenvolvedor do Portal do Open Finance Brasil foi atualizada, em 07/01/2025, com a documentação da versão *patch* da API Renda variável (v1.2.1).   - O cabeçalho do *Swagger* da API Renda variável foi alterado para contemplar informações sobre os produtos FIAGRO e FII.   Comunicamos, adicionalmente, que a data de entrada em produção da nova versão será compartilhada em um Informa posterior.
