# [Open Finance] Informa #619

LEMBRETE – *Go live* das APIs Dados Cadastrais e Contas         De acordo com o Informa #582 (“Divulgação do cronograma de dados do empregador e resolução de problemas conhecidos das APIs de Dados Cadastrais e Contas”, enviado em 22/05/2024), comunicamos que o *go live* das APIs Dados Cadastrais v2.1.0 e Contas v2.4.0 ocorrerá ao decorrer do dia 15/08/2024, entre 00:00 e 23:59.    Ressaltamos que, para instituições que recebem portabilidade de salário, o envio do objeto /data/portabilitiesReceived da API Dados Cadastrais será facultativo até 25/10/2024 e que, a partir desta data, será exigido o envio dos dados disponíveis de todos os clientes para essas instituições.    Lembramos que, conforme comunicado no Informa #611 (“Inativação de recursos no Diretório de participantes”, enviado em 30/07/2024), o Diretório foi atualizado e, para publicação de uma nova versão, as instituições deverão inativar a versão anterior conforme imagem abaixo: |

 Obrigatoriedade do teste de portabilidade de salário - Dados do empregador        No Informa #589 (“LEMBRETE – Execução com sucesso dos testes de dados do empregador”, enviado em 05/06/24) foi informado que o módulo de teste "customer-personal\_api\_portability\_test-module\_v2" da API Dados Cadastrais deve ser executado com sucesso para instituições detentoras que também são transmissoras de dados.    Gostaríamos de esclarecer que a execução deste módulo não é obrigatória para instituições que não recebem portabilidade de salário. Instituições que se enquadrem neste cenário devem informar à Estrutura através do ticket de notificação recebido no Service Desk, preferencialmente, antes do*go live* de dados do empregador em 15/08/2024. |
