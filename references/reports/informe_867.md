# [Open Finance] Informa #867

Disponibilização dos motores para as APIs Contas v2.5.0-beta.2 e Cartão de Crédito v2.4.0-beta.2 |

 Conforme compartilhado no Informa #846 *(“Atualização do cronograma para as APIs de Contas e Cartão de Crédito”),*divulgado em 05/02/2026*,*os motores de conformidade para as APIs Contas v2.5.0-beta.2 e Cartão de Crédito v2.4.0-beta.2 foram disponibilizados em **27/03/2026**e serão utilizados para o **marco de 50%**em **14/04/2026**.     Para o marco de 50%, as instituições devem obter sucesso em metade dos módulos de testes dos respectivos planos, **incluindo os novos módulos destacados abaixo:**      **API Contas v2.5.0-beta.2**   - Functional Tests for Accounts API - Based on Swagger version: 2.5.0-beta.2  *Para este plano de testes, destacamos que****novos módulos****foram criados:*  - accounts\_api\_current-transactions\_test-module\_v2-5 - accounts\_api\_reserved\_balances\_test-module\_v2-5 - accounts\_api\_reserved\_balances\_permissions\_v2-5 - accounts\_api\_reserved\_balances\_operations\_limits\_v2-5  **API Cartão de Crédito v2.4.0-beta.2**  - Functional Tests for Credit Card API - Based on Swagger version: 2.4.0-beta.2   *Para este plano de testes, destacamos que um****novo módulo****foi criado:*   - credit-cards\_api\_instalment\_test-module\_v2-4   As instituições que não atingirem sucesso no marco serão notificadas via tickets do Service Desk.       Mais detalhes sobre os testes podem ser consultados na página de plano de testes. |
