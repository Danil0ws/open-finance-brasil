# [Open Finance] Informa #203

Datas de entregas das APIs da Fase 2 v2.0.1 – Ofício do Banco Central aos participantes da Fase 2 Segue abaixo as datas para a implantação da Fase 2 v2.0.1. Importante ressaltar que tais datas seguem cronograma definido pelo Banco Central.   - Data limite para **início de execução de todos os cenários de testes** no motor de conformidade: **24/08/2022**   - O motor beta está disponível desde 03/08/2022 e pedimos que as instituições iniciem os testes assim que possível, conforme Informa #199 (“Liberação do motor funcional versão beta da Fase 2 v2”)   - Até a data limite, é esperado que sejam **testados** **todos os módulos** dos planos de teste referentes a **todas as APIs** que serão implementadas pela instituição   - Os testes de limites operacionais devem ser executados por todas as instituições, mesmo para aquelas que não implementarão a funcionalidade de controle de limites operacionais   - Para essa data, é aceitável que não se obtenha sucesso na execução de alguns módulos - Data limite para **pedido de certificação funcional**: **10/10/2022**   - A data para início do pedido de certificação será divulgada por meio de Informa ao ecossistema   - O início da certificação depende da maturidade dos planos de testes e, portanto, é possível que as certificações de cada API sejam liberadas em datas distintas - Data final para certificação e **publicação das APIs no diretório**: **31/10/2022** - Data limite para **adaptação pelos receptores**: **23/02/2023**. |
