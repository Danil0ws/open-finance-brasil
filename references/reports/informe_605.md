# [Open Finance] Informa #605

Lançamento das versões *release candidates* das APIs Contas (v2.4.0-rc.1) e Dados cadastrais (v2.1.0-rc.1) Informamos que a área do desenvolvedor do Portal do Open Finance Brasil foi atualizada, em 10/07/2024, com a documentação das versões *release candidates* das APIs Contas (v2.4.0-rc.1) e Dados cadastrais (v2.1.0-rc.1).   - As documentações das APIs passaram pelas seguintes alterações:   - API Dados cadastrais:     - Ajuste no atributo minItens dos campos *portabilitiesReceived* e *paychecksBankLink*.   - API Contas:     - Ajuste na descrição do campo *partiePersonType* dos *endpoints  /transactions* e */transactions-current*.   O *go live* para essas APIs se mantém em 15/08/2024, conforme informe #582 (“Divulgação do cronograma de dados do empregador e resolução de problemas conhecidos das APIs Dados Cadastrais e Contas”, enviado em 22/05/2024).
