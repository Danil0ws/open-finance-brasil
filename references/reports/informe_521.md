# [Open Finance] Informa #521

Lançamento das versões *release candidate* das APIs Consentimento e Recursos  Informamos que a área do desenvolvedor do Portal do Open Finance Brasil foi atualizada, em 31/01/2024, com as **versões *release candidate* das APIs Consentimento (v3.0.0-rc.1) e Recursos (v3.0.0-rc.1).**     Reforçamos também que, em 30/01/2024, encerrou-se o período de consulta ao ecossistema sobre sugestões de melhorias através do Service Desk para as versões das APIs em questão. Sendo assim, alterações nas especificações atuais serão limitadas a correções de erros.     A entrada em produção (*go live*) dessas APIs será realizada em 15/04/2024, conforme Informa #480 (“Atualização dos cronogramas de Fase 2 e 4B, Fase 3 e Perfil FAPI Único”, enviado em 01/11/2023).     Adicionalmente, comunicamos que a página de *changelog* para essas APIs foi reformulada. O novo modelo de *changelog* permitirá que os desenvolvedores comparem a atual versão publicada com:   - A última versão publicada. Nesse caso, com a versão beta (v3.0.0-beta.3) para ambas APIs; - A última versão *current*. Nesse caso, a v2.2.0 para a API Consentimento e v2.1.0 para a API Recursos. |
