# [Open Finance] Informa #689

Participação como transmissoras na etapa de compartilhamento de dados (Dados do cliente) Reforçamos as alterações nas regras de participação como transmissora na etapa de compartilhamento de dados (Dados do cliente) do Open Finance trazidas pela Resolução Conjunta nº10, publicada em 10/07/2024:   - As instituições individuais e as instituições pertencentes a conglomerados com número de clientes superior a cinco milhões se tornaram participantes obrigatórias a partir de 01/01/2025, com prazo até 30/06/2025 para publicação e disponibilização das APIs; - Caso algum CNPJ tenha participação voluntária no compartilhamento de dados, todos os CNPJs do Conglomerado ou do Sistema Cooperativo devem participar do *Open Finance* a partir de 01/07/2025.   Os detalhes técnicos sobre as APIs e testes para certificação estão disponíveis no Portal do Desenvolvedor. |

 Alteração nos valores de limite operacional da API Cartão de crédito (Dados do cliente) Informamos que, em 23/01/2025, os valores de limite operacional do *endpoint* GET /accounts/{creditCardAccountId} da API Cartão de Crédito foram atualizados na página “Referência” da área do desenvolvedor no Portal do Open Finance Brasil.  Comunicamos, adicionalmente, que a data limite para adequação das instituições aos novos valores de limite operacional será até 01/02/2025.
