# [Open Finance] Informa #837

LEMBRETE – Marco 100% das APIs de Recursos e Operações de Crédito (exceto API Empréstimos) |

 Reforçamos que, conforme compartilhado no Informa #789 (*Divulgação dos cronogramas de versionamento minor para as APIs de Dados do cliente*), enviado em 25/09/2025, e, Informa #832 *(Disponibilização dos motores das APIs de Recursos e Operações de Crédito (exceto API Empréstimos),*divulgado em 12/01/2026, o marco de 100% para essas APIs ocorrerá em **26/01/2026**.  Para o marco de 100%, as instituições devem obter sucesso nos seguintes módulos de testes:  **API Recursos v3.1.0**   - *resources\_api\_core\_test-module\_v3-1;*   **API Financiamento v2.4.0**   - *financings\_api\_core\_test-module\_v2-4;* - *financings\_api\_wrong-permissions\_test-module\_v2-4;*   **API Adiantamento a Depositantes v2.5.0**   - *unarranged-accounts-overdraft\_api\_core\_test-module\_V2-5;* - *unarranged-accounts-overdraft\_api\_wrong-permissions\_test-module\_V2-5;*   **API Direitos Creditórios Descontados v2.4.0**   - *invoice-financings\_api\_core\_test-module\_v2-4;* - *invoice-financings\_api\_wrong-permissions\_test-module\_v2-4;*   As instituições que não atingirem sucesso no marco serão notificadas via ticket do Service Desk.  Ressaltamos que a data para publicação no diretório e ***Go live*** dessas APIs será em **29/01/2026**.  Mais detalhes sobre os testes podem ser consultados na página de plano de testes. |

 Atualização do diagrama da Máquina de Estados na página de Orientações da API Consentimento |

 Informamos que foi atualizado o diagrama da **Máquina de Estados** na página de **Orientações – [DC] Consentimento**, e os textos foram ajustados conforme abaixo:  ***Seção:***  *- Regras para a renovação simplificada do consentimento*  ***Remoção da linha:***  *- Para situações nas quais a renovação não seja para prazo indeterminado, o cliente pode alterar a validade do consentimento em até no máximo 12 meses da data de requisição da renovação.*  ***Seção:**  - Casos de erro para a renovação simplificada do consentimento*  ***Remoção da linha:***  *- Diferente de prazo indeterminado e maior que 12 meses da data de requisição (current Date Time).*  Esta atualização refere-se à alteração implementada na **patch da versão 3.3.1 da API de Consentimento**, cuja especificação foi lançada em **15/12/2025**, conforme divulgado no **Informa #824** (*Lançamento da versão v3.3.1 (patch) da API de Consentimento*).  A data de ***Go Live*** está definida para **19/01/2026**, conforme comunicado no **Informa #826** (*Alteração na data de Go Live da versão 3.3.1 (patch) da API de Consentimento*).
