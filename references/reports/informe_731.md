 Release 2025A1 – Extraordinária – Término do Período de Implementação da PCM Informamos o término do período de implementação da *Release* Extraordinária da PCM. Funcionalidades implementadas:   1. Nova API de Dados Relativos à Quantidade de Consentimentos Ativos e Únicos por clientes, conforme cronograma divulgado no informa #723 de 09/04/2025. A documentação funcional pode ser acessada através do endereço no link abaixo. 2. Chamada da Private API (GET) via *FapiInteractionId*: a API passa a aceitar como parâmetro a informação *FapiInteractionID*, permitindo uma maior eficiência e aumento de performance do recurso. A chamada via *ReportId* continuará válida até o término do ciclo de implementação das instituições, conforme cronograma da release extraordinária. |
