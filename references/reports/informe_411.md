# [Open Finance] Informa #411

Atualização dos testes da API de Iniciação de Pagamentos  O plano de testes da API de Iniciação de Pagamentos foi atualizado para incluir a validação de que as instituições estão:  - Aceitando as requisições quando há o envio do X-FAPI - Enviando o código de erro adequado quando não é enviado o X-FAPI na requisição  Dessa forma, o contador dos testes do cronograma de execução obrigatória dos testes após atualização da política de autorização será reiniciado a partir de 26/06/2023.     O cronograma para execução dos testes, conforme Informa #401 (“Liberação do plano de testes da API de iniciação de pagamentos – políticas de autorização”, enviado em 14/06/2023), é:  - **Até 03/07/2023**: Execução obrigatória do plano completo da API de Iniciação de Pagamentos - **04/07/2023 a 17/07/2023**: Execução com sucesso obrigatório do plano completo - **Até 18/07/2023**: Atualização das iniciadoras e implementação em produção - **18/07/2023 a 24/07/2023**: Implementação das detentoras em produção  Será necessário que as instituições criem um novo plano de testes para garantir que estão executando a última versão do motor.     Problemas ou inconsistências identificadas devem ser notificadas através do repositório no GitLab no link abaixo, mas tickets abertos através da plataforma do Service Desk continuarão sendo tratados. |

 Indisponibilidade da FVP 2.0 A FVP 2.0 está indisponível desde sexta-feira (23/06/2023) e as instituições não conseguirão executar os testes até o reestabelecimento, que deve ocorrer até o fim da semana.     A ferramenta está sendo atualizada para utilizar certificado de transporte da cadeia G4, para validar se as instituições já estão com a infraestrutura ajustada conforme informas #374 e #410.     Um novo comunicado será enviado assim que a FVP 2.0 estiver disponível novamente. |
