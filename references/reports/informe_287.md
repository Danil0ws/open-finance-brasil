# [Open Finance] Informa #287

Instruções para Plataforma de Resolução de Disputas   A Plataforma de Resolução de Disputas, desenvolvida pela estrutura, é o meio obrigatório e único de resolução de disputas entre Participantes do Open Finance, onde é possível abrir, responder e gerenciar as disputas vigentes e encerradas.    Os cenários para abertura de uma disputa variam de acordo com o tipo de relação entre cada instituição, assim como as categorias. A plataforma possui uma categorização de acordo com [regulamento](https://ob-public-files.s3.amazonaws.com/Regulamento_de_Resolucao_de_Disputas.pdf), na qual há flexibilidade para indicação de uma nova categoria conforme a necessidade.  Como um esforço de melhoria, hoje (15/12/2022) foi publicada no Portal Open Finance Brasil uma nova página dedicada a vídeos informativos sobre a Plataforma de Resolução de Disputas.
