# [Open Finance] Informa #580

Recertificação simplificada de múltiplas alçadas para API de Pagamentos v4.0.0 Informamos que, as instituições que ofertam múltiplas alçadas deverão executar com sucesso os testes dessa funcionalidade para a API de Pagamento v4.0.0 até 07/06/2024. Essa execução tem como objetivo certificar que as instituições implementaram corretamente o novo comportamento incluído na versão *release candidate* das especificações.    O motor de conformidade foi atualizado em 16/05/2024 e para a contabilização dessas execuções, serão aceitos testes executados em planos criados a partir dessa data, sem a necessidade de submissão de *tickets* no Service Desk. As atualizações do motor foram as seguintes:   - **Novo teste: payments\_api\_multiple-consents-timezone-conditional\_test-module\_v4**   - Em caso de pagamentos agendados, todas as aprovações devem ser realizadas até o dia anterior na data/hora prevista para a primeira liquidação. Caso não seja possível, o consentimento deverá ser rejeitado. - **Testes atualizados com alterações relevantes: payments\_api\_multiple-consents-conditional\_test-module\_v4 e payments\_api\_multiple-consents-no-funds-conditional\_test-module\_v4**   - Para o caso de pagamento imediato, todas as aprovações devem ser realizadas até às 23h59 da data de solicitação do pagamento;   - Para o caso de pagamentos agendados, o prazo de expiração para consentimentos nesse status não deve ser maior que D-1, sendo D o dia previsto para liquidação. |

 Nova rotina de execução da FVP 1.0 Informamos que, a partir de 24/05/2024 passará a ocorrer diariamente a execução da FVP 1.0 com abertura, atualização de evidências e encerramento de *tickets*. Dessa forma, a dinâmica atual será mantida e o tempo de resposta dos *tickets* continuará com SLA de 5 dias úteis.    Além disso, recomendamos que as instituições implementem uma rotina diária de exclusão de *clients* da FVP para evitar erros pendentes na ferramenta. |
