# [Open Finance] Informa #574

Lançamento das versões *minor* das APIs Contas (v2.3.0), Cartão de crédito (v2.3.0) e Empréstimos (v2.2.0)             Informamos que a área do desenvolvedor do Portal do Open Finance Brasil foi atualizada, em 03/05/2024, com a documentação das versões *minor* das APIs Contas (v2.3.0), Cartão de crédito (v2.3.0) e Empréstimos (v2.2.0).   - As documentações das APIs passaram por alterações para incorporar as orientações dos problemas conhecidos nas respectivas APIs;   - Tais versionamentos foram necessários para que o Motor de Qualidade de Dados pudesse recuperar a versão mais atualizada do *Swagger*, contemplando problemas conhecidos.  - Os ajustes nas APIs se deram a partir dos seguintes problemas conhecidos:   - API Contas: BCLOG-F02-198, BCLOG-F02-208, BCLOG-F02-209, BCLOG-F02-214, BCLOG-F02-221, BCLOG-F02-228 e BCLOG-F02-229;   - API Cartão de crédito: BCLOG-F02-198, BCLOG-F02-206, BCLOG-F02-207 e BCLOG-F02-228;   - API Empréstimos: BCLOG-F02-198, BCLOG-F02-201, BCLOG-F02-202, BCLOG-F02-203, BCLOG-F02-217, BCLOG-F02-228 e BCLOG-F02-231.  Os testes referentes ao self.link (BCLOG-F02-198) e ao x-fapi-interaction-Id (BCLOG-F02-228) para essas APIs serão atualizados em breve, no entanto, não haverá necessidade de reexecução dos testes e/ou recertificação das APIs.  - Apesar dos testes não serem exigidos nesse momento, o comportamento das instituições deverá estar adequado em produção. Caso contrário, poderão ocorrer problemas bilaterais ou ensejar notificações de desconformidade pelas ferramentas do ecossistema (ex: MQD e FVP); - A data de disponibilização dos testes será informada posteriormente.
