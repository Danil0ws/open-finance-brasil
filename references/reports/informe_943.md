# [Open Finance] Informa #943

Atualização do Perfil de Segurança CIBA |

 Informamos que foi publicada a versão **Beta 2** do perfil de **Segurança CIBA-BR v2.1.0**, acompanhada das versões atualizadas dos guias de implementação para RP e OP.    Esta publicação faz parte do processo esperado de maturação do perfil.    A nova versão altera unicamente a regra de utilização do campo requested\_expiry, permitindo ao Client (Receptor) solicitar o prazo de validade desejado para a requisição de autenticação CIBA, respeitado o limite máximo estabelecido pela regra específica de cada produto. Para os consentimentos de dados cadastrais e transacionais, esse prazo máximo é de 24 horas.    Os documentos atualizados estão disponíveis nos links abaixo: |

 Disponibilização do Motor de Conformidade da CIBA com API Consentimento v3.3.1 |

 Conforme compartilhado no **Informa #938 (Divulgação da Aprovação do Cronograma do Projeto CIBA)**, divulgado em **21/08/2026**, o Motor de Conformidade da **API Consentimento v3.3.1** será disponibilizado em **28/08/2026**.  Essa versão será utilizada para o **marco A1**, com data prevista para **22/09/2026**. Diante disso, é necessário que as instituições executem com sucesso **o módulo de teste previsto para a versão**.  Para esta versão do Motor de Conformidade, será disponibilizado o seguinte módulo de teste:   - **Core do CIBA:** `ciba_consent-approval_ping_happy-path_test-module_v2-1` |
