# [Open Finance] Informa #447

Lançamento da API de Vínculo de Dispositivo para Pagamentos sem Redirecionamento Informamos que foi publicada hoje (04/09/2023) a versão 1.0.0 das especificações da API de Vínculo de Dispositivo para Pagamentos sem Redirecionamento. Essa API deverá ser utilizada pelas instituições voluntárias do piloto da jornada sem redirecionamento.     Sugestões de melhorias ou correções de bugs deverão ser encaminhadas por meio da abertura de tickets no Service Desk utilizando a opção: Solicitações de Melhorias > APIs.    A categorização do chamado deverá seguir a seguinte orientação:   - Nome da API: Serviços - Fase 3 - Vínculo de dispositivo - Versão: Não se aplica - Título: Jornada sem Redirecionamento – Melhorias   Reforçamos também que as instituições que desejarem participar do piloto ainda poderão se voluntariar. Para isso, deverá ser enviado um e-mail ao Secretariado ([secretariado@openfinancebrasil.org.br](mailto:secretariado@openfinancebrasil.org.br)). |
