# [Open Finance] Informa #502

Nova instituição apta a iniciar serviço de iniciação de pagamentos Pix – Belvo A Estrutura do Open Finance Brasil informa que a seguinte instituição cumpriu todas as etapas do processo de onboarding de iniciadoras com sucesso e, portanto, está apta a iniciar o serviço de iniciação de transações de pagamento Pix no contexto do Open Finance Brasil: Belvo.     Com essa atualização, há atualmente 27 instituições que estão aptas a iniciar o serviço de iniciação de transação de pagamento Pix: |

 - Banco Bradesco - Banco BTG Pactual - Banco BV - Banco do Brasil - Banco Mercantil do Brasil - Banco Safra - Banco Santander - Banco XP - Belvo - Celcoin - Crystal BMC - Ebanx IP - Efí - Genial Investimentos |

 - Hub Pagamentos - Iniciador IP - Inter - Itaú Unibanco - Mercado Pago - Nubank - Parati - PicPay - Quanto Network - Sicoob - SICREDI - U4C - Unicred |

 Novas instituições serão incluídas na listagem oportunamente. |

 [LEMBRETE] Marcos A das APIs de Pagamentos automáticos e Pagamentos v4.0.0 - **Pagamentos automáticos v1.0.0**  Conforme Informa #491 (“Revisão do marco A – API de Pagamentos automáticos”, enviado em 24/11/2023) o prazo para execução dos testes de transferências inteligentes da API de Pagamentos automáticos se encerra hoje, 15/12/2023.  Devido a publicação da versão beta-5 em 14/12/2023, **não será necessária a execução com sucesso dos testes para essa API**, **mas até as 23h59 as instituições deverão iniciar a execução do plano automatic-payments\_test-plan.**   - **Pagamentos v4.0.0**   Conforme Informa #500 (“Alteração relevante no motor funcional da API de Pagamentos – v4.0.0”, enviado em 12/12/2023), **para o marco A da API de Pagamentos v4.0.0, que ocorre em 15/12/2023, será necessária a execução com sucesso** de dois módulos de teste. Devido a uma alteração relevante no motor, serão aceitos apenas planos de teste criados a partir de 14/12/2023. |
