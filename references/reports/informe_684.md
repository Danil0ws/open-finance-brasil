 Erros nas especificações das APIs Renda Fixa Bancária, Renda Fixa Crédito e Títulos do Tesouro Direto O Squad Qualidade de Dados comunica que identificou erro nas especificações das APIs Renda Fixa Bancária, Renda Fixa Crédito e Títulos do Tesouro Direto, comprometendo o processo de validação do Motor de Qualidade de Dados (MQD). Dessa forma, os tickets abertos referentes às devidas APIs devem ser encerrados se estiverem apontando erro para o seguinte campo:   - APIs Renda Fixa Bancária, Renda Fixa Crédito e Títulos do Tesouro Direto   - postFixedIndexerPercentage     - Erro na especificação: A expressão regular não permite valores negativos   Caso o ticket aberto se refira a outros campos ou outras APIs, o erro deverá ser corrigido. |

 Atualização da documentação para criação de massa de dados para API Pagamentos automáticos v2.0.0 Compartilhamos que, conforme comunicado no Informe #677 (“*Orientações sobre a realização de testes de criação de massa de dados (API Pagamentos automáticos v2.0.0)*”), enviado em 20/12/2024, para simular os testes de retentativas dos pagamentos intradia e extradia da API Pagamentos automáticos v2.0.0, será necessária uma massa de dados pré-criados. Esses dados devem atender a critérios específicos para ambos os cenários e pode ser gerado pelo plano automatic-pix-auxiliar\_test-plan\_v2 de acordo com as orientações presentes no Gitlab do fornecedor do motor de conformidade.  Informamos que houve uma **atualização da documentação das orientações** **de criação de massa de dados** no Gitlab do fornecedor. |
