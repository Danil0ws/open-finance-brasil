# [Open Finance] Informa #294

Prazo para reemissão de certificados ICP-Br – Links para o certificado da Certisign    Complementando os Informas #291 (“Prazo para reemissão de certificados ICP-Br”, enviado em 23 de dezembro de 2022) e o #293 (“Prazo para reemissão de certificados ICP-Br – Links atualizados para os certificados”, enviado em 28 de dezembro de 2022), segue link para o certificado SSL EV válido da autoridade certificadora Certisign.    Reforçamos que o prazo para que as instituições ajustem suas infraestruturas para as novas cadeias das autoridades certificadoras Serasa, Soluti e Certisign é 13/01/2023.    Caso haja dúvidas, as instituições poderão abrir tickets no Service Desk no caminho: "Solicitação de Informação" >> "Diretório" com o título “Atualização de cadeias de certificado” |
