# [Open Finance] Informa #422

Cronograma do próximo versionamento *minor* das APIs:  **• Cartão  • Contas**   **• Operações de Crédito - Empréstimos**  **• Operações de Crédito - Financiamento**   **• Operações de Crédito - Adiantamento a Depositantes**  **• Operações de Crédito - Direitos Creditórios Descontados**  Comunicamos que está previsto um novo versionamento *minor* para APIs Cartões, Contas, Operações de Crédito - Empréstimos, Operações de Crédito - Financiamento, Operações de Crédito - Adiantamento a Depositantes e Operações de Crédito - Direitos Creditórios Descontados da fase 2. A *minor* será do tipo sincronizada, ou seja, **não haverá período de convivência com a versão atual**, o que exigirá adequação das receptoras e transmissoras de forma que não haja problemas de interoperabilidade para quem consome as APIs.     As informações referentes às datas de lançamento das especificações, marcos de sucesso, submissão e processamento das certificações e entrada em produção podem ser observadas abaixo: |

 - 14/08/2023: Lançamento da versão *release candidate* - 27/08/2023: Lançamento do motor de conformidade - **11/09/2023: Data limite para execução com sucesso de 25% dos módulos de teste** - **25/09/2023: Data limite para execução com sucesso de 50% dos módulos de teste** - 05/10/2023: Lançamento da versão estável - **09/10/2023: Data limite para execução com sucesso de 75% dos módulos de teste** - **23/10/2023: Data limite para execução com sucesso de 100% dos módulos de teste** - Entre 23/10/2023 e 31/10/2023: Possíveis ajustes finais de documentação e testes - **31/10/2023: *Go live* das versões atualizadas das APIs Cartões, Contas e Operações de crédito** |
