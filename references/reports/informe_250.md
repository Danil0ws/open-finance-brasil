# [Open Finance] Informa #250

**Fase 2 – Atualização da planilha de problemas conhecidos**  O Grupo Técnico de Especificações comunica que foram incluídos dois itens à planilha de problemas conhecidos Fase 2, conforme segue:   - **BCLOG-F02-219**    - **API/Sessão:** *Clientes*   - **Ponto final:** /negócios/identificações   - **Campo:** /dados/contatos/correiosAddresses   - **Qual o problema:** A lista de objetos /data/contatos/correiosAddresses que está no Endpoint /business/identifications da versão 2.0.1 exige no mínimo um objeto, ou seja, um endereço que nem sempre existe para os cadastros PJ   - **Como deveria ser:** Deveria ser adotada a mesma proposta do ponto final /pessoal/identificações, que permite uma lista vazia   - **Orientação:** Caso não exista um endereço a ser comunicado, criar um objeto "Manequim" com os seguintes valores para seus atributos:     - isMain: FALSE     - townName: string vazia ("))     - país: string vazia (")     - countryCode: ("XXX") - **BCLOG-F02-220**    - **API/Sessão:** *Clientes*   - **Ponto final:** /negócios/identificações   - **Campos:** /endereço e /townName   - **Qual o problema:** O REGEX ('^\w{2}[\w\W\s]\*$') dos campos não permite o uso de abreviaturas no início do nome   - **Como deveria ser:** O REGEX deveria permitir abreviaturas   - **Orientação:** Utilizar o *padrão* [\w\W\s]\* |
