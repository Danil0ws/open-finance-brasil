# [Open Finance] Informa #824

Lançamento da versão v3.3.1 (*patch*) da API Consentimento |

 Comunicamos que, em 15/12/2025, foi publicada a versão 3.3.1 (*patch*) das especificações da API Consentimento.       Destacamos a seguinte alteração:  - Atualização da descrição do campo /data/expirationDateTime no *endpoint* POST /consents, removendo a restrição de 12 meses:     - De: Data e hora de expiração da permissão. Reflete a data limite de validade do consentimento. Uma string com data e hora conforme especificação RFC-3339, sempre com a utilização de timezone UTC (UTC time format).       [Restrição] De preenchimento obrigatório nos casos em que houver validade determinada. Em casos de consentimento com prazo indeterminado o campo não deve ser enviado. Quando preenchido, o valor do campo não pode ultrapassar 12 meses.   - Para: Data e hora de expiração da permissão. Reflete a data limite de validade do consentimento. Uma string com data e hora conforme especificação RFC-3339, sempre com a utilização de timezone UTC (UTC time format).        [Restrição] De preenchimento obrigatório nos casos em que houver validade determinada. Em casos de consentimento com prazo indeterminado o campo não deve ser enviado.   Adicionalmente, informamos que as instituições deverão atualizar a versão dessa API no Diretório em **18/01/2026**, e, por se tratar de um versionamento do tipo *patch*, não será necessária nova certificação para esta API, conforme a política de versionamento vigente.        Para mais detalhes, sugerimos acessar os links de documentação abaixo: |
