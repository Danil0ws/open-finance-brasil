# [Open Finance] Informa #488

Período de convivência de APIs correspondentes entre o Open Finance Brasil e o Open Insurance **Definição do período de convivência (multiversionamento)**    Em 16/06/2023, houve *go live* das APIs Títulos de Capitalização, Previdência e Seguros no Open Finance Brasil (OFB). Estas APIs possuem correspondentes no Open Insurance (OPIN) e, conforme designado na Resolução Conjunta n° 5, é necessário haver interoperabilidade entre APIs semelhantes de ambos os ecossistemas.    Para mitigar possíveis impactos para instituições que consomem APIs do OPIN como fonte de dados para exposição no OFB, **foi acordado entre os ecossistemas que haverá um período de convivência de 180 dias entre versões consecutivas das APIs do OPIN que possuem interface com o OFB**, período este chamado de multiversionamento. Desta forma, o OFB terá 6 meses para versionar suas APIs até que termine o período de convivência do OPIN, quando a API anterior não poderá mais ser acessada.  **Início do primeiro período de convivência    Em 30/11/2023, haverá o primeiro versionamento das APIs interoperáveis do OPIN**. Portanto, até 31/05/2024, as seguintes APIs estarão disponíveis em duas versões para acesso:   1. API Capitalization Title: correspondente à API Títulos de Capitalização do OFB;  1. API Pension Plan: correspondente à API Previdência do OFB;  1. API Person: correspondente à API Seguros do OFB.     **Alterações realizadas nas APIs OPIN para permitir o multiversionamento**    Para que seja possibilitado o multiversionamento, **comunicamos que houve alteração nas APIs correntes do OPIN**. Desta forma, a partir de 30/11/2023, haverá impacto nas instituições que desejarem acessar a versão corrente das APIs do OPIN, pois deverão enviar parâmetros indicando qual versão desejam acessar.    Reforçamos que as instituições que acessam APIs do OPIN devem consultar a área do desenvolvedor desse ecossistema para verificar ajustes realizados nas APIs consumidas. |
