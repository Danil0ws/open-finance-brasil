# [Open Finance] Informa #239

Esclarecimento sobre testes de limites operacionais    **Esclarecemos que todas as instituições devem executar com sucesso (e, posteriormente, certificar) todos os módulos de testes de limites operacionais para os produtos que oferece, independentemente se irão implementar limites operacionais ou não.**  O teste foi construído de forma a verificar se todas as instituições estão oferecendo os limites mínimos estabelecidos pela convenção para cada *endpoint*.  Reforçando o Informa #238 (“Execução dos testes da Fase 2 v2”, enviado em 23 de setembro de 2022), **pedimos que as instituições executem os módulos de teste de limites operacionais** para que o motor de testes atinja os critérios de maturidade estabelecidos dentro do cronograma, que prevê abertura de pedidos de certificação até, no máximo, 03 de outubro de 2022.  Os módulos de limites operacionais são:   - resources-api-operational-limits - customer-business-api-operational-limits - customer-personal-api-operational-limits - consents-api-operational-limits - credit-cards-api-operational-limits - accounts-api-operational-limits - loans-api-operational-limits - financings-api-operational-limits - discounted-credit-rights-api-operational-limits - unarranged-overdraft-api-operational-limits |
