# [Open Finance] Informa #563

Orientações para o *go live* das APIs de Pagamentos e Dados do cliente Comunicamos que em 15/04/2024 ocorrerá o *go live* das seguintes APIs:   - Consentimento v3.0.0 - Recurso v3.0.0 - Pagamentos v4.0.0 - Câmbio v1.0.0 - Pagamentos automáticos v1.0.0   - Para esta API, as instituições poderão realizar a publicação até 29/04/2024  As instituições deverão implementar as novas APIs em produção até as 23h59 da data limite para publicação. Adicionalmente, lembramos que a API Câmbio só será funcional com o lançamento em conjunto das APIs Consentimento e Recursos.  Entre 15/04/2024 e 15/07/2024 haverá o período de convivência para as seguintes APIs:  - Consentimento v3.0.0 - Recurso v3.0.0 - Pagamentos v4.0.0    Conforme comunicado no Informa #467 (“Requisitos para o *go live* de novos produtos“, enviado em 06/10/2023) para as APIs de Câmbio v1.0.0 e Pagamentos automáticos v1.0.0, além da obtenção da certificação funcional são necessárias algumas ações adicionais para garantir o correto funcionamento do ecossistema e evitar problemas de interoperabilidade. Para cada papel, as instituições devem:     **Transmissor/Detentor de conta**  - Alterar Authorization Server para reconhecer os escopos do novo produto; - Alterar conteúdo da url de well-known para indicar os novos escopos; - Cadastrar novas famílias de APIs e seus *endpoints* no Diretório  **Receptores/Iniciadores de pagamento:**  - Registro do Software Cliente (clientId):   - Realizar o processo de DCM com as instituições transmissoras atualizando a lista de escopos incluindo os definidos para o novo produto; |

 Abertura do período de submissão das certificações de Pagamentos automáticos Comunicamos **que o período de submissão de certificação da API de Pagamentos automáticos terá início em 12/04/2024, de acordo com as seguintes orientações:**   - Data de submissão dos pedidos de certificação no Service Desk: de 12/04/2024 até 24/04/2024   - Pedidos submetidos após essa data poderão não ser processados até o final da janela de Go Live em 29/04/2024 - **Serão exigidos até quatro planos de teste obrigatórios no mesmo ticket para a emissão da certificação;** - As evidências anexadas deverão ser dos seguintes planos de testes + categoria e executados a partir das seguintes datas: |

 Para dúvidas, favor abrir um ticket na plataforma Service Desk na categoria: Solicitação de informação > Conformidade > Motor de conformidade |

 Adição de escopos de Pagamentos Automáticos no documento de Perfil de Segurança A fim de contemplar os escopos a serem implementados a partir do lançamento da API de Pagamentos Automáticos, informamos que foram feitas as adições do escopo de consentimento de pagamentos recorrentes e escopo de *recurring-payments* nas seções 7.1.2 e 7.2.2, respectivamente, no documento do Perfil de Segurança na Área do Desenvolvedor do Open Finance Brasil.     Ressaltamos que essas alterações não impactam o perfil FAPI único. |

 FAPI Único - Encerramento do período de convivência e descontinuidade dos demais perfis Conforme Informa #559 (“Orientações sobre a publicação da nova certificação de segurança (FAPI único)”, enviado em 02/04/2024), a partir de 15/04/2024 os perfis antigos de segurança serão descontinuados e só deverão ser aceitas chamadas utilizando o novo perfil.     Identificamos que, após a migração para a utilização do PAR, algumas instituições apresentaram um tempo alto de resposta do *endpoint*, ocasionando demora no redirecionamento. Recomendamos que verifiquem se as suas infraestruturas estão adequadas para suportar o volume de chamados após a migração completa. |
