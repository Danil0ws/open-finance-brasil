# [Open Finance] Informa #332

Importante: datas para sucesso nos testes beta do motor de conformidade de dados abertos (APIs de Investimentos, Câmbio e Credenciamento)    Complementando o Informa #331 (“Liberação do motor funcional versão beta das APIs de Dados Abertos (fase 4A)”, enviado em 28/02/2023), comunicamos abaixo o cronograma determinado pela IN 357 para que as instituições participantes obtenham determinadas taxas de sucesso nos testes funcionais das APIs de dados abertos de Investimentos, Câmbio e Credenciamento (fase 4A).     Ressaltamos que todas as instituições devem testar com sucesso 25% dos testes beta até 08/03/2023.     **Cronograma de execução de testes, conforme IN 357:**   - **28/02/2023 - 27/04/2023:** Período de testes do motor e correção de *bugs*   - **08/03/2023**: Data limite para execução com sucesso em 25% dos módulos   - **22/03/2023:** Data limite para execução com sucesso em 50% dos módulos   - **09/04/2023:** Data limite para execução com sucesso em 75% dos módulos   - **27/04/2023:** Data limite para execução com sucesso em 100% dos módulos - **30/04/2023:** ***Go live*** – data limite para publicação das APIs no Diretório de Participantes   A certificação das APIs de dados abertos será realizada de maneira automatizada no momento da publicação no diretório, conforme Guia Operacional do Diretório (páginas 75 a 80). Para a realização dos testes, poderá ser utilizado tanto o motor de conformidade quanto o Diretório de Sandbox.     Problemas ou inconsistências identificadas devem ser notificadas através do repositório no GitLab no link abaixo. Tickets abertos através da plataforma do Service Desk continuarão sendo tratados, porém a expectativa é realizar uma transição gradual para o GitLab com intuito de reduzir a abertura de problemas duplicados e aumentar a celeridade da sua resolução. |
