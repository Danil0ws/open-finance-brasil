# [Open Banking] Informa #115

Esclarecimentos quanto à apresentação das organizações na jornada do cliente Pedimos que as instituições respondam o formulário abaixo para esclarecer qual campo da API está sendo exibido na jornada de consentimento para exibição dos participantes.  Durante a jornada de consentimento da Fase 2 ou Fase 3, o cliente tem a opção de obter mais informações sobre a marca e os participantes a ela relacionados ([Guia de UX](https://openbanking-brasil.github.io/areadesenvolvedor/#guia-de-experiencia-de-compartilhamento-de-dados-e-iniciacao-de-pagamento), páginas 55 e 154).  Para a montagem visual da jornada do cliente, as instituições receptoras/iniciadoras devem obter as informações necessárias a partir da [API de participantes](https://data.directory.openbankingbrasil.org.br/participants) disponibilizada pelo Diretório.    Atualmente, essa API retorna campos informativos quanto a instituições relacionadas à marca.    Devido a características das informações, necessitamos apoio das instituições para averiguar exatamente qual campo da API está sendo exibido ao cliente na jornada de consentimento para exibição dos **participantes**(não das marcas).    **Atenção**: Não está sendo questionado o campo **marca**, mas sim o campo que é utilizado para descrição dos **participantes**.    O formulário estará disponível até dia 24/01/2022, às 20h. |
