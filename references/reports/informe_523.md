# [Open Finance] Informa #523

Execução pontual de testes condicionais na API de Pagamentos v4.0.0  O motor funcional da API de Pagamentos v4.0.0 possui alguns módulos condicionais, cuja obrigatoriedade de execução obedece às seguintes regras:    Execução obrigatória para quem possui múltiplas alçadas   - payments\_api\_multiple-consents-no-funds-conditional\_test-module\_v4 - payments\_api\_multiple-consents-conditional\_test-module\_v4   Execução obrigatória para quem aplica mecanismos de temporização   - payments\_api\_temporization-conditional\_test-module\_v4 - payments\_api\_canc-temporization-conditional\_test-module\_v4   Conforme Informa #480 (“Atualização dos cronogramas de Fase 2 e 4B, Fase 3 e Perfil FAPI único”, enviado em 01/11/2023) o marco de 100% desta API ocorrerá em 19/02/2024.    **Recomendamos que as instituições executem com sucesso os módulos condicionais até 15/02/2024 para garantirmos a maturidade do motor.**     Caso algum problema seja identificado nestes testes, solicitamos que seja reportado através da abertura de ticket no *service desk* ou *issue* no Gitlab. |
