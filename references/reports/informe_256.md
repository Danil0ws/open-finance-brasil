# [Open Finance] Informa #256

Abertura de certificações de limites operacionais da fase 2 v2.0.1  **Comunicamos que as certificações de limites operacionais da fase 2 v2.0.1 estão abertas para submissão de pedidos.** Essas certificações são obrigatórias para todos os participantes da fase 2, inclusive aqueles que não implementaram o controle de limites operacionais, e devem ser obtidas para todas as APIs que foram certificadas funcionalmente.     **Os pedidos devem ser submetidos até o dia 24/10/2022.** Não há garantias de que pedidos de certificações submetidos após essa data serão processados antes da data do go live, em 31/10/2022.      Para a submissão, é necessário realizar um novo plano de testes na versão 4.1.43 ou superior, executado a partir de 17/10/2022, e enviar o documento “Certificado de Conformidade Funcional”, no qual deverão ser indicados todos os módulos para os quais estão sendo solicitadas as certificações. **O nome do deployment na submissão dos pedidos de certificações de limites operacionais deverá ser o mesmo que foi declarado no pedido da certificação da API funcional.**     As certificações são incrementais, ou seja, cada execução do teste pode ser feita para um ou mais módulos, que gerarão as evidências necessárias para os módulos selecionados. Exemplo: execução de um plano para API Accounts e de outro plano para as demais APIs.     Apesar dos arquivos zips poderem ser gerados de maneira segmentada, recomendamos que seja aberto um ticket único por deployment para as certificações de limites operacionais contendo todos os pacotes zips de certificações.      Os pedidos de certificações deverão ser realizados pelo Service Desk na categoria “Enviar pedido de certificação”, com o campo “Teste executado” preenchido com “Fase 2: Limites Operacionais”.     A publicação da versão 2.0.1 das APIs no Diretório de Participantes só poderá ser realizada se a instituição estiver de posse das certificações funcional e de limites operacionais. Maiores informações serão enviadas posteriormente. |

 Atenção: Testes para as adequações do novo padrão de certificados cliente (BRCAC) do Open Finance Brasil  Reforçando o Informa #238 (“Testes para as adequações do novo padrão de certificados cliente - BRCAC - do Open Finance Brasil”, enviado em 23/09/2022), **a execução com sucesso do módulo de teste “dcr-brcac2022-support” é obrigatória por todas as instituições transmissoras de dados e detentoras de conta até 21/10/2022** e será acompanhada para evitar problemas de interoperabilidade nesse processo. Para instituições que suportam tanto MTLS quanto Private Key, executar esse teste com o padrão MTLS.    Até 21/10/2022, serão gerados relatórios com os casos de sucesso e insucesso que serão compartilhados com o Conselho Deliberativo e o Banco Central, mas não será necessária a submissão dos logs pelo Service Desk. |

 Nova categoria de Incidentes para usuários não participantes  Informamos que, no dia 24/10/2022, será disponibilizada a nova categoria de **Incidentes > APIs de Dados Abertos** no ambiente de Produção do Service Desk.    Esta categoria estará disponível **apenas para os usuários de instituições NÃO participantes do Open Finance**. Dessa forma, as instituições participantes deverão estar com as suas integrações do Service Desk preparadas para receber e atender os tickets abertos nesta categoria.
