# [Open Finance] Informa #512

[ERRATA] – Ajustes no motor de conformidade das APIs de Pagamentos No Informa #509 “Ajustes no motor de conformidade das APIs de Pagamentos“, informamos que para a API de Pagamentos automáticos v1.0.0 (transferências inteligentes) foi comunicado que três módulos de teste eram obrigatórios apenas para instituições que ofertam produtos PJ e condicionais para as demais instituições.    Informamos que para esta API, 2 módulos de teste são condicionais para todas as instituições e 2 módulos são exclusivos para instituições que ofertam produtos PJ, sendo eles:  Condicionais para PF/PJ   - automatic-payments\_api\_multiple-consents-core\_test-module\_v1 - automatic-payments\_api\_webhook-multiple-consents\_test-module\_v1  Exclusivos para execução PJ  - automatic-payments\_api\_sweeping-accounts-root-cnpj\_test-module\_v1 (este módulo foi disponibilizado em 05/01/2024) - automatic-payments\_api\_sweeping-accounts-invalid-cnpj\_test-module\_v1 |

 LEMBRETE - Marco de 40% da API de Pagamentos automáticos v1.0.0 (transferências inteligentes) Conforme comunicado no Informa #511 (“Prorrogação do marco de 40% da API de Pagamentos automáticos v1.0.0 (transferências inteligentes)”, enviado em 10/01/2024), o marco de 40% da API de Pagamentos automáticos ocorrerá em 15/01/2024.    Para este marco, as instituições que oferecem produtos PJ deverão obter sucesso em 6 de 15 módulos disponibilizados no motor. Instituições que não oferecem produtos PJ, deverão obter sucesso em 5 dos 13 módulos obrigatórios disponibilizados no motor.    Informamos que o comportamento de dois módulos obrigatórios está em discussão no issue 1181 e, por esse motivo, recomendamos a execução dos demais testes. Os módulos em discussão são os seguintes:   - automatic-payments\_api\_webhook-revoked\_test-module\_v1 - automatic-payments\_api\_revoked-consent\_test-module\_v1 |

 Orientações para execução dos testes do novo perfil FAPI único **A certificação do novo perfil FAPI único é obrigatória como Relying party (RP) para todas as iniciadoras de pagamento e receptoras de dados e como OpenID Provider (OP) para todas as detentoras de conta e transmissoras de dados.**     A execução com sucesso e a submissão dos pedidos de certificação deve ocorrer até 31/01/2024. Até essa data, as instituições deverão seguir as seguintes orientações:   1. **Realizar a execução dos testes em ambiente produtivo**     1. Conforme Informa #507 (“Publicação dos testes de conformidade do novo perfil único FAPI 1.0 em ambiente de produção (OIDF)”, enviado em 22/12/2023), os testes do novo perfil FAPI único estão disponíveis para execução em produção, não devendo ser utilizado o ambiente demo para a execução destes testes    2. O motor em produção pode ser acessado através do link: [https://www.certification.openid.net/login.html](https://bra01.safelinks.protection.outlook.com/?url=https%3A%2F%2Fwww.certification.openid.net%2Flogin.html&data=05%7C02%7Cnaiara.cavalaro%40chicagoadvisory.com.br%7Cf6ea72172ccc4011d2a108dc13b1dd85%7C7531e8b3c928494b9b897ee3d353272d%7C0%7C0%7C638406901839467902%7CUnknown%7CTWFpbGZsb3d8eyJWIjoiMC4wLjAwMDAiLCJQIjoiV2luMzIiLCJBTiI6Ik1haWwiLCJXVCI6Mn0%3D%7C3000%7C%7C%7C&sdata=6%2BcY%2FA3o%2FAvU7p0ORH6o0QMVRQ%2By%2BDziqB6NWThcArY%3D&reserved=0) 2. **Indicar o identificador da instituição no campo “description”**    1.
