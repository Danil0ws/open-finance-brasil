# [Open Finance] Informa #184

Orientações sobre status HTTP 429 para API de Consentimento O BCB informou aos participantes da Fase 2 que considerando o disposto no item 5.1 do Anexo à IN BCB 130/21, conjuntamente com a Res. Conj. 1/20, art. 42, parágrafo único, inciso II, item a), os limites de tráfego previstos não se aplicam à API de consentimento. Dessa forma, os transmissores que estejam retornando código de status HTTP 429 (too many requests) às chamadas da referida API, devem ajustar seus procedimentos.     Não obstante, tendo em vista que a remoção do limite de TPS da API Consents pode expor os participantes ao risco de indisponibilidade por excesso de requisições, foi permitida a manutenção de tal limite (TPS), desde que o participante monitore o retorno 429 na API Consents e incremente sua infraestrutura sempre que esse código for retornado por indício de esgotamento da capacidade atual e não por um ataque intencional.     Da mesma forma, para as APIs de segurança (ex: well-know, DCR, DCM, token...) não deve~~m~~ ser realizado~~s~~ controle de TPM, podendo ser mantido os limites de TPS seguindo a mesma orientação do parágrafo acima. |
