# [Open Finance] Informa #588

Data limite para atualização das versões 2.3.0 das APIs Contas e Cartões de crédito (fase 2) no Diretório Informamos que **as instituições deverão atualizar as versões 2.3.0 das APIs Contas e Cartões de crédito (fase 2) no Diretório** **até o dia 07/06/2024.**    As APIs já foram publicadas na Área do desenvolvedor, conforme divulgado no Informa #574 ("Lançamento das versões *minor* das APIs Contas (v2.3.0), Cartão de crédito (v2.3.0) e Empréstimos (v2.2.0)", enviado em 03/05/2024).   - Essas versões já estão disponíveis para seleção no Diretório – não será necessária a recertificação; - O motor de conformidade está disponível caso a instituição deseje utilizá-lo para validar sua implementação antes da publicação da nova versão; - A data de atualização no Diretório da API de Empréstimos (v2.2.0) será divulgada posteriormente. |

 LEMBRETE – Recertificação simplificada de múltiplas alçadas para a API de Pagamentos v4.0.0 Conforme comunicado no informa #580 (“**Recertificação simplificada de múltiplas alçadas para API de Pagamentos v4.0.0**”, enviado em 20/05/2024) as instituições que oferecem a funcionalidade de múltiplas alçadas, deverão reexecutar com sucesso os módulos de teste desta funcionalidade para a API de Pagamentos v4.0.0 até 07/06/2024.    Serão contabilizadas as execuções com sucesso realizadas em planos de teste criados a partir de 16/05/2024 para os seguintes módulos:   - payments\_api\_multiple-consents-timezone-conditional\_test-module\_v4 - payments\_api\_multiple-consents-conditional\_test-module\_v4 - payments\_api\_multiple-consents-no-funds-conditional\_test-module\_v4   As execuções podem ser acompanhadas através do Dashboard de certificação. Solicitações de acesso ao Dashboard podem ser enviadas através do service desk no seguinte caminho:     Solicitação de acessos > Acompanhamento de certificação > Concessão de acesso |
