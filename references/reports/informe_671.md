# [Open Finance] Informa #671

Atualização das APIs de Operações de crédito (Dados do cliente)             Comunicamos que, segundo os Informes #660 (“*Lançamento da versão patch das APIs Renda fixa crédito e Renda fixa bancária (Dados do cliente)*”, divulgado em 13/11/2024) e #664 (“*Data para atualização da versão minor das APIs Direitos creditórios descontados, Financiamentos e Adiantamento a depositantes (Dados do cliente)*”, divulgado em 21/11/2024), as instituições terão que atualizar em 17/01/2025 as seguintes APIs de Dados do cliente no Diretório:   - Operações de crédito:   - Adiantamento a depositantes v2.3.0   - Financiamentos v2.3   Informamos que o motor de conformidade foi atualizado para essas APIs de Dados do cliente e reforçamos que não será necessário recertificação. Instituições que realizarem alterações em suas implementações deverão realizar testes no motor de conformidade antes da publicação em produção. |

 Alteração dos testes para o motor beta.2 da API Pagamentos automáticos v2.0.0             Conforme comunicado no Informa #661 (“*Novo cronograma de implementação da v2.0.0 da API Pagamentos automáticos (Transferências inteligentes + Pix automático)*”, enviado em 14/11/2024), o primeiro marco do cronograma de implementação da v2.0.0 da API Pagamentos automáticos ocorrerá em 14/01/2024. Esse marco ocorrerá na versão beta.2 do motor de conformidade e as instituições deverão obter sucesso em 50% do total de testes obrigatórios que serão disponibilizados nessa versão do motor em 02/01/2024.     A versão beta.2 do motor contemplará alterações relevantes e adição de testes nos planos de Pix automático e Transferências inteligentes. As instituições deverão criar um plano de testes para execução dos novos módulos e testes alterados.     **Orientações gerais sobre o marco:**   - Disponibilização da especificação beta.2: 06/12/2024; - Disponibilização do motor beta.2: 02/01/2024; - Marco de 50%: 14/01/2024; - **Total de testes necessários para sucesso no marco:**   - 26 testes obrigatórios para todas as instituições detentoras;     - Instituições que ofertam múltiplas alçadas e/ou PJ também deverão obter sucesso nos módulos condicionais conforme descrito abaixo. - **Informações sobre os testes:**   - Transferências inteligentes:     - Planos de testes: (*automatic*-*payments*\_*test*-*plan*\_v1; *automatic*-*payments*-*timezone*\_*test*-*plan*\_v1; *automatic*-*payments*-*webhook*\_*test*-*plan*\_v1)     - 21 testes totais:       - 2 testes PJ (obrigatório para quem oferta o produto PJ);       - 1 múltiplas alçadas (obrigatório para quem oferta múltiplas alçadas).     - Principais mudanças na versão beta-2:       - Atualizado o estado do pagamento para cálculo de limites do consentimento;       - Criação do campo /*data*/*recurringConfiguration*/*sweeping*/*startDateTime*;       - Ajuste no prazo máximo para autorização do consentimento para 60 minutos;       - **Todos os testes terão alteração relevante.**   - Pix Automático:     - Planos de teste : (*automatic*-pix-*payments*\_*test*-*plan*\_v1; *automatic*-*pix*-*payments*-*timezone*\_*test*-*plan*\_v1; *automatic*-pix-*payments*-*webhook*\_*test*-*plan*\_v1; *automatic*-*pix*-*payments*-*retry*\_*test*-*plan*\_v1; *automatic*-*pix*-*auxiliar*-\_*test*-*plan*\_v1 - Auxiliar)     - 34 testes obrigatórios para todas as detentoras:       - A execução com sucesso dos cenários felizes de *retry* será obrigatória para o marco de 50%:         - *automatic*-*payments*\_*api*\_*intraday*-*core*\_*test*-*module*\_v1;         - *automatic*-*payments*\_*api*\_*extraday*-*core*\_*test*-*module*\_v1.     - Principais mudanças na versão beta-2:       - Criação do campo /*data*/*recurringConfiguration*/*automatic*/*referenceStartDateTime*;       - Criação da possibilidade de edição do consentimento com identificação clara do cliente e sincronização de datas entre ITP e detentora;       - Remoção de campos redundantes;       - Revisão dos critérios para contagem de tentativas de pagamento com base nos erros retornados;       - Ajuste no prazo máximo para autorização do consentimento para 60 minutos;       - Todos os testes terão alteração relevante. |
