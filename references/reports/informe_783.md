# [Open Finance] Informa #783

Jornada sem redirecionamento – Lançamento da API Vínculo de dispositivo v2.2.0-rc.2     Informamos que a área do desenvolvedor do Portal do Open Finance Brasil foi atualizada, em 29/08/2025, com a documentação da versão *release candidate* da API Vínculo de dispositivo (v2.2.0-rc.2).    Dentre as alterações, destacamos:   - Definição de comportamentos esperados para o tratamento entre os limites de Pix Automático e JSR; - Incorporação de mecanismo para referenciar consentimentos de dados para permitir a Jornada Otimizada; - Inclusão de *endpoint* na API para habilitar JSR no produto Pix automático.   **O cronograma de certificação e implementação dessas APIs será divulgado posteriormente.**    Para acessar todas as alterações e mais detalhes, sugerimos acessar os links de documentação abaixo: |
