# [Open Finance] Informa #639

Publicação das versões *patch* das APIs de Dados abertos Informamos que a área do desenvolvedor foi atualizada em 07/10/2024 com as versões *patch* das seguintes APIs:   - API Contas v1.0.1 - API Cartão de crédito v1.0.1 - API Empréstimos v1.0.1 - API Financiamentos v1.0.1 - API Direitos creditórios descontados v1.0.1 - API Adiantamento a depositantes v1.0.1 - API Canais de atendimento v2.0.1 - API Credenciamento v1.0.1 - API Câmbio v1.0.1 - API Investimentos v1.0.1  Dentre as alterações, destacamos as mudanças nos campos do tipo URL e URI das APIs.  - Sugerimos consultar os *changelogs* para visualizar as alterações entre as versões das APIs   **As instituições devem atualizar as novas versões no diretório no dia 06/11/2024.**    A certificação dessas APIs ocorre automaticamente no momento da sua publicação no Diretório. Com essas novas versões, os testes se tornarão menos restritivos, ou seja, não impactarão as instituições que já apresentavam sucesso na certificação anterior, não exigindo esforço adicional. |
