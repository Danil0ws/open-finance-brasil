# [Open Banking] Informa #95

Atualização de prazos para certificações da Fase 2 Os prazos para as certificações listadas abaixo, atualmente previstas para finalizar em 30 de novembro de 2021, serão estendidos até 17 de Dezembro de 2021 (sexta-feira):   - Recertificação Funcional Fase 2, para as instituições Transmissoras de Dados que aderiram à Fase 2; - Recertificação de Segurança DCR/DCM, para todas as instituições que aderiram à Fase 2; - Certificação de Segurança *Relying Parties* escopo *unsigned*, para as instituições Receptoras de Dados que aderiram à Fase 2. |
