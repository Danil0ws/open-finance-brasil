# [Open Finance] Informa #590

Correção da Tabela de Dados no Guia de Experiência do Usuário do Open Finance Brasil  Em 13/05/2024, foi aprovada a proposta para a inclusão de dados do empregador no Guia de Experiência do usuário e essa inclusão já está contemplada na nova versão do Guia (v07.02.00). No entanto, as Informações complementares do agrupamento PF foram replicadas erroneamente em Dados cadastrais do agrupamento PJ.     Informamos que o texto correto na "Tabela de Dados | Versão Resumida | Jornada de Compartilhamento de Dados", na categoria "Dados cadastrais" do agrupamento PJ, na página 365 do Guia de Experiência do Usuário (v07.02.00), é: **"Razão social, endereço completo, CNPJ, número de registro no país de origem, telefone, e-mail, data de abertura da empresa, informações de sócios e administradores".**     Atualmente, uma nova proposta está sendo deliberada para a correção do guia, que deve ser refletida na próxima versão, prevista para o final de junho de 2024. |

 Data limite para atualização da versão 2.2.0 da API Empréstimos (Fase 2) no Diretório  Informamos que **as instituições deverão atualizar a versão 2.2.0 da API Empréstimos no Diretório** **até o dia 13/06/2024.**  A API já está publicada na Área do desenvolvedor, conforme divulgado no Informa #574 ("Lançamento das versões *minor* das APIs Contas (v2.3.0), Cartão de crédito (v2.3.0) e Empréstimos (v2.2.0)", enviado em 03/05/2024).   - Essa versão já está disponível para seleção no Diretório – não será necessária a recertificação; - O motor de conformidade está disponível caso a instituição deseje utilizá-lo para validar sua implementação antes da publicação da nova versão; |
