# [Open Finance] Informa #785

Lançamento da v2.2.0-rc.2 da API Pagamentos automáticos      Comunicamos que, em 11/09/2025, foi publicada a versão 2.2.0-rc.2 das especificações da API Pagamentos automáticos, as quais estão disponíveis na área do desenvolvedor do Portal do Open Finance Brasil em:   - Especificações de APIs > Serviços - SV > [SV] Iniciação de Pagamentos > [SV] API – Pagamentos Automáticos > v2.2.0-rc.2 - [SV] Pagamentos Automáticos.   Informações sobre o cronograma de implementação, certificação, bem como a data de *go live*, podem ser encontradas no **Informa #767** (“*Divulgação do cronograma de implementação da v2.2.0 (minor) da API Pagamentos automáticos e lançamento da v2.2.0-rc.1*”, enviado em 24/07/2025).     Para mais detalhes, sugerimos acessar os links de documentação abaixo: |

 Jornada sem redirecionamento – Orientação aos novos entrantes sobre a implementação da API Vínculo de dispositivo     Conforme orientação do Banco Central, os novos entrantes da Jornada sem redirecionamento devem implementar apenas a versão 2.2.0 da API Vínculo de dispositivo.     Informamos que a v2.2.0-rc.2 da API está disponível na área do desenvolvedor do Portal do Open Finance Brasil, conforme divulgado no **Informa #783** (*"Jornada sem redirecionamento – Lançamento da API Vínculo de dispositivo v2.2.0-rc.2",* enviado em 01/09/2025). A publicação da v2.2.0-rc.3 estará disponível na área do desenvolvedor a partir do dia 31/10/2025.     O cronograma completo de certificação e implementação, incluindo a data atualizada para publicação da API em produção, será divulgado posteriormente. |
