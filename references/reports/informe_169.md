# [Open Finance] Informa #169

Nova UI do Diretório e publicação de certificados de segurança  Seguindo o Informa #146 - Testes para Ferramenta de Validação em Produção, a nova interface do usuário (UI) do Diretório foi completamente migrada para a URL oficial do Diretório:     Produção: [https://web.directory.openbankingbrasil.org.br/](https://openbankingbrasil.us5.list-manage.com/track/click?u=49f5ff8910ce85bdb1d9a7864&id=30bf9ef08a&e=0bb3f785da)  Sandbox: [https://web.sandbox.directory.openbankingbrasil.org.br/](https://openbankingbrasil.us5.list-manage.com/track/click?u=49f5ff8910ce85bdb1d9a7864&id=bc27927ddb&e=0bb3f785da)     Caso identifiquem algum problema ou sugestão de melhoria na nova UI, favor abrir um ticket no Service Desk |

 Declaração de certificado de segurança no Authorisation Server  Na nova interface do Diretório, está disponível a funcionalidade para vincular o link do zip das certificações de segurança (FAPI e DCR) de cada Authorisation Server, conforme Informa #160 - Declaração de certificado de segurança no Authorisation Server.     **Reforçamos o pedido para que todas as instituições com Authorisation Servers publicados em produção preencham esse campo até 31/05/2022.**     O procedimento detalhado está descrito no Guia Operacional do Diretório, a partir da página 52. |

 Alteração de número de caracteres no Customer Friendly Server Name  O campo Customer Friendly Server Name do Authorisation Server sofrerá uma alteração para melhorar a experiência do usuário. **O número máximo de caracteres mudará de 257 para 40**. O Guia Operacional do Diretório, páginas 48 e 49, foi atualizado e está disponível no link abaixo.     Reforçamos que **os campos Customer Friendly Server Name e Description** são especialmente susceptíveis a atualizações pelas organizações e **não devem ser utilizados como chave forte**. Caso a instituição queira utilizar alguma chave forte, recomendamos utilizar o AuthorisationServerID. |
