# [Open Finance] Informa #915

Informa – Acompanhamento dos Marcos durante o Período de Convivência da API de Pagamentos v5 |

 Em complemento ao **Informe nº 896, de 20/05/2026**, reforçamos as datas e os marcos definidos para o período de convivência da API de Pagamentos v5 aplicáveis às Instituições Transmissoras de Pagamentos (ITPs), bem como disponibilizamos o dashboard para acompanhamento da evolução desses marcos.   **Datas-alvo**  Durante o período de convivência, as ITPs deverão observar os seguintes marcos de adoção da API de Pagamentos v5:  |  |  | | --- | --- | | **Data** | Marco | | **10/06/2026** | Atingir **10%** das chamadas na API de Pagamentos v5 | | **10/07/2026** | Atingir **50%** das chamadas na API de Pagamentos v5 | | **10/08/2026** | Atingir **100%** das chamadas na API de Pagamentos v5 |  Para fins de apuração do cumprimento dos percentuais estabelecidos, será **considerado o volume total de chamadas realizadas na API de Pagamentos v5, independentemente de a iniciação de pagamento resultar ou não em liquidação.**  **Painel de evolução**  O painel apresenta a evolução do percentual de chamadas realizadas na versão v5 referente ao período de convivência, compreendido entre**21/05/2026 e 21/08/2026**, as instituições deverão acompanhar periodicamente sua evolução por meio do dashboard disponível no link abaixo:  [Dashboard de acompanhamento](https://sa-east-1.quicksight.aws.amazon.com/sn/account/openfinance-brasil/accounts/471112653989/dashboards/eaf92be6-6aef-451e-a5a5-6062ff518217?qs-signin-user-auth=false%23)   Em caso de dúvidas, orientamos as instituições a registrar um ticket no Service Desk. |
