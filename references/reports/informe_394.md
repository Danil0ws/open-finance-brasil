# [Open Finance] Informa #394

Novo cronograma de recorrência da execução obrigatória na FVP 2.0              Comunicamos que, a partir de 04/07/2023, **a FVP 2.0 deverá ser executada de forma recorrente** pelas instituições **uma vez a cada três semanas**, sendo uma semana para execução da ferramenta e duas semanas de pausa.     Orientações gerais:  - A execução será obrigatória para todos os Authorisation Server da instituição - Deverá ser realizada com clientes PF e PJ (quando aplicável), - Deverá realizada para os planos de testes das fases dos recursos do authorisation server (fases 2 e/ou 3) e testes adicionais (quando aplicável)  O cronograma para 2023 será: |

 Adição do módulo consents-server-certificate na FVP 1.0              Conforme Informa #385, o módulo consents-server-certificate foi adicionado na FVP 2.0 para validar a cadeia de certificado das instituições.
