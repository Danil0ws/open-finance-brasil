# [Open Finance] Informa #690

Dados do cliente - Lançamento das versões *minor* das APIs Empréstimos (v2.4.0) e Adiantamento a depositantes (v2.4.0) Informamos que a área do desenvolvedor do Portal do Open Finance Brasil foi atualizada, em 24/01/2025, com a documentação das versões *minor* das APIs Empréstimos (v2.4.0) e Adiantamento a depositantes (v2.4.0).  Dentre as alterações, destacamos:   - API Empréstimos (v2.4.0):   - Ajuste nos *patterns* dos campos chargeRate, maxLength, chargeAmount e feeRates;   - Remoção dos *patterns* dos campos links. - API Adiantamento a depositantes (v2.4.0):   - Ajuste nos *patterns*dos campos *instalmentPeriodicity AdditionalInfo* e *amortizationScheduledAdditionalInfo*em relação à versão 2.3.0;   - Demais ajustes da versão 2.3.0 serão preservados e continuam na versão 2.4.0.   Para acessar todas as alterações, sugerimos consultar o *changelog*.  Reforçamos que, conforme divulgado no Informa #682 (“Cancelamento do *go live* da versão 2.3.0 da API Adiantamento a depositantes (Dados do cliente)”, enviado em 09/01/2025), o *go live* da versão 2.3.0 da API Adiantamento a depositantes foi cancelado. Ou seja, para essa API as instituições passarão da versão 2.2.0 diretamente para a versão 2.4.0.  Adicionalmente, informamos que**:**   - **As instituições deverão atualizar a versão dessas APIs no Diretório em 24/02/2025**; - A data estimada para entrega do motor de conformidade para o versionamento da API Empréstimos é 07/02/2025 e para o versionamento da API Adiantamento a depositantes é 14/02/2025; - Não será exigida recertificação para os versionamentos em tela.
