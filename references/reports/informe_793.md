# [Open Finance] Informa #793

Marco A da API Vínculo de dispositivo v2.2.0 e API Webhook v1.3.0  Informamos que, conforme compartilhado no Informa #789 (“*Jornada sem redirecionamento (JSR) - Divulgação do cronograma de implementação da v2.2.0 (minor) da API Vínculo de dispositivo e v1.3.0 (minor) da API Webhook*”, publicado em 25/09/2025), **o marco A da Jornada sem redirecionamento (JSR)** (API Vínculo de dispositivo v2.2.0 e API Webhook v1.3.0) **ocorrerá em 21/10/2025**.     Para este marco, será utilizada a versão rc.2 do motor de conformidade, cujos testes podem ser consultados na página do plano de testes desta API. Para contabilização de sucesso, as instituições detentoras de conta devem obter sucesso nos seguintes testes obrigatórios:  - **enrollments\_api\_max-challenges\_test-module\_v2-2;** - **enrollments\_api\_rejected-holder-mismatch\_test-module\_v2-2;** - **enrollments\_api\_missing-required-risk-signals\_test-module\_v2-2;** - **enrollments\_automatic-payments\_authorised-executed-scheduled-successfully\_v2-2.**  O marco A tem como objetivo assegurar que as principais mudanças das APIs de Vínculo de Dispositivo e Pagamentos Automáticos foram implementadas de forma correta pelas instituições. **Este marco é obrigatório para instituições que já operam JSR e para os novos entrantes (detentoras de conta obrigatórias no arranjo Pix).**    Ressaltamos que as instituições que não executarem os módulos de teste conforme o esperado serão notificadas via tickets do Service Desk. |
