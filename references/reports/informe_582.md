# [Open Finance] Informa #582

Divulgação do cronograma de dados do empregador e resolução de problemas conhecidos das APIs de Dados Cadastrais e Contas Informamos que o cronograma do produto "dados do empregador" e da resolução dos problemas conhecidos das APIs de Dados Cadastrais (v2.1.0) e Contas (v2.4.0) foi aprovado, conforme abaixo: |

 Para instituições que recebem portabilidade de salário, o envio do objeto /data/portabilitiesReceived da API de Dados Cadastrais será facultativo até 25/10/2024.   - A partir dessa data, será exigido o envio dos dados disponíveis de todos os clientes, cuja instituição recebe a portabilidade salarial.   As versões beta das APIs já foram publicadas na área do desenvolvedor, conforme informes #576 ("Lançamento das versões *minor* das APIs Contas (v2.4.0-beta.1) e Dados cadastrais (v2.1.0-beta.1)", enviado em 07/05/2024) e #579 ("Lançamento da versão beta.2 da API Dados cadastrais (v2.1.0-beta.2)", enviado em 13/05/2024). |

 Lançamento das versões estáveis (v2.0.0) das APIs Seguros, Previdência e Títulos de Capitalização (fase 4A)                A área do desenvolvedor do portal do Open Finance Brasil foi atualizada em 22/05/2024 com a documentação das **versões estáveis v2.0.0 das APIs Seguros, Previdência e Títulos de Capitalização.**    Adicionalmente, informamos que a liberação do diretório para entrada em produção das APIs Seguros, Previdência e Títulos de Capitalização será antecipada **de 27/05/2024 para o dia 24/05/2024**, e a data limite para o *go live* se mantém em 31/05/2024, conforme divulgado no Informa #538 (“Lançamento da versão beta (2.0.0-beta.1) das APIs Títulos de Capitalização e Previdência”, enviado em 04/03/2024)  Sugerimos consultar o *changelog* para que sejam analisadas as alterações entre as versões 2.0.0 e 2.0.0-rc.1. |
