# [Open Finance] Informa #686

LEMBRETE – *Go live* das APIs de Dados do cliente              Conforme comunicado no Informa #664 (“Data para atualização da versão *minor*das APIs Direitos creditórios descontados, Financiamentos e Adiantamento a depositantes (Dados do cliente)” e “Data para atualização da versão *patch*das APIs Renda fixa crédito e Renda fixa bancária (Dados do cliente)”, enviado em 21/11/2024), **em 17/01/2025, as instituições deverão atualizar a versão das seguintes APIs no Diretório de participantes:**   - Direitos creditórios descontados (v2.3.0); - Financiamentos (v2.3.0); - Renda fixa crédito (v1.0.3); - Renda fixa bancária (v1.0.4).   Conforme o Informa #682 (“Cancelamento do go live da versão 2.3.0 da API Adiantamento a depositantes (Dados do cliente)”, enviado em 09/01/2025), a publicação da versão 2.3.0 da API Adiantamento a depositantes foi suspensa e uma nova data será divulgada posteriormente.     O motor de conformidade foi atualizado para as APIs que terão *go live* em 17/01/2025 e, embora a recertificação não seja necessária, instituições que realizarem alterações em suas implementações deverão realizar testes no motor antes da publicação em produção. |
