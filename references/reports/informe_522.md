# [Open Finance] Informa #522

Disponibilização do motor de Contas e Cartão de Crédito – *minor* v2.2.0  Conforme comunicado no Informa #507 (“Lançamento da minor (v2.2.0) das APIs Contas e Cartão de Crédito (Fase 2)”, enviado em 22/12/2023), informamos que o motor atualizado destas APIs foi disponibilizado em 31/01/2024. As instituições deverão executar os seguintes módulos de testes:  ***Accounts: "Functional Tests for Accounts API - Based on Swagger version*: 2.2.0**   - accounts\_api\_core\_test-module\_v2-1 - accounts\_api\_current-transactions\_test-module\_v2-1  ***Credit Card*: *"Functional Tests for Credit Cards API - Based on Swagger version*: 2.2.0**  - credit-cards\_api\_core\_test-module\_v2-1 - credit-cards\_api\_transactions-current\_test-module\_v2-1    Por se tratar de uma versão *minor* sincronizada, as instituições deverão colocar esta versão em produção no dia **01/03/2024, às 23h59**. As datas de testes e *go live* seguirão conforme aprovadas:  - Marco 50%: 19/02/2024; - Marco 100%: 26/02/2024; - *Go live*: 01/03/2024. |
