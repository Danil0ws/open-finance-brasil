# [Open Finance] Informa #504

Disponibilização do motor funcional das APIs Consents e Resources Comunicamos que o motor funcional das APIs de Consents e Resources foi disponibilizado em 15/12/2023 com dois planos de teste:   - resources\_test-plan\_v3 - consents\_test-plan\_v3   Em 18/12/2023 a versão web do motor de conformidade não apresentava a lista dos planos de teste com a nova versão. O cenário foi pontualmente corrigido.    Conforme Informa #488 (“Atualização de cronograma de Consents, Resources e Câmbio”, enviado em 17/11/2023), a disponibilização do motor funcional da API de Câmbio ocorrerá em 22/12/2023.    O cronograma completo de certificação das APIs de Consents, Resources e Câmbio pode ser conferido abaixo: |

 Período de convivência das APIs de fase 1 Informamos que haverá período de convivência entre a v1.x.x das APIs Adiantamento a depositantes, Direitos creditórios descontados, Cartão de crédito, Contas, Empréstimos e Financiamentos (Dados abertos) e a v1.x.x da API Produtos e Serviços. **O período de convivência se iniciará a partir da data de *go* *live* em 27/02/2024 e finalizará em 27/05/2024.** Conforme a política de versionamento, as instituições precisarão manter as duas versões disponíveis pelo prazo de 90 dias para consumo.  Esse período de convivência se deve à manutenção da funcionalidade entre as APIs. Ou seja, apesar de serem APIs na versão 1, elas são derivadas da antiga API Produtos e Serviços. Adicionalmente, informamos que a convivência acima também se aplica para as versões 2.x.x e 1.x.x da API Canais de atendimentos. |
