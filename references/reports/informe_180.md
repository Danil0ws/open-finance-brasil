# [Open Finance] Informa #180

Certificação funcional da Fase 2 v2.0  Conforme Informa #179 "Service Desk - Novo Campo e Status no Fluxo de Atendimento", enviado em 20/06/2022, o Portal do Open Finance Brasil foi atualizado com a documentação da nova versão 2.0 (versionamento major) das APIs de compartilhamento de dados transacionais e cadastrais (“Fase 2”).     De acordo com a Política de Versionamento de lançamento de novas especificações ao ecossistema, os participantes terão 120 dias corridos para implementação da versão 2.0 das APIs.     Para garantir o atendimento dessa data, o processo de certificação funcional deve ser concluído pelas transmissoras de dados seguindo os prazos abaixo:   - Disponibilização de testes no motor de conformidade funcional – **10/07/22** - Data limite para início de execução dos testes pelos participantes – **01/08/2022**   - A maturidade do motor é uma etapa crítica do processo e depende de um número de instituições passando em cada teste e em todo o plano, portanto, essa data limite para que todas as instituições estejam utilizando o motor de conformidade, visa garantir que este atinja a maturidade dentro do prazo esperado - Data limite para pedido de certificação funcional V2.0 – **19/09/2022** - Data limite para processamento das certificações pelo fornecedor – **18/10/2022** - Data limite para publicação das APIs da Fase 2 V2.0 no Diretório – **18/10/2022**    Ponto de atenção:  - As alterações nas APIs da Fase 2 v2.0 que gerarão maior impacto no motor de conformidade se concentram nas APIs de *Consents* e *Resources*   - Essas alterações serão refletidas em diversos planos de testes para validação do retorno esperado   - **Pedimos que as casas priorizem o desenvolvimento e execução dos grupos de testes relacionados com a APIs de *Resources*, cujos detalhes serão enviados em breve, para evitar atrasos na maturidade do motor** |
