# [Open Finance] Informa #575

Alteração relevante no módulo de teste da API de Previdência (Fase 4A)              Informamos que o módulo de teste opendata-pension-risk-coverages\_api\_structural\_test-module\_v2 sofreu uma alteração relevante em 03/05/2024 e por esse motivo, as instituições que oferecem o produto Previdência deverão criar um novo plano de teste a partir dessa data e reexecutar este módulo para o marco de 100%.    Conforme comunicado no Informa #538 (“Lançamento da versão beta (v2.0.0-beta.1) das APIs de Títulos de Capitalização e Previdência (Fase 4A), enviado em 04/03/2024”), o cronograma do versionamento das APIs de Seguros, Capitalização e Previdência pode ser conferido abaixo:   - Marco de 100% de sucesso em 20/05/2024  - *Go live* em 31/05/2024 |

 PCM - Novos campos *AdditionalInfo* para V1 de Pagamentos automáticos            Comunicamos que em razão da publicação da v1 de Pagamentos automáticos verificou-se a necessidade de inclusão de seis novos campos *additionalInfo* para acompanhamento da jornada.  Essa identificação é essencial para o entendimento dos motivos de quebra, cancelamento ou não efetivação da jornada de pagamentos.  A partir de 06/05/2024 a PCM está habilitada para recepção de reportes com esses novos campos *additionalInfo*. O prazo para adequação dos participantes, aprovado em conselho, termina no dia 03/06/2024.  Os seis novos campos *additionalInfo* que deverão ser enviados para PCM são:   - *revocationReasonCode*: Código indicador do motivo da revogação - *revocationReasonDetail*: Detalhe sobre motivo de revogação indicado no campo - *revokedBy*: Quem iniciou a solicitação de revogação - *revokedFrom*: Canal onde iniciou-se o processo de revogação - *rejectedBy*: Quem iniciou a solicitação de rejeição - *rejectedFrom*: Canal onde iniciou-se o processo de rejeição   Adicionalmente os campos *rejectionReasonCode* e *rejectionReasonDetail* já existem no contexto de pagamentos e o seu preenchimento se mantém, seguindo as orientações da documentação da PCM. Não haverá novas obrigatoriedades para *server*.  Todos os campos e contextos obrigatórios estão presentes na tabela em Excel listada na documentação da PCM no link abaixo. Dando prosseguimento aos informes 566 (“PCM -  Nova API para reporte do *Hybrid Flow*”, enviado em 16/04/2024) e informe 568 (“Cronograma da *release* 2024-05-06: API *Hybrid Flow* e novos campos *additionalInfo*”, enviado no dia 19/04/2024), comunicamos que, a partir de 06/05/2024 a PCM está habilitada para recepção de reportes na API *Hybrid Flow*.
