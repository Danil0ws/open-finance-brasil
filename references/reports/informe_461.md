# [Open Finance] Informa #461

Lançamento da versão v3.0.0 estável da API de Pagamentos               Informamos que a Área do Desenvolvedor do Portal do Open Finance Brasil foi atualizada no dia 25/09/2023 com a documentação da **versão v3.0.0 estável da API de Pagamentos**.  O *go live* desta API está previsto para 13/10/2023 conforme divulgado no Informa #417 (“Cronograma dos próximos versionamentos *majors* da API de Iniciação de Pagamentos“, publicado em 04/07/2023).     Reforçamos que as principais diferenças entre as versões *major* 2 e 3 da API de Pagamentos são as **validações realizadas durante a etapa do consentimento.** **Tais validações estão descritas no item 5 das validações contidas no *header* da API**. Além disso, **na página do** **d****iagrama de sequência, no tópico “Momentos de validações assíncronas na etapa do consentimento” estão detalhadas** **quais validações deverão ocorrer em cada etapa do consentimento.**     Por último, informamos que o Guia de Experiência do Usuário atualizado para a v3.0.0 da API de Pagamentos deverá ser publicado até 13/10/2023. Por outro lado, reforçamos que **o *Swagger* é a fonte principal de informação sobre a API.**     Para mais detalhes, sugerimos o acesso aos links de documentação abaixo. |

 Lançamento nova versão beta (v1.0.0-beta.1) das APIs Contas, Cartão de crédito, Empréstimos, Financiamentos, Adiantamento a depositantes e Adiantamento de recebíveis da fase 1, em substituição à API Produtos e Serviços               A área do desenvolvedor do portal do Open Finance Brasil foi atualizada hoje (25/09/2023) com a documentação da nova **versão beta v1.0.0-beta.1 das APIs Contas, Cartão de crédito, Empréstimos, Financiamentos, Adiantamento a depositantes e Adiantamento de recebíveis de Dados abertos**.     **Essas novas APIs devem substituir a API Produtos e Serviços e, após o período de convivência**, esta API será descontinuada. Não haverá, portanto, nova versão atualizando a API Produtos e Serviços. Futuros ajustes e melhorias serão realizados apenas nas novas APIs citadas acima.     É imprescindível que as instituições comecem a desenvolver estas APIs a partir do lançamento desta versão (beta) para não prejudicar o período de certificação e *go-live*, conforme cronograma divulgado por meio do Informa #427 (“Cronograma atualizado de Dados Abertos - APIs Produtos e Serviços, Canais de Atendimento, Comuns e Admins ”, publicado em 28/07/2023)**.**      Durante o desenvolvimento dentro das instituições, **poderão ser reportadas à Estrutura melhorias e necessidades de correções destas APIs**. A partir de hoje (25/09/2023), será disponibilizado um **período de consulta ao ecossistema,** que se encerra em 20/10/2023. **Sugestões encaminhadas após o período de consulta não serão consideradas para a versão 1.0.0 (estável) destas APIs.**   - As sugestões devem ser encaminhadas por meio da abertura de ticket no Service Desk, seguindo a opção: **Solicitações de Melhorias > API’s** - Na abertura do ticket, o título deve ser registrado como “**APIs fase 1 – versão beta**” e, no campo descrição, deve ser citado qual é a API (Ex: API Contas), o *endpoint* (Ex: /personal-accounts), o campo e a sugestão de ajuste na documentação - Para que o ticket possa ser considerado para a versão 1.0.0 (versão estável) das APIs Contas, Cartão de crédito, Empréstimos, Financiamentos, Adiantamento a depositantes e Adiantamento de recebíveis, ele deve ser encaminhado até o prazo máximo estabelecido acima. Do contrário, o ticket será adicionado ao *backlog* de ajustes do GT Especificações Dados abertos para uma próxima versão destas APIs |
