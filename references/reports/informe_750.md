# [Open Finance] Informa #750

Orientações para o *onboarding*dos novos entrantes obrigatórios na etapa de compartilhamento de dados Conforme comunicado no Informa #689 (“*Participação como transmissoras na etapa de compartilhamento de dados (Dados do cliente)*”, enviado em 23/01/2025) a obrigatoriedade de participação na etapa de compartilhamento de dados foi ampliada para instituições individuais ou participantes de conglomerado com mais de 5 milhões de clientes e, **a partir de 01/07/2025, novas organizações entrarão nesta etapa**.  Com o objetivo de tornar a entrada em produção fluida, reduzir a volumetria de problemas bilaterais e garantir a entrega de produtos e serviços interoperáveis e sem fricções ao cliente final, as novas transmissoras de dados deverão passar por um processo de *onboarding*da Associação Open Finance,  realizando testes em produção e monitorando diversos indicadores. **A atuação das novas transmissoras de dados como receptoras de dados só está autorizada após conclusão deste processo de *onboarding****.*  Durante este processo, as transmissoras de dados apenas poderão apresentar as novas marcas a partir do cronograma de escalonamento apresentado abaixo. Antes disso, a restrição de marcas seguirá as seguintes regras:   - **Receptoras de dados:**   - Em 01/07/2025, todas as receptoras de dados deverão restringir as novas marcas da lista de transmissoras de dados disponíveis na jornada de compartilhamento de dados;     - A restrição das marcas deverá ocorrer utilizando a *flag*‘EM HOMOLOGACAO (DC)’, que estará disponível no servidor de autorização das novas organizações transmissoras de dados a partir desta data.   - A *flag*poderá ser consultada através da API Participants, no campo “*Flags*”;   - A partir das datas listadas na seção "Cronograma de habilitação de marcas pelas receptoras" (abaixo), a receptora de dados deverá disponibilizar as novas marcas na sua jornada para todos os usuários da sua base. - **Transmissoras de dados:**   - Instituições transmissoras de dados deverão bloquear DCR/DCM de organizações receptoras de dados que realizarem chamadas antes da data de disponibilização do produto.   **Antecipação de testes por receptoras de dados:**  Caso uma receptora de dados deseje realizar testes com os novos entrantes antes da data de habilitação da marca, deverá abrir um ticket para a Associação demonstrando interesse, desenvolver uma solução para habilitação de usuários restritos exclusivamente para fins de testes em produção e contatar o novo entrante de forma bilateral para evitar bloqueio de chamadas.  A antecipação da disponibilização das novas marcas para o público geral é vedada em qualquer cenário.    **Indicadores monitorados durante o piloto (transmissoras de dados):**   - **Publicação das APIs de Dados abertos e Dados do cliente:**   - Em 01/07/2025, as organizações deverão habilitar o papel regulatório ‘DADOS’ e realizar a publicação das APIs relativas aos produtos que ofertarem;   - As instituições deverão habilitar a *flag*‘EM HOMOLOGACAO (DC)’ em todos os servidores de autorização em que houver a publicação de APIs de compartilhamento de dados;     - A *flag*será retirada pela Associação Open Finance após atingimento do sucesso em todos os indicadores monitorados ao final do processo de *onboarding.* - **Comportamento funcional (FVP):**   - Entre 02/07/2025 e 11/07/2025, as novas transmissoras de dados deverão obter sucesso no teste fvp-customer\_data\_unique\_happy\_path\_test-module para todos os seus servidores de autorização, PF e PJ (quando aplicável);   - A instituição deverá ter usuários testadores que possuam todos os recursos disponíveis contratados, mesmo que não seja o mesmo usuário. Ou seja, todo produto ofertado pela instituição deve ser testado com sucesso pela FVP. - **Integração com as ferramentas do perímetro central:**   - PCM: As instituições devem parear o mínimo de 95% das chamadas realizadas no período, com envio de todos os additionalInfos necessários;   - MQD: Conforme divulgado no Informa #742 (“*Qualidade de Dados – Adoção obrigatória do MQD por novos conglomerados*”, enviado em 19/05/2025), C6, Inter e Pagseguro deverão realizar a integração com o motor de qualidade de dados até 01/07/2025. - **Engajamento:**   - Entre 14/07/2025 e 15/08/2025, as instituições transmissoras de dados deverão realizar 100 consentimentos únicos com 10 receptoras diferentes;   - Os consentimentos únicos devem ser atingidos desde a primeira semana de habilitação das marcas pelas receptoras de dados, seguindo os marcos abaixo:     - 18/07: Mínimo de 10 consentimentos;     - 25/07: Mínimo de 30 consentimentos;     - 01/08: Mínimo de 50 consentimentos;     - 08/08: Mínimo de 70 consentimentos;     - 15/09: Mínimo de 100 consentimentos. - **Tickets bilaterais:**   - Nenhum ticket bilateral crítico deve estar em aberto na data de conclusão do processo de *onboarding,*em 29/08/2025.  **Cronograma de habilitação de marcas pelas receptoras:   Imagem do cronograma de disponibilização escalonada de novas marcas transmissoras para instituições receptoras, vinculada ao Open Finance Brasil. O plano determina que todas as receptoras deverão restringir as novas marcas na primeira semana, com início da disponibilização escalonada a partir de 9 de julho. No topo, em letras grandes e marrons, está o título: “Todas as receptoras deverão restringir as novas marcas na primeira semana – disponibilização ocorrerá de forma escalonada a partir de 09/07”. À esquerda, há um bloco de texto com o título “Premissas” em azul claro e os seguintes tópicos: 1) Instituições receptoras devem restringir da lista de transmissores disponíveis para jornada de compartilhamento de dados os servidores de autorização que possuírem a flag EM HOMOLOGAÇÃO em 01/07; 2) A disponibilização das novas marcas transmissoras ocorrerá de forma escalonada por grupos de receptoras; 3) Os grupos foram definidos com base nos critérios: classificação decrescente das receptoras com base no estoque de consentimentos e participação de pelo menos uma instituição consumidora de dados de grande porte em todos os grupos; 4) Instituições transmissoras deverão realizar testes com a FVP na primeira semana e atingir marcos semanais de consentimento com as receptoras a partir da disponibilização de suas marcas; 5) DCR/DCM de receptoras que realizarem chamadas antes da data de disponibilização da marca deverão ser bloqueados.
