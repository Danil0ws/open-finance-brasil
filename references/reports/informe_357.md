# [Open Finance] Informa #357

Disponibilização de testes do motor de conformidade funcional da API de Payments v2.0.0 para o fluxo client credentials      Conforme Informa #352 (“Atualização de testes do motor de conformidade funcional da API de Payments v2.0.0 para o fluxo client credentials”, enviado em 04/04/2023), três módulos de testes da API de iniciação de pagamentos v2.0 foram atualizados e estão disponíveis para testes no motor de conformidade.     O objetivo, também disponível neste mesmo informa, é verificar se as detentoras de conta estão aderentes à especificação para o fluxo via client credentials conforme política atualizada.     Os módulos são:  - payments-pixscheduling-patch-iniciadora-v2 - payments-pixscheduling-patch-unhappy-v2 - payments-contenttype-jwt-refreshtoken-v2    **O cronograma de execução dos testes no motor de conformidade (ambiente sandbox) é:**   - **Até 10/04/2023:** Disponibilização dos testes - **Até 17/04/2023:** Execução dos testes por todas as detentoras de conta - **Até 24/04/2023:** Execução com sucesso dos testes por todas as detentoras    **Não será necessário o envio de logs através de tickets no service desk.**      **Solicitamos atenção ao preenchimento do campo organisation ID, de acordo com Informa #356, pois este será utilizado para contabilização do sucesso.**     Relembramos que a exclusão do modelo de segurança access\_token terá testes funcionais, a serem publicados pelo Squad Sandbox e com orientação das datas de execução pelas instituições publicada em um Informe posteriormente.     Problemas ou inconsistências identificadas devem ser notificadas preferencialmente através do repositório no GitLab no link abaixo, para evitar duplicação dos temas. Tickets abertos através da plataforma do Service Desk continuarão sendo tratados. |
