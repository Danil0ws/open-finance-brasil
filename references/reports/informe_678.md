# [Open Finance] Informa #678

Disponibilização do motor beta.2 da API Pagamentos automáticos v2.0.0 Informamos que o motor de conformidade da API Pagamentos automáticos v2.0.0 beta.2 foi disponibilizado com alteração relevante nos módulos de Pix automático e Transferências inteligentes, adição de módulos de edição de consentimentos e disponibilização do plano de testes auxiliar para os módulos de retentativas.    Em 02/01/2025 haverá uma segunda entrega do motor beta.2, com a inclusão do plano de testes principal com os módulos de retentativas.    Conforme comunicado no Informa #661 (“Novo cronograma de implementação da v2.0.0 da API Pagamentos automáticos (Transferências inteligentes + Pix automático)”, enviado em 14/11/2024), o marco de 50% da API Pagamentos automáticos v2.0.0 ocorrerá na versão beta.2 do motor de conformidade. As orientações para execução com sucesso do marco podem ser consultadas no Informa #671 (“Alteração dos testes para o motor beta.2 da API Pagamentos automáticos v2.0.0”, enviado em 10/12/2024). |
