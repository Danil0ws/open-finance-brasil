# [Open Finance] Informa #801

Alteração no marco A da API Vínculo de Dispositivo v2.2.0 e API Webhook v1.3.0  Informamos que o marco A, previsto para 21/10/2025, das API Vínculo de Dispositivo v2.2.0 e Webhook v1.3.0 será ajustado em relação ao originalmente divulgado no Informa #793 (“*Marco A da API Vínculo de dispositivo v2.2.0 e API Webhook v1.3.0*”, publicado em 02/10/2025).     O seguinte módulo de teste **não será mais cobrado das instituições** para o sucesso no marco A:  - enrollments\_api\_max-challenges\_test-module\_v2-2.    As demais instruções, prazos e objetivos descritos no Informa #793 permanecem inalterados, devendo as instituições obter sucesso nos seguintes módulos de teste:  - enrollments\_api\_rejected-holder-mismatch\_test-module\_v2-2;  - enrollments\_api\_missing-required-risk-signals\_test-module\_v2-2;  - enrollments\_automatic-payments\_authorised-executed-scheduled-successfully\_v2-2.    As instituições que não obtiverem sucesso nos 3 (três) módulos acima até a data do marco A serão notificadas via tickets do Service Desk. |
