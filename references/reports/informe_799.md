# [Open Finance] Informa #799

LEMBRETE – Marco A da API Vínculo de dispositivo v2.2.0 e API Webhook v1.3.0    Reforçamos que, conforme compartilhado no Informa #793 (“*Marco A da API Vínculo de dispositivo v2.2.0 e API Webhook v1.3.0**​*”, publicado em 02/10/2025), **o marco A da Jornada sem redirecionamento (JSR)** (API Vínculo de dispositivo v2.2.0 e API Webhook v1.3.0)**ocorrerá em 21/10/2025.**    Para este marco, será utilizada a versão rc.2 do motor de conformidade, cujos testes podem ser consultados na página do plano de testes desta API. Para contabilização de sucesso, as instituições detentoras de conta devem obter sucesso nos seguintes testes obrigatórios:  - ***enrollments\_api\_max-challenges\_test-module\_v2-2;*** - ***enrollments\_api\_rejected-holder-mismatch\_test-module\_v2-2;*** - ***enrollments\_api\_missing-required-risk-signals\_test-module\_v2-2;*** - ***enrollments\_automatic-payments\_authorised-executed-scheduled-successfully\_v2-2.***  Neste marco não foi selecionado nenhum módulo da API de Webhook.    **Este marco é obrigatório para instituições que já operam JSR e para os novos entrantes (detentoras de conta obrigatórias no arranjo Pix).**    Caso a instituição não seja obrigatória no Pix e ainda não tenha solicitado dispensa, poderá encaminhar solicitação de dispensa do desenvolvimento deste produto para a Associação Open Finance mediante abertura de chamado no Service Desk na seguinte categoria:  - Solicitação de informação > Conformidade > Política de conformidade.  Ressaltamos que as instituições que não atingirem sucesso no marco conforme o esperado serão notificadas via tickets do Service Desk. |
