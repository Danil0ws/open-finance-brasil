# [Open Finance] Informa #896

Go Live da API Pagamentos v5.0.0 e disponibilização da funcionalidade Pix Saque |

 Informamos que o plano payments-withdraw-qres\_test-plan\_v5 será temporariamente**removido** do processo de certificação da API Pagamentos v5.0.0.  Serão realizados ajustes no referido plano e, após a conclusão das correções, será solicitada uma nova execução do plano pelas instituições participantes.  Dessa forma, até a conclusão dos ajustes necessários do plano e comunicação ao ecossistema, a funcionalidade Pix Saque não deverá ser disponibilizada em ambiente de produção para transações com data.purpose = WITHDRAW pelas instituições.  Esclarecemos que as demais datas previstas no cronograma **permanecem inalteradas:**   - 20/05/2026: Publicação da API Pagamentos v5.0.0 no Diretório;  - 21/05/2026: Go live da nova versão da API;  - 21/05/2026 a 20/08/2026: Período de convivência entre as versões v4.0.0 e v5.0.0 da API Pagamentos.   **Marcos para ITP**   - 10/06/2026 - Migração chamadas 10% - 10/07/2026 - Migração chamadas 50% - 10/08/2026 - Migração chamadas 100%   **Observação**  As instituições que já tiverem criado ou executado o plano payments-withdraw-qres\_test-plan\_v5, independentemente do resultado obtido, não serão prejudicadas durante este período de ajuste. Novas orientações sobre a reexecução do plano serão comunicadas posteriormente. |
