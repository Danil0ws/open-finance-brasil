# [Open Finance] Informa #348

PCM – Alertas     1. **Ambiente de sandbox:**  - O ambiente de sandbox não deve ser acoplado para envio de dados de produção. - Seu uso deve limitar-se a execução de testes funcionais de integração após os quais o consumo do ambiente deve ser encerrado.  1. **Uso incorreto do x-fapi-interaction-id:**  - Detectamos pelos reportes que alguns participantes não estão seguindo a especificação relativa ao cabeçalho x-fapi-interaction-id. - Um x-fapi-interaction-id refere-se a uma interação entre um *CLIENT* e um *SERVER* em uma requisição, ou seja, para cada *request* deve haver um *response* e apenas um com o mesmo x-fapi-interaction-id, e para cada *request* diferente, mesmo que para o mesmo objeto, deve haver um x-fapi-interaction-id diferente. - Do ponto de vista prático isso significa que um x-fapi-interaction-id deve identificar globalmente uma conversa entre um *CLIENT* e um *SERVER*, que se inicia com um *request* específico e termina com o *response* a este *request.* |
