# [Open Finance] Informa #270

Cronograma de certificação da API de Pagamentos v2.0.0 Como parte do processo de certificação e publicação da API de Pagamentos v2.0.0, o Squad Sandbox divulga o cronograma de entregas e ações que as detentoras de conta deverão cumprir.     Foram estipuladas datas intermediárias de testes que as instituições devem obrigatoriamente atender, com condições estabelecidas de taxa de sucesso no plano de testes. O objetivo desses marcos é garantir a maturidade do motor de conformidade funcional para essa certificação.   - **30/10/2022 - 02/12/2022:** Desenvolvimento do motor de testes (funcionais) para as versões 2.0.0 das APIs - **03/12/2022 - 1****3****/01/2023:** Período de testes do motor e correção de *bugs*   - **20/12/2022**: Data limite para execução com sucesso em 30% dos módulos   - **05/01/2023:** Data limite para execução com sucesso em 50% dos módulos   - **13/01/2023:** Data limite para execução com sucesso em 90% dos módulos, incluindo todos os módulos críticos - **13/01/2023 - 01/02/2023**: Período de envio de pedidos certificação funcional V2.0.0.   - Não há garantias de que pedidos de certificação enviados após 01/02/2023 serão processados antes do *go live* - **02/02/2023 - 15/02/2023**: Período de processamento de certificação funcional V2.0.0 - **15/02/2023: *Go live*** – data limite para publicação dos *endpoints* da nova versão da API no Diretório |

 Atualização da cartilha do processo de *onboarding* de ITPs Informamos às detentoras e iniciadoras que a Cartilha de *Onboarding* de instituição Iniciadora de Transação de Pagamento (ITP) foi atualizada para sua 12ª versão. Detalhes dos versionamentos podem ser encontrados na página 23.     Foram atualizadas as regras para pareamento de detentoras (pg. 3) e incluídas clarificações sobre o procedimento de geração de evidências pela ITP (pg. 17).    Para maiores informações, os participantes podem acessar a cartilha. |
