# [Open Finance] Informa #754

LEMBRETE – *Go live* da v1.0.2 da API Títulos do tesouro direto Informamos que, conforme compartilhado no Informa #746 (“*Dados do cliente – Lançamento da versão patch da API Títulos do tesouro direto (v1.0.2)*”, divulgado em 30/05/2025), em 23/06/2025, entre 00:00 e 23:59, as instituições deverão atualizar a versão da API Títulos do tesouro direto v1.0.2 no Diretório de participantes.    O motor de conformidade foi atualizado para a API e, embora a recertificação não seja necessária, as instituições que realizarem alterações em suas implementações deverão realizar testes no motor antes da publicação em produção. |
