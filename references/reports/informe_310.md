# [Open Finance] Informa #310

Fase 3 – Atualização da lista de problemas conhecidos   O Grupo Técnico de Especificações Serviços comunica que foi adicionado um item à lista de problemas conhecidos da fase 3 conforme segue:     - **BCLOG-F03-V02-007**   - **API/Sessão:** API Payments   - **Endpoints:** GET/consents e POST/consents   - **Campo:** /data/creditor/name   - **Qual o problema:** O *pattern* do referido campo foi padronizado conforme a especificação do campo equivalente no arranjo do Pix. Contudo, neste arranjo, há dois campos para informar o nome do credor: um para pessoa natural e outro para pessoa jurídica, sendo que este de pessoa jurídica é mais abrangente em relação aos caracteres aceitos. Além disso, quando foi construída essa versão da API, foi adotado o *pattern* mais restritivo de pessoa natural, o que está impedindo que o crédito seja realizado para empresas que possuam alguns tipos de caracteres em seu nome   - **Como deveria ser:** Deve ser adotado o *pattern* mais abrangente de pessoa jurídica   - **Orientação:** Adotar o *pattern* de pessoa jurídica:     - ^([A-Za-zÀ-ÖØ-öø-ÿ,.@:&\*+\_<>()!?/\\$%\d' -]+)$ |
