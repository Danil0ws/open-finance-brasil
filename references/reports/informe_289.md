# [Open Finance] Informa #289

Importante: prazos regulatórios para adesão ao motor de conformidade funcional da API de Pagamentos v2.0.0     Reforçamos a necessidade das detentoras de conta atenderem os marcos regulatórios definidos na IN 326, com prazos para a adesão ao motor de conformidade funcional da API de Pagamentos v2.0.0.     Para 20/12/2022, era esperado que todas as detentoras de conta que oferecem Pix tivessem **sucesso em 30% dos módulos de testes**. Para as instituições que **não atingiram esse marco**, pedimos que se ajustem o mais breve possível.     **O próximo marco é 05/01/2023, no qual é esperado que todas as detentoras de conta que oferecem Pix tenham sucesso em 50% dos módulos de testes.**    As execuções com sucesso nos testes são fundamentais para que o motor de conformidade funcional atinja a maturidade dentro do prazo esperado para o *go live* da API de Pagamentos v2.0.0. |

 Liberação do mock bank e dos testes condicionais de múltiplas alçadas e temporização   O Mock Bank foi atualizado para a API de Pagamentos v2.0.0 e a documentação pode ser acessada no link abaixo.     Além disso, o motor de conformidade funcional da API de Pagamentos v2.0.0 foi atualizado para disponibilizar **testes condicionais de múltiplas alçadas e temporização**.    Esses testes são **obrigatórios** para a certificação de todas as instituições que possuem essas funcionalidades implementadas e poderão ser considerados nas taxas de sucesso esperadas pela IN 326. |
