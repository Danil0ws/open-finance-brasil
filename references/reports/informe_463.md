# [Open Finance] Informa #463

Adição de orientações para a API de Investimentos de Dados abertos na área do desenvolvedor                Informamos que a **área do desenvolvedor do portal do Open Finance Brasil foi atualizada com a adição de duas subseções na seção de “Orientações” da API de Investimentos de Dados abertos** (fase 4A). Abaixo, seguem os títulos e descrições acrescentadas:   - **Produtos de Investimentos**    Para os produtos de investimentos da fase 4A, não há necessidade de compartilhamento de dados referentes ao mercado secundário, conforme orientação do Banco Central ao final de 2021. Permanecendo válido para o último versionamento realizado em 30/04/2023 nessa API. - **Renda variável**    A tabela abaixo delimita o escopo dos endpoints de Renda Variável. |

 Esse ajuste surgiu em decorrência de questionamentos recorrentes sobre o compartilhamento de dados a respeito do mercado secundário, recebidos via tickets do Service Desk. |
