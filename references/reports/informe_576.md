# [Open Finance] Informa #576

Lançamento das versões *minor* das APIs Contas (v2.4.0-beta.1) e Dados cadastrais (v2.1.0-beta.1) Informamos que a área do desenvolvedor do Portal do Open Finance Brasil foi atualizada, em 06/05/2024, com a documentação das versões *minor* das APIs Contas (v2.4.0-beta.1) e Dados cadastrais (v2.1.0-beta.1).   - As documentações das APIs passaram pelas seguintes alterações:   - API Dados cadastrais:     - Inclusão de dados do empregador;     - Ajuste do *pattern* do campo e-mail;     - Correção dos problemas conhecidos: BCLOG-F02-198, BCLOG-F02-219, BCLOG-F02-220 e BCLOG-F02-223;     - Ajuste na obrigatoriedade e descrição do parâmetro x-fapi-interaction-id.   - API Contas:     - Inclusão de dados do empregador.  - Informações sobre o período de certificação e data de *go live* dessas APIs estão em avaliação e serão compartilhadas posteriormente.    Para mais detalhes, sugerimos acessar os links de documentação abaixo. |

 Tombamento do conteúdo do Guia de implementação da versão 2.0 das APIs de Dados Cadastrais e Transacionais Comunicamos que o conteúdo do Guia de implementação da versão 2.0 das APIs de Dados Cadastrais e Transacionais foi atualizado e incorporado dentro das páginas de orientações de cada uma das APIs as quais fazia referência.   - O Guia, anteriormente presente na área do desenvolvedor na seção “Diretrizes Técnicas e Operacionais”, foi transposto para a seção “Histórico de alterações”.  Reforçamos que o Guia de implementação não deve ser mais utilizado como fonte de informação para implementação das APIs e a sua presença na seção de “Histórico de alterações” é apenas para manter a rastreabilidade do que foi desenvolvido no passado. |
