# [Open Finance] Informa #384

Atualização do cronograma das APIs de Investimentos, Consents e Resources da fase 4B (dados do cliente)                Conforme cronograma apresentado pelo Banco Central na 163ª reunião do Conselho Deliberativo em 11/05/2023, a priorização será nas APIs de Investimento, enquanto o *go live* das APIs de Câmbio e Credenciamento da fase 4B foi suspenso e novas datas serão disponibilizadas posteriormente.  Com isso, o cronograma das APIs de Investimento, Consents e Resources, divulgado no Informa #340, foi atualizado com as seguintes datas:  - **13/03/2023 a 27/07/2023**: Envio de tickets ao GT Especificações com sugestões de ajustes na documentação   - As sugestões devem ser encaminhadas por meio da abertura de um ticket no Service Desk, seguindo a opção: **Solicitações de Melhorias > APIs**;   - Na abertura do ticket, o título deve ser registrado como “**Fase 4B – Release candidate**” e no campo descrição deve ser citado qual é a API (Ex: API Fundos de Investimento), endpoint, campo e sugestão de ajuste na documentação - **09/08/2023**: Publicação da versão estável das APIs - Data dos marcos de sucesso nos testes:   - **07/07/2023** - 0% - execução obrigatória dos testes das APIs de Investimentos, Consents e Resources, sem necessidade de sucesso   - **26/07/2023** - Data limite para execução com sucesso de 25% dos módulos   - **09/08/2023** - Data limite para execução com sucesso de 50% dos módulos   - **23/08/2023** - Data limite para execução com sucesso de 75% dos módulos   - **07/09/2023** - Data limite para execução com sucesso de 100% dos módulos - **08/09/2023 – 14/09/2023**: Submissão de pedidos de certificação no service desk - **15/09/2023 – 28/09/2023**: Processamento de certificações - **29/09/2023**: ***Go-live*** |
