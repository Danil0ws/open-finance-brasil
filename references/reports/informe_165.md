# [Open Finance] Informa #165

Service Desk - Nova Estrutura da Categoria Incidentes > API  Informamos que será feita uma remodelagem na estrutura da categoria Incidentes > API do Service Desk.  A nova estrutura estará disponível a partir do dia 03/06/2022 em ambiente de Produção.    A remodelagem da estrutura tem como objetivo guiar o requisitante no processo de abertura do ticket, permitindo que ele selecione a categoria específica da jornada em que o erro está ocorrendo e insira todas as informações necessárias para o seu atendimento.  Assim, proporcionando uma maior agilidade e precisão na atuação das equipes de atendimento N2.    Estrutura dos menus para abertura dos tickets:      Os novos formulários para a abertura de incidentes possuem campos específicos de cada categoria, sendo necessário o preenchimento dos campos obrigatórios para o encaminhamento para a equipe técnica.    Para consultar as informações adicionais sobre os campos personalizados que serão adicionados os novos formulários, acesse os artigos que estarão disponíveis na [FAQ](https://servicedesk.openbankingbrasil.org.br/KBFAQTree.jsp): API SYSAID > Formulários Customizados.    Estrutura da nova categoria no catálogo de serviços:      Para o esclarecimento de dúvidas referentes à remodelagem na estrutura da categoria Incidentes > API, abra um chamado na plataforma do [Service Desk](https://servicedesk.openbankingbrasil.org.br/). |
