# [Open Finance] Informa #752

Release 2025A1 Extraordinária na PCM – Término do Período de Implementação das Instituições Informamos o término do período de implementação das Instituições referente a Release Extraordinária da PCM, conforme Informa #731 (“*Release 2025A1 – Extraordinária – Término do Período de Implementação da PCM*”, divulgado em 29/04/2025).    Funcionalidades:   - Nova API de Dados Relativos à Quantidade de Consentimentos Ativos e Únicos por clientes, conforme cronograma divulgado no Informa #723 ("*Release Extraordinária 2025-A1 – Dados relativos à quantidade de consentimentos ativos e únicos por clientes*", divulgado em 09/04/2025).   - **A partir de 14/06/2025, o não envio dos dados poderá resultar em notificações através do Service Desk**, onde as instituições deverão tomar as devidas providências para corrigir as não conformidades identificadas. - Chamada da Private API (GET) via FapiInteractionId: Com o cumprimento do período de adequação das instituições, a chamada via ReportId será descontinuada, permanecendo apenas o acesso via FapiInteractionId. |

 LEMBRETE – *Go live* da v2.1.0 da API Pagamentos automáticos Informamos que, conforme compartilhado no Informa #712 (“*Esclarecimento sobre as datas de go live das funcionalidades da API Pagamentos automáticos*”, divulgado em 20/03/2025), o *go live* da API Pagamentos automáticos v2.1.0 ocorrerá em**16/06/2025**. |

 Atualização dos limites operacionais das APIs de Dados do cliente Informamos que, em função da alteração estabelecida pela Instrução Normativa BCB nº 615, divulgada pelo Banco Central em 06/05/2025, a partir de 13/06/2025, os valores de tráfego e limite operacional das APIs de Dados do cliente foram atualizados na página “Referência” da área do desenvolvedor no Portal do Open Finance Brasil.    Destacamos os seguintes módulos impactados:   - API Câmbio   - *exchange\_api\_operational-limits\_test-module* - API Cartão de Crédito   - *credit-cards\_api\_operational-limits\_test-module\_v2-1* - API Contas   - *accounts\_api\_operational-limits\_test-module\_v2-4* - API Dados Cadastrais   - *customer-personal\_api\_operational-limits\_test-module\_v2-2*   - *customer-business\_api\_operational-limits\_test-module\_v2-2* - API Fundos de Investimento   - *funds\_api\_operational-limits\_test-module* - API Operações de Crédito – Adiantamento a Depositantes   - *unarranged-accounts-overdraft\_api\_operational-limits\_test-module\_V2-4* - API Operações de Crédito - Direitos Creditórios Descontados   - *invoice-financings\_api\_operational-limits\_test-module\_v2-3* - API Operações de Crédito - Empréstimos   - *loans\_api\_operational-limits\_test-module\_v2-4* - API Operações de Crédito - Financiamentos   - *financings\_api\_operational-limits\_test-module\_v2-3* - API Renda Fixa Bancária   - *bank-fixed-incomes\_api\_operational-limits\_test-module\_v1* - API Renda Fixa Crédito   - *credit-fixed-incomes\_api\_operational-limits\_test-module\_v1* - API Renda Variável   - *variable-incomes\_api\_operational-limits\_test-module\_v1-2-1* - API Títulos do Tesouro Direto   - *treasure-title\_api\_operational-limits\_test-module*  Além disso, informamos que o motor de conformidade foi atualizado para essas APIs e reforçamos que não será necessária recertificação. Instituições que realizarem alterações em suas implementações deverão realizar testes no motor de conformidade antes da publicação em produção.    Recomenda-se a execução dos testes pelas instituições até **01/07/2025**, seguindo as novas orientações de tráfego e limite operacional. |
