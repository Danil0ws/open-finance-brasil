# [Open Finance] Informa #735

API Pagamentos Automáticos – Complemento aos cenários de retrocompatibilidade    Informamos que, para a API Pagamentos Automáticos v2.1.0, além das informações de retrocompatibilidade já comunicadas no Informa #726 (*“Transferências Inteligentes – Cronograma de implementação da v2.1.0 (minor) da API Pagamentos Automáticos”*, enviado em 16/04/2025), foram incluídos novos tratamentos para situações em que recursos são consultados utilizando versões incompatíveis da API — por exemplo, quando um consentimento criado na v2.1.0 é consultado por meio da v1.0.0.     Solicitamos que as instituições leiam atentamente o conteúdo do tópico **["Orientações Gerais"](https://bra01.safelinks.protection.outlook.com/?url=https%3A%2F%2Fopenfinancebrasil.atlassian.net%2Fwiki%2Fspaces%2FOF%2Fpages%2F920453156%2FAdapta%2Bes%2Bpara%2Bconsultas%2Bde%2Brecursos%2Bentre%2Bas%2Bvers%2Bes%2B1.0.0%2Be%2B2.0.0%2Bou%2Bsuperiores%2Bda%2BAPI%2BPagamentos%2BAutom%2Bticos%23Orienta%25C3%25A7%25C3%25B5es-Gerais&data=05%7C02%7Cgabriela.lettieri%40chicagoadvisory.com.br%7Cf779ea6defd84c2a4c1408dd8cb046dc%7C7531e8b3c928494b9b897ee3d353272d%7C0%7C0%7C638821411233514290%7CUnknown%7CTWFpbGZsb3d8eyJFbXB0eU1hcGkiOnRydWUsIlYiOiIwLjAuMDAwMCIsIlAiOiJXaW4zMiIsIkFOIjoiTWFpbCIsIldUIjoyfQ%3D%3D%7C0%7C%7C%7C&sdata=YEKluL2f18Io9PIc3WbWZZhtGluboJC07vke4Q0wUAI%3D&reserved=0)**, disponível no link abaixo, e atualizem seus tratamentos conforme os cenários descritos:  - Especificações de APIs > Serviços - SV > [SV] Iniciação de Pagamentos > [SV] API – Pagamentos Automáticos > v2.0.0 - [SV] Pagamentos Automáticos > Informações Gerais - [SV] Pagamentos Automáticos - v2.0.0 > Adaptações para consultas de recursos entre as versões 1.0.0 e 2.1.0 ou superiores da API Pagamentos Automáticos. |
