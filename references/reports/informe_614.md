# [Open Finance] Informa #614

Lançamento das versões estáveis das APIs Contas (v2.4.0) e Dados cadastrais (v2.1.0) Informamos que a área do desenvolvedor do Portal do Open Finance Brasil foi atualizada, em 02/08/2024, com a documentação das versões estáveis das APIs Contas (v2.4.0) e Dados cadastrais (v2.1.0).  Não houve alterações entre a última versão release candidate e a versão estável destas APIs.  O *go live* para essas APIs se mantém em 15/08/2024, conforme informe #582 (“Divulgação do cronograma de dados do empregador e resolução de problemas conhecidos das APIs Dados Cadastrais e Contas”, enviado em 22/05/2024).   - Reforçamos que o reprocessamento do histórico do campo partieCnpjCpf (API Contas) não será obrigatório, o envio das informações do empregador só será esperado para transações a partir do *go live* (15/08/2024)    Para mais detalhes sobre o cronograma de implementação e sobre as especificações, sugerimos acessar os links de documentação abaixo. |

 Lançamento da versão beta (v2.0.0-beta.1) da API Vínculo de dispositivo   Informamos que a área do desenvolvedor do Portal Open Finance Brasil foi atualizada no dia 02/08/2024 com a documentação da nova versão 2.0.0-beta.1 da API de Vínculo de dispositivo.      É imprescindível que as instituições comecem a desenvolver esta API imediatamente para não prejudicar o período de certificação e piloto, em 14/11/2024, conforme o cronograma divulgado no Informa #610 (“Divulgação do cronograma de implementação da jornada sem redirecionamento”, enviado em 29/07/2024).      Durante o desenvolvimento nas instituições, poderão ser reportadas à Estrutura melhorias e necessidades de correções desta API. A partir de 02/08/2024, será disponibilizado um período de consulta ao ecossistema, que se encerra em 10/09/2024. Sugestões encaminhadas após o período de consulta não serão consideradas para este versionamento. As sugestões devem ser encaminhadas por meio da abertura de ticket no Service Desk, seguindo a opção: Solicitações de Melhorias > APIs. |
