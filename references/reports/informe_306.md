# [Open Finance] Informa #306

Retrocompatibilidade entre v1 e v2 da API de Iniciação de Pagamentos O GT de Especificações Serviços esclarece que, devido ao versionamento da API de Iniciação de Pagamentos da versão 1.2.0 para a 2.0.0, todos participantes devem observar que:   - Não é permitido que uma transação de pagamento seja iniciada usando o *endpoint* POST /consents da versão 1.2.0 e finalizada com o *endpoint* POST /pix/payments da versão 2.0.0;   - Neste caso, o código de erro a ser retornado deverá ser o 422, code: PAGAMENTO\_RECUSADO\_DETENTORA, detail: tentativa de pagamento com versão divergente do *endpoint* de consentimento. - Não é permitido que uma transação de pagamento seja iniciada usando o *endpoint* POST /consents da versão 2.0.0 e finalizada com o *endpoint* POST /pix/payments da versão 1.2.0;   - Neste caso,  o código de erro a ser retornado deverá ser o 422, code: NAO\_INFORMADO. - Não é permitido que um pagamento que foi agendado utilizando os *endpoints* da versão 2.0.0 seja consultado usando o *endpoint* GET/pix/payment/{paymentId} da versão 1.2.0, visto que essa especificação antiga não prevê o agendamento.  Lembramos que os pagamentos liquidados usando a versão 1.2.0 devem continuar sendo consultados através da nova versão 2.0.0.
