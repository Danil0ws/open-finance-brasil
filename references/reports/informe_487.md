# [Open Finance] Informa #487

Exceção do Período de convivência da API Admin Informamos que não haverá período de convivência entre a v1.0.0 e a v2.0.0 da API Admin, de modo que as instituições não precisarão manter as duas versões disponíveis pelo prazo de 90 dias para consumo.     Por se tratar de uma nova versão da API em que houve alterações no formato de cálculo, as métricas expostas na nova versão serão consideradas após o *go-live*.     O *go-live* da versão v2.0.0 se mantém programado para 17/11/2023. |
