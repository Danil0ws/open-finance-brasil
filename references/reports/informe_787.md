# [Open Finance] Informa #787

Publicação da especificação beta.1 das APIs Consentimento, Dados Cadastrais, Cambio, Cartões e Contas   Informamos que a área do desenvolvedor do Portal do Open Finance Brasil foi atualizada, em 15/09/2025, com as documentações das versões beta.1 das seguintes APIs:   - API Câmbio (v1.1.0-beta.1); - API Cartão de crédito (v2.4.0-beta.1); - API Consentimento (v3.3.0-beta.1); - API Contas (v2.5.0-beta.1); e - API Dados cadastrais (v2.3.0-beta.1).  Dentre as alterações, destacamos:  - Novo padrão de CNPJ; - API Contas: novo *endpoint* para compartilhamento de reserva de saldo (GET /accounts/{accountId}/reserved\_balances); - Ajustes de baixo impacto referentes aos versionamentos de baixa relevância.   **Os cronogramas de certificação e implementação dessas APIs serão divulgados posteriormente.**    Para acessar todas as alterações e mais detalhes, sugerimos acessar os links de documentação abaixo: |
