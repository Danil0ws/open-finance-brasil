# [Open Finance] Informa #628

LEMBRETE - Execução obrigatória FVP Manual Testes Abertos O próximo ciclo de execuções dos testes abertos na FVP Manual iniciará na segunda-feira, 02/09/2024, e finalizará no dia 22/09/2024.    Conforme comunicado no Informa #572 ('Novo modelo de execução da FVP (3.0)'), enviado em 30/04/2024, as instituições em que o fornecedor que realiza os testes restritos da FVP Manual não possui conta aberta devem realizar os testes abertos da FVP Manual para todos os seus servidores PF e PJ (quando aplicável), ao longo de três semanas e a cada dois meses, conforme o cronograma de execução abaixo: |

 Os módulos que essas instituições deverão executar manualmente são:   1. Participantes de Fase 2:    1. Plano de teste: *Production Functional Tests for Consents and Resources API - API Version 2.0.1*    2. Módulos de teste:       1. *fvp-preflight-check-test-v3*       2. *resources\_api\_core\_test-module\_v3* 2. Participantes de Fase 3:    1. Plano de teste: *Production Functional Tests for Payments API - API Version 3.0.0*    2. Módulos de teste:       1. *fvp-preflight-cert-check-payments-test-v4*       2. *fvp-payments-consents-core-test-v4*   O status de abertura de contas pelo fornecedor pode ser conferido através da aba “Parâmetros – FVP” no dashboard de certificação.  Em caso de dúvidas, a instituição pode consultar o “Guia de Operação da Ferramenta de Validação em Produção” disponível no Portal do Desenvolvedor. |
