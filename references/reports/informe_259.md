# [Open Finance] Informa #259

Prazo para abertura de tickets da v1.x das APIs de Dados Cadastrais e Transacionais A partir de 30/10/2022, não poderão mais ser abertos tickets referentes à v1.x das APIs de Dados Cadastrais e Transacionais para os grupos técnicos da convenção, exceto quando houver relação com eventuais problemas de segurança, que poderão ser abertos até 22/02/2023.    Com relação aos tickets bilaterais, estes poderão ser abertos até 22/02/2023.    Sugestões de melhorias das APIs de Dados Cadastrais e Transacionais deverão ser realizadas em relação a versão corrente 2.0.1. |
