# [Open Finance] Informa #324

Orientações para o *go live* da API de Iniciação de Pagamentos v2.0.0  Os participantes do Open Finance que atuam como detentores de conta deverão disponibilizar em produção (*go live*) a versão 2.0.0 da API de Iniciação de Pagamentos às 00:00 do dia 15/02/2023.     Orientações sobre a publicação estão no Guia Operacional do Diretório (capítulo 8). Para essa certificação, a extensão do link da certificação que deve ser declarado na API é .json, ao invés de .zip. Este link será informado através do ticket do pedido de submissão de certificação no service desk e está em um repositório privado do Github, portanto, aparecerá erro 404 ao tentar acessá-lo.     Além disso, é necessário manter a versão 1.2.0 durante o período de convivência (entre as 00:00 do dia 15/02/2023 e as 23:59 do dia 16/05/2023). Maiores informações estão disponíveis nos Informas #272 (“Lançamento da versão 2.0.0 da API de Iniciação de Pagamentos”, enviado em 18/11/2022), #306 (“Retrocompatibilidade entre v1 e v2 da API de Iniciação de Pagamentos”, enviado em 20/01/2023) e #322 (“ERRATA - Retrocompatibilidade entre v1 e v2 da API de Iniciação de Pagamentos”, enviado em 13/02/2023).     Para maiores informações sobre quais versões os novos participantes devem implementar, favor consultar o Informa **#303** (“Orientação de quais versões os novos participantes devem implementar”, enviado em 18/01/2023). |
