# [Open Finance] Informa #246

**Determinação de horário para lançamento de ajustes relacionados com escopos do token de acesso da API de Payments**    Em referência aos ajustes mencionados no Informa #218 (“Inclusão de itens à planilha de problemas conhecidos da Fase 3 - escopos (scopes) do token de acesso (access\_token) da API de iniciação de pagamentos”, enviado em 1º de setembro de 2022), a Estrutura de Governança informa que o **prazo para colocar em produção os ajustes referentes aos escopos, que devem ser utilizados na obtenção do token de acesso para cada endpoint da API de Iniciação de Pagamentos (Fase 3), é às 00:00:00 do dia 05 de outubro de 2022** (no primeiro segundo do dia 05/10/2022).     A determinação visa evitar problemas de interoperabilidade durante a atualização. |

 **Atualização do Guia de Experiência**    O Grupo Técnico de Experiência do Usuário disponibilizou no dia 30/09/2022 uma nova versão do Guia de Experiência (Versão 3.06.02).  As principais atualizações feitas são um reflexo do que foi disposto na [Instrução Normativa n° 298](data/references/Instrução_Normativa_BCB_298.md), publicada pelo Banco Central em 23/08/2022. Outras atualizações visam melhorias e esclarecimentos para as instruções e textos do Guia.  Os temas abordados por conta da IN são:  - Apresentação de recursos de  “Termos e Condições” – Fase 2 - Agrupamento de submodalidades de crédito – Fase 2 - Detalhamento dos dados que serão compartilhados – Fase 2 - Apresentação de tela de confirmação final – Fases 2 e 3  Destaque para outras atualizações, conforme também detalhado no anexo da nova versão do Guia:  - Substituição do nome da ITP fictícia usada nas telas de exemplo - Ajuste de layout padrão das telas já exibidas no guia, agrupando-as antes da etapa de confirmação - Inclusão de telas padrão para visão unificada das etapas de autenticação confirmação feitas na transmissora de dados |
