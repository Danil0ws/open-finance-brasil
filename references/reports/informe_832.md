# [Open Finance] Informa #832

Informamos que foi disponibilizado em **12/01/2026** o motor de conformidade da *patch* versão 3.3.1 da API de Consentimento.  Destacamos a seguinte alteração:   - Atualização da descrição do campo /data/expirationDateTime no *endpoint* POST /consents, remoção da restrição de 12 meses.   Adicionalmente, informamos que as instituições deverão atualizar a versão dessa API no Diretório em **19/01/2026**, e, por se tratar de um versionamento do tipo *patch*, não será necessária nova certificação para esta API, conforme a política de versionamento vigente, porém recomendamos que as instituições executem os testes. |

 Atualização do Guia de Experiência do Usuário – versão 19.00.00 |

 Informamos que o time de UX disponibilizou, no dia 12/01/26, uma nova versão do Guia de Experiência do Usuário (v19.00.00). Esta atualização de versão inclui:   - Inclusão de requisito na Gestão de Vínculos de Conta, cenário Alteração dos Vínculos de Conta.   O detalhamento dos ajustes presentes nesta atualização do Guia encontra-se na página **“Changelog – Guia de Experiência do Usuário”.**    **Importante:** Esta versão do Guia de UX poderá ser monitorada a partir de 90 dias da  sua publicação (12/01/26) para produtos já implementados. Novos produtos, por sua vez, poderão ser monitorados a partir de 90 dias após o início de seu piloto, conforme o calendário vigente. |
