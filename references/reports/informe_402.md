# [Open Finance] Informa #402

[Atenção] Go live das APIs de Dados Abertos – fase 4A 2ª onda (Capitalização, Previdência e Seguros Pessoais)    O **Diretório de Produção foi atualizado para permitir a publicação das APIs de Dados Abertos – fase 4A 2ª onda** (capitalização, previdência e seguros pessoais) **e as instituições terão até 16/06/2023 para publicar as devidas APIs – data do *go live***. O cronograma foi definido pela IN #377 divulgado no Informa #366 [“Cronograma das APIs de Capitalização, Previdência e Seguros Pessoais da fase 4A (dados abertos)”, enviado em 25/04/2023].     Reforçamos que essas APIs terão **certificação automatizada** no Diretório, ou seja, os testes serão executados automaticamente **no momento da publicação da API**. Caso a API esteja conforme, a publicação será feita com sucesso. Caso algum problema seja encontrado, este será notificado e a publicação não será efetivada. Portanto, não será necessária a submissão de pedidos de certificação através de tickets no service desk. Maiores informações estão no Guia Operacional do Diretório (páginas 75 a 80). |
