# [Open Finance] Informa #892

Ampliação do prazo de execuções dos módulos de teste do pedido de certificação da API Pagamentos v5.0.0 |

 Conforme divulgado no Informe #812, referente ao cronograma de certificação e implementação da versão v5.0.0 da API de Pagamentos, foi estabelecida uma data limite para reexecução dos testes de certificação.    Informamos que a data de possíveis reexecuções será excepcionalmente ampliada para 18/05/2026.    Reforçamos, contudo, a importância da observância dos demais prazos previstos no cronograma, destacando que a data de go-live permanece inalterada. |
