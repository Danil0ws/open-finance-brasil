# [Open Finance] Informa #674

Disponibilização do motor para a versão 2.3.0 da API Direitos Creditórios Descontados             Conforme comunicado no Informa #660 (“*Lançamento da versão minor das APIs Direitos creditórios descontados, Financiamentos e Adiantamento a depositantes (Dados do cliente)*”, divulgado em 13/11/2024), a área do desenvolvedor do Portal do Open Finance Brasil foi atualizada, em 13/11/2024, com a documentação da versão *minor* da API Direitos creditórios descontados (v2.3.0) e a disponibilização do motor de conformidade para essa versão ocorreu no dia 13/12/2024.    Informamos que o motor de conformidade foi atualizado para essa API e reforçamos que não será necessária recertificação. Instituições que realizarem alterações em suas implementações deverão realizar testes no motor de conformidade antes da publicação em produção. |
