# [Open Finance] Informa #815

Conforme compartilhado no Informa #789 (“*Divulgação dos cronogramas de versionamento minor para as APIs de Dados do cliente*”, divulgado em 25/09/2025), **a versão estável do motor de conformidade para API Consentimento v3.3.0 foi disponibilizada em 17/11/2025** e será utilizada para o**marco de 100% em 03/12/2025.**    Para essa versão do motor, foram considerados ajustes simples de baixa relevância como validação do novo *header* x-v no retorno de *responses*, a inclusão do campo opcional *isLinked* para o tratamento de Jornada Otimizada e o ajuste para adequação ao novo padrão alfanumérico do *pattern* de CNPJ, que será testado futuramente.     **Sucesso no marco de 100%**  Para fins de contabilização de sucesso neste marco, as instituições devem obter sucesso no seguinte módulo de teste:  - *consents\_api\_core\_test-module\_v3-2*  Mais detalhes sobre os testes podem ser consultados na página de plano de testes.     Por fim, reforçamos que instituições que não obtiverem sucesso no marco serão notificadas via *tickets* do Service Desk. |
