# [Open Banking] Informa #104

Utilização das logomarcas Esclarecemos abaixo os campos que devem ser utilizados para apresentação de logomarcas, pois foi identificado que há instituições apresentando logomarcas de forma equivocada.   - Para instituições transmissoras, as logomarcas que devem ser utilizadas para listar as receptoras são as disponibilizadas nos *software statements* – campo *LogoURI* - Para instituições receptoras, as logomarcas que devem ser utilizadas para listar as transmissoras são as cadastradas nos *authorisation servers* – campo *CustomerFriendlyLogoURI*   Pedimos que as instituições revisem as suas implementações para garantirem a adesão ao padrão explicitado acima.  O Guia Operacional do Diretório está sendo atualizado para contemplar esse esclarecimento. |
