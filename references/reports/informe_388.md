# [Open Finance] Informa #388

Atualização do Guia de Experiência do Usuário do OFB              O Grupo Técnico de Experiência do Usuário disponibilizou no dia 25/05/2023 uma nova versão do Guia de Experiência (Versão 3.09.01).   A atualização desta nova versão inclui ajustes de redação e remoção de ambiguidade. As melhorias estão listadas a seguir, além de detalhadas no anexo “*Alterações da versão*” dentro do próprio Guia:  - Melhorias em texto para requisitos e recomendações para garantir o entendimento dos itens;  - Inclusão de exemplo para o componente de barra de progresso;  - Inclusão de recomendação para informar ao cliente sobre a gratuidade das jornadas de compartilhamento de dados e, caso aplicável, da iniciação de pagamentos;  - Detalhamento para o aviso de arranjos e funcionalidades que ainda não foram implementadas;  - Esclarecimento entre as opções para implementação da jornada de pagamento via Pix. |
