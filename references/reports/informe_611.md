# [Open Finance] Informa #611

Inativação de recursos no Diretório de participantes Informamos que o Diretório foi atualizado, em 29/07/2024, para permitir um *soft delete* de recursos do servidor de autorização. Com essa nova funcionalidade, será possível:   - Estabelecer uma rotina automática para realizar a exclusão de APIs descontinuadas pela Estrutura - Ao efetuar a deleção de recursos, eles permanecerão na interface com o status “Inativo”, permitindo uma melhor rastreabilidade dos dados e mitigando riscos de deleções indevidas    Essa nova funcionalidade implica nas seguintes alterações no processo de publicação e consulta de APIs:  - **Campo “API Version”:** Não será possível editar a versão da API nesse campo   - Para adicionar uma nova versão deverá ser publicada uma nova API - **Status “Ativo/Inativo”:** As APIs publicadas terão um novo campo de status   - Após inativar uma API, será possível ativá-la novamente - **Resposta via APIs:** As APIs inativas não estarão presentes na API de participantes, mas estarão disponíveis para consulta pela Estrutura |
