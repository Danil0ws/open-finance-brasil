# [Open Finance] Informa #691

LEMBRETE sobre marco de 100% e publicação da versão 2.1.0 da API Vínculo de dispositivo Reforçamos que, conforme comunicado no Informa #677 (“*Lançamento da versão 2.1.0 (minor) da API Vínculo de dispositivo*”, divulgado em 20/12/2024), as seguintes datas para versão 2.1.0 da API Vínculo de dispositivo se aproximam:   - **Marco de 100%**: ocorrerá no dia**30/01/2025;** - ***Go live***: ocorrerá no dia**31/01/2025.**   Para o marco de 100%, conforme compartilhado no Informa #687 (“*Alterações e disponibilização do motor para a v2.1.0 da API Vínculo de Dispositivo*”, divulgado em 17/01/2024), as instituições deverão reexecutar com sucesso 2 módulos de teste que tiveram alteração relevante:   - enrollments\_api\_webhook-revoked\_test-module\_v2:   - Na response do POST fido-registration-options o endpoint será validado se o valor de software\_client\_name contido na SSA corresponde ao campo data.rp.name; - enrollments\_api\_excessive-transactionLimit\_test-module\_v2:   - No POST consent authorise, o campo userHandle será enviado vazio. |

 Novo processo de acesso à plataforma de visualização de dados do Open Finance No Informa #543 (“Solicitação de acesso e lançamento da área de acompanhamento de desconformidades”, enviado em 08/03/2024) foi informado que a solicitação de acesso para a Área de Acompanhamento de Situações de Desconformidades ocorreria através do Portal de Serviços do Open Finance.    **A partir de 27/01/2025, a gestão de acesso à Plataforma de Visualização de Dados do Open Finance, que inclui o painel de desconformidades e outros *dashboards*, deverá ser realizada pelo administrador da instituição no Diretório de participantes** através do cadastro de usuário de domínio da organização ‘PDV’ ou ‘SDV’ no sistema ‘Data Visualization Plataform’.   - Usuários PDV podem adicionar e excluir membros do grupo SDV; - Usuários SDV têm acesso limitado, sem permissão para adicionar ou excluir membros.   Os usuários que já possuem acesso à plataforma foram adicionados ao grupo PDV e **as instituições deverão realizar essa validação até 03/02/25.**Após essa data, todos os acessos que não estiverem no Diretório serão cancelados.     Reforçamos que os painéis disponibilizados na Plataforma de Visualização de Dados contêm as devidas restrições de dados para que os usuários visualizem apenas as informações de suas organizações. |
