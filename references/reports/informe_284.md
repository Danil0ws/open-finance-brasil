# [Open Finance] Informa #284

Atualização do Guia de Experiência do Usuário   O Grupo Técnico de Experiência do Usuário disponibilizou no dia 08/12/2022 **uma nova versão do Guia** de Experiência (Versão 3.08.01).      A principal atualização desta nova versão é a **inclusão da jornada CIBA para os casos de compras consecutivas** (após vínculo feito na primeira compra). Os testes de usabilidade, conduzidos pelo GT UX, **revelaram este caso de uso como prioritário para inclusão no Guia**, porém não restringem o uso de CIBA para outras aplicações.    Além disso, foram incorporadas uma série de melhorias e correções no Guia, das quais as principais estão listadas a seguir:   - **Temas de fase 3:**   - Atualização da tabela de status do pagamento;   - Inclusão dos requisitos para jornada do Temporizador Pix;   - Melhorias para jornada do pagamento identificadas a partir dos testes de usabilidade.  - **Temas de fase 2:**   - Melhorias para as notificações após efetivação do consentimento em múltipla alçada;   - Melhorias para exibição do resumo do consentimento na etapa de efetivação. |
