# [Open Finance] Informa #777

Alteração no marco de 100% da API Empréstimos v2.5.0     Informamos que o marco de 100% para a API Empréstimos v2.5.0 será alterado em relação à data originalmente divulgada no Informa #716 (“*Divulgação do cronograma de certificação e homologação do produto Portabilidade de Crédito Pessoal Clean (CPC)*”, divulgado em 28/03/2025):   - De: 19/08/2025; - Para: 02/09/2025.   Para este marco, será utilizada a versão estável do motor de conformidade, cujos testes podem ser consultados na página do plano de testes desta API ou no Informa #764 (“*Disponibilização da versão estável da API Empréstimos (v2.5.0)*”, divulgado em 18/07/2025).    Informamos que **o marco de 100% também se aplica às instituições transmissoras de dados que não operam o produto de Portabilidade de crédito**.  Adicionalmente, informamos que **as demais datas presentes no Informa #716 estão em deliberação e devem ser alteradas (e serão divulgadas em breve)**, e que as instituições que não obtiverem sucesso nos módulos de teste até a data do marco serão notificadas via tickets do Service Desk. |
