# [Open Finance] Informa #879

Publicação da especificação da APIs Dados Abertos Estável |

 Informamos que a área do desenvolvedor do Portal do Open Finance Brasil foi atualizada, em 17/04/2026, com as seguintes documentações das APIs de Dados Abertos da versão estável:   - API Adiantamento a Depositantes v1.1.0 - API Câmbio v1.1.0 - API Canais de Atendimento v2.1.0 - API Cartões de Crédito v1.1.0 - API Contas v1.1.0 - API Credenciamento v1.1.0 - API Direitos Creditórios Descontados v1.1.0 - API Empréstimos v1.1.0 - API Financiamentos v1.1.0 - API Investimentos v1.1.0 - API Previdência v2.1.0 - API Seguros v2.1.0 - API Títulos de Capitalização v2.1.0  **Dentre as alterações, destacamos:**    Revisamos e atualizamos as regras de validação (expressões regulares) de todos os campos que utilizam **CNPJ**, **ISPB**, combinações **CNPJ/CPF** e demais identificadores relacionados, passando a permitir a futura emissão de identificadores alfanuméricos, sem perder a compatibilidade retroativa com valores exclusivamente numéricos em todas as APIs classificadas como Dados Abertos.    **O cronograma de certificação e implementação dessas APIs foram divulgados no informe #868 *(“Divulgação do Cronograma de Dados Abertos”)***    Para acessar todas as alterações e mais detalhes, sugerimos acessar os links de documentação abaixo: |

 Disponibilização do motor para a API de Empréstimos v.2.6.0 - Estável |

 Conforme compartilhado no Informa #808 *(“Divulgação do cronograma de versionamento minor para a API Empréstimos v2.6.0 e publicação das especificações beta.1”)*, divulgado em **31/10/2025**, estamos disponibilizando o motor da API de Empréstimos v2.6.0 – Estável.    Para atingir o marco de 100%, previsto para **12/05/2026**, as instituições devem obter sucesso em todos os módulos de teste do plano abaixo:  **API de Empréstimos v.2.6.0 – Estável**   - **Plano de teste:** Functional Tests for Loans API - Based on Swagger version: 2.6.0   As instituições que não atingirem sucesso no marco serão notificadas via tickets do Service Desk.      Mais detalhes sobre os testes podem ser consultados na página de plano de testes. |
