# [Open Finance] Informa #683

Atualização para versão 2.3.0 do Motor de Qualidade de Dados (MQD) e início do prazo de implementação pelas instituições Buscando a melhoria constante do Motor de Qualidade de Dados, na 229ª Reunião do Conselho Deliberativo foi aprovada a PQD-23, proposta de atualização para versão 2.3.0 do Motor de Qualidade de Dados  (MQD). Conforme cronograma deliberado, a nova versão está disponível a partir de hoje, 10/01/2025, para início da implementação pelas instituições, que, por sua vez, terão até o dia 10/02/2025 para finalizar suas integrações.  O que há de novo na versão 2.3.0:  Análise   - Inclusão do campo opcional: *consentID* (via *Header*), para facilitar a análise do problema - Suporte para envio de informações de organizações para seu conglomerado por meio de uma única instalação do cliente MQD - Armazenamento de informações de *log* localmente, que contêm informações de erro e *payload* de amostra   Segurança   - Atualização de bibliotecas para as versões mais recentes - Atualização de código com potenciais vulnerabilidades de segurança - Inclusão de funcionalidade de suporte HTTPS no cliente - Suporte para mascarar informações privilegiadas ao gravar *logs* localmente   Melhorias   - Suporte para especificação Open API 3.1   Dentre as novas funcionalidades, o Squad Qualidade de dados gostaria de destacar a possibilidade de mascaramento de log para a funcionalidade de armazenamento local de logs do processo de validação. Mascaramento é uma técnica de segurança usada para proteger informações confidenciais ofuscando ou ocultando partes dos dados para impedir acesso ou exposição não autorizados, mantendo o formato geral ou a utilidade dos dados para fins legítimos. O objetivo é que a instituição consiga identificar os campos que estão com erro mas não armazene os dados sensíveis.     Para as instituições que têm interesse nessa funcionalidade (funcionalidade opcional), solicitamos que sugiram os campos que contenham dados sensíveis e que devem ser mascarados. A lista de campos a serem mascarados deve ser endereçada ao e-mail [SquadQualidadedeDados@openfinancebrasil.org.br](mailto:SquadQualidadedeDados@openfinancebrasil.org.br "mailto:SquadQualidadedeDados@openfinancebrasil.org.br"). |

 Solicitações de dispensa da certificação do produto Pix Automático para instituições que suportam apenas conta PJ Instituições detentoras de conta que suportarem apenas contas PJ poderão solicitar para a Estrutura autorização para não execução dos módulos de teste do produto Pix automático da API de Pagamentos automáticos v2.0.0, informando que irão providenciar *opt-out* junto ao arranjo Pix.  A solicitação poderá ser realizada através do Service Desk no seguinte caminho: Solicitação de Informações > Conformidade > Política de conformidade.  Para que seja autorizada, a informação do segmento de atuação da instituição deverá estar devidamente refletida na *flag* do servidor de autorização no Diretório de participantes.  A solicitação de *opt-out* é exclusiva para o produto Pix automático, a obrigatoriedade de execução dos testes de transferências inteligentes e a publicação da v2.0.0 da API Pagamentos automáticos se mantém para todas as instituições detentoras de conta. |
