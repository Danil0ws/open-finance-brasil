# [Open Finance] Informa #485

Marco A – API de Pagamentos automáticos v1 Informamos que o release notes dos testes da v1 da API de Pagamentos automáticos já está disponível.     O motor funcional será disponibilizado em 08/12/2023. Para o marco A, que ocorrerá em 15/12/2023, as instituições deverão executar com sucesso um dos seguintes módulos abaixo:     automatic-payments\_api\_swepping-accounts-consents-core\_test-module  automatic-payments\_api\_automatic-pix-daily-consents-core\_test-module  automatic-payments\_api\_automatic-pix-weekly-consents-core\_test-module  automatic-payments\_api\_automatic-pix-monthly-consents-core\_test-module  automatic-payments\_api\_automatic-pix-yearly-consents-core\_test-module  automatic-payments\_api\_negative-consents-core\_test-module     **Sugerimos a execução do módulo “automatic-payments\_api\_negative-consents-core\_test-module”, que não depende da jornada de experiência do usuário, visto que o guia será disponibilizado posteriormente.**     Reforçamos que o marco A da API de Pagamentos v4 ocorrerá nessa mesma data. Para essa API será necessária a execução com sucesso de dois módulos de teste, conforme comunicado no Informa #480 “Marco A – API de Pagamentos v4”.     Para dúvidas em relação aos testes e certificações, recomendamos a abertura de chamados no Gitlab ou Service Desk. |
