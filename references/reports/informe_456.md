# [Open Finance] Informa #456

Processo de submissão de pedidos de certificação da Fase 4B  No Informa #453 (“Abertura do período de certificação das APIs de Investimentos”, enviado em 15/09/2023), detalhamos o processo de submissão de pedidos de certificação das APIs de Investimentos.     **O processamento das certificações ocorrerá para cada API de forma automatizada. Para garantir que as validações ocorram a nível de cada uma das APIs, solicitamos que sejam abertos chamados específicos contendo os dois planos de teste para cada uma das APIs que a instituição deseje certificar.**    Após o processamento da certificação, a estrutura enviará por Docusign para cada API o termo “Certificado de Conformidade Funcional” para validação do contato técnico e assinatura do representante legal, ambos indicados no formulário.    Podem ser indicados um ou dois representantes legais; no caso de dois terem sido indicados, ambos devem assinar o documento.    No mesmo Informa, comunicamos que o envio do link público contendo os logs de execução do motor deveria ocorrer através do botão “Publish everything”. Informamos que além deste botão, foi implementado o botão “Publish for certification”, que também pode ser utilizado para envio dessas evidências. |
