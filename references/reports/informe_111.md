# [Open Banking] Informa #111

Datas limite de certificação da Fase 3A - 1º Ciclo Conforme esclarecido no Informa #100, o processo de certificação da Fase 3 terá escopo cumulativo. Entretanto, para permitir que as instituições que estão em certificação do 1º Ciclo concluam o processo, serão consideradas as seguintes datas:  14/01/2022: Data limite para **envio** de pedidos de certificação com escopo exclusivo do 1º Ciclo (abertura de tickets com documentação completa)  21/01/2022: Data limite para **concluir** certificação de pedidos abertos anteriormente  A partir de 21/01/2022, os testes dos produtos desse ciclo (Pix Manual, Chave e Recebedor) serão incluídos no plano de testes cumulativo da Fase 3A - 3º Ciclo, junto com os testes de QR Code estático e dinâmico.  A previsão para abertura dos pedidos de certificação do 3º Ciclo é amanhã, 07/01/2022 |
