# [Open Finance] Informa #615

Alteração no campo *consentId* na API de reporte de *Hybrid flow* da PCM            A descrição do campo *consentId* foi atualizada de forma a deixar claro que a fonte do dado para o campo é tanto o *consentId* quanto os demais *Ids* utilizados pelo ecossistema:   - *consentId da* API Consentimento Dados Cadastrais e Transacionais*:* pós POST */open-banking/consents/v3/consents* utilizar a *string* obtida/enviada em *data.consentId* - *consentId da* API Pagamentos: pós POST */open-banking/payments/v4/consents* utilizar a *string* obtida/enviada em *data.consentId* - *recurringConsentId da* API Pagamentos Automáticos: pós POST */open-banking**​**/recurring-consents/v1/recurring-consents* utilizar a *string* obtida/enviada em *data.recurringConsentId* - *enrollmentId* da API Pagamentos Sem Redirecionamento: pós POST */open-banking/enrollments/v1/enrollments* utilizar a *string* obtida/enviada em *data*.*enrollmentId*   Essa informação pode ser consultada na Área do Desenvolvedor. |

 [MQD] Implementação de novas APIs no MQD            Informamos que foi aprovado na 212ª Reunião do Conselho Deliberativo a implementação de 12 novas APIs ao Motor de Qualidade de Dados.      O período de implementação pelas casas iniciará em 12/08/2024 e findará em 15/09/2024.     Dessa forma, as instituições que reportam ao MQD deverão ajustar suas implementações para que passem a enviar os resultados das seguintes APIs:   - Adiantamento a Depositantes - Câmbio - Consentimentos - Dados Cadastrais - Direitos Creditórios - Financiamentos - Fundos de Investimentos - Renda Fixa Bancária - Renda Fixa Crédito - Renda Variável - Recursos - Títulos do Tesouro Direto   Em caso de dúvidas, recomendamos a abertura de ticket no Service Desk. |

 [MQD] Lembrete sobre o prazo de atualização do MQD          Com base no cronograma deliberado na PQD-16, o prazo de atualização do Motor de Qualidade de Dados finda-se em 15/08/2024.  O *Squad* de Qualidade de Dados gostaria de relembrar as instituições da necessidade de atualização para que sejam corrigidos quesitos de segurança e obrigatoriedade de campos que são essenciais para a atuação nas soluções dos problemas detectados pelo Motor. |
