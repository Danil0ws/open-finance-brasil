# [Open Banking] Informa #136

Atualização Diretório – Suporte application/json na obtenção do Software Assertion Informamos que, em 09/03/2022, o Diretório de participantes sofreu uma atualização na sua API interna referente à obtenção do *software statement assertion* para também suportar retorno com mensagem em formato JSON, em conformidade com as especificações publicadas no portal (<https://raw.githubusercontent.com/OpenBanking-Brasil/specs-directory/main/openapi.yaml>).    Previamente, a API retornava uma mensagem no formato JWT, independentemente do *content accept header* enviado. Com essa atualização, a API passou a retornar uma mensagem no formato JSON, quando é enviado um *content accept header* igual a *application/json.*    Vale notar que instituições que já estavam realizando a requisição com esse *header* antes da atualização poderão ter problemas, visto que a resposta passará a ser recebida em formato JSON, ao invés de JWT.    Para essas instituições, é importante garantir que não seja enviado um *header*, o que irá trazer um retorno sempre em JWT, ou requisitar o *mime type Accept*: application/jwt.    A API pode ser acessada através dos seguintes caminhos:   - [https://matls-api.sandbox.directory.openbankingbrasil.org.br/organisations/{OrganisationId}/softwarestatements/{SoftwareStatementId}/assertion](https://matls-api.sandbox.directory.openbankingbrasil.org.br/organisations/%7bOrganisationId%7d/softwarestatements/%7bSoftwareStatementId%7d/assertion) - [https://matls-api.directory.openbankingbrasil.org.br/organisations/{OrganisationId}/softwarestatements/{SoftwareStatementId}/assertion](https://matls-api.directory.openbankingbrasil.org.br/organisations/%7bOrganisationId%7d/softwarestatements/%7bSoftwareStatementId%7d/assertion) |
