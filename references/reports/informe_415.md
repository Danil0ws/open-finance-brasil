# [Open Finance] Informa #415

Escopo de dados expostos na API de Investimentos da fase 4A O GT Especificações Dados Abertos gostaria de reiterar o entendimento sobre o escopo de produtos que deve ser considerado na API de Investimento da Fase 4A, **não sendo então necessário o compartilhamento de dados dos produtos de investimentos de mercado secundário**.  Tal entendimento havia sido pactuado em reunião de alinhamento entre o GT Especificações e representantes do Banco Central ao final de 2021 e permanece válido para a publicação dos referidos produtos. |
