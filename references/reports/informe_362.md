# [Open Finance] Informa #362

Ajustes da API de Payments v2.0.0 para o fluxo client credentials           O Informa #352 (“Atualização de testes do motor de conformidade funcional da API de Payments v2.0.0 para o fluxo client credentials”, enviado em 04/04/2023) orientou sobre a **necessidade de ajustes na API de Payments v2.0 para o fluxo de client credentials e o respectivo cronograma.**     **Reforçamos aqui essas datas e incluímos a data máxima para ajuste em produção**.  - **Até 17/04/2023**: Execução dos três testes por todas as detentoras de conta (sandbox)   - Testes a serem executados - atualizados em 10/04/2023:     - payments-pixscheduling-patch-iniciadora-v2     - payments-pixscheduling-patch-unhappy-v2     - payments-contenttype-jwt-refreshtoken-v2 - **Até 24/04/2023**: Execução com sucesso dos três testes acima por todas as detentoras (sandbox) - **Até 02/05/2023: Atualização da API em ambiente produtivo (produção)**    Não será necessário o envio de logs através de tickets no service desk.      Solicitamos atenção ao preenchimento do campo organisation ID, pois este será utilizado para contabilização do sucesso (maiores detalhes no Informa #356).     Problemas ou inconsistências identificadas devem ser notificadas preferencialmente através do repositório no GitLab no link abaixo, para evitar duplicação dos temas. Tickets abertos através da plataforma do Service Desk continuarão sendo tratados. |
