# [Open Finance] Informa #265

Lançamento da versão release candidate 2.0.0-rc1.0 da API de Iniciação de Pagamentos   A documentação da nova versão *release candidate* v2.0.0-rc1.0 da API de Iniciação de Pagamentos foi publicada hoje (28/10/2022) na Área do Desenvolvedor do Portal Open Finance Brasil. Esta nova documentação pode ser encontrada em: [v2.0.0-rc1.0 - Pagamentos - Área do Desenvolvedor - Open Finance Brasil - Área do Desenvolvedor (atlassian.net)](data/references/guides/v2.md).    Será disponibilizado um período de consulta ao ecossistema de 10 dias, iniciando em 31/10/2022 e encerrando em 09/11/2022 para que sejam coletadas **sugestões de melhoria por parte das casas.**Tais sugestões devem considerar a versão *release candidate* da API de Iniciação de Pagamentos referente aos produtos Pix MANU/DICT/INIC/QRES/QRDN e agendamento. Sugestões encaminhadas fora desse período não serão consideradas.    Toda sugestão de melhoria a ser enviada deve ser registrada no *Service Desk* (<https://servicedesk.openbankingbrasil.org.br/servicePortal/submitSR?category_id=485>) por meio da abertura de um *ticket*, seguindo a opção: Solicitações de Melhorias > APIs. Na abertura do *ticket*, o título deve ser registrado como “Revisão fase 3 – *Release candidate*” e no campo descrição deve ser citado qual é o *endpoint*, campo e sugestão de ajuste na documentação, para que o *ticket* possa ser considerado até o lançamento da versão 2.0.0 definitiva da API de Iniciação de Pagamentos previsto para 19/11/2022.     Tendo em vista os prazos previstos para a entrega da fase 3 em produção, é **recomendado que as instituições iniciem o seu desenvolvimento com base na versão *release candidate* v2.0.0-rc1.0**.     Ressaltamos que o cronograma de certificação prevê uma **execução obrigatória do motor de conformidade em 20/12/2022,** com o intuito de ajudar a avaliar a maturidade do motor, sendo esperado que nesta data as instituições tenham um desenvolvimento minimamente estável.     O Guia de Implementação das APIs de Dados Cadastrais e Transacionais não contempla orientações para a nova versão da API de Iniciação de Pagamentos, de modo que as instituições não devem considerar o seu conteúdo. **Devem ser considerados os *changelogs* e materiais da API de Iniciação de Pagamentos que estão disponíveis na Área do Desenvolvedor** **nos menus “Especificações de APIs” e “Requisitos não Funcionais”.** |
