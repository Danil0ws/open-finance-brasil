# [Open Finance] Informa #679

Disponibilização do plano de testes de retentativas da API Pagamentos automáticos v2.0.0 Informamos que o plano de testes de retentativas da API Pagamentos automáticos v2.0.0 foi disponibilizado em 02/01/2025. De acordo com o Informa #677 (“Orientações sobre a realização de testes de criação de massa de dados (API Pagamentos automáticos v2.0.0)”, enviado em 20/12/2024), para a execução dos testes de retentativas será necessária a criação de uma massa de dados através do plano de testes auxiliar.     **Reforçamos que o marco de 50% da API Pagamentos automáticos v2.0.0 ocorrerá em 14/01/2025 e as instituições deverão executar os testes na versão beta.2 do motor de conformidade.** Os demais planos de testes dessa API foram atualizados em 24/12/2024, conforme publicado no Informa #678 (“Disponibilização do motor beta.2 da API Pagamentos automáticos v2.0.0”, enviado em 24/12/2024), e as orientações para execução com sucesso do marco podem ser consultadas no Informa #671 (“Alteração dos testes para o motor beta.2 da API Pagamentos automáticos v2.0.0”, enviado em 10/12/2024). |
