# [Open Finance] Informa #420

Execução recorrente da FVP 2.0 O cronograma de execução recorrente da FVP 2.0 foi divulgado no Informa #394 e não serão mais abertos ticket individuais de notificação das instituições.     O prazo para execução do ciclo em vigor é até hoje, 10/07/2023.     Reforçamos que:  - A execução será obrigatória para **todos os *authorisation servers* da instituição** - Deverá ser realizada com clientes **PF e PJ**   - Cada authorisation server deverá executar como PF e/ou PJ, a depender se a marca atua com o tipo de cliente em questão. Ou seja, se a marca possui apenas clientes PF, executará apenas PF. Se possui PF e PJ, deverá executar com ambos   - A instituição será responsável por providenciar uma pessoa física com poderes para os testes de PJ, podendo ser, por exemplo, da própria instituição, de um fornecedor ou de cliente parceiro - Deverá ser realizada para **os planos de testes das fases que o *authorisation*** ***server*** **atua** (fases 2 e/ou 3)   - Fase 2     - Plano de testes: “Production Functional Tests for Consents and Resources API - API Version 2.0.1”     - Módulos:       - “fvp-preflight-check-test-v2”       - “resources\_api\_core\_test-module\_v2”   - Fase 3     - Plano de testes: “Production Functional Tests for Payments API- API Version 2.0.0”     - Módulos:       - “fvp-preflight-cert-check-payments-test-v2”       - “fvp-payments-consents-core-test-v2” - Testes adicionais poderão ser exigidos sob demanda e comunicados via Informa.   - Para essa execução de 4 a 10/07/2023, não há necessidade de execução de nenhum teste adicional |

 Atualização do Guia de Experiência do Usuário do OFB O Grupo Técnico de Experiência do Usuário disponibilizou hoje, dia 10/07/2023, uma nova versão do Guia de Experiência (Versão 3.10.01).   A atualização desta nova versão inclui:  - Novos requisitos e recomendações para aplicação de escopo de dados: Investimentos - Fase 4B; - Tabela de dados atualizada; - Mudanças nas regras de utilização e disponibilização de logotipos das Instituições nas jornadas; - Mudança no requisito de cadastro mínimo.  As melhorias estão listadas também no anexo “*Alterações da versão*” dentro do próprio Guia. |
