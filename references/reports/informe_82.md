# [Open Banking] Informa #82

Início do envio de pedidos de Recertificação Funcional Fase 2 Informamos a prorrogação da abertura de pedidos de recertificação funcional Fase 2.  O envio de pedidos para essa recertificação funcional estava previsto para hoje. Contudo, sua prorrogação visa incorporar os testes de roles regulatórias nos motores de conformidade funcional.  Esses testes estarão disponíveis em sua versão beta já na quinta-feira, 04/11. Dessa forma, as instituições poderão realizar a validação desses novos testes e, após validados, o envio de pedidos para recertificação será liberado. |

 Atualização do motor Conformidade Funcional Fase 3 Informamos que o motor de conformidade funcional da Fase 3 foi atualizado nessa segunda-feira (01/11, às 11h30) para suportar as novas atualizações referentes a idempotência e validação do proxy no DICT e também a inclusão de testes funcionais para validação de roles regulatórias.  Com a implementação dos novos testes, requisitamos que todas as instituições realizem novas execuções no motor para garantir que os testes estão conformes e estáveis frente às definições.  Uma vez constatada a consistência dos módulos de teste atualizados, iremos avaliar a abertura do motor, o que deve ocorrer nos próximos dias.  Caso encontrem algum problema nos testes, pedimos que abram um *issue* através do repositório do gitlab do motor funcional.    Como as atualizações impactaram os testes abaixo, pedimos que priorizem a execução nos seguintes módulos:   - payments-api-proxy-fake-email-proxy-test - payments-api-proxy-phone-number-proxy-test - payments-api-proxy-test-incorrect-cpf - payments-consents-api-jti-reuse-test - payments-consents-json-accept-header-jwt-returned-test - payments-api-idempotency-test - payments-api-fapi-testing - payments-api-dcr-happyflow - payments-api-dcr-test-unauthorized-client |
