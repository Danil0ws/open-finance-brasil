# [Open Finance] Informa #764

Disponibilização da versão estável da API Empréstimos (v2.5.0)  **Especificação**   Informamos que a área do desenvolvedor do Portal do Open Finance Brasil foi atualizada, em 18/07/2025, com a documentação da versão estável da API Empréstimos (v2.5.0).     Dentre as alterações, destacamos:  - Alteração no *pattern* do CNPJ; - Alteração das frequências dos limites operacionais para atender Portabilidade de Crédito; - Atualização dos campos referentes a paginação e dados complementares; - Ajustes de descrição de campos.    **Sucesso no marco de 100%**     Reforçamos que, para o marco de 100%, é esperado sucesso nos testes abaixo pelas instituições:  - loans\_api\_credit-portability\_test-module\_v2-5; - loans\_api\_core\_test-module\_v2-5; - loans\_api\_operational-limits\_test-module\_v2-5.    A data de publicação no diretório se mantém prevista para 02/09/2025, conforme divulgado no Informa #716 (“Divulgação do cronograma de certificação e homologação do produto Portabilidade de Crédito Pessoal Clean (CPC)”, divulgado em 28/03/2025).     Para mais detalhes, sugerimos acessar os links de documentação abaixo: |
