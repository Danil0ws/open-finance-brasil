# [Open Finance] Informa #396

Liberação do motor funcional versão beta de Webhook para API de Iniciação de Pagamentos (fase 3)       Informamos que os testes de Pagamentos para Webhook já estão disponíveis no motor de conformidade e disponíveis para execução pelos participantes.     O plano de testes contém 5 módulos de teste que estão disponíveis no plano “Functional Tests for DCR DCM - PAGTO Role - Webhook - Based on Swagger version: 2.0.0 (Beta)”.     Além da configuração do padrão, os testes exigem que a instituição faça o registro da URL do webhook no Software Statement de Teste, dentro do Diretório de Participantes Sandbox. Esse webhook deve ser registrado com o seguinte formato:     [https://web.conformance.directory.openbankingbrasil.org.br/test-mtls/a/<alias](https://web.conformance.directory.openbankingbrasil.org.br/test-mtls/a/%3calias)>     O campo "<alias>" deve corresponder ao campo "alias" que será definido configuração dos testes.     O Software Statement mencionado será utilizado pelo motor de conformidade durante a execução de um DCR/DCM. A instituição precisará fornecer a configuração de teste com os certificados do Software Statement e o ID do Diretório associado a esse Software Statement.     Além do endpoint de webhook, a instituição precisará ter uma conta válida que seja capaz, no ambiente de Sandbox, de receber e concluir um pagamento, similar aos requisitos definidos nos testes da API de Pagamentos v2.     As datas de atingimento dos marcos de sucesso nos testes e o *Go Live* da API deverão acontecer em:  - **19/06/2023**: Data limite para execução com sucesso de 25% dos módulos; - **03/07/2023**: Data limite para execução com sucesso de 50% dos módulos; - **13/07/2023**: Data limite para execução com sucesso de 75% dos módulos; - **26/07/2023**: Data limite para execução com sucesso de 100% dos módulos; - **28/07 a 03/08/2023:**Submissão de pedidos de certificação no Service Desk (modelo regular de certificação, com assinatura pelo DocuSign); - **04/08 a 18/08/2023:**Processamento de certificações; - **18/08/2023**: Implementação das especificações em produção pelas detentoras de conta (*Go Live*)  Mais informações estão disponíveis em:  - Sobre webhook: Convenções de webhook, informações funcionais e guia de segurança - Sobre testes: Release notes (Phase 3v2 - Payments Webhook Tests) |
