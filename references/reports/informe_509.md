# [Open Finance] Informa #509

Alteração no marco das APIs Comum e Fase 1  O motor de conformidade funcional foi atualizado em 05/01/2024 para contemplar a versão beta2 dos Produtos da Fase 1.   Conforme Informe #427 ("Cronograma atualizado de Dados Abertos - APIs Produtos e Serviços, Canais de Atendimento, Comuns e Admins", enviado em 28/07/2023), o marco de 25% para as APIs de Comum e Fase 1 estava previsto para 08/01/2024. Para este marco, as seguintes alterações foram necessárias:   - Para o marco de 08/01/2024 será exigido apenas o início de execução dos testes; - Devido à alteração relevante no motor, para os próximos marcos relativos à Comum e Fase 1, serão contabilizadas como sucesso as execuções realizadas a partir de 06/01/2024.   Os demais marcos seguirão as datas abaixo:    22/01/2024: Marco de 50% de sucesso  05/02/2024: Marco de 75% de sucesso  22/02/2024: Marco de 100% de sucesso  27/02/2024: *Go-live* |

 Ajustes no motor de conformidade das APIs de Pagamentos Estão previstos os seguintes ajustes no motor de conformidade das APIs de Pagamentos:    **API de Pagamentos automáticos v1 (transferências inteligentes)**   - Três módulos passarão a ser condicionais - ou seja, somente obrigatórios para instituições que possuem clientes PJ. Para as instituições que não possuem clientes PJ, bastará não preencher o CNPJ no momento da configuração dos testes que o resultado destes será "skipped"   - automatic-payments\_api\_sweeping-accounts-root-cnpj\_test-module\_v1 (este módulo foi disponibilizado em 05/01/2024)   - automatic-payments\_api\_multiple-consents-core\_test-module\_v1   - automatic-payments\_api\_sweeping-accounts-invalid-cnpj\_test-module\_v1 - 5 módulos de teste serão atualizados em 09/01/2024 para se tornarem menos restritivos   - automatic-payments\_api\_rejected-consent\_test-module\_v1   - automatic-payments\_api\_revoked-consent\_test-module\_v1   - automatic-payments\_api\_startDateTime\_test-module\_v1   - automatic-payments\_api\_sweeping-accounts-wrong-creditor\_test-module\_v1   - automatic-payments\_api\_expirationDateTime\_test-module\_v1    **API de Pagamentos automáticos v4 (agendamentos recorrentes)**  - O módulo payments\_api\_pixscheduling-patch-unhappy\_test-module\_v4 sofrerá alteração relevante em 10/01/2024, e as instituição terão que reexecutar este módulo a partir de 11/01/2024    **API de Pagamentos v4 (agendamentos recorrentes)** **e** **API de Pagamentos automáticos v1 (transferências inteligentes)**  - Os testes de *webhook*, que atualmente estão contidos no plano de testes geral de cada API, serão separados em um plano de testes específico para cada uma das APIs para facilitar a execução até 10/01/2024 - Até a segmentação dos testes, é necessário que seja deletado o cliente existente antes da execução dos testes de *webhook*, visto que ele exige a realização de um DCR |
