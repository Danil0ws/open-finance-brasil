# [Open Finance] Informa #882

LEMBRETE – Marco 100% das APIs de Dados Cadastrais v2.3.0 e Câmbio v1.1.0 |

 Conforme compartilhado no Informa #789 (“Divulgação dos cronogramas de versionamento minor para as APIs de Dados do cliente”), divulgado em 25/09/2025, o marco de 100% para essas APIs ocorrerá em **28/04/2026.**  Para o marco de 100%, as instituições devem obter sucesso nos seguintes planos de testes:  **API Dados Cadastrais v2.3.0**   - Functional Tests for Customer - Business API - Based on Swagger version: 2.3.0;  - Functional Tests for Customer - Personal API - Based on Swagger version: 2.3.0   **API Câmbio v1.1.0**   - Functional Tests for Exchange API - Based on Swagger version: 1.1.0   As instituições que não atingirem sucesso no marco serão notificadas via ticket do Service Desk.  Ressaltamos que a data para publicação no diretório e **Go live** dessas APIs será em **30/04/2026**.  Mais detalhes sobre os testes podem ser consultados na página de plano de testes. |
