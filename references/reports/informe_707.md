# [Open Finance] Informa #707

LEMBRETE - Marco de 100% da API Pagamentos automáticos Conforme comunicado no Informa #661 (“*Novo cronograma de implementação da v2.0.0 da API Pagamentos automáticos (Transferências inteligentes + Pix automático)*”, divulgado em 14/11/2024), **em 13/03/2025 ocorrerá o marco de 100% da API Pagamentos automáticos v2.0.0**.     Para este marco será utilizada a versão rc.1 do motor de conformidade, cujos testes a serem reexecutados podem ser encontrados no Informa #703 (“*Disponibilização da versão rc.1 do motor de conformidade para API Pagamentos automáticos*”, divulgado em 24/02/2025).     Reforçamos que instituições que não obtiverem sucesso no marco serão notificadas via *tickets* do Service Desk. |

 Comprovação de homologação no ambiente Pix *tester* para instituições detentoras de conta do Open Finance **A partir de 08/03/2025, novos entrantes que desejarem atuar como detentores de conta** deverão comprovar à Associação a realização bem-sucedida de testes de Open Finance no ambiente Pix *tester*, mediante a abertura de um ticket no Service Desk, através do seguinte caminho:   - **Solicitação de certificados > Enviar pedido de certificação > Evidência de homologação no ambiente Pix *tester***   - Será aceito como evidência um *print* do ambiente Pix *tester*, indicando a realização dos testes de Open Finance para homologação do Pix;   - Instituições cooperativas singulares que tenham como liquidante no SPI uma entidade do sistema cooperativo organizado em dois ou três níveis poderão indicar a *flag* por meio de sua organização mãe.   Após o envio da evidência, as instituições terão uma *flag* habilitada no Diretório de Participantes, que será validada durante o processamento dos pedidos de certificação das APIs Iniciação de pagamentos.    Para as instituições detentoras que já possuem essas APIs publicadas, a *flag* foi atribuída pela Associação e poderá ser consultada pelos administradores do Diretório, no recurso da organização. |
