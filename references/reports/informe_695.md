# [Open Finance] Informa #695

Dados do cliente – Data para atualização da versão *patch* da API Renda variável Informamos que as instituições deverão atualizar a versão *patch* da API Renda variável (1.2.1) no dia 24/02/2025.    A documentação da API encontra-se publicada na área do desenvolvedor, conforme divulgado no Informa #681 ("Lançamento da versão *patch* da API Renda variável (Dados do cliente)", enviado em 07/01/2025).    O motor de conformidade foi atualizado para esta API e, embora a recertificação não seja necessária, instituições que realizarem alterações em suas implementações deverão realizar testes no motor antes da publicação em produção.     Para mais detalhes, sugerimos acessar os *links*das documentações abaixo. |
