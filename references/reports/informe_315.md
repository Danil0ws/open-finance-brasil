# [Open Finance] Informa #315

Retrocompatibilidade entre v1 e v2 da API de Iniciação de Pagamentos Em complemento ao Informa #306 (“Retrocompatibilidade entre v1 e v2 da API de Iniciação de Pagamentos”, enviado em 20/01/2023), esclarecemos que todos os participantes devem observar as seguintes orientações:   - Não é permitido que um pagamento criado utilizando os *endpoints* da versão 2.0.0 seja consultado usando o *endpoint* GET/pix/payment/{paymentId} da versão 1.2.0;   - Caso essa situação ocorra, a detentora de conta poderá retornar o código de erro 422, code NAO\_INFORMADO. - Não é permitido que o consentimento de um pagamento criado utilizando os *endpoints* da versão 2.0.0 seja consultado usando o *endpoint* GET/consents/{consentId} da versão 1.2.0;   - Caso essa situação ocorra, a detentora de conta poderá retornar o código de erro 422, code NAO\_INFORMADO. |
