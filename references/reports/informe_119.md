# [Open Banking] Informa #119

Liberação dos testes beta da Fase 4A - Investimentos e Credenciamento Informamos a liberação para testes beta do motor de Conformidade Funcional da Fase 4A – Investimentos e Credenciamento. Notem que os testes para os demais produtos estão em ajustes finais e serão liberados na sequência. Pedimos às instituições que iniciem esses testes o quanto antes de forma a contribuir para a maturidade do Motor Funcional.  Os planos de testes disponíveis são:   - Functional tests for Acquiring Services - Business API - based on Swagger version: 1.0.0-rc1.0 (WIP) - Functional tests for Acquiring Services - Personal API - based on Swagger version: 1.0.0-rc1.0 (WIP) - Functional tests for Investments - Fixed Income Bank API - based on Swagger version: 1.0.0-rc1.0 (WIP) - Functional tests for Investments - Fixed Income Credit API- based on Swagger version: 1.0.0-rc1.0 (WIP) - Functional tests for Investments - Funds API - based on Swagger version: 1.0.0-rc1.0 (WIP) - Functional tests for Investments - Treasure API - based on Swagger version: 1.0.0-rc1.0 (WIP) - Functional tests for Investments - Variable Income API - based on Swagger version: 1.0.0-rc1.0 (WIP)   Adicionalmente, requisitamos que problemas ou inconsistências identificadas sejam informados através do repositório no GitLab no link abaixo. Tickets abertos através da plataforma do Service Desk continuarão sendo tratados, porém a expectativa é realizar uma transição gradual para o GitLab com intuito de reduzir a abertura de problemas duplicados e aumentar a celeridade da sua resolução. |
