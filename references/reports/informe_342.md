# [Open Finance] Informa #342

Adição do erro HTTP 529 nas APIs de Dados Abertos da fase 4A  Conforme disposto na Instrução Normativa (IN) nº 306 do Banco Central do Brasil, o Swagger da v1.0.0 das APIs de Dados Abertos da fase 4A - 1ª onda (APIs Câmbio, Investimentos, Credenciamento) será atualizado até 23/03/2023 para abranger o código de erro HTTP 529. A previsão desta atualização nas APIs de Dados Abertos da fase 4A - 2ª onda (APIs Capitalização, Previdência e Seguros) é de até 19/05/2023.  Neste sentido, o GT Especificações Dados Abertos comunica que:   - A IN nº 306 estabeleceu o uso dos códigos de erros HTTP 429 para o limite de tráfego por IP e HTTP 529 para o limite de tráfego global para as APIs de Dados Abertos; - As regras de controle de tráfego já são aplicadas para as APIs da fase 1 (API Produtos e Serviços, API Canais de Atendimentos). No entanto, estas APIs serão revisadas em data futura, a ser definida, e hoje existe um problema conhecido para tratar este erro; - Regras de controle já estão publicadas no Portal indicando a aplicabilidade em todas as APIs.   O GT Especificações Dados Abertos recomenda a releitura da IN n° 306 e consulta aos limites de tráfego vigentes publicados no Portal do Open Finance, disponíveis nos links abaixo. |
