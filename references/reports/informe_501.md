# [Open Finance] Informa #501

Fim do período de convivência da API de Pagamentos v2.0.0  Conforme comunicado no Informa #464 (“Atualização do cronograma da API de Pagamentos – v3.0.0”, enviado em 29/09/2023), o período de convivência entre as versões 2.0.0 e 3.0.0 da API de Pagamentos se encerra em 15/12/2023.  Informamos que **o desligamento da versão 2.0.0 deve ocorrer a partir das 23h59 do dia 15/12/2023 até as 23h59 do dia 18/12/2023**. |

 Workshops – Disponibilização de gravações e materiais Conforme comunicado no Informa #495 (“[LEMBRETE] Workshops: Próximas entregas do Open Finance Brasil”, enviado em 01/12/2023), entre 04/12/2023 e 12/12/2023 foram realizados 5 workshops relativos aos lançamentos que ocorrerão no início 2024, sendo eles:   - Pagamentos recorrentes (v4.0.0 da API de Pagamentos) - Novo perfil FAPI único - Transferências inteligentes (v1.0.0 da API de Pagamentos automáticos) - APIs Comum, Produtos e serviços e Canais de atendimento - APIs de Consents, Resources e Câmbio   Informamos que as gravações dos workshops estão publicadas no canal do youtube do Open Finance Brasil, e os materiais apresentados já estão disponíveis para consulta do ecossistema. Estes materiais contém o conteúdo das apresentações e as perguntas das interações do evento  devidamente respondidas pelos especialistas. |
