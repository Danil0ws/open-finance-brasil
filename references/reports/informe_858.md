# [Open Finance] Informa #858

Lançamento da v5.0.0-rc.1 da API de Pagamentos |

 Comunicamos que, em 06/03/2026, foi publicada a versão v5.0.0-rc.1 das especificações da API de Pagamentos, a qual está disponível na área do desenvolvedor em:     Especificações de APIs > Serviços - SV > [SV] Iniciação de Pagamentos > [SV] API – Pagamentos > v5.0.0-rc.1 - [SV] Pagamentos > Informações técnicas - [SV] Pagamentos - v5.0.0-rc.1     **Principais alterações contempladas na versão v5.0.0-rc.1**     **• Inclusão de novo código de erro para propósito da transação inválido**     Adicionado um novo código ao domínio errors.code na resposta HTTP 422 do endpoint POST /consents, denominado PROPOSITO\_INVALIDO, destinado a representar cenários de preenchimento incorreto do campo responsável pelo propósito da transação;     •**Inclusão do campo qrCode na resposta de criação de pagamentos**   Incluído o campo /data/qrCode na resposta de sucesso do endpoint POST /pix/payments, permitindo o retorno do QR Code associado ao pagamento com as mesmas características presentes na mensagem de requisição;     •**Inclusão de erro para falha de validação de idempotência no cancelamento de pagamentos**    Foi adicionada resposta de erro HTTP 422 ao endpoint PATCH /pix/payments/{paymentId}, com o objetivo de representar falhas relacionadas à validação das chaves de idempotência durante o processo de cancelamento de pagamentos;     **• Ajuste de tamanho máximo e definição de pattern para o campo payloadJWS**   Alterado o tamanho máximo do campo /data/payment/details/payloadJWS, passando de 512 para 16384 caracteres, para suportar corretamente cenários envolvendo QR Codes dinâmicos;    • **Ajuste no RegEx do campo creditor.name para alinhamento com DICT**   Atualizado o RegEx (pattern) do campo /data/creditor/name nas mensagens de requisição do endpoint POST /consents e nas respostas de sucesso dos endpoints POST /consents e GET /consents/{consentId}, com o objetivo de garantir compatibilidade com os caracteres aceitos pelo DICT, eliminando inconsistências de interoperabilidade.       Informações sobre o cronograma de implementação e certificação bem como a data de go live, podem ser encontradas no**Informa #812** (“Divulgação do cronograma de certificação e implementação da v5.0.0 da API Pagamentos”, divulgado em 11/11/2025).
