# [Open Finance] Informa #888

LEMBRETE – Marco 100% da API de Empréstimos |

 Conforme compartilhado no Informa #808 (“Divulgação do cronograma de versionamento minor para a API de Empréstimos v2.6.0 e publicação das especificações beta.1”), divulgado em **31/10/2025**, o **marco de 100%** da API de Empréstimos v2.6.0 – Estável ocorrerá em **12/05/2026.**  Para o marco de 100%, as instituições devem obter sucesso nos seguintes planos de testes:   **API de Empréstimos v2.6.0**   - Functional Tests for Loans API – Based on Swagger version: 2.6.0   As instituições que não atingirem sucesso no marco serão notificadas via ticket do Service Desk, conforme os procedimentos operacionais vigentes.   Ressaltamos que a publicação no diretório e o **Go Live** da API de Empréstimos v2.6.0 ocorrerão conforme o cronograma regulatório, condicionado ao atingimento do marco de certificação.   Mais detalhes sobre os testes podem ser consultados na página de plano de testes: |
