# [Open Finance] Informa #544

[PCM] RFC para nova API de acompanhamento da jornada do cliente no *Hybrid Flow* A Instrução Normativa BCB nº 441, publicada em 20/12/2023, criou a métrica e SLA para o acompanhamento da “Taxa de conversão” observada na jornada de autorização de consentimento.    Para termos clareza do que ocorre na jornada e entendermos qual etapa é a ofensora para obtenção de uma melhor taxa de conversão, o GT Arquitetura propõe um reporte e API específicos das etapas do *Hybrid Flow* para a PCM.    Solicitamos que os participantes avaliem a documentação da proposta produzida até o momento e forneçam contribuições e críticas quanto a:   - Viabilidade; - Completitude da proposta para atingimento do objetivo; - Clareza da especificação técnica, disponível em: https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/37912663/Documenta+o+da+API   Convidamos todos os participantes do ecossistema para contribuírem com esta construção. O período de *RFC* (*request for comments*) da nova API será de 11/03/2024 a 21/03/2024. O canal para envio das contribuições será o e-mail do GT Arquitetura (gt-arquitetura@openfinancebrasil.org.br).    O cronograma oficial com data limite para o envio do reporte para a nova API será deliberado pelo Conselho Deliberativo após aprovação do modelo e da RC-1 da API. |
