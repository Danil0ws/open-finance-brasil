# [Open Finance] Informa #446

Nova instituição apta a iniciar serviço de iniciação de pagamento Pix – Banco Santander A Estrutura do Open Finance Brasil informa que a seguinte instituição cumpriu todas as etapas do processo de onboarding de iniciadoras com sucesso e, portanto, está apta a iniciar o serviço de iniciação de transações de pagamento Pix no contexto do Open Finance Brasil: Banco Santander.     Com essa atualização, há atualmente 23 instituições que estão aptas a iniciar o serviço de iniciação de transação de pagamento Pix:   - Banco Bradesco - Banco BTG Pactual - Banco BV - Banco do Brasil - Banco Mercantil do Brasil - Banco Santander - Banco XP - Celcoin - Crystal BMC - Ebanx IP - Efí - Hub Pagamentos - Inter - Itaú Unibanco - Mercado Pago - Nubank - Parati - PicPay - Quanto Network - Sicoob - SICREDI - U4C - Unicred   Novas instituições serão incluídas na listagem oportunamente. |

 Liberação do motor funcional da versão  2.1.0-rc.1 das APIs de Fase 2   Conforme Informa #443 (“Alteração da data de liberação do motor da Fase 2 [minor] – melhoria na qualidade de dados”), comunicamos que o motor de conformidade da versão minor de melhoria na qualidade de dados da Fase 2 será disponibilizado na data de hoje.    A execução dos testes deverá ocorrer através de um plano de testes apartado para cada uma das APIs:  - Functional Tests for **Credit Cards API** - Based on Swagger version: 2.1.0-rc.1 - Functional Tests for **Accounts API** - Based on Swagger version: 2.1.0-rc-.1 - Functional Tests for **Loans API** - Based on Swagger version: 2.1.0-rc.1 - Functional Tests for **Financings API** - Based on Swagger version: 2.1.0-rc.1 - Functional Tests for **Invoice Financings API** - Based on Swagger version: 2.1.0-rc.1 - Functional Tests for **Unarranged Accounts Overdraft API** - Based on Swagger version: 2.1.0-rc.1   O cronograma completo para a execução dos testes é:  - **30/08/2023**: Lançamento do motor de conformidade - **11/09/2023:**Data limite para execução com sucesso de 25% dos módulos de teste - **25/09/2023:**Data limite para execução com sucesso de 50% dos módulos de teste - **05/10/2023**: Lançamento da versão estável - **09/10/2023:**Data limite para execução com sucesso de 75% dos módulos de teste - **23/10/2023:**Data limite para execução com sucesso de 100% dos módulos de teste - **Entre 23/10/2023 e 31/10/2023:** Possíveis ajustes finais de documentação e testes - **31/10/2023:***Go live* das versões atualizadas das APIs Cartões, Contas e Operações de crédito   |  | | --- | |  | |
