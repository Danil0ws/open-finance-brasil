# [Open Finance] Informa #369

[Atenção] Go live das APIs de Dados Abertos – fase 4A 1ª onda (investimentos, câmbio e credenciamento)            O **Diretório de Produção foi atualizado para permitir a publicação das APIs de Dados Abertos – fase 4A 1ª onda** (investimentos, câmbio e credenciamento) e **as instituições terão até 30/04/2023 para publicar as devidas APIs – data do *go live.*** O cronograma foi definido pela IN #357 divulgado no Informa #331 [“Importante: datas para sucesso nos testes beta do motor de conformidade de dados abertos (APIs de Investimentos, Câmbio e Credenciamento)”, enviado em 02/03/2023].     Reforçamos que essas APIs terão **certificação automatizada** no Diretório, ou seja, os testes serão executados automaticamente **no momento da publicação da API**. Caso a API esteja conforme, a publicação será feita com sucesso. Caso algum problema seja encontrado, este será notificado e a publicação não será efetivada. Portanto, não será necessária a submissão de pedidos de certificação através de tickets no service desk. Maiores informações estão no Guia Operacional do Diretório (páginas 75 a 80). |

 Service Desk – Atualização na categoria Correções Necessárias em APIs            Informamos que no dia 02/05/2023 será atribuído o SLA de 5 dias úteis a categoria **Conformidade > Correções Necessárias em APIs** do Service Desk.  Os tickets encerrados e arquivados anteriormente a data 02/05/2023 não terão o prazo de SLA atualizado. |

 Para consultar informações adicionais referente a esta categoria, acesse os artigos disponíveis na [FAQ](https://servicedesk.openbankingbrasil.org.br/KBFAQTree.jsp): API SYSAID > Formulários Customizados.  Em caso de dúvidas referentes à esta atualização, faça a abertura de um chamado na plataforma do Service Desk. |
