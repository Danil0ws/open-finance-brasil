# [Open Finance] Informa #800

LEMBRETE - Disponibilização da versão estável do motor de conformidade para API Portabilidade de Crédito  Conforme compartilhado no Informa #783 (“*Atualização do cronograma de certificação e homologação do produto Portabilidade de Crédito Pessoal Clean (CPC)*”, divulgado em 01/09/2025), **a versão estável do motor de conformidade para API Portabilidade de Crédito foi disponibilizada em 16/10/2025.**    Para esta versão do motor:  - Todos os 16 (dezesseis) testes não sofreram alterações em relação à RC.1:   - *credit-portability\_api\_core\_test-module\_v1;*   - *credit-portability\_api\_invalid-status\_test-module\_v1;*   - *credit-portability\_api\_contract-term\_test-module\_v1;*   - *credit-portability\_api\_invalid-contract-terms\_test-module\_v1;*   - *credit-portability\_api\_negative\_test-module\_v1;*   - *credit-portability\_api\_accepted\_settlement\_test-module\_v1 ;*   - *credit-portability\_api\_rejected-portability\_test-module\_v1;*   - *credit-portability\_api\_cancelled-portability\_test-module\_v1;*   - *credit-portability\_api\_portability-payment\_core\_test-module\_v1;*   - *credit-portability\_api\_x-fapi\_test-module\_v1;*   - *credit-portability\_api\_expired-consent\_test-module\_v1;*   - *credit-portability\_api\_invalid-token\_test-module\_v1;*   - *credit-portability\_api\_invalid-consent\_test-module\_v1;*   - *credit-portability\_api\_portability-idempotency\_test-module\_v1;*   - *credit-portability\_api\_portability-invalid-payment\_test-module\_v1;*   - *credit-portability\_api\_portability-patch-unhappy\_test-module\_v1.*  Mais detalhes sobre os testes podem ser consultados na página de plano de testes. |
