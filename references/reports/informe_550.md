# [Open Finance] Informa #550

Convite para sugestões sobre portabilidade salarial Tendo em vista a [IN 284](https://bcb.gov.br/estabilidadefinanceira/exibenormativo?tipo=Resolu%C3%A7%C3%A3o%20BCB&numero=284), publicada em 04/01/2023, no que tange a viabilização da portabilidade salarial, convidamos as cadeiras a enviarem sugestões de como os dados podem ser extraídos para melhor atender o cliente na operação.     Solicitamos que confirmem que as instituições possuem esses dados (razão social e CNPJ do empregador) provisionados de forma objetiva e não inferida, qual família de APIs do OFB tem mais sinergia para envio dos dados, e quais dados são necessários para a execução do processo atual de portabilidade (sobretudo na etapa de comunicação bilateral, feita via “Nuclea” [https://www.nuclea.com.br/plataforma-de-portabilidade-de-salario/](https://bra01.safelinks.protection.outlook.com/?url=https%3A%2F%2Fwww.nuclea.com.br%2Fplataforma-de-portabilidade-de-salario%2F&data=05%7C02%7Cnaiara.cavalaro%40chicagoadvisory.com.br%7C3083f4e56172459cfc1508dc48300112%7C7531e8b3c928494b9b897ee3d353272d%7C0%7C0%7C638464618220200670%7CUnknown%7CTWFpbGZsb3d8eyJWIjoiMC4wLjAwMDAiLCJQIjoiV2luMzIiLCJBTiI6Ik1haWwiLCJXVCI6Mn0%3D%7C0%7C%7C%7C&sdata=eqMzSQhhLVyyTgfo6cny5yXyEnILCZf3394sT2m3blM%3D&reserved=0) ).     Pedimos que as informações sejam enviadas até 25/03/2024, para a caixa de e-mail de Dados do Cliente ([gt-specs-dados-cliente@openfinancebrasil.org.br](mailto:gt-specs-dados-cliente@openfinancebrasil.org.br)). |
