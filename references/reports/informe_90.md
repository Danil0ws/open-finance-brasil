# [Open Banking] Informa #90

Atualização de testes funcionais da Fase 2 - Paginação Para garantir a interoperabilidade entre instituições da Fase 2, em particular para as novas regras de paginação, informamos que foi disponibilizada uma atualização para os testes referentes a API de Cartão de Crédito.  Foram incluídos no motor os seguintes módulos de teste, que deverão testar se a instituição implementou corretamente as regras de paginação na listagem das transações com de cartões de crédito:   - credit-card-api-max-page-size-paging-test - credit-card-api-page-size-test - credit-card-api-page-size-too-big-test   Para execução bem-sucedida do módulo *credit-card-api-max-page-size-paging-test*, será necessário que a instituição implemente até 1001 transações de exemplo. Para os casos de execução malsucedida, o teste retornará um *Warning*. O status *Warning*permite que a instituição prossiga com sua certificação, mas recomendamos que seja feito um esforço para adequar as APIs o mais breve possível.  Dado que o teste realiza validações importantes para a interoperabilidade do ambiente, todas as instituições deverão realizar esses 3 cenários de testes adicionais para obter a recertificação Fase 2, inclusive as instituições que já realizaram os testes e submeteram os pedidos de recertificação anteriormente. |
