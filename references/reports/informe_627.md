# [Open Finance] Informa #627

APIs que permanecerão ativas no Diretório Conforme comunicado no Informa #611 (“Inativação de recursos no Diretório de participantes”, enviado em 30/07/2024), o Diretório foi atualizado, permitindo uma rotina automática para realizar a inativação de APIs descontinuadas pela Estrutura.    Diante disso, informamos que somente as APIs relacionadas abaixo permanecerão ativas no Diretório. Todas as demais APIs serão inativadas no Diretório no dia 05/09/2024, uma vez que já foram descontinuadas. |
