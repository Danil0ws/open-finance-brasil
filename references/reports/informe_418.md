# [Open Finance] Informa #418

Lançamento da versão 3.0.0-beta1 da API de Iniciação de Pagamentos Informamos que foi publicada no dia 05/07/2023 a versão 3.0.0-beta1 da API de Iniciação de Pagamentos.     As especificações estão disponíveis na Área do Desenvolvedor em:  - Especificações de APIs > Serviços > Iniciação de Pagamentos > API – Pagamentos > v3.0.0-beta1 - Pagamentos  Será disponibilizado um período de consulta ao ecossistema, iniciando em 05/07/2023 e encerrando em 24/08/2023. Sugestões encaminhadas após o período de consulta não serão consideradas para a versão 3.0.0 da API de Iniciação de Pagamentos.  - As sugestões deverão ser encaminhadas por meio da abertura de tickets no Service Desk, seguindo a opção: Solicitações de Melhorias > APIs; - Na abertura do ticket, o título deverá ser registrado como “API Pagamentos – Melhorias” e no campo descrição deverá ser citado qual é o *endpoint*, campo e sugestão do ajuste na documentação; - Para que o ticket possa ser avaliado para a versão 3.0.0 (versão estável) da API de Pagamentos, ele deverá ser encaminhado dentro do prazo estabelecido acima, do contrário, o ticket será adicionado ao *backlog* de ajustes do GT Especificações Serviços para uma próxima versão.  Reforçamos que as datas de lançamento das versões release candidate, estável, bem como as datas limites para atingimento do sucesso nos módulos de testes, podem ser observados através do Informe #417 (“Cronograma dos próximos versionamentos *majors* da API de Iniciação de Pagamentos”, publicado em 04/07/2023). |
