# [Open Finance] Informa #635

Lançamento das versões *minor* das APIs Dados cadastrais (v2.2.0) e Empréstimos (v2.3.0) Informamos que a área do desenvolvedor do Portal do Open Finance Brasil foi atualizada, em 25/09/2024, com a documentação das versões *minor* das APIs Dados cadastrais (v2.2.0) e Empréstimos (v2.3.0).    Dentre as alterações, destacamos:   - API Dados cadastrais:   - Ajuste no atributo minItems do campo parties   - Ajuste na obrigatoriedade do campo parties para todos os CNPJs que possuam sócios e/ou administradores no cadastro do QSA (Quadro de Sócios e Administradores) - API Empréstimos:   - Ajuste no *pattern* e no atributo maxLength do campo CET   Para acessar todas as alterações, sugerimos consultar o *changelog* dessas APIs.    **Informamos que as instituições deverão atualizar essas APIs no Diretório em 14/10/2024.** Para essas versões, não será necessário realizar a recertificação.     Para mais detalhes, sugerimos acessar os links das documentações abaixo. |

 Atualização da página “Orientações – [DC] Operações de crédito” na área do desenvolvedor  Informamos que a página “Orientações - [DC] Operações de crédito” do menu "Especificações de APIs" na área do desenvolvedor do Portal do Open Finance Brasil foi atualizada com os complementos aos casos de uso de Operações de crédito e o respectivo status a ser informado pela API Recursos (Resources).     Para visualizar as alterações realizadas, consultar o link da documentação abaixo. |

 Disponibilização de novo plano de teste de *webhook* para Jornada sem redirecionamento (JSR) Informamos que hoje, 26/09/2024, foi disponibilizado um plano separado para testes de *webhook* de Jornada sem redirecionamento. A atualização visa à simplificar as execuções dos módulos de teste pelas instituições.    Os módulos de teste que foram migrados para o novo plano de testes são:   - *enrollments\_api\_webhook-rejected\_test-module\_v2* - *enrollments\_api\_webhook-revoked\_test-module\_v2*  Mediante a atualização, as instituições devem executar ambos os planos de testes disponíveis para Jornada sem redirecionamento:  - Plano de testes atual: *no-redirect-payments\_test-plan\_v2* - Novo plano de testes para *webhook*: *no-redirect-payments-webhook\_test-plan\_v2*   Mais detalhes com relação a essa atualização podem ser encontrados na *issue* #1813, disponível no Gitlab. |
