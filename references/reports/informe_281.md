# [Open Finance] Informa #281

Alteração de retorno de erro da API de Iniciação de Pagamentos   O GT Especificações Serviços comunica que foi identificada a necessidade de alterar o retorno de erro dos itens 1.2.4.1 e 2.1.4.1 na documentação da API de Iniciação de Pagamentos, conforme abaixo:   - De: HTTP Status Code 401 – INVALID\_CLIENT - Para: HTTP Status Code 400 – BAD REQUEST   Deste modo, a partir de hoje (05/12/2022) deve ser utilizado o “HTTP status code 400 – BAD REQUEST” em códigos de retorno de validações no DICT. |

 Indisponibilidade nos e-mails da OpenID Foundation  Comunicamos que o provedor de e-mails da OpenID Foundation (OIDF) sofreu uma indisponibilidade entre os dias 02 e 04 de dezembro de 2022. Todos as mensagens de e-mail enviadas nesse período foram impactadas. Pedimos para que, aqueles que contactaram a OIDF nesse período, reenviem os respectivos e-mails, especialmente aquelas mensagens relacionadas com certificação de segurança. |
