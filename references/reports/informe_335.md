# [Open Finance] Informa #335

Lançamento nova versão release candidate (v1.0.0-rc2.0) da API de Capitalização (Dados Abertos)    A área do desenvolvedor do Portal do Open Finance Brasil foi atualizada hoje (08/03/2023) com a documentação da nova versão *release candidate* v1.0.0-rc2.0 da API de Capitalização.   - É imprescindível que as instituições comecem a desenvolver esta API a partir do lançamento desta versão (*release candidate*) para não prejudicar o período de certificação conforme modificações nos cronogramas das fases 4A e 4B divulgadas por meio do Informa #319 (“Modificações nos cronogramas das fases 4A e 4B”, enviado em 10/02/2023). O não cumprimento do cronograma poderá impactar a data final para o Go-live da fase 4A, em 16/06/2023 - Durante o desenvolvimento dentro das instituições, poderão ser reportadas melhorias e necessidade de correções desta API que não ensejem alterações em sua estrutura. Em caráter excepcional, poderão ser avaliadas, a critério da convenção, correções que causem impacto no funcionamento da versão disponibilizada.   Será disponibilizado um período de consulta ao ecossistema iniciando em 11/04/2023 e encerrando em 19/05/2023. Sugestões encaminhadas após o período de consulta não serão consideradas para a versão 1.0.0 destas APIs.   - As sugestões devem ser encaminhadas por meio da abertura de um ticket, seguindo a opção: Solicitações de Melhorias > API’s - Na abertura do ticket, o título deve ser registrado como “**Fase 4A – Release candidate**” e no campo descrição deve ser citado qual é a API (Ex: API Capitalização), endpoint, campo e sugestão de ajuste na documentação - Para que o ticket possa ser considerado para a versão 1.0.0 (versão estável) da API de Capitalização, ele deve ser encaminhado até o prazo máximo estabelecido acima. Do contrário, o ticket será adicionado ao *backlog* de ajustes do GT Especificações Dados Abertos para uma próxima versão. |
