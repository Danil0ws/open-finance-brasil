# [Open Finance] Informa #553

Atualização do cronograma e *go live* da API de Pagamentos automáticos Informamos que o cronograma da API de Pagamentos automáticos foi atualizado e **a publicação em produção deverá ocorrer entre 15/04/2024 e 29/04/2024.**  Além disso, o motor será atualizado e **as instituições deverão obter sucesso em todos os módulos de teste (100% de sucesso) até 03/04/2024**. Módulos com alteração relevante só serão contabilizados para o novo marco a partir da data de atualização do motor conforme listado abaixo:   - **22/03/2024:** **Atualização relevante em 13 módulos de teste: Alteração do escopo de criação do consentimento** **de consent:consentId para recurring-consent:recurringConsentId**   - automatic-payments\_api\_sweeping-accounts-consents-core\_test-module\_v1   - automatic-payments\_api\_expirationDateTime\_test-module\_v1   - automatic-payments\_api\_multiple-consents-core\_test-module\_v1   - automatic-payments\_api\_revoked-consent\_test-module\_v1   - automatic-payments\_api\_startDateTime\_test-module\_v1   - automatic-payments\_api\_sweeping-accounts-core\_test-module\_v1   - automatic-payments\_api\_sweeping-accounts-invalid-cnpj\_test-module\_v1   - automatic-payments\_api\_sweeping-accounts-limits\_test-module\_v1   - automatic-payments\_api\_sweeping-accounts-wrong-creditor\_test-module\_v1   - automatic-payments\_api\_sweeping-accounts-root-cnpj\_test-module\_v1   - automatic-payments\_api\_webhook-revoked\_test-module\_v1   - automatic-payments\_api\_webhook-acsc\_test-module\_v1   - automatic-payments\_api\_webhook-multiple-consents\_test-module\_v1  - **27/03/2024: Disponibilização do motor estável – adição de novo teste e alteração relevante em módulo de múltiplas alçadas**   - Novo módulo de teste “automatic-payments\_api\_invalid-scope\_test-module\_v1” será disponibilizado no motor para verificar que as instituições não estão permitindo pagamentos com o escopo insuficiente   - Módulo “automatic-payments\_api\_multiple-consents-core\_test-module\_v1” sofrerá alteração relevante   Informações adicionais referentes às mudanças no motor podem ser consultadas através de *issues* no GitLab.  Lançamento da versão 1.0.0 da API de Pagamentos automáticos (Transferências inteligentes)  Informamos que a área do desenvolvedor do Portal do Open Finance Brasil foi atualizada, em 21/03/2024, com a **versão v1.0.0 (estável) da API de Pagamentos automáticos.**   - Dentre as alterações, destacamos mudanças relacionadas às regras do x-fapi-interaction-id, adição de novo motivo de rejeição, e esclarecimentos sobre os limites para Transferências inteligentes. - Sugerimos consultar o *changelog* para que sejam analisadas todas as alterações entre a versão estável e a versão *release candidate* 4. |
