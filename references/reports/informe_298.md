# [Open Finance] Informa #298

Fase 3 – Atualização da lista de problemas conhecidos    O Grupo Técnico de Especificações Serviços comunica que foi adicionado um item à planilha de problemas conhecidos da fase 3, conforme segue:   - **BCLOG-F03-V2-002**   - **API/Sessão:** API Payments   - **Endpoints:** Todos   - **Campo:** -   - **Qual o problema:** Problema na descrição dos códigos de erro 400 e 422, que não estão aderentes às especificações da API de Pagamentos     - **Erro 400:** A requisição foi malformada, omitindo atributos obrigatórios, seja *payload* ou através de atributos na URL     - **Erro 422:** A solicitação foi bem formada, mas não pôde ser processada devido à lógica de negócios específica da solicitação   - **Como deveria ser:** As descrições deveriam explicitar as regras conforme as regras de validações descritas no *header* da API   - **Orientação:** Seguir o conteúdo do *header* da API |
