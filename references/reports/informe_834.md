# [Open Finance] Informa #834

LEMBRETE - Jornada sem redirecionamento (JSR) - Lançamento da versão estável v2.2.0 (minor) da API Vínculo de dispositivo e v1.3.0 (minor) da API Webhook |

 De acordo com o Informa #789 (“Jornada sem redirecionamento (JSR) - Divulgação do cronograma de implementação da v2.2.0 *(minor)* da API Vínculo de dispositivo e v1.3.0 *(minor)* da API Webhook”, enviado em 25/09/2025)    Comunicamos que em 12/01/2026 publicamos o **versionamento da estável** da API Vínculo de dispositivo v2.2.0 e da API Webhook v1.3.0 contendo alterações que serão necessárias para o início do piloto do produto em 06/02/2026, destacamos as principais mudanças:     Para API Vínculo de dispositivo:    - Esclarecimentos sobre qual dispositivo devem ser extraídos os sinais de risco quando um autenticador externo ao dispositivo utilizado pelo usuário for responsável pela autenticação (ex. Yubikeys); - Esclarecimentos sobre sinais de riscos condicionais e quais cenários eles são obrigatórios;   Para API Webhook:    - Houve apenas uma alteração, a adição do campo "/data/eventType", responsável por facilitar a identificação do tipo de alteração no recurso que disparou a notificação. Reforçamos que as orientações para **novos entrantes** foram disponibilizadas no **Informa #831** (“Orientações para certificação de jornada sem redirecionamento para novos entrantes”, enviado em 09/01/2026). |
