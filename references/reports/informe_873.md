# [Open Finance] Informa #873

LEMBRETE – Marco de 50% das APIs Contas v2.5.0-beta.2 e Cartão de Crédito v2.4.0-beta.2 |

 Reforçamos que, conforme divulgado no Informa **#846** (“Atualização do cronograma para as APIs de Contas e Cartão de Crédito”, divulgado em 05/02/2026), o motor de conformidade para as **APIs Contas v2.5.0-beta.2** e **Cartão de Crédito v2.4.0-beta.2** foi disponibilizado em **27/03/2026**.  O marco de **50% ocorrerá em 14/04/2026**, sendo esperado que as instituições atinjam sucesso em 50% dos módulos de testes definidos nos respectivos planos de testes.    Complementando o Informe **#867**("Disponibilização dos motores para as APIs Contas v2.5.0-beta.2 e Cartão de Crédito v2.4.0-beta.2", divulgado em 27/03/2026), ressaltamos que as instituições já certificadas não precisarão passar por um novo processo de certificação. No entanto, para atingir o marco de 50%, é necessário executar novamente os testes dos **módulos alterados** e dos **módulos novos**, considerando os resultados obtidos na versão atual dos motores de conformidade.    Para a API Contas v2.5.0-beta.2, deve ser considerado o plano de testes **Functional Tests based on Swagger 2.5.0-beta.2**, com execução do seguinte módulo:   - accounts\_api\_current-transactions\_test-module\_v2-5  **Módulos opcionais** (para instituições que não implementam o endpoint GET /accounts/{accountId}/reserved-balances):  - accounts\_api\_reserved\_balances\_test-module\_v2-5 - accounts\_api\_reserved\_balances\_permissions\_v2-5 - accounts\_api\_reserved\_balances\_operations\_limits\_v2-5  Para a API Cartão de Crédito v2.4.0-beta.2, os testes seguem o plano **Functional Tests for Credit Card API - Based on Swagger version: 2.4.0-beta.2**, com execução dos módulos definidos no respectivo plano de testes, incluindo:  - credit-cards\_api\_transactions-current\_test-module\_v2-1**(Módulo Alterado)** - credit-cards\_api\_core\_test-module\_v2-1**(Módulo Alterado)** - credit-cards\_api\_instalment\_test-module\_v2-4 **(Módulo Novo)**   As instituições que não atingirem sucesso no marco de 50% serão notificadas via tickets do Service Desk.    Mais detalhes podem ser consultados na página de plano de testes das APIs. |
