# [Open Finance] Informa #944

Disponibilização da versão v2.3.0-rc.1 do motor de conformidade da API Vínculo de dispositivo |

 Conforme compartilhado no Informa #928 (“*Jornada sem Redirecionamento (JSR) – Divulgação do cronograma de implementação da versão v2.3.0 da API de Vínculo de Dispositivo*”, divulgado em 28/07/2026) e Informa #930 *(“Publicação da versão v2.3.0-rc.1 da API de Vínculo de Dispositivo – Jornada sem Redirecionamento (JSR)”,* divulgado em 31/07/2026.     **Comunicamos que, em 28/08/2026, a versão v2.3.0-rc.1 do motor de conformidade da API Vínculo de dispositivo foi publicada.**  Esta versão será utilizada para o**marco de certificação 100% com data para 11/09/2026.**    **Sucesso no marco de 100%**    Para o marco de 100%, as instituições devem obter sucesso nos seguintes módulos de testes disponibilizados no **Plano:** Enrollments API - v2.3.0 - Conformance Suite.  **Módulos**:   1. enrollments\_api\_embedded-cross-origin-flow\_test-module\_v2-3; 2. enrollments\_api\_embedded-revoked-top-origin-rejection\_test-module\_v2-3; 3. enrollments\_api\_embedded-untrusted-top-origin-rejection\_test-module\_v2-3; 4. enrollments\_api\_custom-high-transaction-limit\_test-module\_v2-3; 5. enrollments\_api\_optional-limit-absence\_test-module\_v2-3;   Reforçamos que as instituições que não obtiverem sucesso no marco serão notificadas via *tickets* do Service Desk. |
