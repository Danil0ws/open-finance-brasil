# [Open Finance] Informa #766

LEMBRETE - Disponibilização da versão rc.1 do motor de conformidade para API Portabilidade de Crédito Conforme compartilhado no Informa #716 (“*Divulgação do cronograma de certificação e homologação do produto Portabilidade de Crédito Pessoal Clean (CPC)*”, divulgado em 28/03/2025), a **versão rc.1 do motor de conformidade para API Portabilidade de crédito será disponibilizada em 01/08/2025 e será utilizada para o marco de 100% em 12/08/2025.**    Para esta versão do motor, 2 (dois) novos testes foram adicionados:   - credit-portability\_api\_portability-invalid-payment\_test-module\_v1; - credit-portability\_api\_portability-patch-unhappy\_test-module\_v1.   **STR específica para o OFB**  Informamos que as orientações relativas à nova STR 0052 (Transferência para portabilidade de crédito no âmbito do Open Finance) já estão disponíveis através do *Catálogo de Serviços do SFN v5.10*. Destacamos que, a partir de 04/08/2025, a funcionalidade estará disponível para testes em ambiente de homologação.  **Sucesso no marco de 100%**  Para fins de contabilização de sucesso neste marco, as instituições detentoras de conta devem obter**êxito em todos os 16 (dezesseis) testes obrigatórios**. Reforçamos que, nessa versão do motor, todos os testes foram ajustados, sendo, portanto, necessária a criação de um novo plano de testes e sua reexecução integral.  Mais detalhes sobre os testes podem ser consultados na página de plano de testes. |
