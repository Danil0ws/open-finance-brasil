 [LEMBRETE] – Execução obrigatória dos marcos da API Admins, Renovação Simplificada e minor Fase 2 Conforme disponibilizado nos Informas #456 “Divulgação do cronograma de renovação simplificada de consentimento e revisão do cronograma minor da fase 2” e #457 “Liberação do motor funcional das APIs admins e comuns”, **nesta semana, em 27/10/2023 teremos três marcos importantes para o ecossistema:**      **Renovação simplificada:** 100% de sucesso – obrigatório para todas as transmissoras de dados  ***Minor* Fase 2**: 100% de sucesso – obrigatório para todas as transmissoras de dados  **Admins:** Marco de 0% (Início das execuções) – obrigatório para todas as transmissoras de dados e detentoras de contas     Os planos de teste deverão ser criados a partir da data de última alteração no motor, que está disponível no item *Breaking Changes* do release notes de cada API. |

 Renovação simplificada - Disponibilização de novo plano de testes para instituições que oferecem token JWT e atualizações minor no motor Comunicamos que em 17/10/2023 **foi disponibilizada a versão release candidate de Renovação Simplificada, sem mudança nas especificações nem alterações relevantes no motor**. As mudanças foram a atualização do nome do plano de testes e redução do nível de restrição do teste “consents\_api\_extension-invalid-status-rejected\_test-module\_v2”.     Além disso, **foi disponibilizado um novo plano de teste “Functional Tests for Consents Extensions API with JWT” para as instituições que oferecem refresh\_tokens JWT**. Este plano contém um módulo de teste “consents\_api\_extension-jwt-module\_v2” que valida se a instituição retorna um erro 422, conforme já descrito nas especificações.     O prazo para execução com sucesso deste módulo é 27/10/2023. |

 [LEMBRETE] – Execução obrigatória da FVP 2.0 Conforme Informa #441 “Atualização do cronograma de execução da FVP 2.0”, informamos que o ciclo atual para execução da FVP 2.0 se encerra em 30/10/2023.     É necessário que as instituições executem os planos de teste e os módulos abaixo, de acordo com as fases nas quais participam.     **Instituições participantes de Fase 2:**     **Open Finance Brasil Functional Production Tests - FVP Phase 2 - Customer Data**  *fvp-preflight-check-test-v2*  *resources-api-test-v2*     **Instituições participantes de Fase 3:**     **Open Finance Brasil Functional Production Tests - FVP Phase 3 – Payments**  *fvp-preflight-cert-check-payments-test-v2*  *fvp-payments-consents-core-test-v2*     Adicionalmente, informamos que a execução é obrigatória para todos os servidores, e deve ser realizada para clientes PF e PJ (quando aplicável). |
