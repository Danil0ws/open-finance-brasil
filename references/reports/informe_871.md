# [Open Finance] Informa #871

**Disponibilização da versão rc.1 do Motor – API de Pagamentos (v5.0.0)**   Conforme compartilhado o comunicado nos Informas:   - #812 – *Divulgação do cronograma de certificação e implementação da v5.0.0 da API Pagamentos* (11/11/2025)  - #858 – *Lançamento da v5.0.0-rc.1 da API de Pagamentos* (10/03/2026)  Informamos que a versão v5.0.0-rc.1 do motor de conformidade será disponibilizada em 06/04/2026.   Essa versão será utilizada para o marco de 100% de certificação, com data de 22/04/2026. Diante disso, é necessário que as instituições executem com sucesso todos os módulos de testes cujos planos podem ser consultados na página da área do desenvolvedor.      **Estratégia de disponibilização dos testes**    Os testes da versão rc.1 serão fracionados em duas datas:  - **Etapa 1: Motor disponibilizado em 06/04/2026**  - **Etapa 2: Motor disponibilizado em 10/04/2026**  **Etapa 1: Motor disponibilizado em 06/04/2026**     **Breaking Changes:**Cenários alterados que necessitam de uma nova reexecução de todas as instituições participantes, a partir de 06/04/2026, dadas as mudanças comportamento nos testes   **Plano:**payments-timezone\_test-plan\_v5  - Módulo de teste: payments\_api\_consent-bulk-cancel\_negative\_timezone\_test-module\_v5  **Plano:**payments-apes\_test-plan\_v5  - Módulo de teste: payments\_api\_apes-code-unhappy-path-required\_test-module\_v5;​  **Novos cenários:**Obrigatória obtenção de sucesso para todas as instituições participantes, com exceção das instituições dispensadas da Jornada Sem Redirecionamento   **Plano:** payments-apes\_test-plan\_v5, relativo a **APES** (QR Code estático via NFC)  - Módulo de teste: payments\_api\_consent-purpose-validation-unhappy-path-invalid-combination\_test-module\_v5  **Plano:**payments-apdn\_test-plan\_v5, relativo a **APDN** QR Code dinâmico via NFC (por aproximação)  - Módulos de teste:  - payments\_api\_apdn-good-happy-path\_test-module\_v5  - payments\_api\_apdn-mismatched-consent-payment\_test-module\_v5  - payments\_api\_apdn-unhappy-path\_test-module\_v5  -------------------------------------------------------------------------------------------------   **Etapa 2: Motor disponibilizado em 10/04/2026**     **Breaking Change:**Cenário alterado que necessita de uma nova reexecução, de todas as instituições participantes, a partir de 10/04/2026, dada a mudança comportamento no teste:  **Plano:**payments\_test-plan\_v5  - Módulo de teste:  payments\_api\_idempotency\_test-module\_v5  **Novos cenários para Pix Saque e Troco**: Obrigatória a obtenção de sucesso para todas as instituições participantes:  **Plano:**payments-withdraw-qres\_test-plan  - Módulos de testes:  - payments\_api\_pix-withdraw-dynamic-qrdn\_test-module\_v5  - payments\_api\_pix-withdraw-invalid-amount\_test-module\_v5;  - payments\_api\_pix-withdraw-change-exceeds-limit\_test-module\_v5;​  - payments\_api\_pix-withdraw-change-invalid-date\_test-module\_v5. ​  **Plano:**payments-change-qrdn\_test-plan  - Módulo de teste: payments\_api\_pix-change-dynamic-qrdn\_test-module\_v5; |
