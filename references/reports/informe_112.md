# [Open Banking] Informa #112

Abertura de certificação funcional da Fase 3A – 3º Ciclo Comunicamos que está aberta para submissão a certificação funcional da Fase 3A – 3º Ciclo, a qual contempla os produtos do 1º Ciclo (INIC, DICT e Manu) e do 3º Ciclo (QR Code estático e dinâmico).  Reforçamos que, conforme o Informa #111, as instituições que estão executando testes do 1º Ciclo terão até 14/01 para enviar a submissão e até 21/01 para finalizar o processo de certificação. Após essas datas, serão apenas emitidos certificados para o 3º Ciclo, com escopo cumulativo (que englobam todos os produtos até o momento).  Para realizar os testes, será necessário gerar QR Codes dinâmicos pela ferramenta do Pix Tester, disponibilizada pelo BCB. Para maiores informações, favor consultar o Guia de utilização do Pix Tester para certificação funcional do Open Banking.  Caso a instituição encontre problemas nos testes, pedimos que abra um chamado no GitLab endereçado ao motor de conformidade funcional. |
