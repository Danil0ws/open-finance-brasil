# [Open Finance] Informa #630

Atualização do motor de conformidade para problemas conhecidos das APIs de fases 2 e 4B Conforme comunicado nos Informas #603 (“Lançamento das versões *minor* das APIs Financiamento (v2.2.0), Adiantamento a Depositantes (v2.2.0) e Direitos Creditórios Descontados (v2.2.0)”, enviado em 05/07/2024) e #609 (“Lançamento da versão *minor* da API Renda variável (v1.2.0)”, enviado em 18/07/2024), as APIs mencionadas foram atualizadas para incorporar os problemas conhecidos. E, **em 17/09/2024, as instituições deverão realizar a publicação das novas versões no Diretório de participantes:**   - API Financiamentos - *v2.2.0* - API Adiantamento a depositantes - *v2.2.0* - API Diretos Creditórios Descontados - v2.2.0 - API Renda Variável - *v1.2.0*   Informamos que o motor de conformidade foi atualizado e as instituições que realizarem alterações em suas implementações deverão executar os testes no motor antes da publicação em produção. |
