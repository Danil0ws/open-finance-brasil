# [Open Finance] Informa #609

Lançamento da versão 2.1.0-rc.2 (*release candidate*) da API Dados cadastrais Informamos que a área do desenvolvedor do Portal do Open Finance Brasil foi atualizada, em 18/07/2024, com a documentação da versão 2.1.0-rc.2 (*release candidate*) da API Dados cadastrais.    A documentação da API passou pelo seguinte ajuste:  •    Remoção do *pattern* e inclusão do *format* no campo email para permitir caracteres maiúsculos.    O *go live* dessa API se mantém em 15/08/2024, conforme informe #582 ("Divulgação do cronograma de dados do empregador e resolução de problemas conhecidos das APIs Dados Cadastrais e Contas", enviado em 22/05/2024).  Para mais detalhes, sugerimos acessar os links de documentação abaixo. |

 Lançamento da versão *minor* da API Renda variável (v1.2.0) Informamos que a área do desenvolvedor do Portal do Open Finance Brasil foi atualizada, em 18/07/2024, com a documentação da versão *minor* da API Renda variável (v1.2.0).    A documentação da API passou pelas seguintes alterações:  •    Incorporação das orientações do problema conhecido BCLOG-F04-001;  •    Ajustar os *patterns* dos campos de links.    Informamos que as instituições deverão atualizar a versão 1.2.0 dessa API no Diretório em 17/09/2024. Não será necessária a recertificação.  •    A data em que o motor de conformidade estará disponível, caso a instituição deseje utilizá-lo para validar sua implementação antes da publicação da nova versão, será divulgada posteriormente.
