# [Open Banking] Informa #89

Esclarecimento sobre a obrigatoriedade de publicação das APIs de Monitoramento Reiteramos que, conforme IN nº 130, as APIs de Status, de Outages e Métricas são comuns a todos OS participantes do Open Banking Brasil, independentemente da fase de adesão. Portanto, todas as instituições devem publicar essas APIs que monitoram a situação do ambiente. Reforçamos ainda que na API de métricas devem ser reportados os dados de performance de todas demais APIs que a instituição desenvolveu.  Adicionalmente, o cronograma de certificação funcional da API de métricas está em elaboração e deverá ser divulgado nos próximos dias. |

 Abertura de Testes Funcionais versão beta da API de Métricas Estão liberados testes funcionais versão beta para API de métricas - Functional tests for Admin API – based on swagger version 1.0.1 (WIP).  Requisitamos que todas as instituições adicionem o IP do motor de testes (34.218.96.135) ao *allowed list* da API de Métricas, mesmo as que não pretendam realizar os testes nesse momento. |

 Processo de pagamento de certificação de segurança Relying Parties As instituições que aderirem a comunidade Relying Parties poderão adquirir o certificado a um preço reduzido de USD 1.000. Para tal, é necessária a adesão à comunidade RP no canal do Slack do Open Banking Brazil RP Community conforme os passos abaixo:    A) É necessário um membro do RP / TTP para ingressar no canal do [Slack do Open Banking Brazil RP Community](https://app.slack.com/client/T02GHDV50AU/D02KC0EJH6C)  B) Assim que o RP / TPP entrar no canal Slack, o membro precisa se apresentar e apresentar sua organização por meio do subcanal #introduce-yourself  C) Em seguida, enviar mensagem direta para mike.leszcz ou Filip Skokan no Slack selecionando o nome no menu à esquerda com uma solicitação do código de desconto da taxa de certificação RP / TPP.  D) Assim que o código de desconto for recebido, acesse este link e inclua o código de desconto na [Etapa 1](https://openid.net/foundation/members/certifications/new).  Os pagamentos das taxas de certificação deverão ser feitos diretamente para a OpenID Foundation. Para instituições que optaram anteriormente por realizar o pagamento através da estrutura centralizada, pedimos que incluam a observação "Payment made through Chicago Advisory Partners" no campo "descrição" do formulário para submissão da certificação. Neste último caso, informamos que os pagamentos deverão ser recebidos pela estrutura centralizada até o dia 24 de novembro e confirmados através do e-mail [administrativo@openbankingbr.org](mailto:administrativo@openbankingbr.org). |
