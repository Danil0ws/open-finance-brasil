# [Open Finance] Informa #498

Disponibilização do motor funcional da API de Pagamentos automáticos – v1.0.0 Comunicamos que o motor funcional da API de Pagamentos automáticos – v1.0.0 será disponibilizado hoje, 08/12/2023 com três módulos de teste:   - automatic-payments\_api\_swepping-accounts-consents-core\_test-module - automatic-payments\_api\_swepping-accounts-invalid-creditor\_test-module - automatic-payments\_api\_rejected-consent\_test-module   Conforme divulgado no Informa #491 (“Revisão do marco A – API de Pagamentos automáticos”, enviado em 24/11/2023), para o primeiro marco, que ocorrerá em 15/12/2023, **as instituições terão que executar com sucesso um módulos de teste**.      O módulo automatic-payments\_api\_negative-consents-core\_test-module, inicialmente previsto para ser disponibilizado nesta entrega, estará disponível junto com o 2º bloco do motor em 22/12/2023.     **Recomendamos a execução** dos módulos “automatic-payments\_api\_swepping-accounts-invalid-creditor\_test-module” e “automatic-payments\_api\_rejected-consent\_test-module” que não possuem dependência com o guia de UX.     Além disso, na próxima versão da especificação, haverá uma alteração para tornar o campo businessEntity condicional.
