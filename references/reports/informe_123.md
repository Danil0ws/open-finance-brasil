# [Open Banking] Informa #123

Disponibilização de funcionalidade para certificação automatizada da Fase 4A Foi disponibilizado, no diretório de sandbox, uma funcionalidade para certificação automatizada das APIs de dados abertos, iniciando pelas APIs da Fase 4A.  Recomendamos que as instituições acessem o diretório sandbox e se familiarizem com a funcionalidade. Até o momento, já está disponível a funcionalidade para os escopos de Investimentos e Credenciamento.  Nos próximos dias, os demais escopos serão disponibilizados e comunicados ao ecossistema através de Informa.  Para esses escopos, **o novo processo de certificação substituirá a abertura de ticket** e preparação de documentação para pedido de certificação funcional. **Para os demais escopos (Fases 2 e 3), o processo anterior se mantém.**  De maneira análoga às demais fases, o motor de conformidade funcional para realização de testes também engloba os planos de testes dos escopos supracitados para uso livre pelas instituições para apoio ao desenvolvimento.  A disponibilização no diretório de produção e, consequentemente, a abertura da certificação, depende da maturidade dos testes. Portanto, **reforçamos a importância de que as instituições realizem testes.**  As orientações para utilização estão disponíveis no Guia Operacional do Diretório v. 1.1.6, página 63. |
