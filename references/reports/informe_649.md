# [Open Finance] Informa #649

Atualização da métrica de monitoramento (IN BCB nº 441) do cumprimento de papel regulatório – cooperativas           Informamos que a métrica de cumprimento regulatório das modalidades de participação foi atualizada para adequar o monitoramento (IN BCB nº 441) de cooperativas.     Dessa forma, para as organizações identificadas pela *flag* 'Cooperativas de Crédito Singulares, Centrais e Confederações' e com o atributo *ParentOrganisationReference* preenchido no Diretório, a verificação da métrica de cumprimento regulatório das modalidades de participação deve considerar também a presença da *role* CONTA na própria organização filha.     O ajuste na métrica será incorporado no fluxo de monitoramento e gestão de consequências a partir de 30/11/2024. Até essa data, as organizações filiadas das Cooperativas Centrais ou Confederações deverão revisar o cadastro de seus papéis regulatórios no Diretório de participantes. |

 Erro nas especificações das APIs Adiantamento a Depositantes e Fundos de Investimento         O Squad Qualidade de Dados comunica que identificou erro na especificação da API Adiantamento a Depositantes e na API Fundos de Investimento, comprometendo o processo de validação do Motor de Qualidade de Dados (MQD). Dessa forma, os tickets abertos referentes às devidas APIs devem ser encerrados se estiverem apontando erro para o seguinte campo:   - API Adiantamento a Depositantes   - */data/instalmentPeriodicityAdditionalInfo*      - Erro na especificação: O JSON-SCHEMA não consegue validar a obrigatoriedade com base na descrição do campo, conforme a seguir:       - *Description: Campo obrigatório para complementar a informação relativa à periodicidade de pagamento regular quando tiver a opção OUTROS. Preencher o campo quando não aplicável com string vazia ("")* - API Fundos de Investimentos; API Títulos do tesouro direto e API Renda fixa bancária   - */links/last*     - Erro na especificação: O *pattern* do campo está em desacordo com o padrão adotado para os outros campos de links. O *pattern* adotado hoje não permite o uso de *underscore* (\_) nas URLs, o que é, na verdade, uma validação incorreta. Assim, tickets abertos para esse campo que contenham o *pattern* despadronizado devem ser encerrados.   Caso o ticket aberto se refira a outros campos ou outras APIs, o erro deverá ser corrigido. |
