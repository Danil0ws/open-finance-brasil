# [Open Finance] Informa #272

Lançamento da versão 2.0.0 da API de Iniciação de Pagamentos O Grupo Técnico de Especificações Serviços comunica que, no dia 18/11/2022, a *release candidate* da versão 2.0.0 da API de Iniciação de Pagamentos foi lançada como versão estável e as especificações estão disponíveis no Portal do Open Finance Brasil.     Em termos de funcionalidades, esta nova versão acrescenta o agendamento de parcela única para até 12 meses e a possibilidade de o cliente realizar, na iniciadora de pagamentos, o cancelamento das transações de pagamento que estejam nas situações agendada com sucesso, aguardando autorizações de múltipla alçada ou temporizadas.     Foram disponibilizados na Área do Desenvolvedor do Open Finance Brasil:   - As especificações técnicas (Swagger, dicionário de dados, máquina de estados, etc.) no menu: Especificações de APIs > Serviços > Iniciação de Pagamentos > API - Pagamentos > v2.0.0 - Pagamentos - Orientações sobre SLA, desempenho, disponibilidade, TPS, etc. no menu: Requisitos não Funcionais - Resumo das alterações em relação a versão 1.2.0 no menu: Histórico de Alterações > Changelog > Changelog Serviços > API Payments - v2.0.0  Os participantes do Open Finance que atuam como detentores de conta, deverão disponibilizar em produção (*go live*) a versão 2.0.0 da API às 00:00 do dia 15/02/2023. Para garantir a interoperabilidade entre os participantes do ecossistema será necessário obter a certificação funcional conforme cronograma divulgado no Informa #270 ("Cronograma de certificação da API de Pagamentos v2.0.0") enviado em 11/11/2022.     O período de convivência entre as versões 1.2.0 e 2.0.0 da API se inicia às 00:00 do dia 15/02/2023 e vai até às 23:59 do dia 16/05/2023. Somente após este período as detentoras de conta poderão aposentar a versão 1.2.0.     Os participantes que atuam como iniciadores de pagamento podem utilizar tanto a versão 1.2.0 quanto a 2.0.0 durante o período de convivência. Porém, após este período deverão obrigatoriamente utilizar a versão 2.0.0.     Para a abertura de tickets relacionados à versão 1.2.0 da API de Iniciação de Pagamentos, devem ser observadas as orientações abaixo:  - Solicitação de informações > API’s – esta categoria poderá ser utilizada até 16/05/2023 e deve ser usada quando se deseja informações adicionais do comportamento da API. Não deve ser utilizada para apontar problemas na especificação ou sugestões de melhoria. - Solicitação de melhorias > API’s – esta categoria é utilizada para sugestões de melhorias e apontamentos de problemas na especificação. Poderá ser usada normalmente até 14/02/2023, desta data em diante deve-se usar apenas para apontar problemas de segurança. Tem sua aposentadoria ocorrendo em 16/05/2023, a partir deste momento não deve mais ser utilizada para a versão antiga da API. - Incidentes > API’s / Interoperabilidade > (demais subcategorias) – estas categorias são utilizadas para apontamentos de problemas bilaterais entre os participantes do Open Finance. Poderão ser utilizadas normalmente até 14/02/2023. Após esta data deve-se usar apenas para situações de indisponibilidade, segurança e/ou caso haja alguma mudança no comportamento da API. Tem sua aposentadoria ocorrendo em 16/05/2023, a partir deste momento não deve mais ser utilizada para a versão antiga da API. |
