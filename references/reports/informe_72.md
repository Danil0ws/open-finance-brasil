# [Open Banking] Informa #72

Swagger API Service Desk Já está disponível o Swagger da API Service Desk, framework usado para descrever, documentar e auxiliar os desenvolvedores na utilização da API do Service Desk do Open Banking.    Através dele é possível realizar testes de requisição nos ambientes de Sandbox e DEV. Essa funcionalidade permite que o desenvolvedor que utiliza esta documentação da API saiba exatamente o que esperar nas respostas e o que é necessário enviar nas requisições. |

 Catálogo de Serviços - Service Desk Open Banking **Alterações na Categoria de Motor de Conformidade**    A categoria de Motor de conformidade sofrerá as seguintes alterações a partir do dia 25/10:    - A Categoria de Terceiro nível "API" agora está disponível somente dentro da Categoria de Incidentes.    - Alteração da nomenclatura da Subcategoria “Conformidade” para “Motor de Conformidade”;    - Implantação das Categorias de Terceiro Nível, “Lentidão ou Degradação”, “Erro” e “Indisponibilidade”;    De: Incidentes > Conformidade > Motor de Conformidade e API  Para: Incidentes > Motor de Conformidade > Lentidão ou Degradação, Erro e  Indisponibilidade    Visualização da imagem  **Inclusão da Categoria de Segurança**    A categoria “MISP” estará disponível a partir do dia 25/10 para solicitações de Acesso à plataforma de compartilhamento de ameaças de segurança.    Solicitação de Acessos > MISP > Concessão Usuário, Concessão Instância, Revogação Usuário, Revogação Instância |
