# [Open Finance] Informa #539

Lançamento da versão 1.0.0-rc.4 da API de Pagamentos automáticos (Transferências inteligentes)   Informamos que a área do desenvolvedor do Portal do Open Finance Brasil foi atualizada, em 05/03/2024, com a **versão 1.0.0-rc.4 (*release candidate)* da API de Pagamentos automáticos.**   - Sugerimos consultar o *changelog* para que sejam analisadas todas as alterações entre versões 1.0.0-rc.3 e 1.0.0-rc.4; - Dentre as alterações, destacamos as mudanças relacionadas ao campo ibgeTownCode. |

 Atualização de cronograma da API de Pagamentos automáticos (Transferências inteligentes)  Em decorrência do lançamento da nova versão da especificação, **o cronograma da API de Pagamentos automáticos versão 1.0.0 foi atualizado e o marco de 100% que ocorreria em 08/03/2024 foi prorrogado para 13/03/2024**.      Em 08/03/2024, o motor funcional será ajustado, tornando 11 testes menos restritivos e implicando em **uma alteração relevante no módulo automatic-payments\_api\_sweeping-accounts-core\_test-module\_v1.**   - O módulo com alteração relevante terá o comportamento alterado para esperar sucesso em uma chamada realizada sem informar o ibgeTownCode; - Os testes que se tornarão menos restritivos aceitarão que o campo ibgeTownCode não seja enviado.     Após atualização dos testes, é necessário criar um novo plano de testes, mas a reexecução só é obrigatória para o módulo que sofreu alteração relevante. Nos demais módulos, a reexecução não será necessária para as instituições que já obtiveram sucesso.  O cronograma atualizado pode ser conferido abaixo: |

 O cronograma prevê:   - Lançamento de versão estável das especificações em 21/03/2024 - Liberação do motor de testes versão *rc.4* em 08/03/2024 - Liberação do motor de testes versão estável em 27/03/2024 - Marco de 100% de sucesso em 13/03/2024 - *Go liv*e em 15/04/2024 |
