# [Open Finance] Informa #808

Lançamento da v2.2.0-rc.3 da API Vínculo de dispositivo e v1.3.0-rc.2 da API *Webhook* |

 Informamos que em 31/10/2025, foram publicadas as versões 2.2.0-rc.3 e 1.3.0-rc.2 das especificações das APIs Vínculo de dispositivo e Webhook, respectivamente; as quais se encontram disponíveis na área do desenvolvedor do Portal do Open Finance Brasil em: **API Vínculo de dispositivo v2.2.0-rc.3**  - Especificações de APIs > Serviços - SV > [SV] Iniciação de Pagamentos > [SV] API – Pagamentos sem redirecionamento > v2.2.0-rc.3 - [SV] Vínculo de dispositivo;  **API Webhook v1.3.0-rc.2**  - Especificações de APIs > Webhook > v1.3.0-rc.2 – Webhook.   Informações sobre o cronograma de implementação, certificação, bem como a data de *go live*, podem ser encontradas no Informa #789 (“*Jornada sem redirecionamento (JSR) - Divulgação do cronograma de implementação da v2.2.0 (minor) da API Vínculo de dispositivo e v1.3.0 (minor) da API Webhook*”, publicado em 25/09/2025).
