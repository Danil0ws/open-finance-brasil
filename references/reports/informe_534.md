# [Open Finance] Informa #534

[Atenção] *Go live* das APIs de Dados Abertos – Fase 1 (Canais de Atendimento, Produtos e Serviços) e Comum Relembramos que amanhã, **27/02/2024, é o *go live* das APIs de Fase 1 (Canais de Atendimento, Produtos e Serviços) e da API Comum**. O período de convivência entre as versões novas e antigas das APIs vai até 27/05/2024, conforme Informa #504.     Reforçamos que **essas APIs terão certificação automatizada no Diretório**, ou seja, os testes serão executados automaticamente no momento da publicação da API. Caso a API esteja conforme, a publicação será feita com sucesso. Caso algum problema seja encontrado, este será notificado e a publicação não será efetivada. Portanto, não será necessária a submissão de pedidos de certificação através de tickets no service desk. Maiores informações estão no Guia Operacional do Diretório. |
