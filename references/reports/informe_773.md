# [Open Finance] Informa #773

LEMBRETE – Marco de 100% da API Portabilidade de crédito (v1.0.0) Informamos que, conforme compartilhado no Informa #716 (“*Divulgação do cronograma de certificação e homologação do produto Portabilidade de Crédito Pessoal Clean (CPC)*”, publicado em 28/03/2025), **em 12/08/2025 ocorrerá o marco de 100% da API Portabilidade de crédito v1.0.0** (produto CPC).  Para este marco será utilizada a versão rc.1 do motor de conformidade, cujos testes a serem reexecutados podem ser encontrados no Informa #766 (“*LEMBRETE – Disponibilização da versão rc.1 do motor de conformidade para API Portabilidade de Crédito*”, divulgado em 23/07/2025). Reforçamos que instituições que não obtiverem sucesso nesse marco serão notificadas via *tickets*do Service Desk. |
