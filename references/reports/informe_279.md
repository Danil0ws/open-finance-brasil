# [Open Finance] Informa #279

Liberação do motor funcional versão beta da API de Pagamentos v2.0.0 (fase 3)  Informamos a liberação para testes beta do motor de conformidade funcional da API de Pagamentos v2.0.0 (fase 3).      Pedimos às instituições que iniciem esses testes conforme o cronograma abaixo para contribuir com a maturidade do motor funcional. Durante o período beta, os testes serão atualizados conforme sejam encontradas oportunidades de melhorias e/ou bugs e suas alterações estarão disponíveis no *release notes* do Gitlab.     Problemas ou inconsistências identificadas devem ser notificadas através do repositório no GitLab no link abaixo. Tickets abertos através da plataforma do Service Desk continuarão sendo tratados, porém a expectativa é realizar uma transição gradual para o GitLab com intuito de reduzir a abertura de problemas duplicados e aumentar a celeridade da sua resolução.     **Cronograma de execução de testes, conforme Instrução Normativa 326:**   - **30/10/2022 - 02/12/2022:** Desenvolvimento do motor de testes (funcionais) para as versões 2.0.0 das APIs - **03/12/2022 - 13/01/2023:** Período de testes do motor e correção de *bugs*   - **20/12/2022**: Data limite para execução com sucesso em 30% dos módulos   - **05/01/2023:** Data limite para execução com sucesso em 50% dos módulos   - **13/01/2023:** Data limite para execução com sucesso em 90% dos módulos, incluindo todos os módulos críticos - **13/01/2023 - 01/02/2023**: Período de envio de pedidos certificação funcional V2.0.0   - Não há garantias de que pedidos de certificação enviados após 01/02/2023 serão processados antes do *go live* - **02/02/2023 - 15/02/2023**: Período de processamento de certificação funcional V2.0.0 - **15/02/2023:** ***Go live*** – data limite para publicação dos *endpoints* da nova versão da API no Diretório de Participantes |
