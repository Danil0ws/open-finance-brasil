# [Open Finance] Informa #825

LEMBRETE – Marco de 100% para API Vínculo de dispositivo v2.2.0 e API Webhook v1.3.0 |

 Reforçamos que, conforme compartilhado nos Informas #789 (“*Jornada sem redirecionamento (JSR) - Divulgação do cronograma de implementação da v2.2.0 (minor) da API Vínculo de dispositivo e v1.3.0 (minor) da API Webhook*”, divulgado em 25/09/2025) e #818 (“*Disponibilização da versão rc.3 do motor de conformidade para API Vínculo de dispositivo v2.2.0 e API Webhook v1.3.0*”, divulgado em 01/12/2025), **o marco de 100% para a API Vínculo de dispositivo v2.2.0 e a API Webhook v1.3.0 ocorrerá em 08/01/2026.**    Para este marco, será utilizada a versão rc.3 do motor de conformidade, cujos testes podem ser consultados na página do plano de testes destas APIs.    Reforçamos que, conforme orientação do Banco Central, os novos entrantes da Jornada Sem Redirecionamento devem implementar apenas a versão 2.2.0 da API Vínculo de Dispositivo e seguir as demais datas deste cronograma.    **A contabilização do sucesso no marco de 100%** ocorrerá da seguinte forma:  - **Novos entrantes**   - Sucesso em todos os módulos de teste dos planos:     - no-redirect-payments\_test-plan\_v2-2;     - no-redirect-payments-webhook\_test-plan\_v2-2. - **Instituições detentoras que já operam JSR no Open Finance**   - Sucesso nos seguintes módulos de teste:     - Plano: no-redirect-payments\_test-plan\_v2-2       - enrollments\_api\_missing-required-risk-signals\_test-module\_v2-2;       - enrollments\_api\_rejected-holder-mismatch\_test-module\_v2-2;       - enrollments\_api\_max-challenges\_test-module\_v2-2.     - Plano: no-redirect-automatic-payments\_test-plan\_v2\_2       - enrollments\_automatic-payments\_authorised-executed-scheduled-successfully\_v2-2;       - enrollments\_automatic-payments\_sweeping-consent-not-authorised\_v2-2;       - enrollments\_api\_automatic-payment\_enrollment-limits\_negative\_test-module\_v2-2;       - enrollments\_api\_automatic-payments\_enrollment-limits\_v2-2;       - enrollments\_api\_automatic\_payments-unmatching-fields\_test-module\_v2-2;       - enrollments\_api\_debit-account-mismatch\_test-module\_v2-2;       - enrollments\_api\_automatic-payment\_sign-options-invalid-permission\_test-module\_v2-2.     - Plano: no-redirect-payments-webhook\_test-plan\_v2-2       - enrollments\_api\_webhook\_event-type\_test-module\_v2-2;       - enrollments\_api\_webhook-revoked\_test-module\_v2-2.  Relembramos que as instituições que não atingirem sucesso no marco serão notificadas via *tickets* do Service Desk. |
