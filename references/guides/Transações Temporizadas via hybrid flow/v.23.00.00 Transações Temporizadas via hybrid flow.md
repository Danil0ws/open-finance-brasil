# v.23.00.00 Transações Temporizadas via hybrid flow

Esta página reúne os requisitos e recomendações aplicáveis à jornada de pagamento via Open Finance em que a Instituição Detentora de Conta (ID) necessita realizar uma análise mais profunda (temporização) para garantir a efetivação da solicitação via hybrid flow.

Além dos requisitos e recomendações previstos nesta página, aplicam-se a esta jornada aqueles descritos em:

-   Pix via hybrid flow;
    
-   Pix com vencimento através de QR Code dinâmico via hybrid flow;
    
-   Pix Agendado via hybrid flow;
    
-   Pix Automático via hybrid flow;
    
-   Pix Saque e Pix Troco via hybrid flow;
    
-   Transferências Inteligentes via hybrid flow;
    

-   Regulamentação e documentos do arranjo de pagamento vigentes.

# Etapa 5: Efetivação

Nesta etapa, a ITP deve:

-   Informar o usuário sobre a necessidade de análise adicional da solicitação pela ID.
    

wide760#F4F5F7

## Requisitos - ITP

**Cenário: Efetivação da solicitação de pagamento em análise**

REQ.PG-15500

-   `REQ.PG-15500` Informar claramente ao usuário que a solicitação está sujeita a um tempo adicional de análise pela ID antes da sua efetivação.
    

REQ.PG-15600

-   `REQ.PG-15600` Enquanto estiver em análise, permitir que o usuário cancele a solicitação.
