# v.23.00.00 Compartilhamento de Dados PF

O Compartilhamento de Dados via Open Finance permite que os usuários autorizem o envio de suas informações cadastrais e financeiras entre instituições participantes, de forma segura, mantendo o controle sobre quais dados são compartilhados, com quem e por quanto tempo.

Este capítulo apresenta os elementos de experiência do usuário necessários para a implementação do Compartilhamento de Dados para o segmento PF no Open Finance, com a definição das jornadas, de requisitos e de recomendações para as instituições participantes.
