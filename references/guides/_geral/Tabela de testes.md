# Tabela de testes

A tabela abaixo consolida os testes de conformidade executados diariamente pela FVP Automática. Para cada teste, são apresentados o nome do módulo, o Summary original em inglês e um breve resumo sobre a validação realizada.

Para consultar mais detalhes sobre os testes, os cenários executados e os critérios de validação, acesse a página da [Raidiam — FVP Automática](https://gitlab.com/raidiam-conformance/open-finance/certification/-/wikis/FVP/PT/Automatica?redirected_from=FVP/PT/Automatic).
