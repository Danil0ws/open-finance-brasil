# APIs do Diretório de participantes

O Diretório possui APIs abertas e restritas que facilitam o compartilhamento de informações entre os participantes do ecossistema bem como um _webhook_ para notificações de eventos. As APIs abertas permitem o acesso a informações gerais como dados de participantes e chaves públicas, e as APIs restritas são usadas para acessar dados sensíveis, com acesso concedido após a obtenção de um token de autenticação.
