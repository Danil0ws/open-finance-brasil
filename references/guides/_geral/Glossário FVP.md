# Glossário FVP

Esta seção reúne os principais termos e siglas utilizados ao longo da documentação da FVP, apresentando suas definições para facilitar a compreensão dos conceitos e da terminologia empregada.

Termo

Definição

ACSC

Status que indica a conclusão bem-sucedida de uma operação. (Pagamento Liquidado)

Ambiente de Produção

Ambiente real onde são executados testes com dados e serviços das instituições participantes.

API (Application Programming Interface)

Interface que permite a comunicação padronizada entre sistemas.

Authorisation Server ID (AS ID)

Identificador único do Servidor de Autorização da instituição.

Banco Central do Brasil (BCB)

Órgão responsável pela regulamentação e supervisão do Open Finance Brasil.

Cleanup

Processo automático que remove os recursos criados durante um teste.

Contestação

Solicitação de revisão do resultado de um teste ou de um ticket.

CPC

Identificador utilizado nos fluxos de Portabilidade de Crédito.

Creditor Account

Conta do recebedor.

Dashboard FVP Manual – Relação de Contas Abertas

Painel que informa quais instituições possuem conta aberta pelo fornecedor e a responsabilidade de execução dos testes.

DCM (Dynamic Client Management)

Processo de gerenciamento de um Client registrado, permitindo sua atualização ou exclusão.

DCR (Dynamic Client Registration)

Processo de registro dinâmico de um Client no Servidor de Autorização antes da execução dos testes.

Debtor Account

Conta do pagador.

Deleção de Client

Exclusão de um Client registrado no Servidor de Autorização.

Execução assíncrona

Execução realizada automaticamente em momento posterior, sem intervenção do usuário.

Fornecedor

Empresa responsável pela execução dos Testes Restritos ou pelo fornecimento de serviços relacionados à FVP.

Instrução Normativa

Ato normativo que estabelece regras e procedimentos.

ISPB

Código que identifica instituições participantes do Sistema de Pagamentos Brasileiro (SPB).

ITP (Iniciadora de Transação de Pagamento)

Instituição autorizada a iniciar pagamentos em nome do cliente, mediante consentimento.

JSON (JavaScript Object Notation)

Formato utilizado para estruturar e transmitir dados entre sistemas.

Logs

Registros das ações, eventos, respostas e erros gerados durante a execução dos testes.

Múltipla Alçada

Fluxo que exige a aprovação de dois ou mais usuários para concluir uma transação.

Open Finance Brasil

Ecossistema regulado que padroniza o compartilhamento de dados e serviços financeiros entre instituições participantes.

OrgId

Identificador único de uma organização no Diretório dos Participantes.

PF (Pessoa Física)

Cliente identificado por CPF.

PFVPC

Perfil de acesso que permite utilizar a FVP Manual em nome de uma organização.

PJ (Pessoa Jurídica)

Cliente identificado por CNPJ.

Plano de Teste (Test Plan)

Conjunto de configurações que define os testes e parâmetros de uma execução.

QR Code

Código utilizado para direcionar o usuário ao fluxo de autenticação no dispositivo móvel.

QuickSight

Plataforma utilizada para disponibilização dos dashboards da FVP.

Raidiam

Fornecedor responsável pela infraestrutura do Diretório dos Participantes e pelo suporte operacional da FVP.

Redirecionamento (Redirect)

Etapa em que o usuário é direcionado da FVP para a aplicação da instituição para autenticar-se e autorizar uma operação.

Refresh Token

Credencial utilizada para renovar um token de acesso sem nova autenticação do usuário.

Retry

Nova tentativa automática de processamento de uma operação após uma falha.

RJCT

Status que indica que uma operação foi rejeitada.

Salvaguardas Automáticas

Mecanismos que garantem o agendamento de etapas futuras apenas quando as anteriores forem concluídas com sucesso.

Service Desk

Canal oficial para registro e tratamento de dúvidas, incidentes e solicitações.

Servidor de Autorização (Authorization Server)

Componente responsável pela autenticação de usuários e gerenciamento de consentimentos.

Temporização de Negócio

Agendamento das execuções conforme os prazos definidos pelas regras de negócio (ex.: D+2 e D+3).

Ticket

Registro utilizado para acompanhar solicitações, incidentes ou falhas.

Timeout

Expiração da sessão por inatividade.

TOTP (Time-based One-Time Password)

Método de autenticação que utiliza senhas temporárias de uso único.

Waiver (Dispensa)

Autorização concedida pelo Banco Central do Brasil (BCB) que isenta temporariamente a instituição da execução ou aprovação de determinados testes da FVP.
