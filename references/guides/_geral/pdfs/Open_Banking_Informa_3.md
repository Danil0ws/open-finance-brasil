Informe #3 Extraordinário — 09 de junho de 2021


Foram necessárias três correções nas APIs Fase 2:


1. Correção da grafia no retorno da API Accounts (endpoint GET /accounts). O parâmetro
“accountID” foi corrigido para “accountId”, incluindo o pattern correspondente.


2. Correção do retorno da API Credit-cards-accounts (endpoint GET /accounts/
{creditCardAccountId}). O campo paymentMethod foi alterado para uma lista (array).


3. Correção do consentId. O pattern e o tamanho do campo consentId foram revisados para
contemplar a obrigatoriedade do uso do namespace.


Após publicação até o final do dia 09/06, as APIs Fase 2 estarão na versão v1.0.0-rc6.6 conforme
link abaixo.
