Informe #59 — 23 de setembro de 2021


Foi realizada uma atualização na API Fase 3 para versão v1.0.1-rc1.1. Os ajustes contemplam:


- Melhorias na máquina de estados do consentimento;


- Inclusão do campo ibgeTownCode no payload do request e do response;


- Remoção da menção de uso futuro no campo de QRCode, concluindo especificações para
Pix QR Code sem agendamento.


Estes ajustes foram disponibilizados nesta quinta-feira (23/09).


Para mais detalhes, verifique o changelog na Área do Desenvolvedor.


**[ACESSE A API FASE 3](https://openbanking-brasil.github.io/areadesenvolvedor/#fase-3-apis-do-open-banking-brasil)**


Foi realizada a seguinte atualização na seção de problemas conhecidos Fase 2:


- Inclusão de novos problemas conhecidos no documento de Fase 2, contemplando instruções
para a certificação da API Credit Card;


Para mais detalhes, verifique os documentos presentes na seção de problemas conhecidos na
Área do Desenvolvedor.
