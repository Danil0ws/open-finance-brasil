Informe #25 — 23 de julho de 2021


Os seguintes pontos foram ajustados na API Fase 3:


- Remoção do scope ‘consent:consentId’ - alteração nos endpoints de payments/v1/consents
(Post e GET)


- Alteração do description, acrescentando a possibilidade de acesso no endpoint de consulta
de pagamento via fluxo clientCredential e regra de validação do clientId


- Retirada do scope ‘consentID’ – alteração no endpoint de /pix/payments/{paymentId} (GET)


Estes ajustes foram disponibilizados nessa sexta-feira (23/07), alterando a versão atual do Portal
para v1.0.0-rc8.0 e a API Fase 3 para v1.0.0-rc5.2.


Na próxima semana, serão revistos os perfis de segurança de acesso aos endpoints do Swagger
da API Fase 3.


Para maiores detalhes, verifique o changelog na Área do Desenvolvedor.
