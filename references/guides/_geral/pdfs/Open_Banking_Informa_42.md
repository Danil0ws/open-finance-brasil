Informe #42 — 18 de agosto de 2021


Os seguintes ajustes foram realizados na API da Fase 3, contemplando assinatura de mensagens
para o status _code_ 422:


- Alteração do _content type_ do objeto de retorno de _application/json_ para _application/jwt_ em _Un-_
_processableEntityConsents_ ;


- Alteração do _content type_ do objeto de retorno de _application/json_ para _application/jwt_ em _Un-_
_processableEntityPixPayments_ .


Estes ajustes foram disponibilizados nesta quarta-feira (18/08). Com esta atualização, a API Fase 3
passa para sua primeira versão oficial, v1.0.0.


Para mais detalhes, verifique o _changelog_ na Área do Desenvolvedor.
