Informe #51 — 06 de setembro de 2021


Foi corrigido o seguinte ajuste descritos no Informe #50, de sexta-feira 03/09, do ENUM de subtipos de garantia das APIs de Operações de Crédito, que não havia sido atualizado no Portal. As
APIs estão atualizadas.


Informações mais detalhadas se encontram no _changelog_ na Área do Desenvolvedor.


**[ACESSE AS APIs FASE 2](https://openbanking-brasil.github.io/areadesenvolvedor/#fase-2-apis-do-open-banking-brasil)**


Já está disponível na Área do Desenvolvedor, a versão v1.0.1-rc1.0 da API Fase 3. A API voltou
para formato release candidate devido à alteração do calendário da fase 3.


Os ajustes da nova versão contemplam os seguintes pontos:


- Adição da funcionalidade de iniciação de pagamento Pix direto pelo recebedor;


- Inclusão de informações do destino no fluxo de consentimento


Ainda essa semana, a API Fase 3 deve ter novo ajuste para funcionalidade de Pix QR Code, com a
inclusão do campo para código de município.


Informações mais detalhadas se encontram no changelog na Área do Desenvolvedor.


Essas alterações colocam o Portal na versão v1.0.0-rc8.8
