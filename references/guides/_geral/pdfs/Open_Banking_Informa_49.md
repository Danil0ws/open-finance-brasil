Informe #49 — 01 de setembro de 2021


As seguintes atualizações foram realizadas na planilha de problemas conhecidos Fase 2, localizada na Área do Desenvolvedor:


- ID BCLOG-F02-170, campo ResponseAccountTransactions/data: Remoção desta orientação
visto que a recente atualização das especificações contempla lista vazia para o campo


- ID BCLOG-F02-172, campo automaticallyInvestedAmountCurrency: Para o caso de a instituição não ter o valor para o campo amount, ignorar o campo currency, preenchendo o campo
sempre com valor BRL


- IDs BCLOG-F02-173 e BCLOG-F02-174, campo disbursementDate: Em caso de uma instituição não atender com data única, como o campo é opcional, não compartilhar nenhuma data


- IDs BCLOG-F02-175 e BCLOG-F02-176, campo disbursementDate: No caso de uma liberação de recursos feita em D0 mas com referência retroativa feita em D -1, a data correta contabilmente é D -1


Para maiores detalhes destas atualizações, consultar a planilha de problemas conhecidos Fase 2
no Portal Open Banking.
